1. **In a normal browser.** Run your dev server as usual and open it: `window.dsx` is `undefined`, so you see the web branch.
2. **In the app.** Your Despia app is a small project whose web view opens your site (`Components/App.dsx`, `<DSXWebView origin="..." />`). Point `origin` at the address of your dev server, install a development build on a simulator or emulator with `npx despia run`, then keep it in sync with `npx despia dev --target ios` (or `android`): every save reaches the app, and the Despia V4 branch runs.
