This sample gives your web app the full Bluetooth Low Energy stack on iOS (CoreBluetooth) and Android (`android.bluetooth`), in both roles:

- **Central:** scan, connect, discover services, read, write, subscribe to notifications, read RSSI and set the MTU.
- **Peripheral:** publish your own GATT services, answer reads from a value store, receive writes, send notifications, and advertise.

Bytes cross the bridge as lower-case `hex` (or `b64` in parameters). No native object ever reaches the page.

<Warning>
  **Experimental. V3 only.** This is a template, not a Despia feature. It is never migrated to V4. You own and maintain this code once it is in your app. Despia does not support customised code. Read [V3 Extensions](/experiments/v3-extensions) first.
</Warning>

<Note>
  **Tested on:** the peripheral role on an iPhone 15, against a Mac acting as the central. The central role has not been tested yet, and Android has not been run on an emulator or a device. Bluetooth does not run in the iOS simulator.
</Note>

## Files

Copy every file to the path in its title. Paths are under `public/despia/ble/` in your web app, except `extensions.json`, which goes in `public/despia/`.

Before you build, change `client_id`, `ios_bundle_id` and `android_package` in `public/despia/extensions.json` to your own. `public/` is the folder your site serves from its root (in SvelteKit, write `static/`). The paths must stay as written, because the manifest names them. Despia reviews and approves these exact files before a build includes them.

In Despia, turn on the Bluetooth purpose string (`NSBluetoothAlwaysUsageDescription`) and write the sentence your users see in the permission prompt (iOS), and turn on nearby devices, which grants `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT` and `BLUETOOTH_ADVERTISE` on Android 12 and later (Android). The Bluetooth background modes come from the manifest. The two AndroidX libraries must be the versions your app's base build already resolves. The build refuses others.

```swift ios/app/BleCentralRadio.swift
import CoreBluetooth
import Foundation

/// The CoreBluetooth central behind `BleCore`: one CBCentralManager with state restoration, the
/// scanner and the GATT client. It makes no decision of its own; it translates CoreBluetooth
/// callbacks into core inputs and does what the core asks through `BleExtension`'s port.
///
/// The manager is created only when a route needs Bluetooth (which can show the permission prompt)
/// or when iOS relaunched the app to restore it (`restoreBluetoothCentrals`, before launch returns,
/// as CoreBluetooth requires). Its restore identifier is the one the build declared
/// (`claims.bluetooth_centrals: ["main"]`, full form `nativeext.ble.main`).
///
/// Tokens. CoreBluetooth keeps one CBPeripheral per device, so a callback carries no attempt; the
/// radio holds one session per device id with the core's `gen` for the attempt, and every callback
/// reaches the core with that gen. The core allows one live attempt per device (it waits for the
/// confirmed close before the next connect), so a session is never shared by two attempts.
///
/// Executor: the manager is created with `queue: nil`, which CoreBluetooth documents as the main
/// queue for every central-role and peripheral event, so both delegate conformances are isolated to
/// the main actor (`@MainActor CBCentralManagerDelegate`, `@MainActor CBPeripheralDelegate`,
/// SE-0470) and each witness checks at run time that it was called on the main queue.
@MainActor
final class BleCentralRadio: NSObject, @MainActor CBCentralManagerDelegate, @MainActor CBPeripheralDelegate {
    static let cccd = CBUUID(string: "2902")

    /// One connection attempt of one device.
    final class Session {
        let gen: Int
        let peripheral: CBPeripheral
        var connected = false
        var pendingOp = 0
        var pendingKind: String?
        var pendingKey: String?
        var pendingDescriptor: CBDescriptor?
        var pendingMode: String?
        /// A write without response waiting for `peripheralIsReady`.
        var pendingWrite: (CBCharacteristic, Data)?
        /// Discovery steps still running (services, included services, characteristics, descriptors).
        var discovering = 0
        /// A restored peripheral that iOS did not keep connecting: connect it once the radio is on.
        var reconnectWhenOn = false

        init(_ gen: Int, _ peripheral: CBPeripheral) {
            self.gen = gen
            self.peripheral = peripheral
        }
    }

    private let core: BleCore
    private let restoreIdentifier: String
    private(set) var manager: CBCentralManager?
    private var sessions: [String: Session] = [:]
    /// Peripherals seen by a scan or restored, by id, so connect can find them.
    private var known: [String: CBPeripheral] = [:]
    private var scanning = 0
    /// A scan iOS restored, to be handed to the core once the radio is on.
    private var restoredScan: [String]?
    private var readyWaiters: [Waiter] = []

    final class Waiter {
        var continuation: CheckedContinuation<Void, Never>?

        func resume() {
            continuation?.resume()
            continuation = nil
        }
    }

    init(core: BleCore, restoreIdentifier: String) {
        self.core = core
        self.restoreIdentifier = restoreIdentifier
        super.init()
    }

    var hasManager: Bool { manager != nil }

    /// on, off, unauthorized, unsupported, resetting or unknown; unknown before the manager exists.
    var stateName: String {
        guard let m = manager else {
            return CBManager.authorization == .denied || CBManager.authorization == .restricted ? "unauthorized" : "unknown"
        }
        return BleCentralRadio.name(m.state)
    }

    static func name(_ s: CBManagerState) -> String {
        switch s {
        case .poweredOn: return "on"
        case .poweredOff: return "off"
        case .unauthorized: return "unauthorized"
        case .unsupported: return "unsupported"
        case .resetting: return "resetting"
        case .unknown: return "unknown"
        @unknown default: return "unknown"
        }
    }

    static func authorizationName(_ a: CBManagerAuthorization) -> String {
        switch a {
        case .allowedAlways: return "granted"
        case .denied: return "denied"
        case .restricted: return "restricted"
        case .notDetermined: return "not_determined"
        @unknown default: return "not_determined"
        }
    }

    @discardableResult
    func makeManager() -> CBCentralManager {
        if let m = manager { return m }
        let m = CBCentralManager(delegate: self, queue: nil, options: [
            CBCentralManagerOptionRestoreIdentifierKey: restoreIdentifier,
        ])
        manager = m
        return m
    }

    /// Creates the manager when needed and waits until its state is known (the first update can
    /// follow the permission prompt), or until `deadline`.
    func ready(until deadline: DispatchTime) async {
        let m = makeManager()
        if m.state != .unknown { return }
        let w = Waiter()
        readyWaiters.append(w)
        let ns = deadline.uptimeNanoseconds > DispatchTime.now().uptimeNanoseconds
            ? deadline.uptimeNanoseconds - DispatchTime.now().uptimeNanoseconds : 0
        Task { @MainActor [weak w] in
            try? await Task.sleep(nanoseconds: ns)
            w?.resume()
        }
        await withCheckedContinuation { (c: CheckedContinuation<Void, Never>) in
            if m.state != .unknown {
                c.resume()
            } else {
                w.continuation = c
            }
        }
        readyWaiters.removeAll { $0 === w }
    }

    // MARK: scan

    func scanStart(_ scan: Int, _ services: [String], _ duplicates: Bool, _ mode: String) -> String? {
        // `mode` is Android's ScanSettings scan mode; CoreBluetooth has no scan mode to set.
        guard let m = manager, m.state == .poweredOn else { return "unavailable Bluetooth is \(stateName)" }
        let ids = services.map { CBUUID(string: $0) }
        m.scanForPeripherals(withServices: ids.isEmpty ? nil : ids,
                             options: [CBCentralManagerScanOptionAllowDuplicatesKey: duplicates])
        scanning = scan
        return nil
    }

    func scanStop(_ scan: Int) {
        guard scanning == scan else { return }
        scanning = 0
        if let m = manager, m.state == .poweredOn { m.stopScan() }
    }

    static func uuid(_ u: CBUUID) -> String {
        BleCore.uuid(u.uuidString) ?? u.uuidString.lowercased()
    }

    /// Every advertisement field CoreBluetooth reports, in the core's record form.
    static func advertisement(_ p: CBPeripheral, _ data: [String: Any], _ rssi: NSNumber) -> BleObj {
        let adv = BleObj()
        if let name = (data[CBAdvertisementDataLocalNameKey] as? String) ?? p.name { adv["name"] = name }
        // 127 is CoreBluetooth's "RSSI not available".
        if rssi.intValue != 127 { adv["rssi"] = rssi.intValue }
        if let c = data[CBAdvertisementDataIsConnectable] as? NSNumber { adv["connectable"] = c.boolValue }
        if let tx = data[CBAdvertisementDataTxPowerLevelKey] as? NSNumber { adv["txPower"] = tx.intValue }
        var services: [Any] = []
        for key in [CBAdvertisementDataServiceUUIDsKey, CBAdvertisementDataOverflowServiceUUIDsKey] {
            for u in (data[key] as? [CBUUID]) ?? [] { services.append(uuid(u)) }
        }
        var manufacturer: [Any] = []
        if let d = data[CBAdvertisementDataManufacturerDataKey] as? Data, d.count >= 2 {
            let b = [UInt8](d)
            manufacturer.append(BleCore.obj(("id", Int(b[0]) | Int(b[1]) << 8), ("hex", BleCore.hex(Array(b[2...])))))
        }
        var serviceData: [Any] = []
        if let sd = data[CBAdvertisementDataServiceDataKey] as? [CBUUID: Data] {
            for (u, d) in sd.sorted(by: { uuid($0.key) < uuid($1.key) }) {
                serviceData.append(BleCore.obj(("uuid", uuid(u)), ("hex", BleCore.hex([UInt8](d)))))
            }
        }
        adv["services"] = services
        adv["manufacturer"] = manufacturer
        adv["serviceData"] = serviceData
        return adv
    }

    // MARK: links

    func connect(_ id: String, _ gen: Int, _ auto: Bool, _ background: Bool) -> String? {
        guard let m = manager, m.state == .poweredOn else { return "unavailable Bluetooth is \(stateName)" }
        guard let u = UUID(uuidString: id) else { return "unknown_device \(id)" }
        guard let p = known[id] ?? m.retrievePeripherals(withIdentifiers: [u]).first else {
            return "unknown_device this device was not seen by a scan on this phone"
        }
        known[id] = p
        p.delegate = self
        sessions[id] = Session(gen, p)
        // iOS keeps a pending connection without a time limit; the core's connect timer bounds a
        // requested connect, and an automatic reconnect waits for the device.
        m.connect(p, options: nil)
        return nil
    }

    private func session(_ p: CBPeripheral) -> Session? {
        let s = sessions[p.identifier.uuidString]
        return s?.peripheral === p ? s : nil
    }

    func close(_ id: String, _ gen: Int) -> Bool {
        guard let s = sessions[id], s.gen == gen else { return true }
        guard let m = manager, m.state == .poweredOn else {
            sessions[id] = nil
            return true
        }
        // Connected or pending, the close is confirmed by didDisconnectPeripheral; if none comes,
        // the core's close timer releases the session.
        m.cancelPeripheralConnection(s.peripheral)
        return false
    }

    func release(_ id: String, _ gen: Int) {
        guard let s = sessions[id], s.gen == gen else { return }
        sessions[id] = nil
        if let m = manager, m.state == .poweredOn, s.peripheral.state != .disconnected {
            m.cancelPeripheralConnection(s.peripheral)
        }
    }

    static func properties(_ p: CBCharacteristicProperties) -> [Any] {
        var out: [Any] = []
        if p.contains(.broadcast) { out.append("broadcast") }
        if p.contains(.read) { out.append("read") }
        if p.contains(.writeWithoutResponse) { out.append("writeWithoutResponse") }
        if p.contains(.write) { out.append("write") }
        if p.contains(.notify) || p.contains(.notifyEncryptionRequired) { out.append("notify") }
        if p.contains(.indicate) || p.contains(.indicateEncryptionRequired) { out.append("indicate") }
        if p.contains(.authenticatedSignedWrites) { out.append("authenticatedSignedWrites") }
        if p.contains(.extendedProperties) { out.append("extendedProperties") }
        return out
    }

    /// The key of a characteristic: service and characteristic UUIDs with their instance numbers.
    static func key(_ p: CBPeripheral, _ c: CBCharacteristic) -> String? {
        guard let svc = c.service else { return nil }
        var sn = 0
        for x in p.services ?? [] {
            if x === svc { break }
            if x.uuid == svc.uuid { sn += 1 }
        }
        var cn = 0
        for x in svc.characteristics ?? [] {
            if x === c { break }
            if x.uuid == c.uuid { cn += 1 }
        }
        return BleCore.key(uuid(svc.uuid), sn, uuid(c.uuid), cn)
    }

    static func resolve(_ p: CBPeripheral, _ key: String) -> CBCharacteristic? {
        let parts = key.split(whereSeparator: { $0 == "#" || $0 == "/" }).map(String.init)
        guard parts.count == 4, var sn = Int(parts[1]), var cn = Int(parts[3]) else { return nil }
        let su = CBUUID(string: parts[0]), cu = CBUUID(string: parts[2])
        for svc in p.services ?? [] where svc.uuid == su {
            if sn > 0 {
                sn -= 1
                continue
            }
            for c in svc.characteristics ?? [] where c.uuid == cu {
                if cn == 0 { return c }
                cn -= 1
            }
            return nil
        }
        return nil
    }

    func op(_ id: String, _ gen: Int, _ op: Int, _ kind: String, _ key: String?, _ descriptor: String?,
            _ data: [UInt8]?, _ arg: Int) -> String? {
        guard let s = sessions[id], s.gen == gen, s.connected else { return "not_connected the link is not connected" }
        let p = s.peripheral
        switch kind {
        case "discover":
            begin(s, op, kind)
            p.discoverServices(nil)
            return nil
        case "rssi":
            begin(s, op, kind)
            p.readRSSI()
            return nil
        default:
            break
        }
        guard let key = key, let c = BleCentralRadio.resolve(p, key) else {
            return "not_found no such characteristic (run discover first)"
        }
        var d: CBDescriptor?
        if let du = descriptor {
            d = (c.descriptors ?? []).first { $0.uuid == CBUUID(string: du) }
            if d == nil { return "not_found no such descriptor" }
        }
        switch kind {
        case "read":
            if let d = d {
                begin(s, op, kind, key: key, descriptor: d)
                p.readValue(for: d)
                return nil
            }
            guard c.properties.contains(.read) else { return "not_permitted the characteristic is not readable" }
            begin(s, op, kind, key: key)
            p.readValue(for: c)
            return nil
        case "write":
            let value = Data(data ?? [])
            if let d = d {
                // CoreBluetooth refuses writes to the CCCD through writeValue(_:for:) (subscribe sets it).
                if d.uuid == BleCentralRadio.cccd { return "not_permitted the CCCD is written by subscribe" }
                begin(s, op, kind, key: key, descriptor: d)
                p.writeValue(value, for: d)
                return nil
            }
            guard c.properties.contains(.write) else {
                return "not_permitted the characteristic does not accept a write with response"
            }
            begin(s, op, kind, key: key)
            p.writeValue(value, for: c, type: .withResponse)
            return nil
        case "wnr":
            guard c.properties.contains(.writeWithoutResponse) else {
                return "not_permitted the characteristic does not accept a write without response"
            }
            begin(s, op, kind, key: key)
            s.pendingWrite = (c, Data(data ?? []))
            sendPendingWrite(s)
            return nil
        case "sub", "unsub":
            let on = kind == "sub"
            let props = c.properties
            let notify = props.contains(.notify) || props.contains(.notifyEncryptionRequired)
            let indicate = props.contains(.indicate) || props.contains(.indicateEncryptionRequired)
            guard notify || indicate else { return "not_permitted the characteristic neither notifies nor indicates" }
            begin(s, op, kind, key: key, mode: on ? (notify ? "notify" : "indicate") : nil)
            p.setNotifyValue(on, for: c)
            return nil
        default:
            return "bad_value unknown operation \(kind)"
        }
    }

    private func begin(_ s: Session, _ op: Int, _ kind: String, key: String? = nil, descriptor: CBDescriptor? = nil,
                       mode: String? = nil) {
        s.pendingOp = op
        s.pendingKind = kind
        s.pendingKey = key
        s.pendingDescriptor = descriptor
        s.pendingMode = mode
        s.discovering = 0
    }

    /// A write without response goes out when the peripheral can take it; it is settled after the
    /// handoff, on a later main-queue turn (a port call never calls back into the core).
    private func sendPendingWrite(_ s: Session) {
        guard let w = s.pendingWrite, s.peripheral.canSendWriteWithoutResponse else { return }
        s.pendingWrite = nil
        s.peripheral.writeValue(w.1, for: w.0, type: .withoutResponse)
        let op = s.pendingOp, gen = s.gen
        Task { @MainActor [weak self, weak s] in
            guard let self = self, let s = s, s.pendingOp == op, s.pendingKind == "wnr" else { return }
            self.complete(s, gen, nil, nil, nil)
        }
    }

    private func complete(_ s: Session, _ gen: Int, _ code: String?, _ message: String?, _ data: BleObj?) {
        let op = s.pendingOp
        s.pendingKind = nil
        s.pendingKey = nil
        s.pendingDescriptor = nil
        s.pendingMode = nil
        s.pendingWrite = nil
        core.opDone(s.peripheral.identifier.uuidString, gen, op, code, message, data)
    }

    private func done(_ s: Session, _ error: Error?, _ data: BleObj?) {
        if let e = error {
            let att = (e as? CBATTError)?.code
            let code = att == .readNotPermitted || att == .writeNotPermitted ? "not_permitted" : "gatt_error"
            complete(s, s.gen, code, e.localizedDescription, nil)
            return
        }
        complete(s, s.gen, nil, nil, data)
    }

    private func discovered(_ s: Session) {
        var out: [Any] = []
        var sn: [String: Int] = [:]
        for svc in s.peripheral.services ?? [] {
            let su = BleCentralRadio.uuid(svc.uuid)
            let n = sn[su, default: 0]
            sn[su] = n + 1
            var chars: [Any] = []
            var cn: [String: Int] = [:]
            for c in svc.characteristics ?? [] {
                let cu = BleCentralRadio.uuid(c.uuid)
                let m = cn[cu, default: 0]
                cn[cu] = m + 1
                let descs: [Any] = (c.descriptors ?? []).map { BleCentralRadio.uuid($0.uuid) }
                chars.append(BleCore.obj(("uuid", cu), ("n", m), ("properties", BleCentralRadio.properties(c.properties)),
                                         ("descriptors", descs)))
            }
            let included: [Any] = (svc.includedServices ?? []).map { BleCentralRadio.uuid($0.uuid) }
            out.append(BleCore.obj(("uuid", su), ("n", n), ("primary", svc.isPrimary), ("included", included),
                                   ("characteristics", chars)))
        }
        complete(s, s.gen, nil, nil, BleCore.obj(("services", out)))
    }

    private func discoveryStep(_ s: Session, _ error: Error?) {
        guard s.pendingKind == "discover" else { return }
        if let e = error {
            complete(s, s.gen, "gatt_error", "service discovery failed: \(e.localizedDescription)", nil)
            return
        }
        s.discovering -= 1
        if s.discovering <= 0 { discovered(s) }
    }

    /// A descriptor value in bytes: CoreBluetooth gives Data, NSNumber (CCCD and the extended
    /// properties, 16-bit) or String (user description).
    static func descriptorBytes(_ v: Any?) -> [UInt8] {
        if let d = v as? Data { return [UInt8](d) }
        if let n = v as? NSNumber {
            let u = n.uint16Value
            return [UInt8(u & 0xff), UInt8(u >> 8)]
        }
        if let s = v as? String { return Array(s.utf8) }
        return []
    }

    func centralManager(_ central: CBCentralManager, willRestoreState dict: [String: Any]) {

            s.reconnectWhenOn = p.state == .disconnected

        if !scan.isEmpty { restoredScan = scan }
        core.restoredEvent(BleCore.obj(("peripherals", ids), ("scanning", !scan.isEmpty)))

    func peripheral(_ peripheral: CBPeripheral, didUpdateValueFor characteristic: CBCharacteristic, error: Error?) {
        dispatchPrecondition(condition: .onQueue(.main))
        guard let s = session(peripheral), let k = BleCentralRadio.key(peripheral, characteristic) else { return }
        if let e = error {
            if s.pendingKind == "read", s.pendingDescriptor == nil, s.pendingKey == k { done(s, e, nil) }

        done(s, error, nil)
    }

        dispatchPrecondition(condition: .onQueue(.main))
        guard let s = session(peripheral), s.pendingKind == "sub" || s.pendingKind == "unsub",
```

```swift ios/app/BleCore.swift
import Foundation

/// Every decision of the BLE extension, as one state machine on the main thread. Foundation only:
/// no CoreBluetooth, so the same test table runs against this type
/// with swiftc and against its Java twin BleCore.java. The radio and extension files only translate
/// platform callbacks into the inputs below and execute what the `BlePort` is asked to do.
///
/// Tokens. `gen` names one connection attempt, `scan` one scan, `op` one GATT operation step; all
/// come from counters that never repeat in a process. Every radio callback and every timer carries
/// its token back; one whose token is not current changes nothing, replies to nothing and is counted
/// as a stale drop (rules 1, 2 and 7 of the design).
///
/// Port calls never call back into the core: what the platform confirms at once comes back as the
/// return value (an error text, or `true` for a close that needs no callback).
protocol BlePort: AnyObject {
    /// Start a scan. nil when the platform accepted it, else "code message".
    func scanStart(_ scan: Int, _ services: [String], _ duplicates: Bool, _ mode: String) -> String?
    func scanStop(_ scan: Int)
    /// Start connection attempt `gen`. `background`: an automatic reconnect.
    func connect(_ id: String, _ gen: Int, _ auto: Bool, _ background: Bool) -> String?
    /// Begin closing `gen`. True when the platform confirmed the close now (no callback follows).
    func close(_ id: String, _ gen: Int) -> Bool
    /// The close of `gen` was not confirmed in time: release the platform object without waiting.
    func release(_ id: String, _ gen: Int)
    /// Hand one GATT step to the platform (kinds as BleCore.java). nil when accepted, else "code message".
    func op(_ id: String, _ gen: Int, _ op: Int, _ kind: String, _ key: String?, _ descriptor: String?,
            _ data: [UInt8]?, _ arg: Int) -> String?
    func timer(_ kind: String, _ token: Int, _ ms: Int)
    func reply(_ call: Int, _ ok: Bool, _ code: String?, _ message: String?, _ data: BleObj?)
    func emit(_ event: String, _ data: BleObj)
    func isActive(_ call: Int) -> Bool
    func now() -> Int
    /// A callback or timer for a token that is no longer current was dropped.
    func stale(_ what: String)

    // Peripheral role (kinds and answers as BleCore.java's Port). Server and advertiser callbacks
    // come back with the epoch they were made in.
    func serviceAdd(_ epoch: Int, _ uuid: String, _ primary: Bool, _ chars: [BleObj]) -> String?
    func serviceRemove(_ uuid: String)
    func advertiseStart(_ epoch: Int, _ adv: Int, _ params: BleObj) -> String?
    func advertiseStop(_ adv: Int)
    /// nil: handed over now; "pending": notifySent follows; "full": retry after notifyReady; else "code message".
    func notify(_ epoch: Int, _ packet: Int, _ central: String, _ key: String, _ data: [UInt8], _ indicate: Bool) -> String?
    func centralDrop(_ central: String)

/// A JSON object that keeps insertion order (the canonical vector form, shared with the Java twin).
final class BleObj {
    private(set) var keys: [String] = []
    private var values: [String: Any] = [:]

    init(_ pairs: [(String, Any)] = []) {
        for (k, v) in pairs { self[k] = v }
    }

    subscript(key: String) -> Any? {
        get { values[key] }
        set {
            if let v = newValue {
                if values[key] == nil { keys.append(key) }
                values[key] = v
            } else if values.removeValue(forKey: key) != nil {
                keys.removeAll { $0 == key }
            }
        }
    }

    func putAll(_ other: BleObj) {
        for k in other.keys { self[k] = other[k] }
    }

    func copy() -> BleObj {
        let o = BleObj()
        o.putAll(self)
        return o
    }

    /// Plain Foundation form for NativeExtResult and NativeExtContext.emit.
    var plain: [String: Any] {
        var out: [String: Any] = [:]
        for k in keys { out[k] = BleObj.plainValue(values[k]!) }
        return out
    }

    static func plainValue(_ v: Any) -> Any {
        if let o = v as? BleObj { return o.plain }
        if let l = v as? [Any] { return l.map { plainValue($0) } }
        return v
    }

        case 48...57: return Int(c) - 48
        case 97...102: return Int(c) - 87
        case 65...70: return Int(c) - 55
        default: return -1
        }
    }

    /// Hex digits only, even length; nil otherwise.
    static func fromHex(_ s: String?) -> [UInt8]? {
        guard let s = s else { return nil }
        let u = Array(s.utf8)
        guard u.count % 2 == 0 else { return nil }
        var out = [UInt8]()
        out.reserveCapacity(u.count / 2)
        var i = 0
        while i < u.count {
            let hi = nibble(u[i]), lo = nibble(u[i + 1])
            if hi < 0 || lo < 0 { return nil }
            out.append(UInt8((hi << 4) | lo))
            i += 2
        }
        return out
    }

    private static func sextet(_ c: UInt8) -> Int {
        switch c {
        case 65...90: return Int(c) - 65
        case 97...122: return Int(c) - 71
        case 48...57: return Int(c) + 4
        case 43, 45: return 62
        case 47, 95: return 63
        default: return -1
        }
    }

    /// Standard or URL-safe base64, padding optional; nil when malformed.
    static func fromB64(_ s: String?) -> [UInt8]? {
        guard let s = s else { return nil }
        let u = Array(s.utf8)
        var end = u.count
        var pad = 0
        while end > 0 && u[end - 1] == 61 && pad < 2 {
            end -= 1
            pad += 1
        }
        if pad > 0 && u.count % 4 != 0 { return nil }
        if end % 4 == 1 { return nil }
        var out = [UInt8]()
        var acc = 0, bits = 0
        for i in 0..<end {
            let v = sextet(u[i])
            if v < 0 { return nil }
            acc = ((acc << 6) | v) & 0xffffff
            bits += 6
            if bits >= 8 {
                bits -= 8
                out.append(UInt8((acc >> bits) & 0xff))
            }
        }
        // Leftover bits must be zero (canonical encoding).
        if acc & ((1 << bits) - 1) != 0 { return nil }
        return out
    }

    static let base = "-0000-1000-8000-00805f9b34fb"

    private static func allHex(_ s: String) -> Bool {
        s.utf8.allSatisfy { nibble($0) >= 0 }
    }

    /// 16-bit, 32-bit or dashed 128-bit UUID, any case; lower-case 128-bit, or nil.
    static func uuid(_ s: String?) -> String? {
        guard let s = s else { return nil }
        let l = s.lowercased()
        if l.utf8.count == 4 && allHex(l) { return "0000" + l + base }
        if l.utf8.count == 8 && allHex(l) { return l + base }
        let u = Array(l.utf8)
        guard u.count == 36 else { return nil }
        for i in 0..<36 {
            let dash = i == 8 || i == 13 || i == 18 || i == 23
            if dash ? u[i] != 45 : nibble(u[i]) < 0 { return nil }
        }
        return l
    }

    /// Comma-separated UUIDs, at most 20; an empty or missing list is empty; nil when malformed.
    static func uuidList(_ s: String?) -> [String]? {
        var out: [String] = []
        guard let s = s, !s.isEmpty else { return out }
        for part in s.split(separator: ",", omittingEmptySubsequences: false) {
            guard let u = uuid(part.trimmingCharacters(in: .whitespaces)) else { return nil }
            if !out.contains(u) { out.append(u) }
        }
        return out.count > 20 ? nil : out
    }

    /// iOS: a peripheral identifier (UUID). Android: a MAC in the form checkBluetoothAddress accepts.
    static func isId(_ id: String?, _ platform: String) -> Bool {
        guard let id = id else { return false }
        if platform == "android" {
            let u = Array(id.utf8)
            guard u.count == 17 else { return false }
            for i in 0..<17 {
                let c = u[i]
                if i % 3 == 2 ? c != 58 : !((48...57).contains(c) || (65...70).contains(c)) { return false }
            }
            return true
        }
        return id.utf8.count == 36 && uuid(id) != nil
    }

    /// Exactly one of hex and b64 decoded; nil when none, both, or malformed.
    static func bytes(_ hex: String?, _ b64: String?) -> [UInt8]? {
        if (hex == nil) == (b64 == nil) { return nil }
        return hex != nil ? fromHex(hex) : fromB64(b64)
    }

    /// The characteristic key used in replies, records and subscriptions.
    static func key(_ service: String, _ sn: Int, _ chr: String, _ cn: Int) -> String {
        "\(service)#\(sn)/\(chr)#\(cn)"
    }

    /// Canonical JSON with keys in insertion order: the vector form, shared with the Java twin.
    static func json(_ v: Any?) -> String {
        var b = ""
        json(&b, v)
        return b
    }

    private static func json(_ b: inout String, _ v: Any?) {
        guard let v = v, !(v is NSNull) else {
            b += "null"
            return
        }
        if let x = v as? Bool {
            b += x ? "true" : "false"
        } else if let x = v as? Int {
            b += String(x)
        } else if let s = v as? String {
            b += "\""
            for c in s.unicodeScalars {
                if c == "\"" || c == "\\" {
                    b += "\\" + String(c)
                } else if c.value < 0x20 {
                    b += String(format: "\\u%04x", c.value)
                } else {
                    b.unicodeScalars.append(c)
                }
            }
            b += "\""
        } else if let o = v as? BleObj {
            b += "{"
            for (i, k) in o.keys.enumerated() {
                if i > 0 { b += "," }
                json(&b, k)
                b += ":"
                json(&b, o[k])
            }
            b += "}"
        } else if let l = v as? [Any] {
            b += "["
            for (i, x) in l.enumerated() {
                if i > 0 { b += "," }
                json(&b, x)
            }
            b += "]"
        } else if let l = v as? [String] {
            json(&b, l as [Any])
        } else {
            preconditionFailure("no JSON form for \(type(of: v))")
        }
    }

    static func obj(_ pairs: (String, Any)...) -> BleObj {
        BleObj(pairs)
    }

    /// The platform error of a link that went down, as the radio reports it, with the code's
    /// platform name when it has one.
    static func platformError(_ domain: String, _ code: Int, _ message: String) -> BleObj {
        let e = obj(("domain", domain), ("code", code), ("message", message))
        if let n = errorNames[domain]?[code] { e["name"] = n.0 }
        return e
    }

    /// The link event's reason for an error: the code's readable reason, else the radio's.
    static func errorReason(_ e: BleObj?, _ fallback: String) -> String {
        guard let e = e, let d = e["domain"] as? String, let c = e["code"] as? Int,
              let n = errorNames[d]?[c] else { return fallback }
        return n.1
    }

    /// " (domain code name: message)" for a failed call's message, or "" without an error.
    static func errorText(_ e: BleObj?) -> String {
        guard let e = e else { return "" }
        func text(_ k: String) -> String { e[k].map { "\($0)" } ?? "" }
        let name = e["name"].map { " \($0)" } ?? ""
        return " (\(text("domain")) \(text("code"))\(name): \(text("message")))"
    }

    // MARK: replies and records

    private func ok(_ call: Int, _ data: BleObj) {
        if call >= 0 { port.reply(call, true, nil, nil, data) }
    }

    private func fail(_ call: Int, _ code: String, _ message: String) {
        if call >= 0 { port.reply(call, false, code, message, nil) }
    }

    /// "code message" from a port refusal, split.
    private func refused(_ call: Int, _ err: String) {
        if let sp = err.firstIndex(of: " ") {
            fail(call, String(err[..<sp]), String(err[err.index(after: sp)...]))
        } else {
            fail(call, err, "")
        }
    }

    private var journalCount: Int { journal.count - journalHead }

    private func append(_ event: String, _ data: BleObj) {
        nextSeq += 1
        let size = BleCore.json(data).utf8.count + 48
        journal.append((seq: nextSeq, t: port.now(), event: event, data: data, size: size))
        journalSize += size
        while journalCount > BleCore.journalRecords || journalSize > BleCore.journalBytes {
            journalSize -= journal[journalHead].size
            journalHead += 1
            dropped += 1
        }
        if journalHead > 4096 {
            journal.removeFirst(journalHead)
            journalHead = 0
        }
    }

    /// An event that is also a journal record.
    private func record(_ event: String, _ data: BleObj) {
        append(event, data)
        port.emit(event, data)
    }

    private func scheduleFlush() {
        if flushScheduled { return }
        flushScheduled = true
        port.timer("flush", 0, BleCore.flushMs)
    }

    private func flush() {
        flushScheduled = false
        if !pendingDevices.isEmpty {
            let batch = pendingDevices
            pendingDevices = []
            record("device", BleCore.obj(("scan", lastScan), ("devices", batch)))
        }
        if !pendingValues.isEmpty {
            let n = min(BleCore.batchMax, pendingValues.count)
            let batch: [Any] = Array(pendingValues[0..<n])
            pendingValues.removeFirst(n)
            port.emit("value", BleCore.obj(("records", batch), ("dropped", dropped)))
            if !pendingValues.isEmpty { scheduleFlush() }
        }
        if !pendingRequests.isEmpty {
            let n = min(BleCore.batchMax, pendingRequests.count)
            let batch: [Any] = Array(pendingRequests[0..<n])
            pendingRequests.removeFirst(n)
            port.emit("request", BleCore.obj(("records", batch), ("dropped", dropped)))
            if !pendingRequests.isEmpty { scheduleFlush() }
        }
    }

    // MARK: adapter

    var on: Bool { adapterState == "on" }

    private func orderedLinks() -> [Link] { linkOrder.compactMap { links[$0] } }

    private func putLink(_ l: Link) {
        if links[l.id] == nil { linkOrder.append(l.id) }
        links[l.id] = l
    }

    private func removeLink(_ id: String) {
        links[id] = nil
        linkOrder.removeAll { $0 == id }
    }

    private func putClosing(_ id: String, _ c: Closing) {
        if closing[id] == nil { closingOrder.append(id) }
        closing[id] = c
    }

    private func removeClosing(_ id: String) -> Closing? {
        let c = closing.removeValue(forKey: id)
        closingOrder.removeAll { $0 == id }
        return c
    }

    /// The adapter or manager state changed (on, off, unauthorized, unsupported, resetting, unknown).
    func adapter(_ state: String) {
        if state == adapterState { return }
        let wasOn = on
        adapterState = state
        if wasOn && !on {
            epoch += 1
            if scan != 0 { endScan("adapter") }
            serverDown()
            for l in orderedLinks() {
                if l.auto { setAutoWhenOn(l.id, l.wanted) }
                _ = closeLink(l, "adapter", down: true)
                // The radio is off: every platform object of the old epoch is released, none waited for.
                port.release(l.id, l.gen)
            }
            for id in closingOrder {
                let c = closing[id]!
                port.release(id, c.gen)
                if c.disconnectCall >= 0 {
                    ok(c.disconnectCall, BleCore.obj(("id", id), ("state", "disconnected"), ("confirmed", false)))
                }
                if let w = c.waiter { fail(w.call, "unavailable", "Bluetooth is \(state)") }
                if c.reconnect { setAutoWhenOn(id, c.wanted) }
            }
            closing = [:]
            closingOrder = []
        }
        record("adapter", BleCore.obj(("state", state), ("epoch", epoch)))
        if !wasOn && on {
            let again = autoWhenOn
            autoWhenOn = []
            for (id, wanted) in again {
                startLink(id, auto: true, call: -1, seconds: 0, background: true, wanted: wanted)
            }
            serverUp()
        }
        updateHold()
    }

    private func setAutoWhenOn(_ id: String, _ wanted: [String]) {
        if let i = autoWhenOn.firstIndex(where: { $0.0 == id }) { autoWhenOn[i].1 = wanted } else { autoWhenOn.append((id, wanted)) }
    }

    /// Fields of the state reply that the core owns.
    func stateFields() -> BleObj {
        BleCore.obj(("scanning", scan != 0), ("advertising", advertising), ("links", links.count),
                    ("centrals", centralList.count), ("keepAlive", keepAliveWanted), ("epoch", epoch), ("run", run))
    }

    // MARK: scan

    func scanStart(_ call: Int, _ servicesCsv: String?, _ seconds: Int, _ duplicates: Bool, _ mode: String, _ background: Bool) {
        guard let services = BleCore.uuidList(servicesCsv) else {
            fail(call, "bad_value", "services must be up to 20 UUIDs")
            return
        }
        if !on {
            fail(call, "unavailable", "Bluetooth is \(adapterState)")
            return
        }
        if scan != 0 {
            fail(call, "busy", "a scan is already running")
            return
        }
        if background && services.isEmpty {
            fail(call, "filter_required", "a scan in the background needs a service filter")
            return
        }
        nextScan += 1
        let s = nextScan
        if let err = port.scanStart(s, services, duplicates, mode) {
            refused(call, err)
            return
        }
        scan = s
        lastScan = s
        devices = [:]
        deviceOrder = []
        filtered = !services.isEmpty
        if seconds > 0 { port.timer("scan", s, seconds * 1000) }
        ok(call, BleCore.obj(("scan", s)))
    }

    func scanStop(_ call: Int) {
        if scan == 0 {
            ok(call, BleCore.obj(("scan", lastScan), ("stopped", false)))
            return
        }
        let s = scan
        port.scanStop(s)
        endScan("stopped")
        ok(call, BleCore.obj(("scan", s), ("stopped", true)))
    }

    private func endScan(_ reason: String) {
        let s = scan
        scan = 0
        flush()
        record("scan_end", BleCore.obj(("scan", s), ("reason", reason)))
    }

    /// One advertisement. `adv` holds name, rssi, connectable, services, manufacturer, serviceData, txPower.
    func device(_ s: Int, _ id: String, _ adv: BleObj) {
        if s != scan || s == 0 {
            stale("device scan \(s)")
            return
        }
        var d = devices[id]
        if d == nil {
            if devices.count >= BleCore.devicesMax { return }
            let n = BleCore.obj(("id", id), ("seen", 0))
            devices[id] = n
            deviceOrder.append(id)
            d = n
        }
        d!.putAll(adv)
        d!["seen"] = (d!["seen"] as! Int) + 1
        let view = BleCore.obj(("id", id))
        view.putAll(adv)
        pendingDevices.append(view)
        scheduleFlush()
    }

    func scanFailed(_ s: Int, _ reason: String) {
        if s != scan || s == 0 {
            stale("scan_failed \(s)")
            return
        }
        endScan("failed")
    }

    /// The app moved to (true) or out of the background.
    func background(_ inBackground: Bool) {
        if inBackground && scan != 0 && !filtered {
            port.scanStop(scan)
            endScan("background")
        }
    }

    func devices(_ call: Int) {
        let out: [Any] = deviceOrder.compactMap { devices[$0] }
        ok(call, BleCore.obj(("devices", out)))
    }

    // MARK: links

    private func current(_ l: Link?, _ gen: Int) -> Bool {
        return l != nil && l!.gen == gen && !l!.closed
    }

    private func live(_ id: String, _ gen: Int, _ what: String) -> Link? {
        let l = links[id]
        if !current(l, gen) {
            stale("\(what) \(id) gen \(gen)")
            return nil
        }
        return l
    }

    private func stale(_ what: String) {
        staleDrops += 1
        port.stale(what)
    }

    private func checkId(_ call: Int, _ id: String?) -> Bool {
        if !BleCore.isId(id, android ? "android" : "ios") {
            fail(call, "bad_value", "id is not a device id of this platform")
            return false
        }
        return true
    }

    func connect(_ call: Int, _ id: String?, _ auto: Bool, _ seconds: Int) {
        guard checkId(call, id), let id = id else { return }
        if !on {
            fail(call, "unavailable", "Bluetooth is \(adapterState)")
            return
        }
        if let l = links[id] {
            // A pending attempt no call owns (restored by iOS, or an automatic reconnect) is
            // adopted: this call owns it from now on, with its own timeout, and the page's `auto` wins.
            if l.state == "connecting" && l.connectCall < 0 && !l.closed {
                l.connectCall = call
                l.auto = auto
                l.background = false
                boundPending(l, seconds * 1000)
                return
            }
            fail(call, "busy", "this device is linked or connecting")
            return
        }
        if closing[id] != nil {
            // Rule 3: one live platform connection per device. Wait for the confirmed close.
            let c = closing[id]!
            if c.waiter != nil || c.reconnect {
                fail(call, "busy", "this device is still closing")
                return
            }
            nextOp += 1
            c.waiter = Waiter(call: call, auto: auto, seconds: seconds, token: nextOp)
            port.timer("wait", nextOp, seconds * 1000)
            return
        }
        startLink(id, auto: auto, call: call, seconds: seconds, background: false, wanted: [])
    }

    private func startLink(_ id: String, auto: Bool, call: Int, seconds: Int, background: Bool, wanted: [String]) {
        nextGen += 1
        let l = Link(id, nextGen)
        l.auto = auto
        l.background = background
        l.connectCall = call
        for k in wanted { l.addWanted(k) }
        putLink(l)
        if let err = port.connect(id, l.gen, auto, background) {
            removeLink(id)
            l.closed = true
            refused(call, err)
            return
        }
        if call >= 0 { port.timer("connect", l.gen, seconds * 1000) }
        if background {
            record("link", BleCore.obj(("id", id), ("link", l.gen), ("state", "reconnecting"), ("reason", "auto")))
        }
        updateHold()
    }

    /// Bounds an attempt no fresh connect started: when the timer ends it still connecting, the
    /// attempt is closed (the radio cancels it) and reported `timeout`.
    private func boundPending(_ l: Link, _ ms: Int) {
        nextPending += 1
        l.pendingTimer = nextPending
        port.timer("pending", nextPending, ms)
    }

    /// iOS state restoration: a peripheral the system kept for this app. Returns its gen. `pending`:
    /// iOS handed it back still connecting; the attempt is kept, bounded by the default connect
    /// timeout, and ends there unless a page `connect` adopts it (that call's timeout and `auto`).
    func restored(_ id: String, connected: Bool, subscribed: [String], pending: Bool = false) -> Int {
        nextGen += 1
        let l = Link(id, nextGen)
        l.auto = true
        l.background = true
        for k in subscribed {
            l.addWanted(k)
            l.setSub(k, "notify")
        }
        putLink(l)
        if connected {
            l.state = "connected"
        } else if pending {
            l.auto = false
            boundPending(l, BleCore.connectDefaultMs)
        }
        return l.gen
    }

    /// iOS state restoration finished: the `restored` event, kept in the journal like every event.
    func restoredEvent(_ data: BleObj) {
        record("restored", data)
    }

    func connected(_ id: String, _ gen: Int, _ mtu: Int) {
        guard let l = live(id, gen, "connected") else { return }
        if l.state != "connecting" { return }
        l.state = "connected"
        l.mtu = mtu
        if android {
            let m = Op(-1, "mtu")
            m.arg = BleCore.mtuRequest
            m.internal = true
            l.queue.append(m)
        }
        if !l.wanted.isEmpty {
            let d = Op(-1, "discover")
            d.internal = true
            l.queue.append(d)
            for k in l.wanted {
                let s = Op(-1, "sub")
                s.key = k
                s.internal = true
                l.queue.append(s)
            }
        }
        let ready = Op(-1, "ready")
        ready.internal = true
        l.queue.append(ready)
        pump(l)
    }

    /// The platform reported that attempt `gen` disconnected or failed to connect.
    /// `error`: the platform's own error, when it gave one ({domain, code, message}); it reaches the
    /// failed connect call's message and the `link` record unchanged.
    func disconnected(_ id: String, _ gen: Int, _ reason: String, error: BleObj? = nil) {
        let l = links[id]
        if current(l, gen) {
            _ = closeLink(l!, BleCore.errorReason(error, reason), down: true, error: error)
            return
        }
        if let c = closing[id], c.gen == gen {
            finishClosing(id, confirmed: true)
            return
        }
        stale("disconnected \(id) gen \(gen)")
    }

    func disconnect(_ call: Int, _ id: String?) {
        guard checkId(call, id), let id = id else { return }
        guard let l = links[id] else {
            fail(call, "not_connected", "this device is not linked")
            return
        }
        l.auto = false
        l.wanted = []
        let confirmedNow = closeLink(l, "requested", down: false)
        if confirmedNow {
            ok(call, BleCore.obj(("id", id), ("state", "disconnected"), ("confirmed", true)))
        } else {
            closing[id]!.disconnectCall = call
        }
    }

    /// The one cleanup owner (rule 4). Runs to the end, idempotent. `down`: the platform already
    /// reported the link down, so nothing is asked of it. Returns whether the close is confirmed now.
    @discardableResult
    func closeLink(_ l: Link, _ reason: String, down: Bool, error: BleObj? = nil) -> Bool {
        if l.closed { return true }
        l.closed = true
        var ops: [Op] = []
        if let f = l.inFlight { ops.append(f) }
        ops.append(contentsOf: l.queue)
        l.inFlight = nil
        l.queue = []
        for o in ops where !o.internal {
            let msg = o.chunks > 1 ? "the link closed after \(o.chunk) of \(o.chunks) chunks were handed over"
                : "the link closed while the operation waited"
            fail(o.call, "link_lost", msg)
        }
        if l.connectCall >= 0 {
            let code = reason == "timeout" ? "connect_timeout"
                : reason == "adapter" ? "unavailable"
                : reason == "requested" ? "link_lost" : "connect_failed"
            fail(l.connectCall, code, "the connection ended: \(reason)" + BleCore.errorText(error))
            l.connectCall = -1
        }
        if links[l.id] === l { removeLink(l.id) }
        var confirmed = down
        if !down {
            confirmed = port.close(l.id, l.gen)
            if !confirmed {
                putClosing(l.id, Closing(l.gen))
                port.timer("close", l.gen, BleCore.closeMs)
            }
        }
        let rec = BleCore.obj(("id", l.id), ("link", l.gen), ("state", "disconnected"), ("reason", reason))
        if let e = error { rec["error"] = e }
        record("link", rec)
        if l.auto && reason != "requested" && on {
            if let c = closing[l.id] {
                c.reconnect = true
                c.wanted = l.wanted
            } else {
                startLink(l.id, auto: true, call: -1, seconds: 0, background: true, wanted: l.wanted)
            }
        }
        updateHold()
        return confirmed
    }

    private func finishClosing(_ id: String, confirmed: Bool) {
        guard let c = removeClosing(id) else { return }
        if c.disconnectCall >= 0 {
            ok(c.disconnectCall, BleCore.obj(("id", id), ("state", "disconnected"), ("confirmed", confirmed)))
        }
        if !on {
            if let w = c.waiter { fail(w.call, "unavailable", "Bluetooth is \(adapterState)") }
            return
        }
        if c.reconnect {
            startLink(id, auto: true, call: -1, seconds: 0, background: true, wanted: c.wanted)
        } else if let w = c.waiter {
            if !port.isActive(w.call) {
                fail(w.call, "timeout", "the route timed out while the previous connection closed")
                return
            }
            startLink(id, auto: w.auto, call: w.call, seconds: w.seconds, background: false, wanted: [])
        }
    }

    func links(_ call: Int) {
        let out: [Any] = orderedLinks().map { l in
            BleCore.obj(("id", l.id), ("link", l.gen), ("state", l.state), ("auto", l.auto), ("mtu", l.mtu),
                        ("subscriptions", l.subs.map { $0.0 } as [Any]))
        }
        ok(call, BleCore.obj(("links", out)))
    }

    /// The link for `id` when it is current (for the radio's own lookups).
    func link(_ id: String) -> Link? { links[id] }

    // MARK: operations

    private func connectedLink(_ call: Int, _ id: String?) -> Link? {
        guard checkId(call, id), let id = id else { return nil }
        guard let l = links[id], l.state == "connected" else {
            fail(call, "not_connected", "this device is not connected")
            return nil
        }
        return l
    }

    private func target(_ call: Int, _ service: String?, _ sn: Int, _ chr: String?, _ cn: Int) -> String? {
        guard let s = BleCore.uuid(service), let c = BleCore.uuid(chr) else {
            fail(call, "bad_value", "service and char must be UUIDs")
            return nil
        }
        return BleCore.key(s, sn, c, cn)
    }

    private func enqueue(_ call: Int, _ l: Link, _ o: Op) {
        if l.queue.count >= BleCore.queueMax {
            fail(call, "busy", "too many operations are waiting on this link")
            return
        }
        l.queue.append(o)
        pump(l)
    }

    func discover(_ call: Int, _ id: String?) {
        if let l = connectedLink(call, id) { enqueue(call, l, Op(call, "discover")) }
    }

    func read(_ call: Int, _ id: String?, _ service: String?, _ sn: Int, _ chr: String?, _ cn: Int, _ descriptor: String?) {
        guard let l = connectedLink(call, id) else { return }
        guard let k = target(call, service, sn, chr, cn) else { return }
        var d: String?
        if descriptor != nil {
            d = BleCore.uuid(descriptor)
            if d == nil {
                fail(call, "bad_value", "descriptor must be a UUID")
                return
            }
        }
        let o = Op(call, "read")
        o.key = k
        o.descriptor = d
        enqueue(call, l, o)
    }

    func write(_ call: Int, _ id: String?, _ service: String?, _ sn: Int, _ chr: String?, _ cn: Int, _ descriptor: String?,
               _ hexValue: String?, _ b64Value: String?, _ response: Bool) {
        guard let l = connectedLink(call, id) else { return }
        guard let k = target(call, service, sn, chr, cn) else { return }
        guard let data = BleCore.bytes(hexValue, b64Value) else {
            fail(call, "bad_value", "give exactly one of hex and b64, well formed")
            return
        }
        if data.count > BleCore.writeMax {
            fail(call, "too_long", "\(data.count) bytes; at most \(BleCore.writeMax)")
            return
        }
        var withResponse = response
        var d: String?
        if descriptor != nil {
            d = BleCore.uuid(descriptor)
            if d == nil {
                fail(call, "bad_value", "descriptor must be a UUID")
                return
            }
            withResponse = true
        }
        let o = Op(call, withResponse ? "write" : "wnr")
        o.key = k
        o.descriptor = d
        o.data = data
        enqueue(call, l, o)
    }

    func subscribe(_ call: Int, _ id: String?, _ service: String?, _ sn: Int, _ chr: String?, _ cn: Int, _ on: Bool) {
        guard let l = connectedLink(call, id) else { return }
        guard let k = target(call, service, sn, chr, cn) else { return }
        let o = Op(call, on ? "sub" : "unsub")
        o.key = k
        enqueue(call, l, o)
    }

    func rssi(_ call: Int, _ id: String?) {
        if let l = connectedLink(call, id) { enqueue(call, l, Op(call, "rssi")) }
    }

    func mtu(_ call: Int, _ id: String?, _ size: Int) {
        guard let l = connectedLink(call, id) else { return }
        if !android {
            ok(call, BleCore.mtuData(l, requested: false))
            return
        }
        let o = Op(call, "mtu")
        o.arg = size
        enqueue(call, l, o)
    }

    private static func mtuData(_ l: Link, requested: Bool) -> BleObj {
        obj(("mtu", l.mtu), ("writeMax", writeMax), ("writeNoResponseMax", l.mtu - 3), ("requested", requested))
    }

    /// Hands the next operation to the platform when none is in flight.
    private func pump(_ l: Link) {
        while l.inFlight == nil && !l.queue.isEmpty && !l.closed {
            let o = l.queue.removeFirst()
            if !o.internal && !port.isActive(o.call) {
                // Rule 8: a route that timed out starts nothing new. Its reply is the bridge's to drop.
                fail(o.call, "timeout", "the route timed out before the operation started")
                continue
            }
            if o.kind == "ready" {
                ready(l)
                continue
            }
            if o.kind == "wnr" {
                let size = max(1, l.mtu - 3)
                o.chunks = max(1, (o.data!.count + size - 1) / size)
                o.chunk = 0
            }
            l.inFlight = o
            send(l, o)
        }
    }

    private func send(_ l: Link, _ o: Op) {
        nextOp += 1
        o.op = nextOp
        var data = o.data
        if o.kind == "wnr", let all = o.data {
            let size = max(1, l.mtu - 3)
            let from = o.chunk * size, to = min(all.count, from + size)
            data = Array(all[from..<to])
        }
        if let err = port.op(l.id, l.gen, o.op, o.kind, o.key, o.descriptor, data, o.arg) {
            // Rule 6: a refusal settles the step at once and the queue moves on.
            l.inFlight = nil
            if o.internal {
                if o.kind == "sub" { l.failed += 1 }
            } else {
                refused(o.call, err)
            }
            pump(l)
            return
        }
        port.timer("op", o.op, BleCore.opMs)
    }

    private func ready(_ l: Link) {
        record("link", BleCore.obj(("id", l.id), ("link", l.gen), ("state", "connected"),
                                   ("reason", l.background ? "auto" : "requested"),
                                   ("resubscribed", l.resubscribed), ("failed", l.failed)))
        if l.connectCall >= 0 {
            ok(l.connectCall, BleCore.obj(("id", l.id), ("link", l.gen), ("state", "connected"), ("mtu", l.mtu)))
            l.connectCall = -1
        }
    }

    /// One GATT step settled. `code` nil is success; `data` carries the platform's answer
    /// (discover: services; read: hex; rssi: rssi; sub: mode).
    func opDone(_ id: String, _ gen: Int, _ op: Int, _ code: String?, _ message: String?, _ data: BleObj?) {
        guard let l = live(id, gen, "op") else { return }
        guard let o = l.inFlight, o.op == op else {
            stale("op \(op)")
            return
        }
        if code == nil && o.kind == "wnr" && o.chunk + 1 < o.chunks {
            o.chunk += 1
            send(l, o)
            return
        }
        l.inFlight = nil
        settle(l, o, code, message, data)
        pump(l)
    }

    private func settle(_ l: Link, _ o: Op, _ code: String?, _ message: String?, _ data: BleObj?) {
        if o.internal {
            if o.kind == "sub" {
                if code == nil {
                    l.setSub(o.key!, (data?["mode"] as? String) ?? "notify")
                    l.resubscribed += 1
                } else {
                    l.failed += 1
                }
            }
            return
        }
        if let code = code {
            fail(o.call, code, message ?? "")
            return
        }
        switch o.kind {
        case "write":
            ok(o.call, BleCore.obj(("written", o.data!.count), ("chunks", 1)))
        case "wnr":
            ok(o.call, BleCore.obj(("written", o.data!.count), ("chunks", o.chunks)))
        case "sub":
            let mode = (data?["mode"] as? String) ?? "notify"
            l.setSub(o.key!, mode)
            l.addWanted(o.key!)
            ok(o.call, BleCore.obj(("subscribed", true), ("mode", mode)))
        case "unsub":
            l.subs.removeAll { $0.0 == o.key! }
            l.wanted.removeAll { $0 == o.key! }
            ok(o.call, BleCore.obj(("subscribed", false)))
        case "mtu":
            ok(o.call, BleCore.mtuData(l, requested: true))
        case "discover":
            let out = BleCore.obj(("id", l.id))
            if let d = data { out.putAll(d) }
            ok(o.call, out)
        default:
            ok(o.call, data ?? BleObj())
        }
    }

    /// The link's MTU changed. It completes the operation in flight only if that is the MTU request.
    func mtuChanged(_ id: String, _ gen: Int, _ mtu: Int, _ success: Bool) {
        guard let l = live(id, gen, "mtu") else { return }
        if success { l.mtu = mtu }
        if let o = l.inFlight, o.kind == "mtu" {
            l.inFlight = nil
            settle(l, o, nil, nil, nil)
            pump(l)
        }
    }

    /// A characteristic value arrived. `maybeRead`: the platform cannot say whether it answers a
    /// read (iOS didUpdateValueFor); then a read of this characteristic in flight takes it.
    func value(_ id: String, _ gen: Int, _ key: String, _ hexValue: String, _ maybeRead: Bool) {
        guard let l = live(id, gen, "value") else { return }
        if maybeRead, let o = l.inFlight, o.kind == "read", o.descriptor == nil, o.key == key {
            l.inFlight = nil
            settle(l, o, nil, nil, BleCore.obj(("hex", hexValue)))
            pump(l)
            return
        }
        let parts = key.split(whereSeparator: { $0 == "#" || $0 == "/" }).map(String.init)
        let rec = BleCore.obj(("id", id), ("link", gen), ("service", parts[0]), ("char", parts[2]),
                              ("service_n", Int(parts[1])!), ("char_n", Int(parts[3])!), ("hex", hexValue))
        append("value", rec)
        let view = BleCore.obj(("seq", nextSeq), ("t", journal[journal.count - 1].t))
        view.putAll(rec)
        pendingValues.append(view)
        scheduleFlush()
    }

    /// The remote GATT table changed: cached handles are gone, the next operation needs discover.
    func gattChanged(_ id: String, _ gen: Int) {
        guard live(id, gen, "gatt_changed") != nil else { return }
        record("gatt_changed", BleCore.obj(("id", id), ("link", gen)))
    }

        let n: Int

        var subscribers: [(String, String)] = []

        init(_ uuid: String, _ n: Int, _ flags: String, _ value: [UInt8]?) {
            self.uuid = uuid
            self.n = n
            self.flags = flags
            self.value = value

    }

    /// The `chars` grammar of service_add (BleCore.java parseChars): `uuid~flags` or
    /// `uuid~flags~hex`, comma-separated, at most 16; equal UUIDs are numbered in order. nil when malformed.
    static func parseChars(_ spec: String?) -> [BleObj]? {
        var out: [BleObj] = []
        guard let spec = spec, !spec.isEmpty else { return out }
        var seen: [String: Int] = [:]
        for part in spec.split(separator: ",", omittingEmptySubsequences: false) {
            let f = part.split(separator: "~", omittingEmptySubsequences: false).map(String.init)
            if f.count < 2 || f.count > 3 { return nil }
            let flags = f[1]
            guard let u = uuid(f[0].trimmingCharacters(in: .whitespaces)), !flags.isEmpty else { return nil }
            var letters = Set<Character>()
            for c in flags {
                if !"rwcniRW".contains(c) || letters.contains(c) { return nil }
                letters.insert(c)
            }
            if !flags.contains(where: { "rwcni".contains($0) }) { return nil }
            if flags.contains("R") && !flags.contains("r") { return nil }
            if flags.contains("W") && !flags.contains("w") && !flags.contains("c") { return nil }
            var start: Any = NSNull()
            if f.count == 3 {
                guard let b = fromHex(f[2]), !f[2].isEmpty, b.count <= writeMax else { return nil }
                start = hex(b)
            }
            let n = seen[u].map { $0 + 1 } ?? 0
            seen[u] = n
            out.append(obj(("uuid", u), ("n", n), ("flags", flags), ("hex", start)))
            if out.count > charsMax { return nil }
        }
        return out
    }

    /// Server and advertiser callbacks carry the epoch they were made in; an older one changes nothing.
    private func serverCurrent(_ e: Int, _ what: String) -> Bool {
        if e == epoch && on { return true }
        stale("\(what) epoch \(e)")
        return false
    }

    private func chr(_ serviceUUID: String?, _ chrUUID: String?, _ cn: Int) -> Chr? {
        guard let s = BleCore.uuid(serviceUUID), let c = BleCore.uuid(chrUUID), let svc = service(s) else { return nil }
        return svc.chars.first { $0.uuid == c && $0.n == cn }
    }

    private func chrOf(_ key: String) -> Chr? {
        let p = key.split(whereSeparator: { $0 == "#" || $0 == "/" }).map(String.init)
        guard p.count == 4, let svc = service(p[0]), let cn = Int(p[3]) else { return nil }
        return svc.chars.first { $0.uuid == p[2] && $0.n == cn }
    }

    private func lostService(_ key: String) -> Bool {
        service(String(key.prefix(while: { $0 != "#" })))?.lost ?? false
    }

    private static func keyOf(_ s: Service, _ c: Chr) -> String { key(s.uuid, 0, c.uuid, c.n) }

    private static func properties(_ c: Chr) -> [Any] {
        var out: [Any] = []
        if c.has("r") { out.append("read") }
        if c.has("c") { out.append("writeWithoutResponse") }
        if c.has("w") { out.append("write") }
        if c.has("n") { out.append("notify") }
        if c.has("i") { out.append("indicate") }
        return out
    }

    private static func charList(_ s: Service) -> [BleObj] {
        s.chars.map { c in
            obj(("uuid", c.uuid), ("n", c.n), ("flags", c.flags), ("hex", c.value.map { hex($0) as Any } ?? NSNull()))
        }
    }

    private func serviceView(_ s: Service) -> BleObj {
        let chars: [Any] = s.chars.map { c in
            BleCore.obj(("uuid", c.uuid), ("n", c.n), ("properties", BleCore.properties(c)),
                        ("subscribers", c.subscribers.map { $0.0 } as [Any]),
                        ("hex", c.value.map { BleCore.hex($0) as Any } ?? NSNull()))
        }
        return BleCore.obj(("uuid", s.uuid), ("primary", s.primary), ("added", s.added), ("characteristics", chars))
    }

    func serviceAdd(_ call: Int, _ uuidValue: String?, _ primary: Bool, _ spec: String?) {
        let u = BleCore.uuid(uuidValue)
        let parsed = BleCore.parseChars(spec)
        guard let uu = u, let list = parsed else {
            fail(call, "bad_value", u == nil ? "uuid must be a UUID" : "chars does not follow uuid~flags[~hex], at most 16")
            return
        }
        if !on {
            fail(call, "unavailable", "Bluetooth is \(adapterState)")
            return
        }
        if service(uu) != nil {
            fail(call, "bad_value", "this service is already in the table")
            return
        }
        if services.count >= BleCore.servicesMax {
            fail(call, "busy", "the table holds \(BleCore.servicesMax) services")
            return
        }
        let chars = list.map { c -> Chr in
            Chr(c["uuid"] as! String, c["n"] as! Int, c["flags"] as! String,
                (c["hex"] as? String).flatMap { BleCore.fromHex($0) } ?? [])
        }
        let s = Service(uu, primary, chars)
        s.call = call
        services.append(s)
        addQueue.append(s)
        pumpAdds()
    }

    /// Hands the next service to the platform; one add in flight, as Android requires.
    private func pumpAdds() {
        while adding == nil && !addQueue.isEmpty {
            let s = addQueue.removeFirst()
            if s.call >= 0 && !port.isActive(s.call) {
                services.removeAll { $0 === s }
                fail(s.call, "timeout", "the route timed out before the service was added")
                continue
            }
            if let err = port.serviceAdd(epoch, s.uuid, s.primary, BleCore.charList(s)) {
                if s.call >= 0 {
                    services.removeAll { $0 === s }
                    refused(s.call, err)
                    s.call = -1
                }
                continue
            }
            adding = s
            nextOp += 1
            s.token = nextOp
            port.timer("service", s.token, BleCore.opMs)
        }
    }

    /// The platform added (code nil) or refused a service.
    func serviceAdded(_ e: Int, _ uuidValue: String, _ code: String?) {
        if !serverCurrent(e, "service_added") { return }
        guard let s = adding, s.uuid == uuidValue else {
            stale("service_added \(uuidValue)")
            return
        }
        adding = nil
        if code == nil {
            s.added = true
            if s.call >= 0 { ok(s.call, BleCore.obj(("uuid", s.uuid), ("characteristics", serviceView(s)["characteristics"]!))) }
            persistSoon()
        } else if s.call >= 0 {
            services.removeAll { $0 === s }
            fail(s.call, "gatt_error", "the platform refused the service: \(code!)")
        }
        s.call = -1
        pumpAdds()
    }

    func serviceRemove(_ call: Int, _ uuidValue: String?) {
        var targets: [Service] = []
        if let raw = uuidValue {
            guard let u = BleCore.uuid(raw) else {
                fail(call, "bad_value", "uuid must be a UUID")
                return
            }
            guard let s = service(u) else {
                fail(call, "not_found", "no such service in the table")
                return
            }
            targets.append(s)
        } else {
            targets = services
        }
        for s in targets where s === adding || s.call >= 0 {
            fail(call, "busy", "a service is still being added")
            return
        }
        var removed: [Any] = []
        for s in targets {
            services.removeAll { $0 === s }
            addQueue.removeAll { $0 === s }
            if s.added { port.serviceRemove(s.uuid) }
            for c in s.chars {
                for (central, _) in c.subscribers { dropSubscription(central, s.uuid, c) }
            }
            removed.append(s.uuid)
        }
        persistSoon()
        ok(call, BleCore.obj(("removed", removed)))
        pumpNotify()
    }

    func servicesList(_ call: Int) {
        ok(call, BleCore.obj(("services", services.map { serviceView($0) } as [Any]), ("advertising", advertising)))
    }

    func valueSet(_ call: Int, _ serviceUUID: String?, _ chrUUID: String?, _ cn: Int, _ hexValue: String?, _ b64Value: String?) {
        guard let c = chr(serviceUUID, chrUUID, cn) else {
            fail(call, "not_found", "no such characteristic in the table")
            return
        }
        guard let data = BleCore.bytes(hexValue, b64Value) else {
            fail(call, "bad_value", "give exactly one of hex and b64, well formed")
            return
        }
        if overMax(call, data) { return }
        c.value = data
        persistSoon()
        ok(call, BleCore.obj(("bytes", data.count)))
    }

    /// A server value is at most 512 bytes, as an attribute value is.
    private func overMax(_ call: Int, _ data: [UInt8]) -> Bool {
        if data.count <= BleCore.writeMax { return false }
        fail(call, "too_long", "\(data.count) bytes; at most \(BleCore.writeMax)")
        return true
    }

    func notify(_ call: Int, _ serviceUUID: String?, _ chrUUID: String?, _ cn: Int, _ hexValue: String?, _ b64Value: String?,
                _ central: String?) {
        guard let c = chr(serviceUUID, chrUUID, cn) else {
            fail(call, "not_found", "no such characteristic in the table")
            return
        }
        guard let data = BleCore.bytes(hexValue, b64Value) else {
            fail(call, "bad_value", "give exactly one of hex and b64, well formed")
            return
        }
        if overMax(call, data) { return }
        if !c.has("n") && !c.has("i") {
            fail(call, "not_permitted", "the characteristic neither notifies nor indicates")
            return
        }
        let to = c.subscribers.map { $0.0 }.filter { central == nil || central == $0 }
        if to.isEmpty {
            fail(call, "no_subscribers", central == nil ? "no central is subscribed" : "that central is not subscribed")
            return
        }
        var room = Int.max
        for x in to { room = min(room, (centralMtu(of: x) ?? 23) - 3) }
        if data.count > room {
            fail(call, "too_long", "\(data.count) bytes; a subscriber's MTU allows \(room)")
            return
        }
        if notifyQueue.count + to.count > BleCore.notifyMax {
            fail(call, "busy", "too many notifications are waiting")
            return
        }
        c.value = data
        persistSoon()
        var key = ""
        for s in services where s.chars.contains(where: { $0 === c }) { key = BleCore.keyOf(s, c) }
        let job = Job(call, to.count)
        for x in to { notifyQueue.append(Packet(job, x, key, data, c.mode(x) == "indicate")) }
        pumpNotify()
    }

    private func resolve(_ p: Packet, _ sent: Bool) {
        let j = p.job
        j.left -= 1
        if sent { j.sent += 1 }
        if j.left == 0 && !j.failed { ok(j.call, BleCore.obj(("sent", j.sent), ("subscribers", j.total))) }
    }

    private func failJob(_ j: Job, _ code: String, _ message: String) {
        if j.failed { return }
        j.failed = true
        fail(j.call, code, message)
    }

    /// Sends queued packets one at a time, in order.
    private func pumpNotify() {
        while sending == nil && !waitingReady && !notifyQueue.isEmpty {
            let p = notifyQueue[0]
            if !p.job.failed && !p.job.started && !port.isActive(p.job.call) {
                failJob(p.job, "timeout", "the route timed out before the notification was sent")
            }
            let c = p.job.failed ? nil : chrOf(p.key)
            if c == nil || c!.mode(p.central) == nil {
                notifyQueue.removeFirst()
                resolve(p, false)
                continue
            }
            p.job.started = true
            nextOp += 1
            p.packet = nextOp
            let r = port.notify(epoch, p.packet, p.central, p.key, p.data, p.indicate)
            if r == "full" {
                waitingReady = true
                return
            }
            notifyQueue.removeFirst()
            if r == nil {
                resolve(p, true)
            } else if r == "pending" {
                sending = p
                port.timer("notify", p.packet, BleCore.opMs)
            } else {
                let err = r!
                if let sp = err.firstIndex(of: " ") {
                    failJob(p.job, String(err[..<sp]), String(err[err.index(after: sp)...]))
                } else {
                    failJob(p.job, err, "")
                }
                resolve(p, false)
            }
        }
    }

    /// Android onNotificationSent for packet `packet`.
    func notifySent(_ e: Int, _ packet: Int, _ code: String?) {
        if !serverCurrent(e, "notify_sent") { return }
        guard let p = sending, p.packet == packet else {
            stale("notify_sent \(packet)")
            return
        }
        sending = nil
        if let code = code { failJob(p.job, "gatt_error", "the notification failed: \(code)") }
        resolve(p, code == nil)
        pumpNotify()
    }

    /// iOS peripheralManagerIsReady(toUpdateSubscribers:): the transmit queue has room again.
    func notifyReady(_ e: Int) {
        if !serverCurrent(e, "notify_ready") { return }
        if !waitingReady { return }
        waitingReady = false
        pumpNotify()
    }

    /// A remote central connected to this server (Android), or was first seen (iOS).
    func centralConnected(_ e: Int, _ central: String, _ mtu: Int) {
        if !serverCurrent(e, "central") { return }
        seen(central, mtu)
    }

    private func seen(_ central: String, _ mtu: Int) {
        if centralMtu(of: central) != nil {
            if mtu > 0 { setCentral(central, mtu) }
            return
        }
        setCentral(central, mtu > 0 ? mtu : 23)
        record("central", BleCore.obj(("central", central), ("state", "connected"), ("mtu", centralMtu(of: central)!)))
        updateHold()
    }

    func centralMtu(_ e: Int, _ central: String, _ mtu: Int) {
        if !serverCurrent(e, "central_mtu") { return }
        if centralMtu(of: central) != nil { setCentral(central, mtu) }
    }

    func centralDisconnected(_ e: Int, _ central: String) {
        if !serverCurrent(e, "central_gone") { return }
        if centralMtu(of: central) == nil {
            stale("central_gone " + central)
            return
        }
        endCentral(central, "remote")
        pumpNotify()
    }

    private func endCentral(_ central: String, _ reason: String) {
        for s in services { for c in s.chars { c.remove(central) } }
        prepared.removeAll { $0.0.hasPrefix(central + "|") }
        centralList.removeAll { $0.0 == central }
        record("central", BleCore.obj(("central", central), ("state", "disconnected"), ("reason", reason)))
        updateHold()
    }

    private func dropSubscription(_ central: String, _ serviceUUID: String, _ c: Chr) {
        c.remove(central)
        record("central", BleCore.obj(("central", central), ("state", "unsubscribed"), ("service", serviceUUID),
                                      ("char", c.uuid), ("char_n", c.n)))
        if !android && !subscribed(central) { centralList.removeAll { $0.0 == central } }
    }

    private func subscribed(_ central: String) -> Bool {
        services.contains { s in s.chars.contains { $0.mode(central) != nil } }
    }

    /// A central subscribed (`mode` notify or indicate) or unsubscribed (nil). Returns the ATT
    /// outcome: ok, not_found, not_permitted or stale.
    func subscription(_ e: Int, _ central: String, _ mtu: Int, _ key: String, _ mode: String?) -> String {
        if !serverCurrent(e, "subscription") { return "stale" }
        guard let c = chrOf(key) else { return "not_found" }
        if let m = mode, !c.has(m == "indicate" ? "i" : "n") { return "not_permitted" }
        seen(central, mtu)
        let svc = String(key.prefix(while: { $0 != "#" }))
        if let m = mode {
            c.setMode(central, m)
            record("central", BleCore.obj(("central", central), ("state", "subscribed"), ("service", svc), ("char", c.uuid),
                                          ("char_n", c.n), ("mode", m), ("mtu", centralMtu(of: central)!)))
        } else if c.mode(central) != nil {
            dropSubscription(central, svc, c)
        }
        pumpNotify()
        return "ok"
    }

    /// Android: the CCCD value this central reads back.
    func cccd(_ central: String, _ key: String) -> String {
        switch chrOf(key)?.mode(central) {
        case nil: return "0000"
        case "indicate"?: return "0200"
        default: return "0100"
        }
    }

    /// A read request, answered from the value store: {status, hex}. Status ok, not_found,
    /// not_permitted, invalid_offset, unlikely or stale.
    func readRequest(_ e: Int, _ central: String, _ mtu: Int, _ key: String, _ offset: Int) -> BleObj {
        if !serverCurrent(e, "read_request") { return BleCore.obj(("status", "stale")) }
        guard let c = chrOf(key) else { return BleCore.obj(("status", lostService(key) ? "unlikely" : "not_found")) }
        seen(central, mtu)
        if !c.has("r") { return BleCore.obj(("status", "not_permitted")) }
        guard let v = c.value else { return BleCore.obj(("status", "unlikely")) }
        if offset > v.count { return BleCore.obj(("status", "invalid_offset")) }
        return BleCore.obj(("status", "ok"), ("hex", BleCore.hex(Array(v[offset...]))))
    }

    /// Write requests of one central, applied all or none (iOS delivers a batch and answers it once;
    /// Android passes one). Each is {key, offset, hex}. `prepare`: an Android prepared write.
    func writeRequests(_ e: Int, _ central: String, _ mtu: Int, _ reqs: [BleObj], _ prepare: Bool) -> String {
        if !serverCurrent(e, "write_request") { return "stale" }
        var next: [(String, [UInt8])] = []
        for r in reqs {
            let key = r["key"] as! String
            guard let c = chrOf(key) else { return "not_found" }
            if !c.has("w") && !c.has("c") { return "not_permitted" }
            guard let data = BleCore.fromHex(r["hex"] as? String) else { return "invalid_length" }
            let slot = prepare ? central + "|" + key : key
            let base = next.last { $0.0 == slot }?.1
                ?? (prepare ? prepared.first { $0.0 == slot }?.1 ?? [] : c.value ?? [])
            let offset = r["offset"] as! Int
            if offset > base.count { return "invalid_offset" }
            if offset + data.count > BleCore.writeMax { return "invalid_length" }
            let v = Array(base[0..<offset]) + data
            if let i = next.firstIndex(where: { $0.0 == slot }) { next[i].1 = v } else { next.append((slot, v)) }
        }
        seen(central, mtu)
        for (slot, v) in next {
            if prepare {
                if let i = prepared.firstIndex(where: { $0.0 == slot }) { prepared[i].1 = v } else { prepared.append((slot, v)) }
            } else {
                commit(central, slot, v)
            }
        }
        return "ok"
    }

    /// Android onExecuteWrite: commit (true) or drop this central's prepared writes.
    func executeWrite(_ e: Int, _ central: String, _ execute: Bool) -> String {
        if !serverCurrent(e, "execute_write") { return "stale" }
        let mine = prepared.filter { $0.0.hasPrefix(central + "|") }
        prepared.removeAll { $0.0.hasPrefix(central + "|") }
        if execute {
            for (slot, v) in mine { commit(central, String(slot.dropFirst(central.count + 1)), v) }
        }
        return "ok"
    }

    private func commit(_ central: String, _ key: String, _ v: [UInt8]) {
        guard let c = chrOf(key) else { return }
        c.value = v
        let p = key.split(whereSeparator: { $0 == "#" || $0 == "/" }).map(String.init)
        let rec = BleCore.obj(("central", central), ("kind", "write"), ("service", p[0]), ("char", p[2]),
                              ("char_n", Int(p[3])!), ("hex", BleCore.hex(v)))
        append("request", rec)
        let view = BleCore.obj(("seq", nextSeq), ("t", journal[journal.count - 1].t))
        view.putAll(rec)
        pendingRequests.append(view)
        scheduleFlush()
        persistSoon()
    }

    func centrals(_ call: Int) {
        let out: [Any] = centralList.map { (central, mtu) in
            var subs: [Any] = []
            for s in services { for c in s.chars where c.mode(central) != nil { subs.append(BleCore.keyOf(s, c)) } }
            return BleCore.obj(("central", central), ("mtu", mtu), ("subscriptions", subs))
        }
        ok(call, BleCore.obj(("centrals", out)))
    }

    func centralDrop(_ call: Int, _ central: String?) {
        if !android {
            fail(call, "platform_limit", "iOS has no API to drop a remote central")
            return
        }
        guard let c = central, BleCore.isId(c, "android"), centralMtu(of: c) != nil else {
            fail(call, "unknown_device", "that central is not connected")
            return
        }
        port.centralDrop(c)
        ok(call, BleCore.obj(("dropped", true)))
    }

    // MARK: advertising

    func advertiseStart(_ call: Int, _ servicesCsv: String?, _ name: String?, _ manufacturerId: Int, _ manufacturerHex: String?,
                        _ serviceDataUuid: String?, _ serviceDataHex: String?, _ connectable: Bool, _ mode: String, _ seconds: Int) {
        guard let uuids = BleCore.uuidList(servicesCsv) else {
            fail(call, "bad_value", "services must be up to 20 UUIDs")
            return
        }
        if (manufacturerId < 0) != (manufacturerHex == nil) || manufacturerId > 0xFFFF
            || (manufacturerHex != nil && BleCore.fromHex(manufacturerHex) == nil) {
            fail(call, "bad_value", "manufacturer_id (0 to 65535) and manufacturer_hex go together, as an id and hex bytes")
            return
        }
        let sdUuid = serviceDataUuid.flatMap { BleCore.uuid($0) }
        if (serviceDataUuid == nil) != (serviceDataHex == nil) || (serviceDataUuid != nil && sdUuid == nil)
            || (serviceDataHex != nil && BleCore.fromHex(serviceDataHex) == nil) {
            fail(call, "bad_value", "service_data_uuid and service_data_hex go together, as a UUID and hex bytes")
            return
        }
        if !on {
            fail(call, "unavailable", "Bluetooth is \(adapterState)")
            return
        }
        if adv != 0 {
            fail(call, "busy", "advertising is already running")
            return
        }
        let p = BleCore.obj(("services", uuids as [Any]), ("name", BleCore.nul(name)),
                            ("manufacturerId", BleCore.nul(manufacturerId < 0 ? nil : manufacturerId)),
                            ("manufacturerHex", BleCore.nul(manufacturerHex?.lowercased())),
                            ("serviceDataUuid", BleCore.nul(sdUuid)),
                            ("serviceDataHex", BleCore.nul(serviceDataHex?.lowercased())),
                            ("connectable", connectable), ("mode", mode), ("seconds", seconds))
        advWanted = p
        advUntil = 0
        advCall = call
        startAdvertising(seconds)
    }

    private func startAdvertising(_ seconds: Int) {
        nextAdv += 1
        let t = nextAdv
        let p = advWanted!
        p["seconds"] = seconds
        if let err = port.advertiseStart(epoch, t, p) {
            advWanted = nil
            if advCall >= 0 { refused(advCall, err) } else { record("advertise_end", BleCore.obj(("reason", "failed"))) }
            advCall = -1
            return
        }
        adv = t
        port.timer("advertise_start", t, BleCore.opMs)
    }

    private static func isSet(_ v: Any?) -> Bool { v != nil && !(v is NSNull) }

    /// A JSON value, null when absent (BleObj keeps no nil).
    private static func nul(_ v: Any?) -> Any { v ?? NSNull() }

    /// What this platform really advertises of the request.
    private func applied(_ p: BleObj) -> BleObj {
        BleCore.obj(("name", BleCore.nul(BleCore.isSet(p["name"]) ? (android ? "adapter" : "given") : nil)),
                    ("manufacturer", android && BleCore.isSet(p["manufacturerId"])),
                    ("serviceData", android && BleCore.isSet(p["serviceDataUuid"])),
                    ("connectable", android ? p["connectable"]! : true as Any),
                    ("mode", android ? p["mode"]! : NSNull() as Any))
    }

    func advertiseStarted(_ e: Int, _ t: Int, _ code: String?) {
        if !serverCurrent(e, "advertise_started") { return }
        if t != adv || advertising {
            stale("advertise_started \(t)")
            return
        }
        if let code = code {
            adv = 0
            advWanted = nil
            if advCall >= 0 { fail(advCall, "advertise_failed", code) } else { record("advertise_end", BleCore.obj(("reason", "failed"))) }
            advCall = -1
            return
        }
        if advCall >= 0 && !port.isActive(advCall) {
            // The page already has the timeout: what it asked for does not stay on.
            port.advertiseStop(t)
            adv = 0
            advWanted = nil
            fail(advCall, "timeout", "advertising started after the route timed out")
            advCall = -1
            return
        }
        advertising = true
        let seconds = advWanted!["seconds"] as! Int
        if advUntil == 0 && seconds > 0 { advUntil = port.now() + seconds * 1000 }
        if seconds > 0 { port.timer("advertise", t, max(0, advUntil - port.now())) }
        if advCall >= 0 { ok(advCall, BleCore.obj(("advertising", true), ("applied", applied(advWanted!)))) }
        advCall = -1
        updateHold()
        persistSoon()
    }

    func advertiseStop(_ call: Int) {
        let was = advertising
        if adv != 0 { port.advertiseStop(adv) }
        if advCall >= 0 { fail(advCall, "advertise_failed", "advertise_stop came before the platform started it") }
        advCall = -1
        adv = 0
        advertising = false
        advWanted = nil
        if was { record("advertise_end", BleCore.obj(("reason", "stopped"))) }
        updateHold()
        persistSoon()
        ok(call, BleCore.obj(("advertising", false)))
    }

    // MARK: adapter changes of the server

    /// Bluetooth left on: the server's platform objects of the old epoch are gone.
    private func serverDown() {
        if adv != 0 {
            if advertising { record("advertise_end", BleCore.obj(("reason", "adapter"))) }
            if advCall >= 0 {
                fail(advCall, "unavailable", "Bluetooth is \(adapterState)")
                advWanted = nil
            }
            advCall = -1
            adv = 0
            advertising = false
        }
        for (central, _) in centralList { endCentral(central, "adapter") }
        prepared = []
        if let p = sending { failJob(p.job, "unavailable", "Bluetooth is \(adapterState)") }
        for p in notifyQueue { failJob(p.job, "unavailable", "Bluetooth is \(adapterState)") }
        sending = nil
        notifyQueue = []
        waitingReady = false
        var waiting = addQueue
        if let a = adding { waiting.insert(a, at: 0) }
        for s in waiting where s.call >= 0 {
            services.removeAll { $0 === s }
            fail(s.call, "unavailable", "Bluetooth is \(adapterState)")
            s.call = -1
        }
        adding = nil
        addQueue = []
        for s in services { s.added = false }
    }

    /// Bluetooth is on again: re-apply the page's services and advertising (inside its duration).
    private func serverUp() {
        for s in services where !s.added && s !== adding && !addQueue.contains(where: { $0 === s }) { addQueue.append(s) }
        pumpAdds()
        if let w = advWanted, adv == 0 {
            let seconds = w["seconds"] as! Int
            if advUntil == 0 || seconds == 0 {
                startAdvertising(seconds)
            } else if advUntil > port.now() {
                startAdvertising((advUntil - port.now() + 999) / 1000)
            } else {
                advWanted = nil
                persistSoon()
            }
        }
    }

    // MARK: keep-alive (Android foreground service) and the iOS server file

    /// Links, remote centrals and advertising: what the Android keep-alive service holds the process for.
    func holdCount() -> Int { links.count + centralList.count + (advertising ? 1 : 0) }

    private func updateHold() {
        if !android { return }
        let want = keepAliveWanted && holdCount() > 0
        if want && !holdActive {
            holdGen += 1
            let err = port.keepAlive(true, holdGen)
            holdActive = err == nil
            holdReason = err.map { String($0.split(separator: " ", maxSplits: 1)[0]) }
        } else if !want && holdActive {
            holdActive = false
            holdReason = nil
            _ = port.keepAlive(false, holdGen)
        }
    }

    /// BleLinkService.onStartCommand (Android): whether start generation `g` is still the one to keep running.
    func holdCurrent(_ g: Int) -> Bool { holdActive && g == holdGen }

    /// keep_alive. `backgroundModes`: iOS only, whether the build declares the Bluetooth background modes.
    func keepAlive(_ call: Int, _ enabled: Bool, _ backgroundModes: Bool) {
        keepAliveWanted = enabled
        if !android {
            ok(call, BleCore.obj(("enabled", enabled), ("active", backgroundModes),
                                 ("reason", BleCore.nul(backgroundModes ? nil : "no_background_mode"))))
            return
        }
        updateHold()
        let reason = BleCore.nul(!enabled || holdActive ? nil : holdCount() == 0 ? "idle" : holdReason)
        ok(call, BleCore.obj(("enabled", enabled), ("active", holdActive), ("reason", reason)))
    }

    /// iOS: the server table and advertising, written to ble-server.json (nil: nothing to keep).
    func serverSnapshot() -> BleObj? {
        if services.isEmpty && advWanted == nil { return nil }
        let svcs: [Any] = services.map {
            BleCore.obj(("uuid", $0.uuid), ("primary", $0.primary), ("chars", BleCore.charList($0) as [Any]))
        }
        return BleCore.obj(("services", svcs), ("advertise", BleCore.nul(advWanted)), ("until", advUntil))
    }

    private func persistSoon() {
        if android || persistScheduled { return }
        persistScheduled = true
        port.timer("persist", 0, BleCore.persistMs)
    }

    /// iOS only. What launch does with ble-server.json once the peripheral manager settled:
    /// absent, none; unreadable, move it aside (never overwritten); readable and iOS restored the
    /// server, keep it; readable and no restore call came, an ordinary launch: delete it.
    static func serverFileAction(_ file: String, restored: Bool) -> String {
        switch file {
        case "absent": return "none"
        case "unreadable": return "move_aside"
        default: break
        }
        if restored { return "keep" }
        return "delete"
    }

    /// iOS state restoration of the server. `snapshot`: ble-server.json as JSONSerialization
    /// read it, nil when missing or unreadable. `restoredServices`: the service UUIDs iOS kept;
    /// `wasAdvertising`: whether iOS kept advertising. A restored service the file does not describe
    /// keeps its UUID with no values: reads of it answer `unlikely`. Records `restored`.
    func serverRestored(_ snapshot: [String: Any]?, restoredServices: [String], wasAdvertising: Bool) {
        let saved = (snapshot?["services"] as? [[String: Any]]) ?? []
        var lost: [Any] = []
        for raw in restoredServices {
            guard let u = BleCore.uuid(raw), service(u) == nil else { continue }
            if let s = saved.first(where: { ($0["uuid"] as? String) == u }) {
                let chars = ((s["chars"] as? [[String: Any]]) ?? []).map { c in
                    Chr(c["uuid"] as? String ?? "", c["n"] as? Int ?? 0, c["flags"] as? String ?? "",
                        (c["hex"] as? String).flatMap { BleCore.fromHex($0) })
                }
                let svc = Service(u, s["primary"] as? Bool ?? true, chars)
                svc.added = true
                services.append(svc)
            } else {
                let svc = Service(u, true, [])
                svc.added = true
                svc.lost = true
                services.append(svc)
                lost.append(u)
            }
        }
        if wasAdvertising, let a = snapshot?["advertise"] as? [String: Any] {
            let keys = ["services", "name", "manufacturerId", "manufacturerHex", "serviceDataUuid", "serviceDataHex",
                        "connectable", "mode", "seconds"]
            let p = BleObj()
            for k in keys { p[k] = a[k] ?? NSNull() }
            if !(p["seconds"] is Int) { p["seconds"] = 0 }
            advWanted = p
            nextAdv += 1
            adv = nextAdv
            advertising = true
            advUntil = snapshot?["until"] as? Int ?? 0
            if advUntil > 0 { port.timer("advertise", adv, max(0, advUntil - port.now())) }
        }
        record("restored", BleCore.obj(("services", services.map { $0.uuid } as [Any]), ("advertising", advertising),
                                       ("lost", lost)))
    }

    // MARK: timers

    func timer(_ kind: String, _ token: Int) {
        switch kind {
        case "flush":
            flush()
        case "scan":
            if token == scan && scan != 0 {
                port.scanStop(scan)
                endScan("elapsed")
            } else {
                stale("scan timer \(token)")
            }
        case "connect":
            for l in orderedLinks() where l.gen == token && !l.closed && l.state == "connecting" {
                closeLink(l, "timeout", down: false)
                return
            }
            stale("connect timer \(token)")
        case "pending":
            for l in orderedLinks() where l.pendingTimer == token && !l.closed && l.state == "connecting" {
                closeLink(l, "timeout", down: false)
                return
            }
            stale("pending timer \(token)")
        case "op":
            for l in orderedLinks() {
                if let o = l.inFlight, o.op == token, !l.closed {
                    l.inFlight = nil
                    settle(l, o, "gatt_error", "the operation got no answer in \(BleCore.opMs / 1000) s", nil)
                    closeLink(l, "op_timeout", down: false)
                    return
                }
            }
            stale("op timer \(token)")
        case "close":
            for id in closingOrder where closing[id]!.gen == token {
                port.release(id, token)
                finishClosing(id, confirmed: false)
                return
            }
            stale("close timer \(token)")
        case "wait":
            for id in closingOrder {
                let c = closing[id]!
                if let w = c.waiter, w.token == token {
                    c.waiter = nil
                    fail(w.call, "connect_timeout", "the previous connection did not close in time")
                    return
                }
            }
            stale("wait timer \(token)")
        case "service":
            if let s = adding, s.token == token {
                adding = nil
                port.serviceRemove(s.uuid)
                if s.call >= 0 {
                    services.removeAll { $0 === s }
                    fail(s.call, "gatt_error", "the platform did not confirm the service in \(BleCore.opMs / 1000) s")
                    s.call = -1
                }
                pumpAdds()
            } else {
                stale("service timer \(token)")
            }
        case "notify":
            if let p = sending, p.packet == token {
                sending = nil
                failJob(p.job, "gatt_error", "the notification got no answer in \(BleCore.opMs / 1000) s")
                resolve(p, false)
                pumpNotify()
            } else {
                stale("notify timer \(token)")
            }
        case "advertise_start":
            if token == adv && !advertising {
                port.advertiseStop(token)
                adv = 0
                advWanted = nil
                if advCall >= 0 {
                    fail(advCall, "advertise_failed", "the platform did not answer the advertising start")
                } else {
                    record("advertise_end", BleCore.obj(("reason", "failed")))
                }
                advCall = -1
            } else {
                stale("advertise_start timer \(token)")
            }
        case "advertise":
            if token == adv && advertising {
                port.advertiseStop(token)
                adv = 0
                advertising = false
                advWanted = nil
                record("advertise_end", BleCore.obj(("reason", "elapsed")))
                updateHold()
                persistSoon()
            } else {
                stale("advertise timer \(token)")
            }
        case "persist":
            persistScheduled = false
            port.persist(serverSnapshot())
        default:
            stale("timer \(kind)")
        }
    }

    // MARK: journal

    func events(_ call: Int, _ after: Int, _ max: Int) {
        var out: [Any] = []
        var next = after
        var i = journalHead
        while i < journal.count && out.count < max {
            let r = journal[i]
            i += 1
            if r.seq <= after { continue }
            out.append(BleCore.obj(("seq", r.seq), ("t", r.t), ("event", r.event), ("data", r.data)))
            next = r.seq
        }
        ok(call, BleCore.obj(("records", out), ("next", next), ("dropped", dropped), ("run", run)))
    }
}
```

```swift ios/app/BleExtension.swift
import CoreBluetooth
import Foundation

/// Universal Bluetooth LE for the page: scan, connect, GATT client, GATT server, advertising and raw
/// bytes. Every decision is `BleCore`'s (shared vector table with the Android twin);
/// `BleCentralRadio` and `BlePeripheralRadio` talk to CoreBluetooth. This type owns the bridge side: route parameters, the Bluetooth authorization, one
/// reply per call, events and timers. Main actor, as NativeExtension requires; the core's
/// port is an isolated conformance (`@MainActor BlePort`), so the core runs on the main actor too.
///
/// The CBCentralManager is created only when a route needs Bluetooth (the permission prompt can
/// follow) or when iOS relaunched the app to restore it (`restoreBluetoothCentrals`). The
/// CBPeripheralManager is created only by a server route, or at launch when `ble-server.json`
/// exists (iOS restores a peripheral manager only when it is created again during launch). `state`
/// without `prompt` never creates a manager before the app is authorized, so it never prompts.
///
/// Each route that reaches the core gets a call number; the core answers each exactly once through
/// `reply`, which resumes that route's continuation. A route that timed out while it waited for the
/// manager starts nothing (`call.isActive`).
@MainActor
final class BleExtension: NSObject, NativeExtension, @MainActor BlePort {
    private var ctx: NativeExtContext!
    private var core: BleCore!
    private var radio: BleCentralRadio!
    private var server: BlePeripheralRadio!
    private var nextCall = 0
    private var calls: [Int: Waiting] = [:]
    private var inBackground = false

    private struct Waiting {
        let call: NativeExtCall
        let continuation: CheckedContinuation<NativeExtResult, Never>
    }

    required override init() { super.init() }

    func didLaunch(_ context: NativeExtContext) {
        ctx = context
        core = BleCore(port: self, platform: "ios", run: UUID().uuidString)
        radio = BleCentralRadio(core: core, restoreIdentifier: context.bluetoothRestoreIdentifier("main"))
        server = BlePeripheralRadio(core: core, restoreIdentifier: context.bluetoothRestoreIdentifier("server"),
                                    dataDirectory: context.dataDirectory, log: { [weak context] in context?.log($0) })
        // Both managers watch the same radio; whichever settles tells the core (it ignores a repeat).
        server.onState = { [weak self] state in self?.core.adapter(state) }
        server.launch()
    }

    func restoreBluetoothCentrals(_ identifiers: [String]) {
        guard identifiers.contains(ctx.bluetoothRestoreIdentifier("main")) else { return }
        radio.makeManager()
    }

    func sceneDidChange(_ phase: NativeExtScenePhase) {
        switch phase {
        case .didEnterBackground: inBackground = true
        case .willEnterForeground, .didBecomeActive: inBackground = false
        case .willResignActive: return
        }
        core.background(inBackground)
    }

    /// Routes that read the core's own state and never touch the radio.
    private static let local: Set<String> = ["events", "devices", "links", "scan_stop", "disconnect", "services",
                                             "service_remove", "value_set", "advertise_stop", "centrals", "central_drop",
                                             "keep_alive"]
    private static let radioRoutes: Set<String> = ["scan_start", "connect", "discover", "read", "write", "subscribe",
                                                   "unsubscribe", "rssi", "mtu"]
    /// Routes of the GATT server and the advertiser: they need the peripheral manager.
    private static let serverRoutes: Set<String> = ["service_add", "notify", "advertise_start"]

    func handle(_ call: NativeExtCall) async -> NativeExtResult {
        if call.route == "state" { return await state(call) }
        if BleExtension.local.contains(call.route) { return await run(call) }
        if BleExtension.serverRoutes.contains(call.route) {
            await server.ready(until: call.deadline)
            guard call.isActive else { return .error(code: "timeout", message: "the peripheral manager was not ready before the route timed out") }
        } else {
            guard BleExtension.radioRoutes.contains(call.route) else { return .error(code: "not_registered", message: call.route) }
            await radio.ready(until: call.deadline)
            guard call.isActive else { return .error(code: "timeout", message: "Bluetooth was not ready before the route timed out") }
        }
        if CBManager.authorization == .denied || CBManager.authorization == .restricted {
            return .error(code: "permission_denied", message: "Bluetooth access was denied")
        }
        return await run(call)
    }

    private func state(_ call: NativeExtCall) async -> NativeExtResult {
        let prompt = call.params["prompt"] as? Bool ?? false
        if prompt || radio.hasManager || CBManager.authorization == .allowedAlways {
            if server.hasManager && !radio.hasManager && !prompt {
                await server.ready(until: call.deadline)
                guard call.isActive else { return .error(code: "timeout", message: "state timed out") }
            } else {
                await radio.ready(until: call.deadline)
                guard call.isActive else { return .error(code: "timeout", message: "state timed out") }
            }
        }
        // Either manager reports the one radio; the central's name is used once it exists.
        let name = radio.hasManager ? radio.stateName : (server.stateName ?? radio.stateName)
        let data = BleCore.obj(("state", name),
                               ("authorization", BleCentralRadio.authorizationName(CBManager.authorization)))
        data.putAll(core.stateFields())
        return .ok(data.plain)
    }

    /// Hands the route to the core and waits for its one reply.
    private func run(_ call: NativeExtCall) async -> NativeExtResult {
        nextCall += 1
        let c = nextCall
        return await withCheckedContinuation { (k: CheckedContinuation<NativeExtResult, Never>) in
            calls[c] = Waiting(call: call, continuation: k)
            dispatch(c, call)
        }
    }

    private func dispatch(_ c: Int, _ call: NativeExtCall) {
        let p = call.params
        let id = p["id"] as? String
        func int(_ k: String, _ d: Int) -> Int { p[k] as? Int ?? d }
        func flag(_ k: String, _ d: Bool) -> Bool { p[k] as? Bool ?? d }
        func str(_ k: String) -> String? { p[k] as? String }
        switch call.route {
        case "events": core.events(c, int("after", 0), int("max", 200))
        case "scan_start":
            core.scanStart(c, str("services"), int("seconds", 0), flag("duplicates", false), str("mode") ?? "balanced",
                           inBackground)
        case "scan_stop": core.scanStop(c)
        case "devices": core.devices(c)
        case "connect": core.connect(c, id, flag("auto", false), int("seconds", 10))
        case "disconnect": core.disconnect(c, id)
        case "links": core.links(c)
        case "discover": core.discover(c, id)
        case "read":
            core.read(c, id, str("service"), int("service_n", 0), str("char"), int("char_n", 0), str("descriptor"))
        case "write":
            core.write(c, id, str("service"), int("service_n", 0), str("char"), int("char_n", 0), str("descriptor"),
                       str("hex"), str("b64"), flag("response", true))
        case "subscribe", "unsubscribe":
            core.subscribe(c, id, str("service"), int("service_n", 0), str("char"), int("char_n", 0),
                           call.route == "subscribe")
        case "rssi": core.rssi(c, id)
        case "mtu": core.mtu(c, id, int("size", BleCore.mtuRequest))
        case "service_add": core.serviceAdd(c, str("uuid"), flag("primary", true), str("chars"))
        case "service_remove": core.serviceRemove(c, str("uuid"))
        case "services": core.servicesList(c)
        case "value_set": core.valueSet(c, str("service"), str("char"), int("char_n", 0), str("hex"), str("b64"))
        case "notify":
            core.notify(c, str("service"), str("char"), int("char_n", 0), str("hex"), str("b64"), str("central"))
        case "advertise_start":
            core.advertiseStart(c, str("services"), str("name"), int("manufacturer_id", -1), str("manufacturer_hex"),
                                str("service_data_uuid"), str("service_data_hex"), flag("connectable", true),
                                str("mode") ?? "balanced", int("seconds", 0))
        case "advertise_stop": core.advertiseStop(c)
        case "centrals": core.centrals(c)
        case "central_drop": core.centralDrop(c, str("central"))
        case "keep_alive": core.keepAlive(c, flag("enabled", false), BleExtension.backgroundModes)
        default: reply(c, false, "not_registered", call.route, nil)
        }
    }

    // MARK: BlePort: radio

    func scanStart(_ scan: Int, _ services: [String], _ duplicates: Bool, _ mode: String) -> String? {
        radio.scanStart(scan, services, duplicates, mode)
    }

    func scanStop(_ scan: Int) { radio.scanStop(scan) }

    func connect(_ id: String, _ gen: Int, _ auto: Bool, _ background: Bool) -> String? {
        radio.connect(id, gen, auto, background)
    }

    func close(_ id: String, _ gen: Int) -> Bool { radio.close(id, gen) }

    func release(_ id: String, _ gen: Int) { radio.release(id, gen) }

    func op(_ id: String, _ gen: Int, _ op: Int, _ kind: String, _ key: String?, _ descriptor: String?,
            _ data: [UInt8]?, _ arg: Int) -> String? {
        radio.op(id, gen, op, kind, key, descriptor, data, arg)
    }

    func serviceAdd(_ epoch: Int, _ uuid: String, _ primary: Bool, _ chars: [BleObj]) -> String? {
        server.serviceAdd(epoch, uuid, primary, chars)
    }

    func serviceRemove(_ uuid: String) { server.serviceRemove(uuid) }

    func advertiseStart(_ epoch: Int, _ adv: Int, _ params: BleObj) -> String? { server.advertiseStart(epoch, adv, params) }

    func advertiseStop(_ adv: Int) { server.advertiseStop(adv) }

    func notify(_ epoch: Int, _ packet: Int, _ central: String, _ key: String, _ data: [UInt8], _ indicate: Bool) -> String? {
        server.notify(epoch, packet, central, key, data, indicate)
    }

    /// iOS has no API to drop a remote central; the core answers `platform_limit` before this is reached.
    func centralDrop(_ central: String) {}

    /// Android only (the keep-alive service); iOS keeps links in the background by its background modes.
    func keepAlive(_ start: Bool, _ hold: Int) -> String? { nil }

    func persist(_ snapshot: BleObj?) { server.persist(snapshot) }

    /// Whether this build declares both Bluetooth background modes (the manifest's info_plist rows).
    static var backgroundModes: Bool {
        let modes = Bundle.main.object(forInfoDictionaryKey: "UIBackgroundModes") as? [String] ?? []
        return modes.contains("bluetooth-central") && modes.contains("bluetooth-peripheral")
    }

    // MARK: BlePort: bridge

    func timer(_ kind: String, _ token: Int, _ ms: Int) {
        Task { @MainActor [weak self] in
            try? await Task.sleep(nanoseconds: UInt64(ms) * 1_000_000)
            self?.core.timer(kind, token)
        }
    }

    func reply(_ call: Int, _ ok: Bool, _ code: String?, _ message: String?, _ data: BleObj?) {
        guard let w = calls.removeValue(forKey: call) else { return }
        w.continuation.resume(returning: ok ? .ok(data?.plain ?? [:]) : .error(code: code ?? "handler_error", message: message ?? ""))
    }

    func emit(_ event: String, _ data: BleObj) { ctx.emit(event, data.plain) }

    func isActive(_ call: Int) -> Bool { calls[call]?.call.isActive ?? false }

    func now() -> Int { Int(Date().timeIntervalSince1970 * 1000) }

    func stale(_ what: String) { ctx.log("stale \(what)") }
}
```

```swift ios/app/BlePeripheralRadio.swift
import CoreBluetooth
import Foundation

/// The CoreBluetooth peripheral behind `BleCore`: one CBPeripheralManager with state restoration,
/// the GATT server and the advertiser. It makes no decision of its own; it translates CoreBluetooth
/// callbacks into core inputs and does what the core asks through `BleExtension`'s port.
///
/// The manager is created only when a server route needs Bluetooth, or at launch when
/// `ble-server.json` exists in the extension's data directory: iOS restores a peripheral manager
/// only when the app creates it again with the same identifier during launch, and the NX runtime
/// does not route `.bluetoothPeripherals` (a recorded runtime gap), so the file is the launch signal.
/// Once the manager's first state settled: iOS called `willRestoreState`, so the core adopts the
/// restored services with the file's values (`BleCore.serverRestored`); or it did not, an ordinary
/// launch, and the file is deleted (`BleCore.serverFileAction`). An unreadable file is moved aside,
/// never overwritten, and reads of the restored services then answer `unlikely`.
///
/// Characteristics are created without a value, so every read reaches the core's value store;
/// writes are applied by the core all or none. Bluetooth going off removes the local database and
/// stops advertising (CoreBluetooth's own rule); the core re-adds under its next epoch.
///
/// Executor: the manager is created with `queue: nil`, the main queue, so the delegate conformance
/// is isolated to the main actor (`@MainActor CBPeripheralManagerDelegate`, SE-0470) and each witness
/// checks at run time that it was called on the main queue.
@MainActor
final class BlePeripheralRadio: NSObject, @MainActor CBPeripheralManagerDelegate {
    private let core: BleCore
    private let restoreIdentifier: String
    private let file: URL
    private let log: (String) -> Void
    private(set) var manager: CBPeripheralManager?
    /// The epoch the core gave with its latest add or advertisement; requests arrive for it. -1 while off.
    private var liveEpoch = -1
    /// Services CoreBluetooth holds, by the core's UUID form (restored ones included).
    private var table: [String: CBMutableService] = [:]
    /// Services the core handed over before the manager was powered on, added once it is.
    private var waitingAdds: [(epoch: Int, service: CBMutableService)] = []
    /// Epoch of each add in flight, by UUID: didAdd answers with it.
    private var adding: [String: Int] = [:]
    private var advertiseToken = 0
    private var advertiseEpoch = 0
    private var waitingAdvertise: [String: Any]?
    /// Centrals that subscribed, by id: updateValue sends to one of them.
    private var centrals: [String: CBCentral] = [:]
    private var restoredServices: [CBMutableService]?
    private var restoredAdvertising = false
    private var launchedWithFile = false
    private var settled = false
    private var readyWaiters: [BleCentralRadio.Waiter] = []

    init(core: BleCore, restoreIdentifier: String, dataDirectory: URL, log: @escaping (String) -> Void) {
        self.core = core
        self.restoreIdentifier = restoreIdentifier
        self.file = dataDirectory.appendingPathComponent("ble-server.json")
        self.log = log
        super.init()
    }

    var hasManager: Bool { manager != nil }

    var stateName: String? { manager.map { BleCentralRadio.name($0.state) } }

    /// At launch: create the manager only when the server file says iOS may restore one.
    func launch() {
        guard FileManager.default.fileExists(atPath: file.path) else { return }
        launchedWithFile = true
        makeManager()
    }

    @discardableResult
    func makeManager() -> CBPeripheralManager {
        if let m = manager { return m }
        let m = CBPeripheralManager(delegate: self, queue: nil, options: [
            CBPeripheralManagerOptionRestoreIdentifierKey: restoreIdentifier,
        ])
        manager = m
        return m
    }

    /// Creates the manager when needed and waits until its state is known, or until `deadline`.
    func ready(until deadline: DispatchTime) async {
        let m = makeManager()
        if m.state != .unknown { return }
        let w = BleCentralRadio.Waiter()
        readyWaiters.append(w)
        let ns = deadline.uptimeNanoseconds > DispatchTime.now().uptimeNanoseconds
            ? deadline.uptimeNanoseconds - DispatchTime.now().uptimeNanoseconds : 0
        Task { @MainActor [weak w] in
            try? await Task.sleep(nanoseconds: ns)
            w?.resume()
        }
        await withCheckedContinuation { (c: CheckedContinuation<Void, Never>) in
            if m.state != .unknown {
                c.resume()
            } else {
                w.continuation = c
            }
        }
        readyWaiters.removeAll { $0 === w }
    }

    private var on: Bool { manager?.state == .poweredOn }

    // MARK: keys

    /// The core's key of a local characteristic: one instance per service UUID, so the service number is 0.
    static func key(_ c: CBCharacteristic) -> String? {
        guard let svc = c.service else { return nil }
        var cn = 0
        for x in svc.characteristics ?? [] {
            if x === c { break }
            if x.uuid == c.uuid { cn += 1 }
        }
        return BleCore.key(BleCentralRadio.uuid(svc.uuid), 0, BleCentralRadio.uuid(c.uuid), cn)
    }

    private func resolve(_ key: String) -> CBMutableCharacteristic? {
        let p = key.split(whereSeparator: { $0 == "#" || $0 == "/" }).map(String.init)
        guard p.count == 4, let svc = table[p[0]], var cn = Int(p[3]) else { return nil }
        for c in svc.characteristics ?? [] where BleCentralRadio.uuid(c.uuid) == p[2] {
            if cn == 0 { return c as? CBMutableCharacteristic }
            cn -= 1
        }
        return nil
    }

    static func centralId(_ c: CBCentral) -> String { c.identifier.uuidString }

    /// ATT MTU of a central: the longest update plus the 3-byte header.
    static func mtu(_ c: CBCentral) -> Int { c.maximumUpdateValueLength + 3 }

    static func attError(_ outcome: String, read: Bool) -> CBATTError.Code {
        switch outcome {
        case "ok": return .success
        case "not_found": return .attributeNotFound
        case "not_permitted": return read ? .readNotPermitted : .writeNotPermitted
        case "invalid_offset": return .invalidOffset
        case "invalid_length": return .invalidAttributeValueLength
        default: return .unlikelyError
        }
    }

    // MARK: GATT server

    func serviceAdd(_ epoch: Int, _ uuid: String, _ primary: Bool, _ chars: [BleObj]) -> String? {
        guard let m = manager, m.state == .poweredOn || m.state == .unknown else {
            return "unavailable Bluetooth is \(stateName ?? "unknown")"
        }
        let svc = CBMutableService(type: CBUUID(string: uuid), primary: primary)
        var list: [CBMutableCharacteristic] = []
        for c in chars {
            let f = c["flags"] as? String ?? ""
            var props: CBCharacteristicProperties = []
            var perms: CBAttributePermissions = []
            if f.contains("r") {
                props.insert(.read)
                perms.insert(f.contains("R") ? .readEncryptionRequired : .readable)
            }
            if f.contains("w") { props.insert(.write) }
            if f.contains("c") { props.insert(.writeWithoutResponse) }
            if f.contains("w") || f.contains("c") { perms.insert(f.contains("W") ? .writeEncryptionRequired : .writeable) }
            if f.contains("n") { props.insert(.notify) }
            if f.contains("i") { props.insert(.indicate) }
            // No value: a cached value would make the characteristic read-only and bypass the core's store.
            list.append(CBMutableCharacteristic(type: CBUUID(string: c["uuid"] as? String ?? ""), properties: props,
                                                value: nil, permissions: perms))
        }
        svc.characteristics = list
        liveEpoch = epoch
        if m.state == .poweredOn {
            add(epoch, svc)
        } else {
            // The manager was created after the central one and has not settled yet: add once it is on.
            waitingAdds.append((epoch, svc))
        }
        return nil
    }

    private func add(_ epoch: Int, _ svc: CBMutableService) {
        let u = BleCentralRadio.uuid(svc.uuid)
        adding[u] = epoch
        table[u] = svc
        manager?.add(svc)
    }

    func serviceRemove(_ uuid: String) {
        waitingAdds.removeAll { BleCentralRadio.uuid($0.service.uuid) == uuid }
        guard let svc = table.removeValue(forKey: uuid) else { return }
        if on { manager?.remove(svc) }
    }

    func notify(_ epoch: Int, _ packet: Int, _ central: String, _ key: String, _ data: [UInt8], _ indicate: Bool) -> String? {
        guard let m = manager, m.state == .poweredOn, epoch == liveEpoch else { return "unavailable the GATT server is closed" }
        guard let c = resolve(key) else { return "not_found the characteristic is not in the server" }
        guard let to = centrals[central] else { return "unknown_device the central is no longer subscribed" }
        // iOS sends a notification or an indication by the characteristic's properties and the subscription.
        return m.updateValue(Data(data), for: c, onSubscribedCentrals: [to]) ? nil : "full"
    }

    // MARK: advertiser

    func advertiseStart(_ epoch: Int, _ adv: Int, _ params: BleObj) -> String? {
        guard let m = manager, m.state == .poweredOn || m.state == .unknown else {
            return "unavailable Bluetooth is \(stateName ?? "unknown")"
        }
        // iOS advertises only service UUIDs and a local name (Apple, startAdvertising(_:)).
        var data: [String: Any] = [
            CBAdvertisementDataServiceUUIDsKey: ((params["services"] as? [Any]) ?? []).compactMap { $0 as? String }.map { CBUUID(string: $0) },
        ]
        if let name = params["name"] as? String { data[CBAdvertisementDataLocalNameKey] = name }
        advertiseToken = adv
        advertiseEpoch = epoch
        liveEpoch = epoch
        if m.state == .poweredOn {
            m.startAdvertising(data)
        } else {
            waitingAdvertise = data
        }
        return nil
    }

    func advertiseStop(_ adv: Int) {
        guard adv == advertiseToken else { return }
        advertiseToken = 0
        waitingAdvertise = nil
        if on { manager?.stopAdvertising() }
    }

    // MARK: the server file

    func persist(_ snapshot: BleObj?) {
        do {
            if let s = snapshot {
                let data = try JSONSerialization.data(withJSONObject: s.plain, options: [.sortedKeys])
                // Written to a temporary file and renamed, never in place.
                try data.write(to: file, options: [.atomic])
            } else if FileManager.default.fileExists(atPath: file.path) {
                try FileManager.default.removeItem(at: file)
            }
        } catch {
            log("ble-server.json not written: \((error as NSError).domain) \((error as NSError).code)")
        }
    }

    /// Moved-aside server files are kept for diagnosis, at most this many, the newest.
    static let asideKept = 3

    /// Removes moved-aside server files beyond the newest `asideKept`.
    static func pruneAside(_ dir: URL) {
        let names = ((try? FileManager.default.contentsOfDirectory(atPath: dir.path)) ?? [])
            .filter { $0.hasPrefix("ble-server.unreadable-") && $0.hasSuffix(".json") }
        for name in asideOverflow(names) {
            try? FileManager.default.removeItem(at: dir.appendingPathComponent(name))
        }
    }

    /// The moved-aside names to remove: all but the newest `asideKept`, by their time stamp.
    static func asideOverflow(_ names: [String]) -> [String] {
        func stamp(_ n: String) -> Int {
            Int(n.dropFirst("ble-server.unreadable-".count).dropLast(".json".count)) ?? 0
        }
        let newest = names.sorted { stamp($0) > stamp($1) }
        return Array(newest.dropFirst(asideKept))
    }

    /// Once the first state settled: adopt what iOS restored, or end an ordinary launch's file.
    private func settleLaunch() {
        guard launchedWithFile else { return }
        var snapshot: [String: Any]?
        var state = "absent"
        if let data = try? Data(contentsOf: file) {
            snapshot = (try? JSONSerialization.jsonObject(with: data)) as? [String: Any]
            state = snapshot == nil ? "unreadable" : "readable"
        } else if FileManager.default.fileExists(atPath: file.path) {
            state = "unreadable"
        }
        let restored = restoredServices != nil || restoredAdvertising
        switch BleCore.serverFileAction(state, restored: restored) {
        case "move_aside":
            let dir = file.deletingLastPathComponent()
            let aside = dir.appendingPathComponent("ble-server.unreadable-\(Int(Date().timeIntervalSince1970)).json")
            try? FileManager.default.moveItem(at: file, to: aside)
            BlePeripheralRadio.pruneAside(dir)
        case "delete":
            try? FileManager.default.removeItem(at: file)
        default:
            break
        }
        guard restored else { return }
        let services = restoredServices ?? []
        for s in services { table[BleCentralRadio.uuid(s.uuid)] = s }
        liveEpoch = core.epoch
        if restoredAdvertising { advertiseEpoch = core.epoch }
        core.serverRestored(state == "readable" ? snapshot : nil, restoredServices: services.map { BleCentralRadio.uuid($0.uuid) },
                            wasAdvertising: restoredAdvertising)
        // The core's restored advertisement token is the newest one it made.
        if restoredAdvertising { advertiseToken = core.advertisingToken }
        // Centrals that stayed subscribed while the app was gone.
        for s in services {
            for c in s.characteristics ?? [] {
                guard let mc = c as? CBMutableCharacteristic, let k = BlePeripheralRadio.key(mc) else { continue }
                for central in mc.subscribedCentrals ?? [] {
                    let id = BlePeripheralRadio.centralId(central)
                    centrals[id] = central
                    _ = core.subscription(liveEpoch, id, BlePeripheralRadio.mtu(central), k, BlePeripheralRadio.mode(mc))
                }
            }
        }

        restoredAdvertising = false
    }

    func peripheralManagerDidUpdateState(_ peripheral: CBPeripheralManager) {
        dispatchPrecondition(condition: .onQueue(.main))
        let s = peripheral.state
        if s != .unknown {
            let waiters = readyWaiters
            readyWaiters = []
            waiters.forEach { $0.resume() }
        }
        if s != .poweredOn {
            // CoreBluetooth cleared the local database and stopped advertising; the core re-adds.
            liveEpoch = -1
            table = [:]
            adding = [:]
            centrals = [:]
            advertiseToken = 0
        }
        if !settled && s != .unknown {
            settled = true
            settleLaunch()
        }
        if s != .unknown { onState?(BleCentralRadio.name(s)) }
        guard s == .poweredOn else { return }
        let adds = waitingAdds
        waitingAdds = []
        for (e, svc) in adds where e == core.epoch { add(e, svc) }
        if let data = waitingAdvertise, advertiseEpoch == core.epoch {
            waitingAdvertise = nil
            peripheral.startAdvertising(data)
        }
    }

    }

        dispatchPrecondition(condition: .onQueue(.main))
        guard let k = BlePeripheralRadio.key(characteristic) else { return }
        let id = BlePeripheralRadio.centralId(central)
        centrals[id] = central
        let r = core.subscription(liveEpoch, id, BlePeripheralRadio.mtu(central), k, BlePeripheralRadio.mode(characteristic))

    }

        dispatchPrecondition(condition: .onQueue(.main))
        core.notifyReady(liveEpoch)
    }

    func peripheralManager(_ peripheral: CBPeripheralManager, didReceiveRead request: CBATTRequest) {
        dispatchPrecondition(condition: .onQueue(.main))
        let id = BlePeripheralRadio.centralId(request.central)
        guard let k = BlePeripheralRadio.key(request.characteristic) else {
            peripheral.respond(to: request, withResult: .attributeNotFound)
            return
        }
        let r = core.readRequest(liveEpoch, id, BlePeripheralRadio.mtu(request.central), k, request.offset)
        let status = r["status"] as? String ?? "unlikely"
        if status == "ok", let hex = r["hex"] as? String, let bytes = BleCore.fromHex(hex) { request.value = Data(bytes) }
        peripheral.respond(to: request, withResult: BlePeripheralRadio.attError(status, read: true))
    }

    func peripheralManager(_ peripheral: CBPeripheralManager, didReceiveWrite requests: [CBATTRequest]) {
        dispatchPrecondition(condition: .onQueue(.main))
        guard let first = requests.first else { return }
        let id = BlePeripheralRadio.centralId(first.central)
        var reqs: [BleObj] = []
        for q in requests {
            guard let k = BlePeripheralRadio.key(q.characteristic) else {
                peripheral.respond(to: first, withResult: .attributeNotFound)
                return
            }
            reqs.append(BleCore.obj(("key", k), ("offset", q.offset), ("hex", BleCore.hex([UInt8](q.value ?? Data())))))
        }
        // iOS delivers one batch and takes one answer, for the first request (all or none).
        let r = core.writeRequests(liveEpoch, id, BlePeripheralRadio.mtu(first.central), reqs, false)
        peripheral.respond(to: first, withResult: BlePeripheralRadio.attError(r, read: false))
    }
```

```java android/ble/src/main/java/despia/ext/ble/AndroidRadio.java
 * the keep-alive service start and the adapter receiver. It makes no decision of its own. Every

    String scanStart(int scan, List<String> services, boolean duplicates, String mode) {
        BluetoothAdapter a = adapter();
        BluetoothLeScanner s = a == null || !a.isEnabled() ? null : a.getBluetoothLeScanner();
        if (s == null) return "unavailable Bluetooth is " + adapterState();
        List<ScanFilter> filters = new ArrayList<>();
        for (String u : services) {
            filters.add(new ScanFilter.Builder().setServiceUuid(ParcelUuid.fromString(u)).build());
        }
        int m = "low_power".equals(mode) ? ScanSettings.SCAN_MODE_LOW_POWER
                : "low_latency".equals(mode) ? ScanSettings.SCAN_MODE_LOW_LATENCY : ScanSettings.SCAN_MODE_BALANCED;
        ScanSettings settings = new ScanSettings.Builder().setScanMode(m).build();
        Set<String> seen = Collections.synchronizedSet(new HashSet<>());
        ScanCallback cb = new ScanCallback() {
            @Override
            public void onScanResult(int callbackType, ScanResult r) {
                String id = r.getDevice().getAddress();
                boolean first = seen.add(id);
                Map<String, Object> adv = duplicates || first ? advertisement(r) : null;
                main.post(() -> {
                    if (adv != null) core.device(scan, id, adv);
                });
            }

            @Override
            public void onBatchScanResults(List<ScanResult> results) {
                List<Object[]> batch = new ArrayList<>();
                for (ScanResult r : results) {
                    String id = r.getDevice().getAddress();
                    if (seen.add(id) || duplicates) batch.add(new Object[]{id, advertisement(r)});
                }
                main.post(() -> {
                    for (Object[] e : batch) core.device(scan, (String) e[0], castMap(e[1]));
                });
            }

            @Override
            public void onScanFailed(int errorCode) {
                main.post(() -> core.scanFailed(scan, "error " + errorCode));
            }
        };
        try {
            s.startScan(filters.isEmpty() ? null : filters, settings, cb);
        } catch (RuntimeException e) {
            // SecurityException (a permission revoked meanwhile) or IllegalStateException (Bluetooth off).
            return "scan_failed the scan could not start (" + e.getClass().getSimpleName() + ")";
        }
        scanner = s;
        scanCallback = cb;
        return null;
    }

        return (Map<String, Object>) o;
    }

        scanCallback = null;

        } catch (RuntimeException ignored) {

        }

    /** Every advertisement field the platform reports, in the core's record form. */
    static Map<String, Object> advertisement(ScanResult r) {
        Map<String, Object> adv = BleCore.obj();
        ScanRecord rec = r.getScanRecord();
        String name = rec == null ? null : rec.getDeviceName();
        if (name != null) adv.put("name", name);
        adv.put("rssi", r.getRssi());
        if (Build.VERSION.SDK_INT >= 26) adv.put("connectable", r.isConnectable());
        List<Object> services = new ArrayList<>();
        List<Object> manufacturer = new ArrayList<>();
        List<Object> serviceData = new ArrayList<>();
        if (rec != null) {
            if (rec.getServiceUuids() != null) {
                for (ParcelUuid u : rec.getServiceUuids()) services.add(u.getUuid().toString().toLowerCase(Locale.ROOT));
            }
            SparseArray<byte[]> m = rec.getManufacturerSpecificData();
            if (m != null) {
                for (int i = 0; i < m.size(); i++) {
                    manufacturer.add(BleCore.obj("id", m.keyAt(i), "hex", BleCore.hex(copy(m.valueAt(i)))));
                }
            }
            Map<ParcelUuid, byte[]> sd = rec.getServiceData();
            if (sd != null) {
                for (Map.Entry<ParcelUuid, byte[]> e : sd.entrySet()) {
                    serviceData.add(BleCore.obj("uuid", e.getKey().getUuid().toString().toLowerCase(Locale.ROOT),
                            "hex", BleCore.hex(copy(e.getValue()))));
                }
            }
            if (rec.getTxPowerLevel() != Integer.MIN_VALUE) adv.put("txPower", rec.getTxPowerLevel());
        }
        adv.put("services", services);
        adv.put("manufacturer", manufacturer);
        adv.put("serviceData", serviceData);
        return adv;

    String connect(String id, int gen, boolean auto, boolean background) {
        BluetoothAdapter a = adapter();
        if (a == null || !a.isEnabled()) return "unavailable Bluetooth is " + adapterState();
        if (!BluetoothAdapter.checkBluetoothAddress(id)) return "unknown_device " + id;
        Session s = new Session(id, gen);
        try {
            BluetoothDevice d = a.getRemoteDevice(id);
            // A new callback object per attempt (finding 3): a late callback of an older attempt
            // carries the older gen and is dropped by the core. autoConnect only for the automatic
            // reconnect, which then waits for the device without a time limit.
            s.gatt = d.connectGatt(app, background, s, BluetoothDevice.TRANSPORT_LE);
        } catch (RuntimeException e) {
            return "connect_failed " + e.getClass().getSimpleName();
        }
        if (s.gatt == null) return "connect_failed the stack refused the connection";
        sessions.put(gen, s);
        return null;
    }

    private void connectionState(Session s, int status, int newState) {
        if (newState == BluetoothProfile.STATE_CONNECTED && status == BluetoothGatt.GATT_SUCCESS) {
            s.connected = true;
            core.connected(s.id, s.gen, 23);
            return;
        }
        if (newState == BluetoothProfile.STATE_DISCONNECTED || status != BluetoothGatt.GATT_SUCCESS) {
            // The platform's own duty: a disconnected BluetoothGatt is closed by its owner.
            closeGatt(s);
            core.disconnected(s.id, s.gen, status == BluetoothGatt.GATT_SUCCESS ? "remote" : "status " + status,
                    status == BluetoothGatt.GATT_SUCCESS ? null : gattError(status));
        }
    }

    /** The GATT status of a failed or dropped link as the page sees it (the same shape as iOS's
     *  NSError domain, code and description). */
    static java.util.Map<String, Object> gattError(int status) {
        return BleCore.platformError("android.bluetooth.BluetoothGatt", status, "GATT status " + status);
    }

    private void closeGatt(Session s) {
        if (sessions.remove(s.gen) == null) return;
        try {
            s.gatt.close();
        } catch (RuntimeException ignored) {
            // Already closed by the stack.
        }
    }

    boolean close(String id, int gen) {
        Session s = sessions.get(gen);
        if (s == null) return true;
        if (!s.connected) {
            // A pending connect gives no callback when cancelled: close at once, confirmed.
            try {
                s.gatt.disconnect();
            } catch (RuntimeException ignored) {
                // Nothing to cancel.
            }
            closeGatt(s);
            return true;
        }
        s.closing = true;
        try {
            s.gatt.disconnect();
        } catch (RuntimeException e) {
            closeGatt(s);
            return true;
        }
        return false;
    }

    void release(String id, int gen) {
        Session s = sessions.get(gen);
        if (s != null) closeGatt(s);
    }

    private void discovered(Session s, int status) {
        if (!"discover".equals(s.pendingKind)) return;
        if (status != BluetoothGatt.GATT_SUCCESS) {
            fail(s, "gatt_error", "service discovery failed (status " + status + ")");
            return;
        }
        List<Object> out = new ArrayList<>();
        Map<String, Integer> sn = new HashMap<>();
        for (BluetoothGattService svc : s.gatt.getServices()) {
            String su = svc.getUuid().toString().toLowerCase(Locale.ROOT);
            int n = sn.merge(su, 1, Integer::sum) - 1;
            List<Object> chars = new ArrayList<>();
            Map<String, Integer> cn = new HashMap<>();
            for (BluetoothGattCharacteristic c : svc.getCharacteristics()) {
                String cu = c.getUuid().toString().toLowerCase(Locale.ROOT);
                int m = cn.merge(cu, 1, Integer::sum) - 1;
                List<Object> descs = new ArrayList<>();
                for (BluetoothGattDescriptor d : c.getDescriptors()) descs.add(d.getUuid().toString().toLowerCase(Locale.ROOT));
                chars.add(BleCore.obj("uuid", cu, "n", m, "properties", properties(c.getProperties()), "descriptors", descs));
            }
            List<Object> included = new ArrayList<>();
            for (BluetoothGattService inc : svc.getIncludedServices()) included.add(inc.getUuid().toString().toLowerCase(Locale.ROOT));
            out.add(BleCore.obj("uuid", su, "n", n, "primary", svc.getType() == BluetoothGattService.SERVICE_TYPE_PRIMARY,
                    "included", included, "characteristics", chars));
        }
        complete(s, null, null, BleCore.obj("services", out));
    }

    static List<Object> properties(int p) {
        List<Object> out = new ArrayList<>();
        if ((p & BluetoothGattCharacteristic.PROPERTY_BROADCAST) != 0) out.add("broadcast");
        if ((p & BluetoothGattCharacteristic.PROPERTY_READ) != 0) out.add("read");
        if ((p & BluetoothGattCharacteristic.PROPERTY_WRITE_NO_RESPONSE) != 0) out.add("writeWithoutResponse");
        if ((p & BluetoothGattCharacteristic.PROPERTY_WRITE) != 0) out.add("write");
        if ((p & BluetoothGattCharacteristic.PROPERTY_NOTIFY) != 0) out.add("notify");
        if ((p & BluetoothGattCharacteristic.PROPERTY_INDICATE) != 0) out.add("indicate");
        if ((p & BluetoothGattCharacteristic.PROPERTY_SIGNED_WRITE) != 0) out.add("authenticatedSignedWrites");
        if ((p & BluetoothGattCharacteristic.PROPERTY_EXTENDED_PROPS) != 0) out.add("extendedProperties");
        return out;
    }

    /** The key of a characteristic: service and characteristic UUIDs with their instance numbers. */
    static String keyOf(BluetoothGatt g, BluetoothGattCharacteristic c) {
        BluetoothGattService svc = c.getService();
        int sn = 0;
        for (BluetoothGattService x : g.getServices()) {
            if (x == svc) break;
            if (x.getUuid().equals(svc.getUuid())) sn++;
        }
        int cn = 0;
        for (BluetoothGattCharacteristic x : svc.getCharacteristics()) {
            if (x == c) break;
            if (x.getUuid().equals(c.getUuid())) cn++;
        }
        return BleCore.key(svc.getUuid().toString().toLowerCase(Locale.ROOT), sn, c.getUuid().toString().toLowerCase(Locale.ROOT), cn);
    }

    private static BluetoothGattCharacteristic resolve(BluetoothGatt g, String key) {
        String[] p = key.split("[#/]");
        UUID su = UUID.fromString(p[0]), cu = UUID.fromString(p[2]);
        int sn = Integer.parseInt(p[1]), cn = Integer.parseInt(p[3]);
        for (BluetoothGattService svc : g.getServices()) {
            if (!svc.getUuid().equals(su) || sn-- > 0) continue;
            for (BluetoothGattCharacteristic c : svc.getCharacteristics()) {
                if (c.getUuid().equals(cu) && cn-- == 0) return c;
            }
            return null;
        }
        return null;
    }

    String op(String id, int gen, int op, String kind, String key, String descriptor, byte[] data, int arg) {
        Session s = sessions.get(gen);
        if (s == null || !s.connected) return "not_connected the link is not connected";
        BluetoothGatt g = s.gatt;
        try {
            if ("mtu".equals(kind)) {
                return begin(s, op, kind, null, g.requestMtu(arg), "requestMtu");
            }
            if ("discover".equals(kind)) {
                return begin(s, op, kind, null, g.discoverServices(), "discoverServices");
            }
            if ("rssi".equals(kind)) {
                return begin(s, op, kind, null, g.readRemoteRssi(), "readRemoteRssi");
            }
            BluetoothGattCharacteristic c = resolve(g, key);
            if (c == null) return "not_found no such characteristic (run discover first)";
            int props = c.getProperties();
            BluetoothGattDescriptor d = null;
            if (descriptor != null) {
                d = c.getDescriptor(UUID.fromString(descriptor));
                if (d == null) return "not_found no such descriptor";
            }
            switch (kind) {
                case "read":
                    if (d != null) return begin(s, op, kind, null, g.readDescriptor(d), "readDescriptor");
                    if ((props & BluetoothGattCharacteristic.PROPERTY_READ) == 0) return "not_permitted the characteristic is not readable";
                    return begin(s, op, kind, null, g.readCharacteristic(c), "readCharacteristic");
                case "write":
                    if (d != null) {
                        if (CCCD.equals(d.getUuid())) return "not_permitted the CCCD is written by subscribe";
                        return begin(s, op, kind, null, writeDescriptor(g, d, data), "writeDescriptor");
                    }
                    if ((props & BluetoothGattCharacteristic.PROPERTY_WRITE) == 0) {
                        return "not_permitted the characteristic does not accept a write with response";
                    }
                    return begin(s, op, kind, null, writeCharacteristic(g, c, data, BluetoothGattCharacteristic.WRITE_TYPE_DEFAULT),
                            "writeCharacteristic");
                case "wnr":
                    if ((props & BluetoothGattCharacteristic.PROPERTY_WRITE_NO_RESPONSE) == 0) {
                        return "not_permitted the characteristic does not accept a write without response";
                    }
                    return begin(s, op, kind, null, writeCharacteristic(g, c, data, BluetoothGattCharacteristic.WRITE_TYPE_NO_RESPONSE),
                            "writeCharacteristic");
                case "sub":
                case "unsub": {
                    boolean on = "sub".equals(kind);
                    boolean indicate = (props & BluetoothGattCharacteristic.PROPERTY_INDICATE) != 0
                            && (props & BluetoothGattCharacteristic.PROPERTY_NOTIFY) == 0;
                    if ((props & (BluetoothGattCharacteristic.PROPERTY_NOTIFY | BluetoothGattCharacteristic.PROPERTY_INDICATE)) == 0) {
                        return "not_permitted the characteristic neither notifies nor indicates";
                    }
                    BluetoothGattDescriptor cccd = c.getDescriptor(CCCD);
                    if (cccd == null) return "not_found the characteristic has no CCCD";
                    if (!g.setCharacteristicNotification(c, on)) return "gatt_error setCharacteristicNotification was refused";
                    byte[] v = !on ? BluetoothGattDescriptor.DISABLE_NOTIFICATION_VALUE
                            : indicate ? BluetoothGattDescriptor.ENABLE_INDICATION_VALUE : BluetoothGattDescriptor.ENABLE_NOTIFICATION_VALUE;
                    return begin(s, op, kind, on ? (indicate ? "indicate" : "notify") : null, writeDescriptor(g, cccd, v), "writeDescriptor");
                }
                default:
                    return "bad_value unknown operation " + kind;
            }
        } catch (SecurityException e) {
            return "permission_denied Bluetooth access was revoked";
        } catch (RuntimeException e) {
            return "gatt_error " + e.getClass().getSimpleName();
        }
    }

    private static String begin(Session s, int op, String kind, String mode, boolean accepted, String call) {
        if (!accepted) return "gatt_error " + call + " was refused by the stack";
        s.pendingOp = op;
        s.pendingKind = kind;
        s.pendingMode = mode;
        return null;

    private void done(Session s, int status, Map<String, Object> data) {
        if (status != BluetoothGatt.GATT_SUCCESS) {
            fail(s, status == BluetoothGatt.GATT_READ_NOT_PERMITTED || status == BluetoothGatt.GATT_WRITE_NOT_PERMITTED
                    ? "not_permitted" : "gatt_error", "status " + status);
            return;
        }
        complete(s, null, null, data);
    }

    private void fail(Session s, String code, String message) {
        complete(s, code, message, null);
    }

    private void complete(Session s, String code, String message, Map<String, Object> data) {
        int op = s.pendingOp;
        s.pendingKind = null;
        s.pendingMode = null;
        core.opDone(s.id, s.gen, op, code, message, data);
    }

    /**
     * The GATT server of one epoch: its own platform object and its own callback, like a client
     * Session. Bluetooth going off ends it; the core re-adds its services under the next epoch.

    final class Server extends BluetoothGattServerCallback {
        final int epoch;
        BluetoothGattServer gatt;
        final Map<String, BluetoothGattService> table = new HashMap<>();
        /** The notification packet onNotificationSent answers (the core sends one at a time). */

        Server(int epoch) {
            this.epoch = epoch;

        @Override
        public void onConnectionStateChange(BluetoothDevice device, int status, int newState) {
            String id = device.getAddress();
            boolean up = newState == BluetoothProfile.STATE_CONNECTED;

        }

        @Override
        public void onServiceAdded(int status, BluetoothGattService service) {

            String id = device.getAddress();
            boolean cccd = CCCD.equals(d.getUuid());

            main.post(() -> cccdRead(this, device, id, requestId, offset, cccd, k));
        }

        @Override
        public void onDescriptorWriteRequest(BluetoothDevice device, int requestId, BluetoothGattDescriptor d,

            String k = serverKey(d.getCharacteristic());

        }

        public void onExecuteWrite(BluetoothDevice device, int requestId, boolean execute) {
            String id = device.getAddress();
            main.post(() -> respond(this, device, requestId, status(core.executeWrite(epoch, id, execute), false), 0, null));
        }

        @Override
        public void onNotificationSent(BluetoothDevice device, int status) {
            main.post(() -> core.notifySent(epoch, packet, status == BluetoothGatt.GATT_SUCCESS ? null : "status " + status));
        }

    private Server server;

    private BluetoothManager manager() {
        return (BluetoothManager) app.getSystemService(Context.BLUETOOTH_SERVICE);
    }

    /** The server of {@code epoch}, opened on first use; an older epoch's server is closed first. */
    private Server serverFor(int epoch) {
        if (server != null && server.epoch == epoch) return server;
        closeServer();
        BluetoothManager m = manager();
        if (m == null) return null;
        Server s = new Server(epoch);
        try {
            s.gatt = m.openGattServer(app, s);
        } catch (RuntimeException e) {
            return null;
        }
        if (s.gatt == null) return null;
        server = s;
        return s;
    }

    private void closeServer() {
        Server s = server;
        server = null;
        if (s == null) return;
        try {
            s.gatt.close();
        } catch (RuntimeException ignored) {
            // The stack already ended it (Bluetooth off).
        }
    }

    /** The core's key of a local characteristic: one instance per service UUID, so the service number is 0. */
    static String serverKey(BluetoothGattCharacteristic c) {
        if (c == null) return null;
        BluetoothGattService svc = c.getService();
        int cn = 0;
        for (BluetoothGattCharacteristic x : svc.getCharacteristics()) {
            if (x == c) break;
            if (x.getUuid().equals(c.getUuid())) cn++;
        }
        return BleCore.key(svc.getUuid().toString().toLowerCase(Locale.ROOT), 0, c.getUuid().toString().toLowerCase(Locale.ROOT), cn);
    }

    private static BluetoothGattCharacteristic resolveLocal(Server s, String key) {
        String[] p = key.split("[#/]");
        BluetoothGattService svc = s.table.get(p[0]);
        if (svc == null) return null;
        UUID cu = UUID.fromString(p[2]);
        int cn = Integer.parseInt(p[3]);
        for (BluetoothGattCharacteristic c : svc.getCharacteristics()) {
            if (c.getUuid().equals(cu) && cn-- == 0) return c;
        }
        return null;
    }

    /** A central's link to this server; links this app opened as a client are the client's, not a central. */
    private void serverConnection(Server s, String id, boolean up) {
        if (up) {
            for (Session x : sessions.values()) if (x.id.equals(id)) return;
            core.centralConnected(s.epoch, id, 23);
        } else {
            core.centralDisconnected(s.epoch, id);
        }
    }

    /** The ATT status of a core outcome. */
    static int status(String outcome, boolean read) {
        switch (outcome) {
            case "ok":
                return BluetoothGatt.GATT_SUCCESS;
            case "not_found":
                return ATT_ATTRIBUTE_NOT_FOUND;
            case "not_permitted":
                return read ? BluetoothGatt.GATT_READ_NOT_PERMITTED : BluetoothGatt.GATT_WRITE_NOT_PERMITTED;
            case "invalid_offset":
                return BluetoothGatt.GATT_INVALID_OFFSET;
            case "invalid_length":
                return BluetoothGatt.GATT_INVALID_ATTRIBUTE_LENGTH;
            default:
                return ATT_UNLIKELY;
        }
    }

    private void respond(Server s, BluetoothDevice device, int requestId, int status, int offset, byte[] value) {
        try {
            s.gatt.sendResponse(device, requestId, status, offset, value);
        } catch (RuntimeException ignored) {
            // The server of that epoch is closed; the central's request ends with the link.
        }
    }

    private void readRequest(Server s, BluetoothDevice device, String id, int requestId, int offset, String key) {
        Map<String, Object> r = key == null ? BleCore.obj("status", "not_found") : core.readRequest(s.epoch, id, 0, key, offset);
        String hex = (String) r.get("hex");
        respond(s, device, requestId, status((String) r.get("status"), true), offset, hex == null ? null : BleCore.fromHex(hex));
    }

    private void writeRequest(Server s, BluetoothDevice device, String id, int requestId, String key, boolean prepared,
                              boolean responseNeeded, int offset, byte[] value) {
        String r = key == null ? "not_found" : core.writeRequests(s.epoch, id, 0,
                Collections.singletonList(BleCore.obj("key", key, "offset", offset, "hex", BleCore.hex(value))), prepared);
        if (responseNeeded) respond(s, device, requestId, status(r, false), offset, prepared ? value : null);
    }

    /** The CCCD is served here (Android leaves it to the app); any other descriptor is not in the table. */
    private void cccdRead(Server s, BluetoothDevice device, String id, int requestId, int offset, boolean cccd, String key) {
        if (!cccd || key == null) {
            respond(s, device, requestId, ATT_ATTRIBUTE_NOT_FOUND, offset, null);
            return;
        }
        byte[] v = BleCore.fromHex(core.cccd(id, key));
        if (offset > v.length) {
            respond(s, device, requestId, BluetoothGatt.GATT_INVALID_OFFSET, offset, null);
            return;
        }
        respond(s, device, requestId, BluetoothGatt.GATT_SUCCESS, offset, java.util.Arrays.copyOfRange(v, offset, v.length));
    }

    private void cccdWrite(Server s, BluetoothDevice device, String id, int requestId, boolean cccd, String key,
                           boolean prepared, boolean responseNeeded, int offset, byte[] value) {
        int st;
        if (!cccd || key == null) {
            st = ATT_ATTRIBUTE_NOT_FOUND;
        } else if (prepared || offset != 0 || value.length != 2) {
            st = BluetoothGatt.GATT_INVALID_ATTRIBUTE_LENGTH;
        } else {
            String mode = (value[0] & 2) != 0 ? "indicate" : (value[0] & 1) != 0 ? "notify" : null;
            st = status(core.subscription(s.epoch, id, 0, key, mode), false);
        }
        if (responseNeeded) respond(s, device, requestId, st, offset, null);
    }

    String serviceAdd(int epoch, String uuid, boolean primary, List<Map<String, Object>> chars) {
        BluetoothAdapter a = adapter();
        if (a == null || !a.isEnabled()) return "unavailable Bluetooth is " + adapterState();
        Server s = serverFor(epoch);
        if (s == null) return "unavailable the GATT server could not be opened";
        BluetoothGattService svc = new BluetoothGattService(UUID.fromString(uuid),
                primary ? BluetoothGattService.SERVICE_TYPE_PRIMARY : BluetoothGattService.SERVICE_TYPE_SECONDARY);
        for (Map<String, Object> c : chars) {
            String f = (String) c.get("flags");
            int props = 0, perms = 0;
            if (f.indexOf('r') >= 0) {
                props |= BluetoothGattCharacteristic.PROPERTY_READ;
                perms |= f.indexOf('R') >= 0 ? BluetoothGattCharacteristic.PERMISSION_READ_ENCRYPTED
                        : BluetoothGattCharacteristic.PERMISSION_READ;
            }
            if (f.indexOf('w') >= 0) props |= BluetoothGattCharacteristic.PROPERTY_WRITE;
            if (f.indexOf('c') >= 0) props |= BluetoothGattCharacteristic.PROPERTY_WRITE_NO_RESPONSE;
            if (f.indexOf('w') >= 0 || f.indexOf('c') >= 0) {
                perms |= f.indexOf('W') >= 0 ? BluetoothGattCharacteristic.PERMISSION_WRITE_ENCRYPTED
                        : BluetoothGattCharacteristic.PERMISSION_WRITE;
            }
            if (f.indexOf('n') >= 0) props |= BluetoothGattCharacteristic.PROPERTY_NOTIFY;
            if (f.indexOf('i') >= 0) props |= BluetoothGattCharacteristic.PROPERTY_INDICATE;
            BluetoothGattCharacteristic ch = new BluetoothGattCharacteristic(UUID.fromString((String) c.get("uuid")), props, perms);
            if (f.indexOf('n') >= 0 || f.indexOf('i') >= 0) {
                ch.addDescriptor(new BluetoothGattDescriptor(CCCD,
                        BluetoothGattDescriptor.PERMISSION_READ | BluetoothGattDescriptor.PERMISSION_WRITE));
            }
            svc.addCharacteristic(ch);
        }
        try {
            if (!s.gatt.addService(svc)) return "gatt_error addService was refused by the stack";
        } catch (SecurityException e) {
            return "permission_denied Bluetooth access was revoked";
        } catch (RuntimeException e) {
            return "gatt_error " + e.getClass().getSimpleName();
        }
        s.table.put(uuid, svc);
        return null;
    }

    void serviceRemove(String uuid) {
        Server s = server;
        BluetoothGattService svc = s == null ? null : s.table.remove(uuid);

        } catch (SecurityException e) {

        } catch (RuntimeException e) {

        return null;
    }

    /**
     * Starts (hold generation {@code hold}) or ends {@link BleLinkService}. A start needs a started
     * activity: from API 31 a foreground service cannot start from the background.
     */
    String keepAlive(boolean start, int hold, boolean foreground) {
        if (!start) {
            BleLinkService.release();
            return null;
        }
        if (!foreground) return "not_foreground no activity is started";
        if (!connectedDeviceAllowed()) return "not_permitted no permission for a connectedDevice foreground service";
        Intent i = new Intent(app, BleLinkService.class).putExtra(BleLinkService.EXTRA_HOLD, hold);
        try {
            if (Build.VERSION.SDK_INT >= 26) app.startForegroundService(i);
            else app.startService(i);
        } catch (SecurityException e) {
            return "not_permitted " + e.getClass().getSimpleName();
        } catch (IllegalStateException e) {
            // ForegroundServiceStartNotAllowedException (API 31) is an IllegalStateException.
            return "not_foreground " + e.getClass().getSimpleName();
        }
        return null;
    }

    /**
     * Android 14 (API 34) refuses {@code startForeground} with type {@code connectedDevice} unless the
     * app holds one of the permissions that type lists, and a service started with
     * {@code startForegroundService} that stops before entering the foreground crashes the app. So
     * the service is only started when the type's prerequisite holds. The list is the platform's,
     * from the foreground service types page (developer.android.com, read 2026-11-20).
     */
    boolean connectedDeviceAllowed() {
        if (Build.VERSION.SDK_INT < 34) return true;
        for (String p : CONNECTED_DEVICE_PERMISSIONS) {
            if (app.checkSelfPermission(p) == PackageManager.PERMISSION_GRANTED) return true;
        }
        return false;
    }

        "android.permission.BLUETOOTH_CONNECT", "android.permission.BLUETOOTH_ADVERTISE",
        "android.permission.BLUETOOTH_SCAN", "android.permission.CHANGE_NETWORK_STATE",
        "android.permission.CHANGE_WIFI_STATE", "android.permission.CHANGE_WIFI_MULTICAST_STATE",
        "android.permission.NFC", "android.permission.TRANSMIT_IR", "android.permission.UWB_RANGING",
```

```java android/ble/src/main/java/despia/ext/ble/BleCore.java
/**
 * Every decision of the BLE extension, as one state machine on the main thread. Pure Java: no
 * android import, so the same test table runs against this class on a
 * plain JVM and against its Swift twin BleCore.swift. The radio files only translate platform
 * callbacks into the inputs below and execute what the {@link Port} is asked to do.
 *
 * <p>Tokens. {@code gen} names one connection attempt, {@code scan} one scan, {@code op} one GATT
 * operation step; all come from counters that never repeat in a process. Every radio callback and
 * every timer carries its token back; one whose token is not current changes nothing, replies to
 * nothing and is counted as a stale drop (rules 1, 2 and 7 of the design).
 *
 * <p>Port calls never call back into the core: what the platform confirms at once comes back as the
 * return value (an error text, or {@code true} for a close that needs no callback).
 */
public final class BleCore {

    /** What the core asks of the platform side. Implemented by the radio adapter and by test fakes. */
    public interface Port {
        /** Start a scan. Returns null when the platform accepted it, else "code message". */
        String scanStart(int scan, List<String> services, boolean duplicates, String mode);

        void scanStop(int scan);

        /** Start connection attempt {@code gen}. {@code background}: an automatic reconnect. */
        String connect(String id, int gen, boolean auto, boolean background);

        /** Begin closing {@code gen}. True when the platform confirmed the close now (no callback follows). */
        boolean close(String id, int gen);

        /** The close of {@code gen} was not confirmed in time: release the platform object without waiting. */
        void release(String id, int gen);

        /**
         * Hand one GATT step to the platform. Kinds: mtu (arg = size), discover, read, write
         * (with response), wnr (one chunk without response), sub, unsub, rssi. Returns null when
         * the platform accepted it, else "code message" (the step settles at once).
         */
        String op(String id, int gen, int op, String kind, String key, String descriptor, byte[] data, int arg);

        void timer(String kind, int token, long ms);

        void reply(int call, boolean ok, String code, String message, Map<String, Object> data);

        void emit(String event, Map<String, Object> data);

        boolean isActive(int call);

        long now();

        /** A callback or timer for a token that is no longer current was dropped. */
        void stale(String what);

        // Peripheral role. Server and advertiser callbacks come back with the epoch they were made in.

        /** Add one service to the platform's GATT server. null when accepted (serviceAdded follows). */
        String serviceAdd(int epoch, String uuid, boolean primary, List<Map<String, Object>> chars);

        void serviceRemove(String uuid);

        /** Start advertising as token {@code adv}. null when accepted (advertiseStarted follows). */
        String advertiseStart(int epoch, int adv, Map<String, Object> params);

        void advertiseStop(int adv);

        /**
         * Send one notification or indication packet to one central. null: handed over now; "pending":
         * notifySent follows; "full": the transmit queue is full, retry after notifyReady; else
         * "code message" (the packet settles at once).
         */
        String notify(int epoch, int packet, String central, String key, byte[] data, boolean indicate);

        /** Android: end a remote central's link (centralDisconnected follows). */
        void centralDrop(String central);

        /** Android keep-alive service: start (true) or stop hold generation {@code hold}. null, or why it did not start. */
        String keepAlive(boolean start, int hold);

        /** iOS: write the server snapshot (null: delete the file). */
        void persist(Map<String, Object> snapshot);
    }

    // ---- codec --------------------------------------------------------------------------------

    private static final char[] HEX = "0123456789abcdef".toCharArray();

    public static String hex(byte[] b) {
        char[] out = new char[b.length * 2];
        for (int i = 0; i < b.length; i++) {
            out[2 * i] = HEX[(b[i] >> 4) & 15];
            out[2 * i + 1] = HEX[b[i] & 15];
        }
        return new String(out);
    }

    private static int nibble(char c) {
        if (c >= '0' && c <= '9') return c - '0';
        if (c >= 'a' && c <= 'f') return c - 'a' + 10;
        if (c >= 'A' && c <= 'F') return c - 'A' + 10;
        return -1;
    }

    /** Hex digits only, even length; null otherwise. */
    public static byte[] fromHex(String s) {
        if (s == null || s.length() % 2 != 0) return null;
        byte[] out = new byte[s.length() / 2];
        for (int i = 0; i < out.length; i++) {
            int hi = nibble(s.charAt(2 * i)), lo = nibble(s.charAt(2 * i + 1));
            if (hi < 0 || lo < 0) return null;
            out[i] = (byte) ((hi << 4) | lo);
        }
        return out;
    }

    private static int sextet(char c) {
        if (c >= 'A' && c <= 'Z') return c - 'A';
        if (c >= 'a' && c <= 'z') return c - 'a' + 26;
        if (c >= '0' && c <= '9') return c - '0' + 52;
        if (c == '+' || c == '-') return 62;
        if (c == '/' || c == '_') return 63;
        return -1;
    }

    /** Standard or URL-safe base64, padding optional; null when malformed. */
    public static byte[] fromB64(String s) {
        if (s == null) return null;
        int end = s.length();
        int pad = 0;
        while (end > 0 && s.charAt(end - 1) == '=' && pad < 2) {
            end--;
            pad++;
        }
        if (pad > 0 && s.length() % 4 != 0) return null;
        if (end % 4 == 1) return null;
        byte[] out = new byte[end * 3 / 4];
        int acc = 0, bits = 0, n = 0;
        for (int i = 0; i < end; i++) {
            int v = sextet(s.charAt(i));
            if (v < 0) return null;
            acc = (acc << 6) | v;
            bits += 6;
            if (bits >= 8) {
                bits -= 8;
                out[n++] = (byte) ((acc >> bits) & 0xff);
            }
        }
        // Leftover bits must be zero (canonical encoding).
        if ((acc & ((1 << bits) - 1)) != 0) return null;
        return out;
    }

    static final String BASE = "-0000-1000-8000-00805f9b34fb";

    private static boolean allHex(String s) {
        for (int i = 0; i < s.length(); i++) if (nibble(s.charAt(i)) < 0) return false;
        return true;
    }

    /** 16-bit, 32-bit or dashed 128-bit UUID, any case; lower-case 128-bit, or null. */
    public static String uuid(String s) {
        if (s == null) return null;
        String l = s.toLowerCase(Locale.ROOT);
        if (l.length() == 4 && allHex(l)) return "0000" + l + BASE;
        if (l.length() == 8 && allHex(l)) return l + BASE;
        if (l.length() != 36) return null;
        for (int i = 0; i < 36; i++) {
            char c = l.charAt(i);
            boolean dash = i == 8 || i == 13 || i == 18 || i == 23;
            if (dash ? c != '-' : nibble(c) < 0) return null;
        }
        return l;
    }

    /** Comma-separated UUIDs, at most 20; an empty or missing list is empty; null when malformed. */
    public static List<String> uuidList(String s) {
        List<String> out = new ArrayList<>();
        if (s == null || s.isEmpty()) return out;
        for (String part : s.split(",", -1)) {
            String u = uuid(part.trim());
            if (u == null) return null;
            if (!out.contains(u)) out.add(u);
        }
        return out.size() > 20 ? null : out;
    }

    /** iOS: a peripheral identifier (UUID). Android: a MAC in the form checkBluetoothAddress accepts. */
    public static boolean isId(String id, String platform) {
        if (id == null) return false;
        if ("android".equals(platform)) {
            if (id.length() != 17) return false;
            for (int i = 0; i < 17; i++) {
                char c = id.charAt(i);
                if (i % 3 == 2 ? c != ':' : !((c >= '0' && c <= '9') || (c >= 'A' && c <= 'F'))) return false;
            }
            return true;
        }
        return id.length() == 36 && uuid(id) != null;
    }

    /** Exactly one of hex and b64 decoded; null when none, both, or malformed. */
    public static byte[] bytes(String hex, String b64) {
        if ((hex == null) == (b64 == null)) return null;
        return hex != null ? fromHex(hex) : fromB64(b64);
    }

    /** The characteristic key used in replies, records and subscriptions. */

    /** Canonical JSON with keys in insertion order: the vector form, shared with the Swift twin. */
    public static String json(Object v) {
        StringBuilder b = new StringBuilder();
        json(b, v);
        return b.toString();
    }

    @SuppressWarnings("unchecked")
    private static void json(StringBuilder b, Object v) {
        if (v == null) {
            b.append("null");
        } else if (v instanceof Boolean || v instanceof Integer || v instanceof Long) {
            b.append(v);
        } else if (v instanceof String) {
            b.append('"');
            String s = (String) v;
            for (int i = 0; i < s.length(); i++) {
                char c = s.charAt(i);
                if (c == '"' || c == '\\') b.append('\\').append(c);
                else if (c < 0x20) b.append(String.format(Locale.ROOT, "\\u%04x", (int) c));
                else b.append(c);
            }
            b.append('"');
        } else if (v instanceof Map) {
            b.append('{');
            boolean first = true;
            for (Map.Entry<String, Object> e : ((Map<String, Object>) v).entrySet()) {
                if (!first) b.append(',');
                first = false;
                json(b, e.getKey());
                b.append(':');
                json(b, e.getValue());
            }
            b.append('}');
        } else if (v instanceof List) {
            b.append('[');
            boolean first = true;
            for (Object o : (List<Object>) v) {
                if (!first) b.append(',');
                first = false;
                json(b, o);
            }
            b.append(']');
        } else {
            throw new IllegalArgumentException("no JSON form for " + v.getClass().getName());
        }
    }

    /** The platform error of a link that went down, as the radio reports it, with the code's name. */
    public static Map<String, Object> platformError(String domain, int code, String message) {
        Map<String, Object> e = obj("domain", domain, "code", code, "message", message);
        Map<Integer, String[]> names = ERROR_NAMES.get(domain);
        String[] n = names == null ? null : names.get(code);
        if (n != null) e.put("name", n[0]);
        return e;
    }

    /** The link event's reason for an error: the code's readable reason, else the radio's. */
    static String errorReason(Map<String, Object> e, String fallback) {
        if (e == null || !(e.get("domain") instanceof String) || !(e.get("code") instanceof Integer)) return fallback;
        Map<Integer, String[]> names = ERROR_NAMES.get((String) e.get("domain"));
        String[] n = names == null ? null : names.get((Integer) e.get("code"));
        return n == null ? fallback : n[1];
    }

    /** " (domain code name: message)" for a failed call's message, or "" without an error. */
    static String errorText(Map<String, Object> e) {
        if (e == null) return "";
        String name = e.containsKey("name") ? " " + e.get("name") : "";
        return " (" + e.get("domain") + " " + e.get("code") + name + ": " + e.get("message") + ")";
    }

    public static Map<String, Object> obj(Object... kv) {
        Map<String, Object> m = new LinkedHashMap<>();
        for (int i = 0; i < kv.length; i += 2) m.put((String) kv[i], kv[i + 1]);
        return m;
    }

    /** Install-time and runtime permissions a role needs on an API level; {install, runtime}. */
    public static List<List<String>> permissions(int sdk, String role, boolean neverForLocation) {
        List<String> install = new ArrayList<>(), runtime = new ArrayList<>();
        boolean scan = "scan".equals(role) || "central".equals(role);
        boolean connect = "connect".equals(role) || "central".equals(role) || "advertise".equals(role);
        boolean advertise = "advertise".equals(role);
        if (sdk >= 31) {
            if (scan) {
                runtime.add("android.permission.BLUETOOTH_SCAN");
                if (!neverForLocation) runtime.add("android.permission.ACCESS_FINE_LOCATION");
            }
            if (advertise) runtime.add("android.permission.BLUETOOTH_ADVERTISE");
            if (connect) runtime.add("android.permission.BLUETOOTH_CONNECT");
        } else {
            install.add("android.permission.BLUETOOTH");
            if (scan || advertise) install.add("android.permission.BLUETOOTH_ADMIN");
            if (scan) runtime.add("android.permission.ACCESS_FINE_LOCATION");
        }
        List<List<String>> out = new ArrayList<>();
        out.add(install);
        out.add(runtime);
        return out;
    }

    // ---- replies and records --------------------------------------------------------------------

    private void ok(int call, Map<String, Object> data) {
        if (call >= 0) port.reply(call, true, null, null, data);
    }

    private void fail(int call, String code, String message) {
        if (call >= 0) port.reply(call, false, code, message, null);
    }

    /** "code message" from a port refusal, split. */
    private void refused(int call, String err) {
        int sp = err.indexOf(' ');
        fail(call, sp < 0 ? err : err.substring(0, sp), sp < 0 ? "" : err.substring(sp + 1));
    }

    private void append(String event, Map<String, Object> data) {
        Map<String, Object> rec = obj("seq", ++nextSeq, "t", port.now(), "event", event, "data", data);
        int size = json(data).length() + 48;
        journal.addLast(rec);
        journalBytes += size;
        rec.put("_size", size);
        while (journal.size() > JOURNAL_RECORDS || journalBytes > JOURNAL_BYTES) {
            Map<String, Object> old = journal.removeFirst();
            journalBytes -= (Integer) old.get("_size");
            dropped++;
        }
    }

    /** An event that is also a journal record. */
    private void record(String event, Map<String, Object> data) {
        append(event, data);
        port.emit(event, data);
    }

    private void scheduleFlush() {
        if (flushScheduled) return;
        flushScheduled = true;
        port.timer("flush", 0, FLUSH_MS);
    }

    private void flush() {
        flushScheduled = false;
        if (!pendingDevices.isEmpty()) {
            List<Object> batch = new ArrayList<>(pendingDevices);
            pendingDevices.clear();
            record("device", obj("scan", lastScan, "devices", batch));
        }
        if (!pendingValues.isEmpty()) {
            int n = Math.min(BATCH_MAX, pendingValues.size());
            List<Object> batch = new ArrayList<>(pendingValues.subList(0, n));
            pendingValues.subList(0, n).clear();
            port.emit("value", obj("records", batch, "dropped", dropped));
            if (!pendingValues.isEmpty()) scheduleFlush();
        }
        if (!pendingRequests.isEmpty()) {
            int n = Math.min(BATCH_MAX, pendingRequests.size());
            List<Object> batch = new ArrayList<>(pendingRequests.subList(0, n));
            pendingRequests.subList(0, n).clear();
            port.emit("request", obj("records", batch, "dropped", dropped));
            if (!pendingRequests.isEmpty()) scheduleFlush();
        }
    }

    public boolean on() {
        return "on".equals(adapter);
    }

    public int epoch() {
        return epoch;
    }

    /** The adapter or manager state changed (on, off, unauthorized, unsupported, resetting, unknown). */
    public void adapter(String state) {
        if (state.equals(adapter)) return;
        boolean wasOn = on();
        adapter = state;
        if (wasOn && !on()) {
            epoch++;
            if (scan != 0) endScan("adapter");
            serverDown();
            for (Link l : new ArrayList<>(links.values())) {
                if (l.auto) autoWhenOn.put(l.id, new LinkedHashSet<>(l.wanted));
                closeLink(l, "adapter", true);
                // The radio is off: every platform object of the old epoch is released, none waited for.
                port.release(l.id, l.gen);
            }
            for (Map.Entry<String, Closing> e : new ArrayList<>(closing.entrySet())) {
                Closing c = e.getValue();
                port.release(e.getKey(), c.gen);
                if (c.disconnectCall >= 0) ok(c.disconnectCall, obj("id", e.getKey(), "state", "disconnected", "confirmed", false));
                if (c.waiter != null) fail(c.waiter.call, "unavailable", "Bluetooth is " + state);
                if (c.reconnect) autoWhenOn.put(e.getKey(), c.wanted);
            }
            closing.clear();
        }
        record("adapter", obj("state", state, "epoch", epoch));
        if (!wasOn && on()) {
            for (Map.Entry<String, Set<String>> e : new ArrayList<>(autoWhenOn.entrySet())) {
                startLink(e.getKey(), true, -1, 0, true, e.getValue());
            }
            autoWhenOn.clear();
            serverUp();
        }
        updateHold();
    }

    public Map<String, Object> stateFields() {
        return obj("scanning", scan != 0, "advertising", advertising, "links", links.size(), "centrals", centrals.size(),
                "keepAlive", keepAliveWanted, "epoch", epoch, "run", run);
    }

    // ---- scan -----------------------------------------------------------------------------------

    public void scanStart(int call, String servicesCsv, int seconds, boolean duplicates, String mode, boolean background) {
        List<String> services = uuidList(servicesCsv);
        if (services == null) {
            fail(call, "bad_value", "services must be up to 20 UUIDs");
            return;
        }
        if (!on()) {
            fail(call, "unavailable", "Bluetooth is " + adapter);
            return;
        }
        if (scan != 0) {
            fail(call, "busy", "a scan is already running");
            return;
        }
        if (background && services.isEmpty()) {
            fail(call, "filter_required", "a scan in the background needs a service filter");
            return;
        }
        int s = ++nextScan;
        String err = port.scanStart(s, services, duplicates, mode);
        if (err != null) {
            refused(call, err);
            return;
        }
        scan = s;
        lastScan = s;
        devices.clear();
        filtered = !services.isEmpty();
        if (seconds > 0) port.timer("scan", s, seconds * 1000L);
        ok(call, obj("scan", s));
    }

    boolean filtered;

    public void scanStop(int call) {
        if (scan == 0) {
            ok(call, obj("scan", lastScan, "stopped", false));
            return;
        }
        int s = scan;
        port.scanStop(s);
        endScan("stopped");
        ok(call, obj("scan", s, "stopped", true));
    }

    private void endScan(String reason) {
        int s = scan;
        scan = 0;
        flush();
        record("scan_end", obj("scan", s, "reason", reason));
    }

    /** One advertisement. {@code adv} holds name, rssi, connectable, services, manufacturer, serviceData, txPower. */
    public void device(int s, String id, Map<String, Object> adv) {
        if (s != scan || s == 0) {
            stale("device scan " + s);
            return;
        }
        Map<String, Object> d = devices.get(id);
        if (d == null) {
            if (devices.size() >= DEVICES_MAX) return;
            d = obj("id", id, "seen", 0);
            devices.put(id, d);
        }
        d.putAll(adv);
        d.put("seen", (Integer) d.get("seen") + 1);
        Map<String, Object> view = obj("id", id);
        view.putAll(adv);
        pendingDevices.add(view);
        scheduleFlush();
    }

    public void scanFailed(int s, String reason) {
        if (s != scan || s == 0) {
            stale("scan_failed " + s);
            return;
        }
        endScan("failed");
    }

    /** The app moved to (true) or out of the background. */
    public void background(boolean inBackground) {
        if (inBackground && scan != 0 && !filtered) {
            port.scanStop(scan);
            endScan("background");
        }
    }

    private boolean current(Link l, int gen) {
        return l != null && l.gen == gen && !l.closed;
    }

    private Link live(String id, int gen, String what) {
        Link l = links.get(id);
        if (!current(l, gen)) {
            stale(what + " " + id + " gen " + gen);
            return null;
        }
        return l;

    private void stale(String what) {
        staleDrops++;
        port.stale(what);
    }

    private boolean checkId(int call, String id) {
        if (!isId(id, android ? "android" : "ios")) {
            fail(call, "bad_value", "id is not a device id of this platform");
            return false;
        }
        return true;
    }

    public void connect(int call, String id, boolean auto, int seconds) {
        if (!checkId(call, id)) return;
        if (!on()) {
            fail(call, "unavailable", "Bluetooth is " + adapter);
            return;
        }
        Link pending = links.get(id);
        if (pending != null) {
            // A pending attempt no call owns (restored by iOS, or an automatic reconnect) is
            // adopted: this call owns it from now on, with its own timeout, and the page's `auto` wins.
            if ("connecting".equals(pending.state) && pending.connectCall < 0 && !pending.closed) {
                pending.connectCall = call;
                pending.auto = auto;
                pending.background = false;
                boundPending(pending, seconds * 1000);
                return;
            }
            fail(call, "busy", "this device is linked or connecting");
            return;
        }
        if (closing.containsKey(id)) {
            // Rule 3: one live platform connection per device. Wait for the confirmed close.
            Closing c = closing.get(id);
            if (c.waiter != null || c.reconnect) {
                fail(call, "busy", "this device is still closing");
                return;
            }
            c.waiter = new Waiter(call, auto, seconds, ++nextOp);
            port.timer("wait", c.waiter.token, seconds * 1000L);
            return;
        }
        startLink(id, auto, call, seconds, false, new LinkedHashSet<>());
    }

    private void startLink(String id, boolean auto, int call, int seconds, boolean background, Set<String> wanted) {
        Link l = new Link(id, ++nextGen);
        l.auto = auto;
        l.background = background;
        l.connectCall = call;
        l.wanted.addAll(wanted);
        links.put(id, l);
        String err = port.connect(id, l.gen, auto, background);
        if (err != null) {
            links.remove(id);
            l.closed = true;
            refused(call, err);
            return;
        }
        if (call >= 0) port.timer("connect", l.gen, seconds * 1000L);
        if (background) record("link", obj("id", id, "link", l.gen, "state", "reconnecting", "reason", "auto"));
        updateHold();
    }

    /**
     * Bounds an attempt no fresh connect started: when the timer ends it still connecting, the
     * attempt is closed (the radio cancels it) and reported {@code timeout}.
     */
    private void boundPending(Link l, int ms) {
        l.pendingTimer = ++nextPending;
        port.timer("pending", l.pendingTimer, ms);
    }

        return restored(id, connected, subscribed, false);

    /**
     * iOS state restoration (the Swift twin's; Android has none). {@code pending}: handed back still
     * connecting; kept, bounded by the default connect timeout, unless a page connect adopts it.
     */
    public int restored(String id, boolean connected, List<String> subscribed, boolean pending) {
        Link l = new Link(id, ++nextGen);
        l.auto = true;
        l.background = true;
        for (String k : subscribed) {
            l.wanted.add(k);
            l.subs.put(k, "notify");
        }
        links.put(id, l);
        if (connected) {
            l.state = "connected";
        } else if (pending) {
            l.auto = false;
            boundPending(l, CONNECT_DEFAULT_MS);
        }
        return l.gen;
    }

    public void connected(String id, int gen, int mtu) {
        Link l = live(id, gen, "connected");
        if (l == null) return;
        if (!"connecting".equals(l.state)) return;
        l.state = "connected";
        l.mtu = mtu;
        if (android) {
            Op m = new Op(-1, "mtu");
            m.arg = MTU_REQUEST;
            m.internal = true;
            l.queue.add(m);
        }
        if (!l.wanted.isEmpty()) {
            Op d = new Op(-1, "discover");
            d.internal = true;
            l.queue.add(d);
            for (String k : l.wanted) {
                Op s = new Op(-1, "sub");
                s.key = k;
                s.internal = true;
                l.queue.add(s);
            }
        }
        Op ready = new Op(-1, "ready");
        ready.internal = true;
        l.queue.add(ready);
        pump(l);
    }

    /** The platform reported that attempt {@code gen} disconnected or failed to connect. */
    public void disconnected(String id, int gen, String reason) {
        disconnected(id, gen, reason, null);
    }

    /** {@code error}: the platform's own error, when it gave one ({domain, code, message}); it
     *  reaches the failed connect call's message and the {@code link} record unchanged. */
    public void disconnected(String id, int gen, String reason, Map<String, Object> error) {
        Link l = links.get(id);
        if (current(l, gen)) {
            closeLink(l, errorReason(error, reason), true, error);
            return;
        }
        Closing c = closing.get(id);
        if (c != null && c.gen == gen) {
            finishClosing(id, true);
            return;
        }
        stale("disconnected " + id + " gen " + gen);
    }

    public void disconnect(int call, String id) {
        if (!checkId(call, id)) return;
        Link l = links.get(id);
        if (l == null) {
            fail(call, "not_connected", "this device is not linked");
            return;
        }
        l.auto = false;
        l.wanted.clear();
        boolean confirmedNow = closeLink(l, "requested", false);
        if (confirmedNow) {
            ok(call, obj("id", id, "state", "disconnected", "confirmed", true));
        } else {
            closing.get(id).disconnectCall = call;
        }
    }

    /**
     * The one cleanup owner (rule 4). Runs to the end, idempotent. {@code down}: the platform already
     * reported the link down, so nothing is asked of it. Returns whether the close is confirmed now.
     */
    boolean closeLink(Link l, String reason, boolean down) {
        return closeLink(l, reason, down, null);
    }

    boolean closeLink(Link l, String reason, boolean down, Map<String, Object> error) {
        if (l.closed) return true;
        l.closed = true;
        List<Op> ops = new ArrayList<>();
        if (l.inFlight != null) ops.add(l.inFlight);
        ops.addAll(l.queue);
        l.inFlight = null;
        l.queue.clear();
        for (Op o : ops) {
            if (o.internal) continue;
            String msg = o.chunks > 1 ? "the link closed after " + o.chunk + " of " + o.chunks + " chunks were handed over"
                    : "the link closed while the operation waited";
            fail(o.call, "link_lost", msg);
        }
        if (l.connectCall >= 0) {
            String code = "timeout".equals(reason) ? "connect_timeout"
                    : "adapter".equals(reason) ? "unavailable"
                    : "requested".equals(reason) ? "link_lost" : "connect_failed";
            fail(l.connectCall, code, "the connection ended: " + reason + errorText(error));
            l.connectCall = -1;
        }
        if (links.get(l.id) == l) links.remove(l.id);
        boolean confirmed = down;
        if (!down) {
            confirmed = port.close(l.id, l.gen);
            if (!confirmed) {
                Closing c = new Closing(l.gen);
                closing.put(l.id, c);
                port.timer("close", l.gen, CLOSE_MS);
            }
        }
        Map<String, Object> rec = obj("id", l.id, "link", l.gen, "state", "disconnected", "reason", reason);
        if (error != null) rec.put("error", error);
        record("link", rec);
        if (l.auto && !"requested".equals(reason) && on()) {
            Closing c = closing.get(l.id);
            if (c != null) {
                c.reconnect = true;
                c.wanted = new LinkedHashSet<>(l.wanted);
            } else {
                startLink(l.id, true, -1, 0, true, l.wanted);
            }
        }
        updateHold();
        return confirmed;
    }

    private void finishClosing(String id, boolean confirmed) {
        Closing c = closing.remove(id);
        if (c == null) return;
        if (c.disconnectCall >= 0) ok(c.disconnectCall, obj("id", id, "state", "disconnected", "confirmed", confirmed));
        if (!on()) {
            if (c.waiter != null) fail(c.waiter.call, "unavailable", "Bluetooth is " + adapter);
            return;
        }
        if (c.reconnect) {
            startLink(id, true, -1, 0, true, c.wanted);
        } else if (c.waiter != null) {
            Waiter w = c.waiter;
            if (!port.isActive(w.call)) {
                fail(w.call, "timeout", "the route timed out while the previous connection closed");
                return;
            }
            startLink(id, w.auto, w.call, w.seconds, false, new LinkedHashSet<>());
        }
    }

        }
        ok(call, obj("links", out));
    }

    private Link connectedLink(int call, String id) {
        if (!checkId(call, id)) return null;
        Link l = links.get(id);
        if (l == null || !"connected".equals(l.state)) {
            fail(call, "not_connected", "this device is not connected");

        }
        return l;
    }

    private String target(int call, String service, int sn, String chr, int cn) {
        String s = uuid(service), c = uuid(chr);
        if (s == null || c == null) {
            fail(call, "bad_value", "service and char must be UUIDs");
            return null;
        }
        return key(s, sn, c, cn);
    }

    private void enqueue(int call, Link l, Op o) {
        if (l.queue.size() >= QUEUE_MAX) {
            fail(call, "busy", "too many operations are waiting on this link");
            return;
        }
        l.queue.add(o);
        pump(l);
    }

    public void discover(int call, String id) {
        Link l = connectedLink(call, id);
        if (l != null) enqueue(call, l, new Op(call, "discover"));
    }

    public void read(int call, String id, String service, int sn, String chr, int cn, String descriptor) {
        Link l = connectedLink(call, id);
        if (l == null) return;
        String k = target(call, service, sn, chr, cn);
        if (k == null) return;
        String d = null;
        if (descriptor != null) {
            d = uuid(descriptor);
            if (d == null) {
                fail(call, "bad_value", "descriptor must be a UUID");
                return;
            }
        }
        Op o = new Op(call, "read");
        o.key = k;
        o.descriptor = d;
        enqueue(call, l, o);
    }

    public void write(int call, String id, String service, int sn, String chr, int cn, String descriptor,
                      String hexValue, String b64Value, boolean response) {
        Link l = connectedLink(call, id);
        if (l == null) return;
        String k = target(call, service, sn, chr, cn);
        if (k == null) return;
        byte[] data = bytes(hexValue, b64Value);
        if (data == null) {
            fail(call, "bad_value", "give exactly one of hex and b64, well formed");
            return;
        }
        if (data.length > WRITE_MAX) {
            fail(call, "too_long", data.length + " bytes; at most " + WRITE_MAX);
            return;
        }
        String d = null;
        if (descriptor != null) {
            d = uuid(descriptor);
            if (d == null) {
                fail(call, "bad_value", "descriptor must be a UUID");
                return;
            }
            response = true;
        }
        Op o = new Op(call, response ? "write" : "wnr");
        o.key = k;
        o.descriptor = d;
        o.data = data;
        enqueue(call, l, o);
    }

    public void subscribe(int call, String id, String service, int sn, String chr, int cn, boolean on) {
        Link l = connectedLink(call, id);
        if (l == null) return;
        String k = target(call, service, sn, chr, cn);
        if (k == null) return;
        Op o = new Op(call, on ? "sub" : "unsub");
        o.key = k;
        enqueue(call, l, o);
    }

    }

    private static Map<String, Object> mtuData(Link l, boolean requested) {
        return obj("mtu", l.mtu, "writeMax", WRITE_MAX, "writeNoResponseMax", l.mtu - 3, "requested", requested);
    }

    /** Hands the next operation to the platform when none is in flight. */
    private void pump(Link l) {
        while (l.inFlight == null && !l.queue.isEmpty() && !l.closed) {
            Op o = l.queue.poll();
            if (!o.internal && !port.isActive(o.call)) {
                // Rule 8: a route that timed out starts nothing new. Its reply is the bridge's to drop.
                fail(o.call, "timeout", "the route timed out before the operation started");
                continue;
            }
            if ("ready".equals(o.kind)) {
                ready(l);
                continue;
            }
            if ("wnr".equals(o.kind)) {
                int size = Math.max(1, l.mtu - 3);
                o.chunks = Math.max(1, (o.data.length + size - 1) / size);
                o.chunk = 0;
            }
            l.inFlight = o;
            send(l, o);
        }
    }

    private void send(Link l, Op o) {
        o.op = ++nextOp;
        byte[] data = o.data;
        if ("wnr".equals(o.kind)) {
            int size = Math.max(1, l.mtu - 3);
            int from = o.chunk * size, to = Math.min(o.data.length, from + size);
            data = java.util.Arrays.copyOfRange(o.data, from, to);
        }
        String err = port.op(l.id, l.gen, o.op, o.kind, o.key, o.descriptor, data, o.arg);
        if (err != null) {
            // Rule 6: a refusal settles the step at once and the queue moves on.
            l.inFlight = null;
            if (o.internal) {
                if ("sub".equals(o.kind)) l.failed++;
            } else {
                refused(o.call, err);
            }
            pump(l);
            return;
        }
        port.timer("op", o.op, OP_MS);
    }

    private void ready(Link l) {
        record("link", obj("id", l.id, "link", l.gen, "state", "connected", "reason", l.background ? "auto" : "requested",
                "resubscribed", l.resubscribed, "failed", l.failed));
        if (l.connectCall >= 0) {
            ok(l.connectCall, obj("id", l.id, "link", l.gen, "state", "connected", "mtu", l.mtu));
            l.connectCall = -1;
        }
    }

    /**
     * One GATT step settled. {@code code} null is success; {@code data} carries the platform's answer
     * (discover: services; read: hex; rssi: rssi; sub: mode).
     */
    public void opDone(String id, int gen, int op, String code, String message, Map<String, Object> data) {
        Link l = live(id, gen, "op");
        if (l == null) return;
        Op o = l.inFlight;
        if (o == null || o.op != op) {
            stale("op " + op);
            return;
        }
        if (code == null && "wnr".equals(o.kind) && o.chunk + 1 < o.chunks) {
            o.chunk++;
            send(l, o);
            return;
        }
        l.inFlight = null;
        settle(l, o, code, message, data);
        pump(l);
    }

    private void settle(Link l, Op o, String code, String message, Map<String, Object> data) {
        if (o.internal) {
            if ("sub".equals(o.kind)) {
                if (code == null) {
                    l.subs.put(o.key, data != null && data.get("mode") != null ? (String) data.get("mode") : "notify");
                    l.resubscribed++;
                } else {
                    l.failed++;
                }
            }
            return;
        }
        if (code != null) {
            fail(o.call, code, message);
            return;
        }
        switch (o.kind) {
            case "write":
                ok(o.call, obj("written", o.data.length, "chunks", 1));
                break;
            case "wnr":
                ok(o.call, obj("written", o.data.length, "chunks", o.chunks));
                break;
            case "sub": {
                String mode = data != null && data.get("mode") != null ? (String) data.get("mode") : "notify";
                l.subs.put(o.key, mode);
                l.wanted.add(o.key);
                ok(o.call, obj("subscribed", true, "mode", mode));
                break;
            }
            case "unsub":
                l.subs.remove(o.key);
                l.wanted.remove(o.key);
                ok(o.call, obj("subscribed", false));
                break;
            case "mtu":
                ok(o.call, mtuData(l, true));
                break;
            case "discover": {
                Map<String, Object> out = obj("id", l.id);
                if (data != null) out.putAll(data);
                ok(o.call, out);
                break;
            }
            default:
                ok(o.call, data == null ? obj() : data);
        }
    }

    /** The link's MTU changed. It completes the operation in flight only if that is the MTU request. */
    public void mtuChanged(String id, int gen, int mtu, boolean success) {
        Link l = live(id, gen, "mtu");
        if (l == null) return;
        if (success) l.mtu = mtu;
        Op o = l.inFlight;
        if (o != null && "mtu".equals(o.kind)) {
            l.inFlight = null;
            settle(l, o, null, null, null);
            pump(l);
        }
    }

    /**
     * A characteristic value arrived. {@code maybeRead}: the platform cannot say whether it answers a
     * read (iOS didUpdateValueFor); then a read of this characteristic in flight takes it.
     */
    public void value(String id, int gen, String key, String hexValue, boolean maybeRead) {
        Link l = live(id, gen, "value");
        if (l == null) return;
        Op o = l.inFlight;
        if (maybeRead && o != null && "read".equals(o.kind) && o.descriptor == null && key.equals(o.key)) {
            l.inFlight = null;
            settle(l, o, null, null, obj("hex", hexValue));
            pump(l);
            return;

        String[] parts = key.split("[#/]");
        Map<String, Object> rec = obj("id", id, "link", gen, "service", parts[0], "char", parts[2],
                "service_n", Integer.parseInt(parts[1]), "char_n", Integer.parseInt(parts[3]), "hex", hexValue);
        append("value", rec);
        Map<String, Object> view = obj("seq", nextSeq, "t", journal.peekLast().get("t"));
        view.putAll(rec);
        pendingValues.add(view);
        scheduleFlush();
    }

    /**
     * The {@code chars} grammar of service_add: characteristics separated by commas, each
     * {@code uuid~flags} or {@code uuid~flags~hex}. Flags r (read), w (write), c (write without
     * response), n (notify), i (indicate), R (read needs encryption, with r), W (write needs
     * encryption, with w or c). At most 16; equal UUIDs are numbered in order. Null when malformed.
     */
    public static List<Map<String, Object>> parseChars(String spec) {
        List<Map<String, Object>> out = new ArrayList<>();
        if (spec == null || spec.isEmpty()) return out;
        Map<String, Integer> seen = new LinkedHashMap<>();
        for (String part : spec.split(",", -1)) {
            String[] f = part.split("~", -1);
            if (f.length < 2 || f.length > 3) return null;
            String u = uuid(f[0].trim());
            String flags = f[1];
            if (u == null || flags.isEmpty()) return null;
            for (int i = 0; i < flags.length(); i++) {
                char c = flags.charAt(i);
                if ("rwcniRW".indexOf(c) < 0 || flags.indexOf(c) != i) return null;
            }
            boolean any = false;
            for (char c : new char[]{'r', 'w', 'c', 'n', 'i'}) any |= flags.indexOf(c) >= 0;
            if (!any) return null;
            if (flags.indexOf('R') >= 0 && flags.indexOf('r') < 0) return null;
            if (flags.indexOf('W') >= 0 && flags.indexOf('w') < 0 && flags.indexOf('c') < 0) return null;
            String start = null;
            if (f.length == 3) {
                byte[] b = fromHex(f[2]);
                if (b == null || f[2].isEmpty() || b.length > WRITE_MAX) return null;
                start = hex(b);
            }
            int n = seen.containsKey(u) ? seen.get(u) + 1 : 0;
            seen.put(u, n);
            Map<String, Object> c = obj("uuid", u, "n", n, "flags", flags);
            c.put("hex", start);
            out.add(c);
            if (out.size() > CHARS_MAX) return null;
        }
        return out;
    }

    /** Server and advertiser callbacks carry the epoch they were made in; an older one changes nothing. */
    private boolean serverCurrent(int e, String what) {
        if (e == epoch && on()) return true;
        stale(what + " epoch " + e);
        return false;
    }

    private Chr chr(String service, String chr, int cn) {
        String s = uuid(service), c = uuid(chr);
        Service svc = s == null ? null : services.get(s);
        if (svc == null || c == null) return null;
        for (Chr x : svc.chars) if (x.uuid.equals(c) && x.n == cn) return x;
        return null;
    }

    private Chr chrOf(String key) {
        String[] p = key.split("[#/]");
        Service svc = services.get(p[0]);
        if (svc == null) return null;
        int cn = Integer.parseInt(p[3]);
        for (Chr x : svc.chars) if (x.uuid.equals(p[2]) && x.n == cn) return x;
        return null;
    }

    private static String keyOf(Service s, Chr c) {
        return key(s.uuid, 0, c.uuid, c.n);
    }

    private static List<Object> properties(Chr c) {
        List<Object> out = new ArrayList<>();
        if (c.has('r')) out.add("read");
        if (c.has('c')) out.add("writeWithoutResponse");
        if (c.has('w')) out.add("write");
        if (c.has('n')) out.add("notify");
        if (c.has('i')) out.add("indicate");
        return out;
    }

    private static List<Map<String, Object>> charList(Service s) {
        List<Map<String, Object>> out = new ArrayList<>();
        for (Chr c : s.chars) {
            Map<String, Object> m = obj("uuid", c.uuid, "n", c.n, "flags", c.flags);
            m.put("hex", c.value == null ? null : hex(c.value));
            out.add(m);
        }
        return out;
    }

    private Map<String, Object> serviceView(Service s) {
        List<Object> chars = new ArrayList<>();
        for (Chr c : s.chars) {
            Map<String, Object> m = obj("uuid", c.uuid, "n", c.n, "properties", properties(c),
                    "subscribers", new ArrayList<Object>(c.subscribers.keySet()));
            m.put("hex", c.value == null ? null : hex(c.value));
            chars.add(m);
        }
        return obj("uuid", s.uuid, "primary", s.primary, "added", s.added, "characteristics", chars);
    }

    public void serviceAdd(int call, String uuidValue, boolean primary, String spec) {
        String u = uuid(uuidValue);
        List<Map<String, Object>> parsed = parseChars(spec);
        if (u == null || parsed == null) {
            fail(call, "bad_value", u == null ? "uuid must be a UUID" : "chars does not follow uuid~flags[~hex], at most 16");
            return;
        }
        if (!on()) {
            fail(call, "unavailable", "Bluetooth is " + adapter);
            return;
        }
        if (services.containsKey(u)) {
            fail(call, "bad_value", "this service is already in the table");
            return;
        }
        if (services.size() >= SERVICES_MAX) {
            fail(call, "busy", "the table holds " + SERVICES_MAX + " services");
            return;
        }
        List<Chr> chars = new ArrayList<>();
        for (Map<String, Object> c : parsed) {
            chars.add(new Chr((String) c.get("uuid"), (Integer) c.get("n"), (String) c.get("flags"),
                    c.get("hex") == null ? new byte[0] : fromHex((String) c.get("hex"))));
        }
        Service s = new Service(u, primary, chars);
        s.call = call;
        services.put(u, s);
        addQueue.add(s);
        pumpAdds();
    }

    /** Hands the next service to the platform; one add in flight, as Android requires. */
    private void pumpAdds() {
        while (adding == null && !addQueue.isEmpty()) {
            Service s = addQueue.poll();
            if (s.call >= 0 && !port.isActive(s.call)) {
                services.remove(s.uuid);
                fail(s.call, "timeout", "the route timed out before the service was added");
                continue;
            }
            String err = port.serviceAdd(epoch, s.uuid, s.primary, charList(s));
            if (err != null) {
                if (s.call >= 0) {
                    services.remove(s.uuid);
                    refused(s.call, err);
                    s.call = -1;
                }
                continue;
            }
            adding = s;
            s.token = ++nextOp;
            port.timer("service", s.token, OP_MS);
        }
    }

    /** The platform added (code null) or refused a service. */
    public void serviceAdded(int e, String uuidValue, String code) {
        if (!serverCurrent(e, "service_added")) return;
        Service s = adding;
        if (s == null || !s.uuid.equals(uuidValue)) {
            stale("service_added " + uuidValue);
            return;
        }
        adding = null;
        if (code == null) {
            s.added = true;
            if (s.call >= 0) ok(s.call, obj("uuid", s.uuid, "characteristics", serviceView(s).get("characteristics")));
            persistSoon();
        } else if (s.call >= 0) {
            services.remove(s.uuid);
            fail(s.call, "gatt_error", "the platform refused the service: " + code);
        }
        s.call = -1;
        pumpAdds();
    }

    public void serviceRemove(int call, String uuidValue) {
        List<Service> targets = new ArrayList<>();
        if (uuidValue == null) {
            targets.addAll(services.values());
        } else {
            String u = uuid(uuidValue);
            if (u == null) {
                fail(call, "bad_value", "uuid must be a UUID");
                return;
            }
            Service s = services.get(u);
            if (s == null) {
                fail(call, "not_found", "no such service in the table");
                return;
            }
            targets.add(s);
        }
        for (Service s : targets) {
            if (s == adding || s.call >= 0) {
                fail(call, "busy", "a service is still being added");
                return;
            }
        }
        List<Object> removed = new ArrayList<>();
        for (Service s : targets) {
            services.remove(s.uuid);
            addQueue.remove(s);
            if (s.added) port.serviceRemove(s.uuid);
            for (Chr c : s.chars) {
                for (String central : new ArrayList<>(c.subscribers.keySet())) dropSubscription(central, s.uuid, c);
            }
            removed.add(s.uuid);
        }
        persistSoon();
        ok(call, obj("removed", removed));
        pumpNotify();
    }

    public void services(int call) {
        List<Object> out = new ArrayList<>();
        for (Service s : services.values()) out.add(serviceView(s));
        ok(call, obj("services", out, "advertising", advertising));
    }

    public void valueSet(int call, String service, String chrUuid, int cn, String hexValue, String b64Value) {
        Chr c = chr(service, chrUuid, cn);
        if (c == null) {
            fail(call, "not_found", "no such characteristic in the table");
            return;
        }
        byte[] data = bytes(hexValue, b64Value);
        if (data == null) {
            fail(call, "bad_value", "give exactly one of hex and b64, well formed");
            return;
        }
        if (overMax(call, data)) return;
        c.value = data;
        persistSoon();
        ok(call, obj("bytes", data.length));
    }

    /** A server value is at most 512 bytes, as an attribute value is. */
    private boolean overMax(int call, byte[] data) {
        if (data.length <= WRITE_MAX) return false;
        fail(call, "too_long", data.length + " bytes; at most " + WRITE_MAX);
        return true;
    }

    public void notify(int call, String service, String chrUuid, int cn, String hexValue, String b64Value, String central) {
        Chr c = chr(service, chrUuid, cn);
        if (c == null) {
            fail(call, "not_found", "no such characteristic in the table");
            return;
        }
        byte[] data = bytes(hexValue, b64Value);
        if (data == null) {
            fail(call, "bad_value", "give exactly one of hex and b64, well formed");
            return;
        }
        if (overMax(call, data)) return;
        if (!c.has('n') && !c.has('i')) {
            fail(call, "not_permitted", "the characteristic neither notifies nor indicates");
            return;
        }
        List<String> to = new ArrayList<>();
        for (String x : c.subscribers.keySet()) if (central == null || central.equals(x)) to.add(x);
        if (to.isEmpty()) {
            fail(call, "no_subscribers", central == null ? "no central is subscribed" : "that central is not subscribed");
            return;
        }
        int room = Integer.MAX_VALUE;
        for (String x : to) room = Math.min(room, centrals.getOrDefault(x, 23) - 3);
        if (data.length > room) {
            fail(call, "too_long", data.length + " bytes; a subscriber's MTU allows " + room);
            return;
        }
        if (notifyQueue.size() + to.size() > NOTIFY_MAX) {
            fail(call, "busy", "too many notifications are waiting");
            return;
        }
        c.value = data;
        persistSoon();
        String key = null;
        for (Service s : services.values()) if (s.chars.contains(c)) key = keyOf(s, c);
        Job job = new Job(call, to.size());
        for (String x : to) notifyQueue.add(new Packet(job, x, key, data, "indicate".equals(c.subscribers.get(x))));
        pumpNotify();
    }

    private void resolve(Packet p, boolean sent) {
        Job j = p.job;
        j.left--;
        if (sent) j.sent++;
        if (j.left == 0 && !j.failed) ok(j.call, obj("sent", j.sent, "subscribers", j.total));
    }

    private void failJob(Job j, String code, String message) {
        if (j.failed) return;
        j.failed = true;
        fail(j.call, code, message);
    }

    /** Sends queued packets one at a time, in order. */
    private void pumpNotify() {
        while (sending == null && !waitingReady && !notifyQueue.isEmpty()) {
            Packet p = notifyQueue.peek();
            if (!p.job.failed && !p.job.started && !port.isActive(p.job.call)) {
                failJob(p.job, "timeout", "the route timed out before the notification was sent");
            }
            Chr c = p.job.failed ? null : chrOf(p.key);
            if (c == null || !c.subscribers.containsKey(p.central)) {
                notifyQueue.poll();
                resolve(p, false);
                continue;
            }
            p.job.started = true;
            p.packet = ++nextOp;
            String r = port.notify(epoch, p.packet, p.central, p.key, p.data, p.indicate);
            if ("full".equals(r)) {
                waitingReady = true;
                return;
            }
            notifyQueue.poll();
            if (r == null) {
                resolve(p, true);
            } else if ("pending".equals(r)) {
                sending = p;
                port.timer("notify", p.packet, OP_MS);
            } else {
                int sp = r.indexOf(' ');
                failJob(p.job, sp < 0 ? r : r.substring(0, sp), sp < 0 ? "" : r.substring(sp + 1));
                resolve(p, false);
            }
        }
    }

    /** Android onNotificationSent for packet {@code packet}. */
    public void notifySent(int e, int packet, String code) {
        if (!serverCurrent(e, "notify_sent")) return;
        Packet p = sending;
        if (p == null || p.packet != packet) {
            stale("notify_sent " + packet);
            return;
        }
        sending = null;
        if (code != null) failJob(p.job, "gatt_error", "the notification failed: " + code);
        resolve(p, code == null);
        pumpNotify();
    }

    /** iOS peripheralManagerIsReady(toUpdateSubscribers:): the transmit queue has room again. */
    public void notifyReady(int e) {
        if (!serverCurrent(e, "notify_ready")) return;
        if (!waitingReady) return;
        waitingReady = false;
        pumpNotify();
    }

    /** A remote central connected to this server (Android), or was first seen (iOS). */
    public void centralConnected(int e, String central, int mtu) {
        if (!serverCurrent(e, "central")) return;
        seen(central, mtu);
    }

    private void seen(String central, int mtu) {
        if (centrals.containsKey(central)) {
            if (mtu > 0) centrals.put(central, mtu);
            return;
        }
        centrals.put(central, mtu > 0 ? mtu : 23);
        record("central", obj("central", central, "state", "connected", "mtu", centrals.get(central)));
        updateHold();
    }

    public void centralMtu(int e, String central, int mtu) {
        if (!serverCurrent(e, "central_mtu")) return;
        if (centrals.containsKey(central)) centrals.put(central, mtu);
    }

    public void centralDisconnected(int e, String central) {
        if (!serverCurrent(e, "central_gone")) return;
        if (!centrals.containsKey(central)) {
            stale("central_gone " + central);
            return;
        }
        endCentral(central, "remote");
        pumpNotify();
    }

    private void endCentral(String central, String reason) {
        for (Service s : services.values()) for (Chr c : s.chars) c.subscribers.remove(central);
        prepared.keySet().removeIf(k -> k.startsWith(central + "|"));
        centrals.remove(central);
        record("central", obj("central", central, "state", "disconnected", "reason", reason));
        updateHold();
    }

    private void dropSubscription(String central, String service, Chr c) {
        c.subscribers.remove(central);
        record("central", obj("central", central, "state", "unsubscribed", "service", service, "char", c.uuid,
                "char_n", c.n));
        if (!android && !subscribed(central)) centrals.remove(central);
    }

    private boolean subscribed(String central) {
        for (Service s : services.values()) for (Chr c : s.chars) if (c.subscribers.containsKey(central)) return true;
        return false;
    }

    /**
     * A central subscribed ({@code mode} notify or indicate) or unsubscribed (null). Android: a CCCD
     * write the extension serves; iOS: didSubscribeTo or didUnsubscribeFrom. Returns the ATT outcome:
     * ok, not_found, not_permitted or stale.
     */
    public String subscription(int e, String central, int mtu, String key, String mode) {
        if (!serverCurrent(e, "subscription")) return "stale";
        Chr c = chrOf(key);
        if (c == null) return "not_found";
        if (mode != null && !c.has("indicate".equals(mode) ? 'i' : 'n')) return "not_permitted";
        seen(central, mtu);
        String service = key.substring(0, key.indexOf('#'));
        if (mode == null) {
            if (c.subscribers.containsKey(central)) dropSubscription(central, service, c);
        } else {
            c.subscribers.put(central, mode);
            record("central", obj("central", central, "state", "subscribed", "service", service, "char", c.uuid,
                    "char_n", c.n, "mode", mode, "mtu", centrals.get(central)));
        }
        pumpNotify();
        return "ok";
    }

    /** Android: the CCCD value this central reads back. */
    public String cccd(String central, String key) {
        Chr c = chrOf(key);
        String mode = c == null ? null : c.subscribers.get(central);
        return mode == null ? "0000" : "indicate".equals(mode) ? "0200" : "0100";
    }

    /** A read request, answered from the value store: {status, hex}. Status ok, not_found, not_permitted, invalid_offset, unlikely or stale. */
    public Map<String, Object> readRequest(int e, String central, int mtu, String key, int offset) {
        if (!serverCurrent(e, "read_request")) return obj("status", "stale");
        Chr c = chrOf(key);
        if (c == null) return obj("status", "not_found");
        seen(central, mtu);
        if (!c.has('r')) return obj("status", "not_permitted");
        if (c.value == null) return obj("status", "unlikely");
        if (offset > c.value.length) return obj("status", "invalid_offset");
        return obj("status", "ok", "hex", hex(java.util.Arrays.copyOfRange(c.value, offset, c.value.length)));
    }

    /**
     * Write requests of one central, applied all or none (iOS delivers a batch and answers it once;
     * Android passes one). Each is {key, offset, hex}. {@code prepare}: an Android prepared write,
     * buffered until executeWrite. Returns ok, not_found, not_permitted, invalid_offset,
     * invalid_length or stale.
     */
    public String writeRequests(int e, String central, int mtu, List<Map<String, Object>> reqs, boolean prepare) {
        if (!serverCurrent(e, "write_request")) return "stale";
        Map<String, byte[]> next = new LinkedHashMap<>();
        for (Map<String, Object> r : reqs) {
            String key = (String) r.get("key");
            Chr c = chrOf(key);
            if (c == null) return "not_found";
            if (!c.has('w') && !c.has('c')) return "not_permitted";
            byte[] data = fromHex((String) r.get("hex"));
            if (data == null) return "invalid_length";
            String slot = prepare ? central + "|" + key : key;
            byte[] base = next.containsKey(slot) ? next.get(slot)
                    : prepare ? prepared.getOrDefault(slot, new byte[0]) : c.value == null ? new byte[0] : c.value;
            int offset = (Integer) r.get("offset");
            if (offset > base.length) return "invalid_offset";
            if (offset + data.length > WRITE_MAX) return "invalid_length";
            byte[] v = java.util.Arrays.copyOf(base, offset + data.length);
            System.arraycopy(data, 0, v, offset, data.length);
            next.put(slot, v);
        }
        seen(central, mtu);
        for (Map.Entry<String, byte[]> x : next.entrySet()) {
            if (prepare) prepared.put(x.getKey(), x.getValue());
            else commit(central, x.getKey(), x.getValue());
        }
        return "ok";
    }

    /** Android onExecuteWrite: commit (true) or drop this central's prepared writes. */
    public String executeWrite(int e, String central, boolean execute) {
        if (!serverCurrent(e, "execute_write")) return "stale";
        for (String slot : new ArrayList<>(prepared.keySet())) {
            if (!slot.startsWith(central + "|")) continue;
            byte[] v = prepared.remove(slot);
            if (execute) commit(central, slot.substring(central.length() + 1), v);
        }
        return "ok";
    }

    private void commit(String central, String key, byte[] v) {
        Chr c = chrOf(key);
        if (c == null) return;
        c.value = v;
        String[] p = key.split("[#/]");
        Map<String, Object> rec = obj("central", central, "kind", "write", "service", p[0], "char", p[2],
                "char_n", Integer.parseInt(p[3]), "hex", hex(v));
        append("request", rec);
        Map<String, Object> view = obj("seq", nextSeq, "t", journal.peekLast().get("t"));
        view.putAll(rec);
        pendingRequests.add(view);
        scheduleFlush();
        persistSoon();
    }

    // ---- advertising ----------------------------------------------------------------------------

    public void advertiseStart(int call, String servicesCsv, String name, int manufacturerId, String manufacturerHex,
                               String serviceDataUuid, String serviceDataHex, boolean connectable, String mode, int seconds) {
        List<String> uuids = uuidList(servicesCsv);
        if (uuids == null) {
            fail(call, "bad_value", "services must be up to 20 UUIDs");
            return;
        }
        if ((manufacturerId < 0) != (manufacturerHex == null) || manufacturerId > 0xFFFF
                || (manufacturerHex != null && fromHex(manufacturerHex) == null)) {
            fail(call, "bad_value", "manufacturer_id (0 to 65535) and manufacturer_hex go together, as an id and hex bytes");
            return;
        }
        String sdUuid = serviceDataUuid == null ? null : uuid(serviceDataUuid);
        if ((serviceDataUuid == null) != (serviceDataHex == null) || (serviceDataUuid != null && sdUuid == null)
                || (serviceDataHex != null && fromHex(serviceDataHex) == null)) {
            fail(call, "bad_value", "service_data_uuid and service_data_hex go together, as a UUID and hex bytes");
            return;
        }
        if (!on()) {
            fail(call, "unavailable", "Bluetooth is " + adapter);
            return;
        }
        if (adv != 0) {
            fail(call, "busy", "advertising is already running");
            return;
        }
        Map<String, Object> p = obj("services", new ArrayList<Object>(uuids), "name", name);
        p.put("manufacturerId", manufacturerId < 0 ? null : manufacturerId);
        p.put("manufacturerHex", manufacturerHex == null ? null : manufacturerHex.toLowerCase(Locale.ROOT));
        p.put("serviceDataUuid", sdUuid);
        p.put("serviceDataHex", serviceDataHex == null ? null : serviceDataHex.toLowerCase(Locale.ROOT));
        p.put("connectable", connectable);
        p.put("mode", mode);
        p.put("seconds", seconds);
        advWanted = p;
        advUntil = 0;
        advCall = call;
        startAdvertising(seconds);
    }

    private void startAdvertising(int seconds) {
        int t = ++nextAdv;
        Map<String, Object> p = advWanted;
        p.put("seconds", seconds);
        String err = port.advertiseStart(epoch, t, p);
        if (err != null) {
            advWanted = null;
            if (advCall >= 0) refused(advCall, err);
            else record("advertise_end", obj("reason", "failed"));
            advCall = -1;
            return;
        }
        adv = t;
        port.timer("advertise_start", t, OP_MS);
    }

    /** What this platform really advertises of the request. */
    private Map<String, Object> applied(Map<String, Object> p) {
        Map<String, Object> a = obj();
        a.put("name", p.get("name") == null ? null : android ? "adapter" : "given");
        a.put("manufacturer", android && p.get("manufacturerId") != null);
        a.put("serviceData", android && p.get("serviceDataUuid") != null);
        a.put("connectable", android ? p.get("connectable") : Boolean.TRUE);
        a.put("mode", android ? p.get("mode") : null);
        return a;
    }

    public void advertiseStarted(int e, int t, String code) {
        if (!serverCurrent(e, "advertise_started")) return;
        if (t != adv || advertising) {
            stale("advertise_started " + t);
            return;
        }
        if (code != null) {
            adv = 0;
            advWanted = null;
            if (advCall >= 0) fail(advCall, "advertise_failed", code);
            else record("advertise_end", obj("reason", "failed"));
            advCall = -1;
            return;
        }
        if (advCall >= 0 && !port.isActive(advCall)) {
            // The page already has the timeout: what it asked for does not stay on.
            port.advertiseStop(t);
            adv = 0;
            advWanted = null;
            fail(advCall, "timeout", "advertising started after the route timed out");
            advCall = -1;
            return;
        }
        advertising = true;
        int seconds = (Integer) advWanted.get("seconds");
        if (advUntil == 0 && seconds > 0) advUntil = port.now() + seconds * 1000L;
        if (seconds > 0) port.timer("advertise", t, Math.max(0, advUntil - port.now()));
        if (advCall >= 0) ok(advCall, obj("advertising", true, "applied", applied(advWanted)));
        advCall = -1;
        updateHold();
        persistSoon();
    }

    public void advertiseStop(int call) {
        boolean was = advertising;
        if (adv != 0) port.advertiseStop(adv);
        if (advCall >= 0) fail(advCall, "advertise_failed", "advertise_stop came before the platform started it");
        advCall = -1;
        adv = 0;
        advertising = false;
        advWanted = null;
        if (was) record("advertise_end", obj("reason", "stopped"));
        updateHold();
        persistSoon();
        ok(call, obj("advertising", false));
    }

    // ---- adapter changes of the server ----------------------------------------------------------

    /** Bluetooth left on: the server's platform objects of the old epoch are gone. */
    private void serverDown() {
        if (adv != 0) {
            if (advertising) record("advertise_end", obj("reason", "adapter"));
            if (advCall >= 0) {
                fail(advCall, "unavailable", "Bluetooth is " + adapter);
                advWanted = null;
            }
            advCall = -1;
            adv = 0;
            advertising = false;
        }
        for (String central : new ArrayList<>(centrals.keySet())) endCentral(central, "adapter");
        prepared.clear();
        if (sending != null) failJob(sending.job, "unavailable", "Bluetooth is " + adapter);
        for (Packet p : notifyQueue) failJob(p.job, "unavailable", "Bluetooth is " + adapter);
        sending = null;
        notifyQueue.clear();
        waitingReady = false;
        List<Service> waiting = new ArrayList<>(addQueue);
        if (adding != null) waiting.add(0, adding);
        for (Service s : waiting) {
            if (s.call >= 0) {
                services.remove(s.uuid);
                fail(s.call, "unavailable", "Bluetooth is " + adapter);
                s.call = -1;
            }
        }
        adding = null;
        addQueue.clear();
        for (Service s : services.values()) s.added = false;
    }

    /** Bluetooth is on again: re-apply the page's services and advertising (inside its duration). */
    private void serverUp() {
        for (Service s : services.values()) if (!s.added && s != adding && !addQueue.contains(s)) addQueue.add(s);
        pumpAdds();
        if (advWanted != null && adv == 0) {
            int seconds = (Integer) advWanted.get("seconds");
            if (advUntil == 0 || seconds == 0) {
                startAdvertising(seconds);
            } else if (advUntil > port.now()) {
                startAdvertising((int) ((advUntil - port.now() + 999) / 1000));
            } else {
                advWanted = null;
                persistSoon();
            }
        }
    }

                        return;

                return;

                for (Link l : links.values()) {

                        closeLink(l, "timeout", false);
                        return;
                    }
                }
                stale("pending timer " + token);
                return;
            case "op":
                for (Link l : links.values()) {
                    if (l.inFlight != null && l.inFlight.op == token && !l.closed) {
                        Op o = l.inFlight;
                        l.inFlight = null;
                        settle(l, o, "gatt_error", "the operation got no answer in " + OP_MS / 1000 + " s", null);
                        closeLink(l, "op_timeout", false);
                        return;
                    }
                }
                stale("op timer " + token);
                return;
            case "close":
                for (Map.Entry<String, Closing> e : closing.entrySet()) {
                    if (e.getValue().gen == token) {
                        String id = e.getKey();
                        port.release(id, token);
                        finishClosing(id, false);
                        return;
                    }
                }
                stale("close timer " + token);
                return;
            case "wait":
                for (Map.Entry<String, Closing> e : closing.entrySet()) {
                    Waiter w = e.getValue().waiter;
                    if (w != null && w.token == token) {
                        e.getValue().waiter = null;
                        fail(w.call, "connect_timeout", "the previous connection did not close in time");
                        return;
                    }
                }
                stale("wait timer " + token);
                return;
            case "service":
                if (adding != null && adding.token == token) {
                    Service s = adding;
                    adding = null;
                    port.serviceRemove(s.uuid);
                    if (s.call >= 0) {
                        services.remove(s.uuid);
                        fail(s.call, "gatt_error", "the platform did not confirm the service in " + OP_MS / 1000 + " s");
                        s.call = -1;
                    }
                    pumpAdds();
                } else {
                    stale("service timer " + token);
                }
                return;
            case "notify":
                if (sending != null && sending.packet == token) {
                    Packet p = sending;
                    sending = null;
                    failJob(p.job, "gatt_error", "the notification got no answer in " + OP_MS / 1000 + " s");
                    resolve(p, false);
                    pumpNotify();
                } else {
                    stale("notify timer " + token);
                }
                return;
            case "advertise_start":
                if (token == adv && !advertising) {
                    port.advertiseStop(token);
                    adv = 0;
                    advWanted = null;
                    if (advCall >= 0) fail(advCall, "advertise_failed", "the platform did not answer the advertising start");
                    else record("advertise_end", obj("reason", "failed"));
                    advCall = -1;
                } else {
                    stale("advertise_start timer " + token);
                }
                return;
            case "advertise":
                if (token == adv && advertising) {
                    port.advertiseStop(token);
                    adv = 0;
                    advertising = false;
                    advWanted = null;
                    record("advertise_end", obj("reason", "elapsed"));
                    updateHold();
                    persistSoon();
                } else {
                    stale("advertise timer " + token);
                }
                return;
            case "persist":
                persistScheduled = false;
                port.persist(serverSnapshot());
                return;
            default:
                stale("timer " + kind);
        }
    }
```

```java android/ble/src/main/java/despia/ext/ble/BleExtension.java
/**
 * Universal Bluetooth LE for the page: scan, connect, GATT client, GATT server, advertising, the
 * keep-alive service and raw bytes. Every decision is
 * {@link BleCore}'s; {@link AndroidRadio} talks to the stack. This class owns the bridge side: route
 * parameters, permissions, one reply per call, events and timers, all on the main thread.
 *
 * <p>Permissions by role ({@link BleCore#permissions}): from API 31 the dashboard-owned
 * BLUETOOTH_SCAN (plus ACCESS_FINE_LOCATION unless the app declares BLUETOOTH_SCAN with
 * neverForLocation) and BLUETOOTH_CONNECT; on API 24 to 30 the install-time BLUETOOTH and
 * BLUETOOTH_ADMIN (declared by this module with maxSdkVersion 30) and ACCESS_FINE_LOCATION at
 * runtime. Advertising adds BLUETOOTH_ADVERTISE from API 31; the GATT server needs BLUETOOTH_CONNECT. A missing install-time grant is reported, never requested. Missing runtime permissions are
 * requested through the activity's ActivityResultRegistry under {@link ExtContext#resultKey},
 * registered on {@code created}; one request at a time.
 *
 * <p>Each route that needs a prompt is an attempt tied to its {@link ExtCall}: an answer after the
 * call timed out starts nothing, and a destroyed activity ends the wait, so nothing stays busy.
 * Nothing starts at launch: the adapter receiver is registered on the first route call.

    private static final class Attempt {
        final ExtCall call;
        final ExtResult.Callback reply;
        final String role;

            this.reply = reply;

    private static final class Waiting {
        final ExtCall call;
        final ExtResult.Callback reply;

    @Override

    @Override
    public void onActivityEvent(Activity activity, ActivityEvent event) {
        if (event == ActivityEvent.STARTED) {
            if (startedActivities++ == 0 && radioStarted) core.background(false);
        } else if (event == ActivityEvent.STOPPED) {
            if (startedActivities > 0 && --startedActivities == 0 && radioStarted) core.background(true);
        }
        if (!(activity instanceof ComponentActivity)) return;
        ComponentActivity a = (ComponentActivity) activity;
        if (event == ActivityEvent.CREATED) {
            if (permission != null) permission.unregister();
            registeredOn = a;
            permission = a.getActivityResultRegistry().register(ctx.resultKey("permissions"),
                    new ActivityResultContracts.RequestMultiplePermissions(), (Map<String, Boolean> result) -> {
                        Attempt at = pending;
                        if (at == null || at.ended) return;
                        if (!at.call.isActive()) {
                            // A late Allow: the page already has the timeout. Start nothing.
                            finish(at, ExtResult.error("timeout", "Bluetooth was allowed after the route timed out"));
                        } else if (missingRuntime(at.role).isEmpty()) {
                            proceed(at);
                        } else {
                            finish(at, ExtResult.error("permission_denied", "Bluetooth access was denied"));
                        }
                    });
        } else if (event == ActivityEvent.DESTROYED && registeredOn == a && permission != null) {
            permission.unregister();
            permission = null;
            registeredOn = null;
            // Recreated (configuration, or the system reclaimed it): the permission answer reaches
            // the launcher the new activity registers under the same key, so the route waits.
            // Finishing: the answer can no longer arrive; the route waiting for it ends.
            if (pending != null && !pending.ended && a.isFinishing()) {
                finish(pending, ExtResult.error("unavailable", "the activity was destroyed"));
            }
        }

    static String role(String route, Map<String, Object> params) {
        switch (route) {
            case "scan_start":

            case "advertise_start":
            case "advertise_stop":

    @Override
    public void handle(ExtCall call, ExtResult.Callback reply) {
        String role = role(call.route, call.params);
        if (role == null) {
            dispatch(call, reply);
            return;
        }
        if (pending != null && !pending.ended && pending.call.isActive()) {
            reply.reply(ExtResult.error("busy", "a Bluetooth permission request is already open"));
            return;
        }
        Attempt at = new Attempt(call, reply, role);
        pending = at;
        String installTime = missingInstallTime(role);
        List<String> runtime = missingRuntime(role);
        if (installTime != null) {
            finish(at, ExtResult.error("unavailable", installTime + " is not declared in this build"));
        } else if (runtime.isEmpty()) {
            proceed(at);
        } else if (permission != null) {
            permission.launch(runtime.toArray(new String[0]));
        } else {
            finish(at, ExtResult.error("permission_denied", "Bluetooth access is not granted"));
        }
    }

    /** The permission is in place: hand the route to the core. Never leaves the slot taken. */
    private void proceed(Attempt at) {
        if (pending == at) pending = null;
        ExtResult.Callback once = r -> {
            if (at.ended) return;
            at.ended = true;
            at.reply.reply(r);
        };
        try {
            dispatch(at.call, once);
        } catch (RuntimeException e) {
            once.reply(ExtResult.error("handler_error", e.getClass().getSimpleName()));
        }
    }

        if (pending == at) pending = null;
        if (at.ended) return;

        at.reply.reply(result);

    private boolean scanNeverForLocation() {
        try {
            Context app = ctx.app();
            PackageInfo info = app.getPackageManager().getPackageInfo(app.getPackageName(), PackageManager.GET_PERMISSIONS);
            if (info.requestedPermissions == null || info.requestedPermissionsFlags == null) return false;
            for (int i = 0; i < info.requestedPermissions.length; i++) {
                if (Manifest.permission.BLUETOOTH_SCAN.equals(info.requestedPermissions[i])) {
                    return (info.requestedPermissionsFlags[i] & PackageInfo.REQUESTED_PERMISSION_NEVER_FOR_LOCATION) != 0;
                }
            }
        } catch (PackageManager.NameNotFoundException | RuntimeException e) {
            ctx.log("permission flags unreadable: " + e.getClass().getSimpleName());
        }
        return false;
```

```java android/ble/src/main/java/despia/ext/ble/BleLinkService.java
import android.app.Notification;
import android.app.NotificationChannel;
import android.app.NotificationManager;

import android.app.Service;
import android.content.Intent;
import android.content.pm.ServiceInfo;
import android.os.Build;
import android.os.IBinder;
import android.util.Log;

/**
 * Keeps the process alive while the page asked for it ({@code keep_alive?enabled=true}) and a link,
 * a remote central or advertising exists. It decides nothing: {@link BleCore#holdCurrent} says
 * whether a start is still wanted. Started only by {@link AndroidRadio#keepAlive} while an activity
 * is started; never at launch, never sticky.
 *
 * <p>Every start enters the foreground first (the platform's obligation after
 * {@code startForegroundService}), then a start whose hold generation is no longer current stops
 * with {@code stopSelfResult} of its own start id, so an older start never ends a newer one. There is
 * no unqualified {@code stopSelf()}.
 */
public final class BleLinkService extends Service {
    static final String EXTRA_HOLD = "despia.ext.ble.hold";
    static final String CHANNEL = "nativeext.ble.link";
    static final int NOTIFICATION = 0x0B1E;

    /** The core of the running extension (set when it is created; main thread only). */
    static BleCore core;
    private static BleLinkService running;
    private int lastStartId;

    @Override
    public IBinder onBind(Intent intent) {
        return null;
    }

    @Override
    public int onStartCommand(Intent intent, int flags, int startId) {
        lastStartId = startId;
        running = this;
        if (!enterForeground()) {
            leave(startId);
            return START_NOT_STICKY;
        }
        int g = intent == null ? -1 : intent.getIntExtra(EXTRA_HOLD, -1);
        BleCore c = core;
        if (c == null || !c.holdCurrent(g)) leave(startId);
        // A restart with a null intent would show the notification for links that no longer exist.
        return START_NOT_STICKY;
    }

    /** Ends the service for the newest start; called when the core's hold ends. */
    static void release() {
        BleLinkService s = running;
        if (s != null) s.leave(s.lastStartId);
    }

    private void leave(int startId) {
        stopForeground(STOP_FOREGROUND_REMOVE);
        stopSelfResult(startId);
    }

    @Override
    public void onDestroy() {
        if (running == this) running = null;
        super.onDestroy();
    }

    private String text(String name, String fallback) {
        int id = getResources().getIdentifier(name, "string", getPackageName());
        return id == 0 ? fallback : getString(id);
    }

    @SuppressWarnings("deprecation")
    private boolean enterForeground() {
        Notification.Builder b;
        if (Build.VERSION.SDK_INT >= 26) {
            NotificationManager nm = getSystemService(NotificationManager.class);
            if (nm != null) {
                nm.createNotificationChannel(new NotificationChannel(CHANNEL,
                        text("nx_ble_channel_name", "Bluetooth connections"), NotificationManager.IMPORTANCE_LOW));
            }
            b = new Notification.Builder(this, CHANNEL);
        } else {
            b = new Notification.Builder(this).setPriority(Notification.PRIORITY_LOW);
        }
        b.setSmallIcon(android.R.drawable.stat_sys_data_bluetooth)
                .setContentTitle(text("nx_ble_link_title", "Bluetooth"))
                .setContentText(text("nx_ble_link_text", "Keeping Bluetooth devices connected"))
                .setOngoing(true);
        Intent launch = getPackageManager().getLaunchIntentForPackage(getPackageName());
        if (launch != null) b.setContentIntent(PendingIntent.getActivity(this, 0, launch, PendingIntent.FLAG_IMMUTABLE));
        try {
            if (Build.VERSION.SDK_INT >= 29) {
                startForeground(NOTIFICATION, b.build(), ServiceInfo.FOREGROUND_SERVICE_TYPE_CONNECTED_DEVICE);
            } else {
                startForeground(NOTIFICATION, b.build());
            }
            return true;
        } catch (RuntimeException e) {
            // API 34: SecurityException without the connected-device grant; API 31:
            // ForegroundServiceStartNotAllowedException. Links go on while the process lives.
            Log.w("nativeext.ble", "keep-alive could not enter the foreground: " + e.getClass().getSimpleName());
            return false;
        }
    }
}
```

## Using it from your web app

Every route answers once in its own variable and callback, `ble<Route>` and `onBle<Route>`, for example `bleScanStart` and `onBleScanStart`. Events arrive on their own callbacks. Define the event callbacks before you call a route.

<Tabs>
  <Tab title="Central">
    ```javascript
    import despia from 'despia-native';

    const ble = (route, params = {}) => {
      const query = new URLSearchParams(params).toString();
      const name = 'ble' + route.split('_').map((w) => w[0].toUpperCase() + w.slice(1)).join('');
      return despia(`extension://ble/${route}${query ? '?' + query : ''}`, [name]).then((r) => r[name]);
    };

    const HEART_RATE = '180d';
    const MEASUREMENT = '2a37';

    // Devices found while scanning, batched every 50 ms.
    window.onBleDevice = (e) => e.devices.forEach((d) => console.log(d.id, d.name, d.rssi));
    // Notified values.
    window.onBleValue = (e) => e.records.forEach((v) => console.log(v.char, v.hex));
    // Link changes: connected, reconnecting, disconnected.
    window.onBleLink = (e) => console.log(e.id, e.state, e.reason);

    // 1. Ask for Bluetooth and check the adapter.
    const state = await ble('state', { prompt: true });
    if (!state.ok || state.data.state !== 'on') throw new Error(state.code || state.data.state);

    // 2. Scan for 10 seconds for devices that advertise the service.
    await ble('scan_start', { services: HEART_RATE, seconds: 10 });
    // ...later, pick a device from onBleDevice or from:
    const { data: { devices } } = await ble('devices');

    // 3. Connect, discover and subscribe.
    const id = devices[0].id;
    await ble('connect', { id, auto: true });
    await ble('discover', { id });
    await ble('subscribe', { id, service: HEART_RATE, char: MEASUREMENT });

    // 4. Read and write.
    const read = await ble('read', { id, service: '180f', char: '2a19' }); // battery level
    console.log(read.data.hex);
    await ble('write', { id, service: 'fff0', char: 'fff1', hex: '0102' });

    // 5. Done.
    await ble('disconnect', { id });
    ```

  <Tab title="Peripheral">
    ```javascript
    import despia from 'despia-native';

    const ble = (route, params = {}) => {
      const query = new URLSearchParams(params).toString();
      const name = 'ble' + route.split('_').map((w) => w[0].toUpperCase() + w.slice(1)).join('');
      return despia(`extension://ble/${route}${query ? '?' + query : ''}`, [name]).then((r) => r[name]);
    };

    const SERVICE = '0000fff0-0000-1000-8000-00805f9b34fb';
    const STATUS = '0000fff1-0000-1000-8000-00805f9b34fb';  // read and notify
    const COMMAND = '0000fff2-0000-1000-8000-00805f9b34fb'; // write

    // Centrals connecting, subscribing and leaving.
    window.onBleCentral = (e) => console.log(e.central, e.state);
    // Writes from centrals, batched.
    window.onBleRequest = (e) => e.records.forEach((w) => console.log(w.central, w.char, w.hex));
    // Advertising ended: stopped, elapsed, adapter or failed.
    window.onBleAdvertiseEnd = (e) => console.log(e.reason);

    await ble('state', { prompt: true });

    // 1. Publish a service. chars: <uuid>~<flags>[~<start hex>], separated by commas.
    //    Flags: r read, w write, c write without response, n notify, i indicate,
    //    R and W read and write over an encrypted link.
    await ble('service_add', { uuid: SERVICE, chars: `${STATUS}~rn~00,${COMMAND}~w` });

    // 2. Set the value reads are answered with.
    await ble('value_set', { service: SERVICE, char: STATUS, hex: '01' });

    // 3. Advertise for 5 minutes.
    const adv = await ble('advertise_start', { services: SERVICE, name: 'My Device', seconds: 300 });
    console.log(adv.data.applied); // what this platform really advertises

    // 4. Notify every subscribed central.
    await ble('notify', { service: SERVICE, char: STATUS, hex: '02' });

    // 5. Done.
    await ble('advertise_stop');
    await ble('service_remove');
    ```

Ask for Bluetooth first: call `state` with `prompt=true` before the first scan, connect or server route, so the system prompt is answered before anything waits on it. A route that waited too long answers `timeout` and started nothing. Call it again. A `connect` to a device that is already connecting (for example one iOS brought back after your app relaunched) joins that attempt and resolves with its result.

### Routes

**Central**

| Route         | Parameters                                                                              | Answer `data`                                    |
| ------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------ |
| `state`       | `prompt`                                                                                | `state`, `authorization`, `scanning`, `advertising`, `links`, `centrals`, `keepAlive`, `epoch`, `run` |
| `events`      | `after` (0 or more), `max` (1 to 200)                                                   | `records`, `next`, `dropped`, `run`              |
| `scan_start`  | `services` (comma-separated, up to 20), `seconds` (0 to 3600, 0 until `scan_stop`), `duplicates`, `mode` | `scan`                          |
| `scan_stop`   | none                                                                                    | `scan`, `stopped`                                |
| `devices`     | none                                                                                    | `devices` (up to 200)                            |
| `connect`     | `id` (required), `auto`, `seconds` (1 to 20, default 10)                                 | `id`, `link`, `state`, `mtu`                     |
| `disconnect`  | `id` (required)                                                                         | `id`, `state`, `confirmed`                       |
| `links`       | none                                                                                    | `links`                                          |
| `discover`    | `id` (required)                                                                         | `id`, `services`                                 |
| `read`        | `id`, `service`, `char` (required), `service_n`, `char_n`, `descriptor`                  | `hex`                                            |
| `write`       | as `read`, plus `hex` or `b64`, `response` (default `true`)                              | `written`, `chunks`                              |
| `subscribe`, `unsubscribe` | `id`, `service`, `char` (required), `service_n`, `char_n`                  | `subscribed`, `mode`                             |
| `rssi`        | `id` (required)                                                                         | `rssi`                                           |
| `mtu`         | `id` (required), `size` (23 to 517)                                                     | `mtu`, `writeMax`, `writeNoResponseMax`, `requested` |

**Peripheral**

| Route             | Parameters                                                                     | Answer `data`                       |
| ----------------- | ------------------------------------------------------------------------------ | ----------------------------------- |
| `service_add`     | `uuid` (required), `primary` (default `true`), `chars`                         | `uuid`, `characteristics`           |
| `service_remove`  | `uuid`; without it, every service                                              | `removed`                           |
| `services`        | none                                                                           | `services`, `advertising`           |
| `value_set`       | `service`, `char` (required), `char_n`, `hex` or `b64` (up to 512 bytes)        | `bytes`                             |
| `notify`          | as `value_set`, plus `central` (one central; without it, every subscribed one) | `sent`, `subscribers`               |
| `advertise_start` | `services`, `name` (up to 26), `manufacturer_id` with `manufacturer_hex`, `service_data_uuid` with `service_data_hex`, `connectable` (default `true`), `mode`, `seconds` (0 to 3600) | `advertising`, `applied` |
| `advertise_stop`  | none                                                                           | `advertising`                       |
| `centrals`        | none                                                                           | `centrals`                          |
| `central_drop`    | `central` (required)                                                           | `dropped`                           |
| `keep_alive`      | `enabled` (required)                                                           | `enabled`, `active`, `reason`       |

`mode` is `low_power`, `balanced` or `low_latency`. A device `id` is the iOS peripheral identifier or the Android MAC address. UUIDs can be 16, 32 or 128 bit in any case; answers always use lower-case 128-bit. `service_n` and `char_n` number equal UUIDs in discovery order.

### Events

| Event           | Callback            | Scope      | When                                                         |
| --------------- | ------------------- | ---------- | ------------------------------------------------------------ |
| `adapter`       | `onBleAdapter`      | `app`      | Bluetooth turned on or off                                   |
| `restored`      | `onBleRestored`     | `app`      | iOS restored the Bluetooth state after a relaunch            |
| `device`        | `onBleDevice`       | `document` | Devices found by a scan, batched every 50 ms                 |
| `scan_end`      | `onBleScanEnd`      | `document` | A scan ended                                                 |
| `link`          | `onBleLink`         | `document` | A link connected, is reconnecting, or disconnected           |
| `value`         | `onBleValue`        | `document` | Notified values, batched every 50 ms                         |
| `gatt_changed`  | `onBleGattChanged`  | `document` | A device changed its services                                |
| `central`       | `onBleCentral`      | `document` | A central connected, disconnected, subscribed or unsubscribed |
| `request`       | `onBleRequest`      | `document` | Writes from centrals, batched                                |
| `advertise_end` | `onBleAdvertiseEnd` | `document` | Advertising stopped, elapsed, lost the adapter, or failed    |

`restored` carries `peripherals` and `scanning` for the central role, and `services`, `advertising` and `lost` for the server role. Every event is also a journal record, so a page that was not loaded when it happened reads it with `events`. `device` and `value` are batched every 50 ms.

### Error codes

A failed `connect` answers `connect_failed`. Its message and the `link` event carry the platform's own error: `error: {domain, code, message, name}`, the CoreBluetooth error on iOS and the GATT status on Android. A known code also gives a readable `reason`, such as `encryption_timeout`.

Besides the [standard codes](/experiments/v3-extensions#error-codes): `busy`, `unavailable`, `permission_denied`, `scan_failed`, `bad_value`, `unknown_device`, `not_connected`, `not_found`, `not_permitted`, `too_long`, `connect_failed`, `connect_timeout`, `gatt_error`, `link_lost`, `filter_required` (a scan in the background needs a service filter), `advertise_failed`, `no_subscribers` and `platform_limit` (this platform has no such API; the message names it).

## Platform limits

- **iOS.** No scan `mode` and no MTU request (`mtu` answers `requested: false`). No API to drop a central (`central_drop` answers `platform_limit`). An advertisement carries only service UUIDs and a local name, is always connectable, and in the background carries no name. In the background, a scan without a service filter is stopped, and a new one answers `filter_required`.
- **iOS, reads.** A characteristic value and a read answer arrive through the same callback, so a notification that lands while a read of the same characteristic is in flight answers that read.
- **Android.** No state restoration: links, the server and advertising end with the app's process. Use `keep_alive` to keep links while the app is in the background. With `name`, Android advertises the device's own Bluetooth name. A controller without advertising support answers `platform_limit`.
- **Both.** One GATT operation runs at a time per link, up to 64 wait, and each has a 10 second timeout that closes the link. Writes are at most 512 bytes. A write without response means the bytes were handed to the system, not that they were delivered.
