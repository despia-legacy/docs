title: "Media Picker"
description: "A copy-paste V3 Extension with the platforms' own file pickers, native video transcoding and an upload that survives the app being killed."
icon: "photo-film"
tag: "Experimental"
---

This sample replaces the web view's `<input type="file">` with the platform's own pickers for every kind of file. Each picked file reaches your page as a local URL at once, with no base64 and no bytes through the bridge. You can transcode video natively and upload a file to your server in a way that survives the app being killed.

- **Pick:** photos and videos, audio, documents and any MIME type, from the library, the camera or the Files app.
- **Use:** play, show or `fetch` the file straight from its local URL.
- **Transcode:** video to a preset size, codec, frame rate and audio setting, with progress.
- **Upload:** to your https URL with `PUT` or `POST`, with retries, also after a relaunch.

<Warning>
  **Experimental. V3 only.** This is a template, not a Despia feature. It is never migrated to V4. You own and maintain this code once it is in your app. Despia does not support customised code. Read [V3 Extensions](/experiments/v3-extensions) first.
</Warning>

<Note>
  **Tested on:** the Android emulator and an iPhone 15 (the picker). Not every scenario passed yet, and denying the camera was not tested.
</Note>

## Files

Copy every file to the path in its title. Paths are under `public/despia/mediapicker/` in your web app, except `extensions.json`, which goes in `public/despia/`. `public/` is the folder your site serves from its root (in SvelteKit, write `static/`). The paths must stay as written, because the manifest names them. Despia reviews and approves these exact files before a build includes them.

Before you build:

- In `public/despia/extensions.json`, set `client_id`, `ios_bundle_id` and `android_package` to your own app's values. The sample's `com.example.app` is a placeholder.
- In `manifest.json`, in the `upload` route's `hosts`, replace `upload.example.com` with the host your uploads go to.
- In Despia, turn on the camera and microphone purpose strings (iOS) and `CAMERA` (Android), which the manifest lists under `requires`.

The Android dependencies must be the versions your app's base build already resolves. The build refuses others. The approval policy is a file you send to Despia with your approval request. It is not served from your site.

```swift ios/app/MediaFileServer.swift
import Foundation
import Network

/// Serves picked files to the page over HTTP on the loopback interface only, so `<img>`, `<video>`,
/// `<audio>` and `fetch()` read them straight from disk with byte ranges, never through the bridge.
///
/// Why loopback: the extension API gives no access to the web view (no WKURLSchemeHandler can be
/// registered after the web view exists, and NativeExtContext offers none), and a bridge reply is a
/// JavaScript string, which would mean base64 for every byte. The base app's ATS dictionary already
/// sets NSAllowsLocalNetworking (WebView/Info.plist), and loopback is not subject to iOS local
/// network privacy.
///
/// Security: bound to 127.0.0.1 and to the loopback interface; read-only (GET, HEAD, OPTIONS); every
/// URL carries a 256-bit random token that exists only while its file is held; no cookie or
/// credential is read or set, so the URL itself is the capability and `Access-Control-Allow-Origin: *`
/// grants nothing a page without the URL could use. Any app on the device could connect to the
/// port, but without a token it gets 404.
///
/// Threading: the table and the listener live on `queue`; `onPort` is called on the main queue.
final class MediaFileServer {
    struct Entry {
        let path: URL
        let mime: String
    }

    private let queue = DispatchQueue(label: "nativeext.mediapicker.server")
    private var listener: NWListener?
    private var table: [String: Entry] = [:]
    private var boundPort: UInt16 = 0
    private var preferredPort: UInt16 = 0
    private let log: (String) -> Void
    /// Main queue: the port now serving (nil while none is bound).
    var onPort: ((UInt16?) -> Void)?

    static let chunk = 256 * 1024
    /// A connection that sends no complete head in this time is closed (as on Android).
    static let headTimeout: TimeInterval = 10
    /// Concurrent connections; a media element opens a few, more are closed at once (as on Android).
    static let maxConnections = 16
    private var open: [ObjectIdentifier: NWConnection] = [:]

    init(log: @escaping (String) -> Void) {
        self.log = log
    }

    /// Starts listening if not already; tries the last port first so URLs the page holds stay valid
    /// after iOS reclaimed the socket during suspension.
    func ensureRunning() {
        queue.async { self.startLocked() }
    }

    private func startLocked() {
        if let l = listener, l.state == .ready || l.state == .setup { return }
        listener?.cancel()
        listener = nil
        let params = NWParameters.tcp
        params.requiredInterfaceType = .loopback
        params.acceptLocalOnly = true
        params.allowLocalEndpointReuse = true
        let port = NWEndpoint.Port(rawValue: preferredPort) ?? .any
        params.requiredLocalEndpoint = NWEndpoint.hostPort(host: .ipv4(.loopback), port: port)
        let l: NWListener
        do {
            l = try NWListener(using: params)
        } catch {
            log("file server not started: \(error.localizedDescription)")
            if preferredPort != 0 {
                preferredPort = 0
                startLocked()
            } else {
                report(nil)
            }
            return
        }
        l.newConnectionHandler = { [weak self] c in self?.accept(c) }
        l.stateUpdateHandler = { [weak self, weak l] state in
            guard let self = self, let l = l, self.listener === l else { return }
            switch state {
            case .ready:
                self.boundPort = l.port?.rawValue ?? 0
                self.preferredPort = self.boundPort
                self.report(self.boundPort)
            case .failed(let e):
                self.log("file server stopped: \(e.localizedDescription)")
                l.cancel()
                self.listener = nil
                self.boundPort = 0
                self.report(nil)
                // The preferred port may be taken by now: the next ensureRunning tries it, then any.
                if case .posix(let code) = e, code == .EADDRINUSE { self.preferredPort = 0 }
            case .cancelled:
                if self.listener === l { self.listener = nil }
            default:
                break
            }
        }
        listener = l
        l.start(queue: queue)
    }

    private func report(_ port: UInt16?) {
        DispatchQueue.main.async { [weak self] in self?.onPort?(port) }
    }

    func publish(token: String, entry: Entry) {
        precondition(MPCore.isToken(token))
        queue.async { self.table[token] = entry }
    }

    func withdraw(token: String) {
        queue.async { self.table[token] = nil }
    }

    func stop() {
        queue.async {
            self.listener?.cancel()
            self.listener = nil
            self.table.removeAll()
            for c in self.open.values { c.cancel() }
        }
    }

    // MARK: Connections

    private func accept(_ c: NWConnection) {
        // Belt and braces: the listener is loopback-only; anything else is closed unanswered.
        if case .hostPort(let host, _) = c.endpoint {
            switch host {
            case .ipv4(let a) where a == .loopback: break
            case .ipv6(let a) where a == .loopback: break
            default:
                c.cancel()
                return
            }
        }
        guard open.count < MediaFileServer.maxConnections else {
            c.cancel()
            return
        }
        let key = ObjectIdentifier(c)
        open[key] = c
        c.stateUpdateHandler = { [weak self] state in
            switch state {
            case .cancelled, .failed:
                self?.open[key] = nil
                self?.heads.remove(key)
            default: break
            }
        }
        // Closed when the head is not complete in time; a served request owns the connection after.
        let deadline = DispatchWorkItem { [weak self, weak c] in
            guard let c = c, self?.heads.contains(ObjectIdentifier(c)) == true else { return }
            c.cancel()
        }
        heads.insert(key)
        queue.asyncAfter(deadline: .now() + MediaFileServer.headTimeout, execute: deadline)
        c.start(queue: queue)
        read(c, [])
    }

    /// Connections still waiting for a complete head.
    private var heads: Set<ObjectIdentifier> = []

    private func read(_ c: NWConnection, _ buffer: [UInt8]) {
        c.receive(minimumIncompleteLength: 1, maximumLength: MPCore.maxHead) { [weak self] data, _, complete, error in
            guard let self = self else { return c.cancel() }
            var buf = buffer
            if let d = data { buf.append(contentsOf: d) }
            switch MPCore.parseHead(buf) {
            case .needMore:
                if complete || error != nil {
                    self.heads.remove(ObjectIdentifier(c))
                    c.cancel()
                } else {
                    self.read(c, buf)
                }
            case .bad(let status):
                self.heads.remove(ObjectIdentifier(c))
                self.respond(c, head: MPCore.responseHead(status: status, mime: nil, size: 0, range: nil, method: "GET",
                                                          privateNetwork: false), body: nil)
            case .request(let req, _):
                self.heads.remove(ObjectIdentifier(c))
                self.serve(c, req)
            }
        }
    }

    private func serve(_ c: NWConnection, _ req: MPRequest) {
        let entry = MPCore.token(fromTarget: req.target).flatMap { table[$0] }
        var size: Int64 = 0
        var handle: FileHandle?
        if let e = entry, let h = try? FileHandle(forReadingFrom: e.path) {
            handle = h
            size = Int64(h.seekToEndOfFile())
        }
        let known = handle != nil
        let r = MPCore.range(req.headers["range"], size: size)
        let status = MPCore.status(method: req.method, known: known, range: r)
        let pn = req.headers["access-control-request-private-network"] == "true"
        let head = MPCore.responseHead(status: status, mime: entry?.mime, size: size, range: status == 206 ? r : nil,
                                       method: req.method, privateNetwork: pn)
        guard req.method == "GET", status == 200 || status == 206, let h = handle, r.end >= r.start else {
            try? handle?.close()
            respond(c, head: head, body: nil)
            return
        }
        h.seek(toFileOffset: UInt64(r.start))
        c.send(content: Data(head.utf8), completion: .contentProcessed { [weak self] err in
            guard err == nil else {
                try? h.close()
                return c.cancel()
            }
            self?.stream(c, h, remaining: r.end - r.start + 1)
        })
    }

    /// Sends the range in chunks, each after the previous one was taken by the connection, so a
    /// 4K video is never held in memory.
    private func stream(_ c: NWConnection, _ h: FileHandle, remaining: Int64) {
        guard remaining > 0 else {
            try? h.close()
            c.send(content: nil, contentContext: .finalMessage, isComplete: true, completion: .contentProcessed { _ in c.cancel() })
            return
        }
        let n = Int(min(Int64(MediaFileServer.chunk), remaining))
        let data = h.readData(ofLength: n)
        guard !data.isEmpty else {
            // The file shrank or was released while being read: end the response short.
            try? h.close()
            return c.cancel()
        }
        c.send(content: data, completion: .contentProcessed { [weak self] err in
            guard err == nil, let self = self else {
                try? h.close()
                return c.cancel()
            }
            self.stream(c, h, remaining: remaining - Int64(data.count))
        })
    }

    private func respond(_ c: NWConnection, head: String, body: Data?) {
        var out = Data(head.utf8)
        if let b = body { out.append(b) }
        c.send(content: out, contentContext: .finalMessage, isComplete: true, completion: .contentProcessed { _ in c.cancel() })
    }
}
```

```swift ios/app/MediaPickerCore.swift
import Foundation

// Pure decisions of the media picker (Foundation only, no UIKit, AVFoundation or Network).
// Every rule here has a twin in android/.../MediaCore.java, and both follow the same
// shared rules. The platform files only translate.

/// What the page asked to pick: categories (`image`, `video`, `audio`, `document`) and MIME types
/// (`application/pdf`, `image/*`). Open form: any MIME type the platform knows is accepted.
struct MPTypes: Equatable {
    var categories: Set<String>
    var mimes: [String]

    var isAny: Bool { categories.contains("any") || (categories.isEmpty && mimes.isEmpty) }

    /// Everything asked for can be shown by the photo library (images and videos only).
    var visualOnly: Bool {
        guard !isAny else { return false }
        let catsVisual = categories.allSatisfy { $0 == "image" || $0 == "video" }
        let mimesVisual = mimes.allSatisfy { $0.hasPrefix("image/") || $0.hasPrefix("video/") }
        return catsVisual && mimesVisual
    }

    var wantsImages: Bool { isAny || categories.contains("image") || mimes.contains { $0.hasPrefix("image/") } }
    var wantsVideos: Bool { isAny || categories.contains("video") || mimes.contains { $0.hasPrefix("video/") } }
}

struct MPRange: Equatable {
    let status: Int
    let start: Int64
    let end: Int64
}

struct MPRequest: Equatable {
    let method: String
    let target: String
    let headers: [String: String]
}

enum MPHead: Equatable {
    case needMore
    case bad(Int)
    case request(MPRequest, consumed: Int)
}

struct MPTarget: Equatable {
    let width: Int
    let height: Int
    let bitrateKbps: Int
}

enum MPOutcome: Equatable {
    case uploaded
    case failed(String)
    case requeue
    case retry(String)
}

enum MPCore {
    static let categoryWords: Set<String> = ["image", "video", "audio", "document", "any"]
    static let maxTypeTokens = 32
    static let maxHead = 16 * 1024
    static let maxNameScalars = 120
    /// Space and horizontal tab only (the same set as MediaCore.java), never Unicode spaces.
    static let spaces = CharacterSet(charactersIn: " \t")

    // MARK: Types and sources

    /// nil: the page's `types` is not a list of categories and MIME types (`bad_value`).
    static func parseTypes(_ raw: String?) -> MPTypes? {
        var out = MPTypes(categories: [], mimes: [])
        guard let raw = raw else { return out }
        let tokens = raw.split(separator: ",", omittingEmptySubsequences: false)
            .map { $0.trimmingCharacters(in: MPCore.spaces).lowercased() }
        if tokens.count == 1, tokens[0].isEmpty { return out }
        guard tokens.count <= maxTypeTokens else { return nil }
        for t in tokens {
            if categoryWords.contains(t) {
                out.categories.insert(t)
            } else if isMime(t) {
                if !out.mimes.contains(t) { out.mimes.append(t) }
            } else {
                return nil
            }
        }
        return out
    }

    private static let mimeChars = Set("abcdefghijklmnopqrstuvwxyz0123456789!#$&^_.+-")

    static func isMime(_ s: String) -> Bool {
        let parts = s.split(separator: "/", omittingEmptySubsequences: false)
        guard parts.count == 2 else { return false }
        func token(_ p: Substring) -> Bool {
            guard let first = p.first, p.count <= 64, first.isLetter || first.isNumber, first.isASCII else { return false }
            return p.allSatisfy { mimeChars.contains($0) }
        }
        return token(parts[0]) && (parts[1] == "*" || token(parts[1]))
    }

    /// The picker to show: `library`, `files`, `camera` or `sheet` (a native choice of the three);
    /// nil when the request cannot be met by that source (`bad_value`).
    static func source(requested: String, types: MPTypes) -> String? {
        switch requested {
        case "auto":
            if types.visualOnly { return "library" }
            if !types.isAny && !types.wantsImages && !types.wantsVideos { return "files" }
            return "sheet"
        case "library":

    static func safeName(_ raw: String, fallbackExtension: String) -> String {
        var s = raw

        var scalars = String.UnicodeScalarView()
        for u in s.unicodeScalars where !isHidden(u.value) { scalars.append(u) }
        s = String(scalars)
        while let f = s.first, f == "." || f == " " { s.removeFirst() }
        while let l = s.last, l == " " { s.removeLast() }
        if s.isEmpty { return "file" + fallbackExtension }
        let all = Array(s.unicodeScalars)
        if all.count <= maxNameScalars { return s }
        var ext: [Unicode.Scalar] = []
        if let dot = all.lastIndex(of: "."), all.count - dot <= 16, dot > 0 { ext = Array(all[dot...]) }
        var view = String.UnicodeScalarView()
        view.append(contentsOf: all[0..<(maxNameScalars - ext.count)])
        view.append(contentsOf: ext)
        return String(view)

    /// One request head from the bytes read so far. A head without its blank line is `needMore`
    /// until it reaches 16 KiB (431). Methods and headers are checked strictly; anything this server
    /// does not understand is 400.
    static func parseHead(_ bytes: [UInt8]) -> MPHead {
        var end = -1
        if bytes.count >= 4 {
            for i in 0...(bytes.count - 4) where bytes[i] == 13 && bytes[i + 1] == 10 && bytes[i + 2] == 13 && bytes[i + 3] == 10 {
                end = i
                break
            }
        }
        if end < 0 { return bytes.count >= maxHead ? .bad(431) : .needMore }
        if end + 4 > maxHead { return .bad(431) }
        // ASCII only; CR and LF only as a CRLF pair; no other control but HT.
        for i in 0..<end {
            let b = bytes[i]
            if b >= 0x7F { return .bad(400) }
            if b == 13 && bytes[i + 1] != 10 { return .bad(400) }
            if b == 10 && (i == 0 || bytes[i - 1] != 13) { return .bad(400) }
            if b < 0x20 && b != 9 && b != 10 && b != 13 { return .bad(400) }
        }
        guard let text = String(bytes: bytes[0..<end], encoding: .ascii) else { return .bad(400) }
        let lines = text.components(separatedBy: "\r\n")
        let first = lines[0].split(separator: " ", omittingEmptySubsequences: false)
        guard first.count == 3 else { return .bad(400) }
        let method = String(first[0]), target = String(first[1]), version = String(first[2])
        guard !method.isEmpty, method.utf8.allSatisfy({ $0 >= 0x41 && $0 <= 0x5A }),
              target.hasPrefix("/"), version == "HTTP/1.1" || version == "HTTP/1.0" else { return .bad(400) }
        var headers: [String: String] = [:]
        for line in lines.dropFirst() {
            guard let colon = line.firstIndex(of: ":"), colon != line.startIndex,
                  let f = line.first, f != " ", f != "\t" else { return .bad(400) }
            let name = line[..<colon].lowercased()
            guard name.utf8.allSatisfy({ $0 > 0x20 && $0 < 0x7F && $0 != 0x3A }) else { return .bad(400) }
            let value = line[line.index(after: colon)...].trimmingCharacters(in: MPCore.spaces)
            if name == "range", headers[name] != nil { return .bad(400) }
            if headers[name] == nil { headers[name] = value }
        }
        return .request(MPRequest(method: method, target: target, headers: headers), consumed: end + 4)
    }

    /// The token of `/f/<token>` or `/f/<token>/<name>`; the query, if any, is ignored.
    static func token(fromTarget target: String) -> String? {
        var path = Substring(target)
        if let q = path.firstIndex(where: { $0 == "?" || $0 == "#" }) { path = path[..<q] }
        let parts = path.split(separator: "/", omittingEmptySubsequences: false)
        guard parts.count == 3 || parts.count == 4, parts[0].isEmpty, parts[1] == "f" else { return nil }
        let t = String(parts[2])
        return isToken(t) ? t : nil
    }

    /// One byte range of a file of `size` bytes (RFC 9110 14.2): 206 with the range, 416 when
    /// unsatisfiable, 200 for the whole file when there is no Range or one this server ignores
    /// (another unit, several ranges, or a malformed one, which the RFC allows ignoring).
    static func range(_ header: String?, size: Int64) -> MPRange {
        let whole = MPRange(status: 200, start: 0, end: size - 1)
        guard let h = header?.trimmingCharacters(in: MPCore.spaces), !h.isEmpty else { return whole }
        guard h.lowercased().hasPrefix("bytes=") else { return whole }
        let spec = h.dropFirst(6).trimmingCharacters(in: MPCore.spaces)
        guard !spec.contains(","), let dash = spec.firstIndex(of: "-") else { return whole }
        let a = String(spec[..<dash]).trimmingCharacters(in: MPCore.spaces)
        let b = String(spec[spec.index(after: dash)...]).trimmingCharacters(in: MPCore.spaces)
        func num(_ s: String) -> Int64? {
            guard !s.isEmpty, s.count <= 18, s.utf8.allSatisfy({ $0 >= 0x30 && $0 <= 0x39 }) else { return nil }
            return Int64(s)
        }
        let unsatisfiable = MPRange(status: 416, start: 0, end: -1)
        if a.isEmpty {
            guard let n = num(b) else { return whole }
            if n == 0 || size == 0 { return unsatisfiable }
            return MPRange(status: 206, start: max(0, size - n), end: size - 1)
        }
        guard let first = num(a) else { return whole }
        if b.isEmpty {
            return first >= size ? unsatisfiable : MPRange(status: 206, start: first, end: size - 1)
        }
        guard let last = num(b), last >= first else { return whole }
        if first >= size { return unsatisfiable }
        return MPRange(status: 206, start: first, end: min(last, size - 1))
    }

    static let reasons: [Int: String] = [200: "OK", 204: "No Content", 206: "Partial Content", 400: "Bad Request",
                                         404: "Not Found", 405: "Method Not Allowed", 416: "Range Not Satisfiable",

    /// The response head. The URL is the capability (no cookie or credential is ever read), so any
    /// origin may read a file whose URL it holds; nothing is cached; every response closes.
    static func responseHead(status: Int, mime: String?, size: Int64, range: MPRange?, method: String,
                             privateNetwork: Bool) -> String {
        var h: [(String, String)] = []
        var length: Int64 = 0
        if status == 200 || status == 206 {
            h.append(("Content-Type", mime ?? "application/octet-stream"))
            h.append(("Accept-Ranges", "bytes"))
            if status == 206, let r = range {
                h.append(("Content-Range", "bytes \(r.start)-\(r.end)/\(size)"))
                length = r.end - r.start + 1
            } else {
                length = size
            }
        } else if status == 416 {
            h.append(("Content-Range", "bytes */\(size)"))
        }
        if status == 204 {
            h.append(("Access-Control-Allow-Methods", "GET, HEAD, OPTIONS"))
            h.append(("Access-Control-Allow-Headers", "Range"))
            h.append(("Access-Control-Max-Age", "600"))
            if privateNetwork { h.append(("Access-Control-Allow-Private-Network", "true")) }
        } else {
            h.append(("Content-Length", String(length)))
        }
        h.append(("Access-Control-Allow-Origin", "*"))
        if status == 200 || status == 206 {
            h.append(("Access-Control-Expose-Headers", "Content-Length, Content-Range, Accept-Ranges"))
        }
        h.append(("Cache-Control", "no-store"))
        h.append(("Cross-Origin-Resource-Policy", "cross-origin"))
        h.append(("X-Content-Type-Options", "nosniff"))
        if status == 405 { h.append(("Allow", "GET, HEAD, OPTIONS")) }
        h.append(("Connection", "close"))
        var out = "HTTP/1.1 \(status) \(reasons[status] ?? "Error")\r\n"
        for (k, v) in h { out += "\(k): \(v)\r\n" }
        return out + "\r\n"
    }

    /// Status for a parsed request against the file table: 204 preflight, 405 other methods,

    static func status(method: String, known: Bool, range r: MPRange) -> Int {
        if method == "OPTIONS" { return 204 }

        guard known else { return 404 }

    static let presetShortSide: [String: Int] = ["480p": 480, "540p": 540, "720p": 720, "1080p": 1080,
                                                  "1440p": 1440, "2160p": 2160]

    /// Output size and bitrate for a source of `width` x `height` (as displayed). Never upscales:
    /// the short side is the preset's or the source's, whichever is smaller; the long side keeps the
    /// aspect ratio; both are even. A given bitrate is used as is; the default comes from the table
    /// and never exceeds the source's own bitrate when that is known. nil for an unknown preset or
    /// a source without a size.
    static func target(width: Int, height: Int, preset: String, codec: String, bitrateKbps: Int,
                       sourceKbps: Int, frameRate: Double) -> MPTarget? {
        guard width > 0, height > 0 else { return nil }
        let srcShort = min(width, height), srcLong = max(width, height)
        let want: Int
        if preset == "source" { want = srcShort } else {
            guard let p = presetShortSide[preset] else { return nil }
            want = p
        }
        let short = min(srcShort, want)
        let outShort = max(2, short - short % 2)
        let longD = Double(srcLong) * Double(outShort) / Double(srcShort)
        var outLong = Int(longD.rounded())
        outLong = max(2, outLong - outLong % 2)
        let w = width >= height ? outLong : outShort
        let h = width >= height ? outShort : outLong
        var kbps = bitrateKbps
        if kbps <= 0 {
            let table: [(Int, Int)] = [(480, 2000), (540, 2500), (720, 5000), (1080, 8000), (1440, 16000)]
            var base = 35000
            for (side, rate) in table where outShort <= side { base = rate; break }
            if codec == "hevc" { base = Int((Double(base) * 0.6).rounded()) }
            if frameRate > 31 { base = Int((Double(base) * 1.5).rounded()) }
            if sourceKbps > 0 { base = min(base, sourceKbps) }
            kbps = base
        }
        return MPTarget(width: w, height: h, bitrateKbps: kbps)
    }

    /// `bitrate_kbps` arrives as text (the schema bounds a declared int maximum at 4096): digits only,
    /// 100 to 400000, or empty for the default (0).
    static func bitrate(_ raw: String?) -> Int? {
        guard let s = raw, !s.isEmpty else { return 0 }
        guard s.count <= 6, s.utf8.allSatisfy({ $0 >= 0x30 && $0 <= 0x39 }), let n = Int(s), n >= 100, n <= 400_000 else { return nil }
        return n
    }

    /// The upload outcome rules:
    /// 2xx uploaded; 3xx final (redirect_refused when the delegate refused it); 4xx final; a
    /// transport error that spans background is requeued uncounted; else a counted retry.
    static func classify(status: Int?, transportError: Bool, refused: Bool, spansBackground: Bool) -> MPOutcome {
        if let c = status, (300..<400).contains(c) { return .failed(refused ? "redirect_refused" : "http") }
        if let c = status, (400..<500).contains(c) { return .failed("http") }
        if !transportError, let c = status, (200..<300).contains(c) { return .uploaded }
        if transportError && spansBackground { return .requeue }
        return .retry(transportError ? "network" : "http")
    }

    /// multipart/form-data framing around the file bytes (RFC 7578). The field name is checked by
    /// `formName`; in the file name, quote, backslash and control characters become "_".
    static func multipart(boundary: String, field: String, filename: String, contentType: String) -> (String, String) {
        var safe = String.UnicodeScalarView()
        for u in filename.unicodeScalars {

        entries.filter { !keep.contains($0) }.sorted()

    /// The end state of a transcode. One that already ended while the transcoder stopped (a
    /// background expiry set failed/background_expired, the cancel route set cancelled) keeps that
    /// state and reason; otherwise the transcoder's outcome (done, cancelled, failed) decides.
    static func settle(state: String, reason: String?, outcome: String, outcomeReason: String?) -> (state: String, reason: String?) {
        if state == "failed" || state == "cancelled" { return (state, reason ?? outcomeReason ?? state) }
        switch outcome {

        case "cancelled": return ("cancelled", "cancelled")

        }
```

```swift ios/app/MediaPickerExtension.swift
        case "release": return release(call.params["id"] as? String, all: call.params["all"] as? Bool ?? false)
        case "transcode": return await transcode(call)
        case "upload": return upload(call)
        case "jobs": return jobs(call.params["id"] as? String)
        case "cancel": return cancel(call.params["id"] as? String ?? "")
        default: return .error(code: "not_registered", message: call.route)
        }
    }

    private func pick(_ call: NativeExtCall) async -> NativeExtResult {
        let p = call.params
        guard !presenter.isPresenting else { return .error(code: "busy", message: "a picker is already open") }
        guard let types = MPCore.parseTypes(p["types"] as? String) else {
            return .error(code: "bad_value", message: "types is a comma list of image, video, audio, document, any and MIME types")
        }
        guard let source = MPCore.source(requested: p["source"] as? String ?? "auto", types: types) else {
            return .error(code: "bad_value", message: "that source cannot offer these types")
        }
        let cameraMode = MPCore.cameraMode(types: types, requested: p["camera"] as? String ?? "both")
        if source == "camera" {
            guard MediaPickerPresenter.cameraAvailable else { return .error(code: "camera_unavailable", message: "this device has no camera") }
            guard cameraMode != nil else { return .error(code: "bad_value", message: "camera does not match types") }
            switch AVCaptureDevice.authorizationStatus(for: .video) {
            case .denied, .restricted:
                return .error(code: "permission_denied", message: "camera access is off for this app in Settings")
            case .notDetermined:
                let granted = await AVCaptureDevice.requestAccess(for: .video)
                guard call.isActive else { return .error(code: "timeout", message: "pick timed out before the camera was allowed") }
                guard granted else { return .error(code: "permission_denied", message: "camera access was denied") }
            default:
                break
            }
        }
        let (limit, lowered) = MPCore.limit(requested: p["limit"] as? Int ?? 0, multiple: p["multiple"] as? Bool ?? false, platformMax: 0)
        var tint: UIColor?
        if let hex = p["accent_color"] as? String {
            guard let c = Self.color(hex) else { return .error(code: "bad_value", message: "accent_color is #RRGGBB") }
            tint = c
        }
        let id = UUID().uuidString.lowercased()
        let req = MediaPickerPresenter.Request(source: source, types: types, limit: limit,
                                               representation: p["representation"] as? String ?? "current",
                                               ordered: p["ordered"] as? Bool ?? false, cameraMode: cameraMode,
                                               maxDurationS: p["max_duration_s"] as? Int ?? 0,
                                               quality: p["camera_quality"] as? String ?? "high", tint: tint)
        let record = PickRecord(id: id, state: "presenting", source: source, maxFileMB: p["max_file_mb"] as? Int ?? 0,
                                maxTotalMB: p["max_total_mb"] as? Int ?? 0, limit: limit)
        picks[id] = record
        let shown = presenter.present(req) { [weak self] outcome in self?.picked(id, outcome) }
        guard shown else {
            picks[id] = nil
            return .error(code: "unavailable", message: "the app is not in the foreground")
        }
        var out: [String: Any] = ["pickId": id, "state": "presenting", "source": source, "limit": limit, "limitLowered": lowered]
        // Platform facts for options this platform does not offer, said instead of silently ignored.
        if p["tab"] != nil { out["tabApplied"] = false }
        return .ok(out)
    }

    private func picked(_ pickId: String, _ outcome: MediaPickerPresenter.Outcome) {
        guard var pick = picks[pickId] else { return }
        switch outcome {
        case .cancelled:
            pick.state = "cancelled"
            picks[pickId] = pick
            ctx.emit("pick", pickSnapshot(pick))
        case .failed(let code, let message):
            pick.state = "failed"
            pick.reason = code
            picks[pickId] = pick
            ctx.log("pick failed: \(message)")
            ctx.emit("pick", pickSnapshot(pick))
        case .picked(let items):
            var accepted = items
            var overLimit: [MPIncoming] = []
            if pick.limit > 0, items.count > pick.limit {
                accepted = Array(items.prefix(pick.limit))
                overLimit = Array(items.dropFirst(pick.limit))
            }
            for _ in overLimit {
                let f = newFile(pickId: pickId, origin: "pick", name: "file", mime: "application/octet-stream")
                var r = f
                r.state = "failed"
                r.reason = "limit_exceeded"
                files[r.id] = r
                pick.fileIds.append(r.id)
            }
            for item in accepted {
                let f = newFile(pickId: pickId, origin: item.isCamera ? "camera" : "pick", name: "file", mime: "application/octet-stream")
                files[f.id] = f
                pick.fileIds.insert(f.id, at: pick.fileIds.count - overLimit.count)
                importItem(item, into: f.id)
            }
            for case let .file(u) in overLimit { try? FileManager.default.removeItem(at: u) }
            for case let .movie(u) in overLimit { try? FileManager.default.removeItem(at: u) }
            pick.state = accepted.isEmpty ? "done" : "loading"
            picks[pickId] = pick
            ctx.emit("pick", pickSnapshot(pick))
            settlePickIfDone(pickId)
        }
    }

    private func newFile(pickId: String?, origin: String, name: String, mime: String) -> FileRecord {
        FileRecord(id: UUID().uuidString.lowercased(), token: Self.newToken(), pickId: pickId, origin: origin, name: name,
                   mime: mime, kind: MPCore.kind(mime: mime), bytes: 0, state: "loading")
    }

    static func newToken() -> String {
        var b = [UInt8](repeating: 0, count: 32)
        let ok = SecRandomCopyBytes(kSecRandomDefault, b.count, &b)
        precondition(ok == errSecSuccess, "no system randomness")
        return MPCore.token(fromBytes: b)
    }

    private func dir(_ id: String) -> URL { filesRoot.appendingPathComponent(id, isDirectory: true) }

    /// Copies one picked item into its own directory, off the main actor, then returns here.
    private func importItem(_ item: MPIncoming, into id: String) {
        let d = dir(id)
        try? FileManager.default.createDirectory(at: d, withIntermediateDirectories: true)
        let done: (Result<(URL, String, String), Error>) -> Void = { [weak self] r in
            Task { @MainActor [weak self] in self?.imported(id, r) }
        }
        switch item {
        case .provider(let p, let typeId):
            let type = UTType(typeId)
            let ext = type?.preferredFilenameExtension.map { "." + $0 } ?? ""
            let mime = type?.preferredMIMEType ?? "application/octet-stream"
            let suggested = p.suggestedName.map { $0 + ext } ?? ("file" + ext)
            let progress = p.loadFileRepresentation(forTypeIdentifier: typeId) { url, error in
                // The provider's file exists only inside this callback: copy it now.
                guard let url = url else { return done(.failure(error ?? CocoaError(.fileReadUnknown))) }
                let name = MPCore.safeName(suggested, fallbackExtension: ext)
                let dest = d.appendingPathComponent(name)
                do {
                    try FileManager.default.copyItem(at: url, to: dest)
                    done(.success((dest, name, mime)))
                } catch {
                    done(.failure(error))
                }
            }
            observe(progress, id)
        case .file(let url):
            let ext = url.pathExtension.isEmpty ? "" : "." + url.pathExtension
            let name = MPCore.safeName(url.lastPathComponent, fallbackExtension: ext)
            let mime = UTType(filenameExtension: url.pathExtension)?.preferredMIMEType ?? "application/octet-stream"
            let dest = d.appendingPathComponent(name)
            DispatchQueue.global(qos: .userInitiated).async {
                do {
                    try FileManager.default.moveItem(at: url, to: dest)
                    done(.success((dest, name, mime)))
                } catch {
                    done(.failure(error))
                }
            }
        case .photo(let data, let mime, let ext):
            let name = "photo-" + String(id.prefix(8)) + ext
            let dest = d.appendingPathComponent(name)
            DispatchQueue.global(qos: .userInitiated).async {
                do {
                    try data.write(to: dest, options: .atomic)
                    done(.success((dest, name, mime)))
                } catch {
                    done(.failure(error))
                }
            }
        case .movie(let url):
            let ext = url.pathExtension.isEmpty ? ".mov" : "." + url.pathExtension
            let name = "video-" + String(id.prefix(8)) + ext
            let mime = UTType(filenameExtension: url.pathExtension)?.preferredMIMEType ?? "video/quicktime"
            let dest = d.appendingPathComponent(name)
            DispatchQueue.global(qos: .userInitiated).async {
                do {
                    try FileManager.default.moveItem(at: url, to: dest)
                    done(.success((dest, name, mime)))
                } catch {
                    done(.failure(error))
                }
            }
        }
    }

    private var observers: [String: NSKeyValueObservation] = [:]

    /// iCloud downloads and large copies report progress; the page sees it on `file` events.
    private func observe(_ progress: Progress, _ id: String) {
        var last = 0.0
        observers[id] = progress.observe(\.fractionCompleted) { p, _ in
            let f = p.fractionCompleted
            guard f - last >= 0.02 || f >= 1 else { return }
            last = f
            Task { @MainActor [weak self] in
                guard let self = self, var r = self.files[id], r.state == "loading" else { return }
                r.progress = min(f, 0.99)
                self.files[id] = r
                self.ctx.emit("file", self.fileSnapshot(r))
            }
        }
    }

    private func imported(_ id: String, _ result: Result<(URL, String, String), Error>) {
        observers[id] = nil
        guard var r = files[id], r.state == "loading" else {
            // Released while loading: whatever arrived goes.
            try? FileManager.default.removeItem(at: dir(id))
            return
        }
        switch result {
        case .failure(let e):
            r.state = "failed"
            r.reason = "import_failed"
            ctx.log("import failed: \(e.localizedDescription)")
            try? FileManager.default.removeItem(at: dir(id))
        case .success(let (url, name, mime)):
            r.name = name
            r.mime = mime
            r.kind = MPCore.kind(mime: mime)
            r.bytes = ((try? FileManager.default.attributesOfItem(atPath: url.path))?[.size] as? NSNumber)?.int64Value ?? 0
            r.progress = nil
            let pick = r.pickId.flatMap { picks[$0] }
            if let reason = MPCore.admit(sizes: [r.bytes], maxFileMB: pick?.maxFileMB ?? 0, maxTotalMB: 0)[0] {
                r.state = "failed"
                r.reason = reason
                try? FileManager.default.removeItem(at: dir(id))
            } else {
                r.state = (pick?.maxTotalMB ?? 0) > 0 ? "loaded" : "ready"
                if r.kind == "image" { Self.imageSize(url, &r) }
                if r.state == "ready" { server.publish(token: r.token, entry: .init(path: url, mime: r.mime)) }
            }
        }
        files[id] = r
        if r.state != "loaded" { ctx.emit("file", fileSnapshot(r)) }
        if r.state == "ready", r.kind == "video" || r.kind == "audio" { probeMedia(id) }
        if let p = r.pickId { settlePickIfDone(p) }
    }

    /// The pick ends when no file is loading. With max_total_mb, files were held as "loaded" until
    /// now and are admitted in pick order; the rest fail with total_exceeded.
    private func settlePickIfDone(_ pickId: String) {
        guard var pick = picks[pickId], pick.state == "loading" else { return }
        let own = pick.fileIds.compactMap { files[$0] }
        guard !own.contains(where: { $0.state == "loading" }) else { return }
        if pick.maxTotalMB > 0 {
            let held = own.filter { $0.state == "loaded" }
            let verdicts = MPCore.admit(sizes: held.map { $0.bytes }, maxFileMB: 0, maxTotalMB: pick.maxTotalMB)
            for (f, v) in zip(held, verdicts) {
                var r = f
                if let reason = v {
                    r.state = "failed"
                    r.reason = reason
                    try? FileManager.default.removeItem(at: dir(r.id))
                } else {
                    r.state = "ready"
                    server.publish(token: r.token, entry: .init(path: dir(r.id).appendingPathComponent(r.name), mime: r.mime))
                }
                files[r.id] = r
                ctx.emit("file", fileSnapshot(r))
                if r.state == "ready", r.kind == "video" || r.kind == "audio" { probeMedia(r.id) }
            }
        }
        pick.state = "done"
        picks[pickId] = pick
        ctx.emit("pick", pickSnapshot(pick))
    }

    private static func imageSize(_ url: URL, _ r: inout FileRecord) {
        guard let src = CGImageSourceCreateWithURL(url as CFURL, nil),
              let props = CGImageSourceCopyPropertiesAtIndex(src, 0, nil) as? [CFString: Any],
              let w = props[kCGImagePropertyPixelWidth] as? Int, let h = props[kCGImagePropertyPixelHeight] as? Int else { return }
        let o = props[kCGImagePropertyOrientation] as? Int ?? 1
        // EXIF 5 to 8 rotate by 90 degrees: report the size as displayed.
        if o >= 5 { (r.width, r.height) = (h, w) } else { (r.width, r.height) = (w, h) }
    }

    private func probeMedia(_ id: String) {
        guard let r = files[id] else { return }
        let url = dir(id).appendingPathComponent(r.name)
        Task { @MainActor [weak self] in
            let asset = AVURLAsset(url: url)
            let duration = (try? await asset.load(.duration)).map { Int(CMTimeGetSeconds($0) * 1000) }
            var size: (Int, Int)?
            if let v = try? await asset.loadTracks(withMediaType: .video).first,
               let (n, t) = try? await v.load(.naturalSize, .preferredTransform) {
                let s = n.applying(t)
                size = (Int(abs(s.width).rounded()), Int(abs(s.height).rounded()))
            }
            guard let self = self, var now = self.files[id], now.state == "ready" else { return }
            now.durationMs = duration
            if let s = size { (now.width, now.height) = s }
            self.files[id] = now
            self.ctx.emit("file", self.fileSnapshot(now))
        }
    }

    private func result(_ pickId: String) -> NativeExtResult {
        guard let p = picks[pickId] else { return .error(code: "not_found", message: "unknown pick") }
        return .ok(pickSnapshot(p))
    }

    private func listFiles(_ id: String?) -> NativeExtResult {
        if let id = id {
            guard MPCore.isId(id), let r = files[id] else { return .error(code: "not_found", message: "unknown file") }
            return .ok(fileSnapshot(r))
        }
        let list = files.values.filter { $0.state != "released" }.sorted { $0.id < $1.id }.map(fileSnapshot)
        var out: [String: Any] = ["files": list]
        if let b = base() { out["base"] = b }
        return .ok(out)
    }

    /// Whether a running transcode or an unfinished upload still needs this file.
    private func inUse(_ id: String) -> Bool {
        if transcodes.values.contains(where: { ($0.sourceId == id || $0.outputId == id) && ($0.state == "queued" || $0.state == "transcoding") }) {
            return true
        }
        return store.records.values.contains { $0.fileId == id && $0.state == "uploading" }
    }

    private func release(_ id: String?, all: Bool) -> NativeExtResult {
        var ids: [String] = []
        if all {
            ids = files.values.filter { $0.state != "released" && !inUse($0.id) }.map { $0.id }
        } else {
            guard let id = id, MPCore.isId(id), let r = files[id], r.state != "released" else {
                return .error(code: "not_found", message: "unknown file")
            }
            guard !inUse(id) else { return .error(code: "busy", message: "a transcode or an upload still needs this file; cancel it first") }
            ids = [id]
        }
        var failed: [String] = []
        for id in ids.sorted() where !releaseFile(id) { failed.append(id) }
        if !failed.isEmpty {
            return .error(code: "release_failed", message: "\(failed.count) file(s) could not be deleted; the next launch deletes them")
        }
        return .ok(["released": ids.sorted()])
    }

    @discardableResult
    private func releaseFile(_ id: String) -> Bool {
        guard var r = files[id] else { return true }
        server.withdraw(token: r.token)
        r.state = "released"
        r.reason = nil
        files[id] = r
        let ok: Bool
        do {
            try FileManager.default.removeItem(at: dir(id))
            ok = true
        } catch {
            ok = !FileManager.default.fileExists(atPath: dir(id).path)
        }
        ctx.emit("file", fileSnapshot(r))
        return ok
    }

    // MARK: Transcode

    private func transcode(_ call: NativeExtCall) async -> NativeExtResult {
        let p = call.params
        guard let id = p["id"] as? String, MPCore.isId(id), let src = files[id] else { return .error(code: "not_found", message: "unknown file") }
        guard src.state == "ready", src.kind == "video" else { return .error(code: "bad_value", message: "only a ready video can be transcoded") }
        guard let bitrate = MPCore.bitrate(p["bitrate_kbps"] as? String) else {
            return .error(code: "bad_value", message: "bitrate_kbps is 100 to 400000")
        }
        let codec = p["codec"] as? String ?? "h264"
        let preset = p["preset"] as? String ?? "720p"
        let frameRate = p["frame_rate"] as? Int ?? 0
        let path = dir(id).appendingPathComponent(src.name)
        guard let info = await MediaTranscoder.probe(path) else {
            return .error(code: "unreadable", message: "the video's tracks cannot be read")
        }
        guard call.isActive else { return .error(code: "timeout", message: "transcode timed out before it started") }
        guard files[id]?.state == "ready" else { return .error(code: "not_found", message: "the file was released") }
        let fps = frameRate > 0 ? Double(frameRate) : info.fps
        guard let target = MPCore.target(width: info.width, height: info.height, preset: preset, codec: codec,
                                         bitrateKbps: bitrate, sourceKbps: info.kbps, frameRate: fps) else {
            return .error(code: "bad_value", message: "unknown preset or a video without a size")
        }
        guard MediaTranscoder.supports(codec: codec, target: target) else {
            return .error(code: "not_supported_on_device", message: "this device cannot encode \(codec) at \(target.width)x\(target.height)")
        }
        var out = newFile(pickId: nil, origin: "transcode", name: "video-" + UUID().uuidString.prefix(8).lowercased() + ".mp4", mime: "video/mp4")
        out.state = "loading"
        out.progress = 0
        files[out.id] = out
        let job = TranscodeJob(id: UUID().uuidString.lowercased(), sourceId: id, outputId: out.id, state: "queued", progress: 0,
                               reason: nil, target: target, codec: codec, frameRate: frameRate,
                               keepAudio: (p["audio"] as? String ?? "keep") == "keep", audioKbps: p["audio_bitrate_kbps"] as? Int ?? 128)
        transcodes[job.id] = job
        transcodeOrder.append(job.id)
        nextTranscode()
        let now = transcodes[job.id] ?? job
        return .ok(jobSnapshot(now))
    }

    private func nextTranscode() {
        guard runningTranscode == nil, let next = transcodeOrder.first(where: { transcodes[$0]?.state == "queued" }),
              var job = transcodes[next], let src = files[job.sourceId], let out = files[job.outputId] else { return }
        try? FileManager.default.createDirectory(at: dir(out.id), withIntermediateDirectories: true)
        job.state = "transcoding"
        transcodes[next] = job
        runningTranscode = next
        let t = MediaTranscoder()
        transcoder = t
        beginTranscodeAssertion()
        ctx.emit("job", jobSnapshot(job))
        t.start(source: dir(src.id).appendingPathComponent(src.name), output: dir(out.id).appendingPathComponent(out.name),
                options: .init(target: job.target, codec: job.codec, frameRate: job.frameRate, keepAudio: job.keepAudio, audioKbps: job.audioKbps),
                progress: { [weak self] p in self?.transcodeProgress(next, p) },
                done: { [weak self] r in self?.transcodeDone(next, r) })
    }

    private func transcodeProgress(_ jobId: String, _ p: Double) {
        guard var j = transcodes[jobId], j.state == "transcoding" else { return }
        j.progress = p
        transcodes[jobId] = j
        ctx.emit("job", jobSnapshot(j))
    }

    private func transcodeDone(_ jobId: String, _ r: Result<MediaTranscoder.Output, MediaTranscoder.Failure>) {
        runningTranscode = nil
        transcoder = nil
        endTranscodeAssertion()
        guard var j = transcodes[jobId] else { return nextTranscode() }
        var out = files[j.outputId]
        // A job that already ended while the transcoder stopped (background_expired, a cancel)
        // keeps its state and reason: the transcoder reports both as cancelled.
        let outcome: (String, String?)
        switch r {
        case .success: outcome = ("done", nil)
        case .failure(let e): outcome = (Self.isCancel(e) ? "cancelled" : "failed", Self.reason(e))
        }
        let settled = MPCore.settle(state: j.state, reason: j.reason, outcome: outcome.0, outcomeReason: outcome.1)
        switch (r, settled.state) {
        case (.success(let o), "done"):
            j.state = "done"
            j.progress = 1
            if var f = out, f.state == "loading" {
                let path = dir(f.id).appendingPathComponent(f.name)
                f.state = "ready"
                f.progress = nil
                f.bytes = ((try? FileManager.default.attributesOfItem(atPath: path.path))?[.size] as? NSNumber)?.int64Value ?? 0
                (f.width, f.height, f.durationMs) = (o.width, o.height, o.durationMs)
                server.publish(token: f.token, entry: .init(path: path, mime: f.mime))
                out = f
            }
        default:
            j.state = settled.state
            j.reason = settled.reason
            if var f = out, f.state == "loading" {
                f.state = "failed"
                f.reason = j.reason
                f.progress = nil
                try? FileManager.default.removeItem(at: dir(f.id))
                out = f
            }
        }
        transcodes[jobId] = j
        if let f = out {
            files[f.id] = f
            ctx.emit("file", fileSnapshot(f))
        }
        ctx.emit("job", jobSnapshot(j))
        nextTranscode()
    }

    private static func isCancel(_ e: MediaTranscoder.Failure) -> Bool {
        if case .cancelled = e { return true }
        return false
    }

    private static func reason(_ e: MediaTranscoder.Failure) -> String {
        switch e {
        case .unreadable: return "unreadable"
        case .noVideo: return "no_video"
        case .notSupported: return "not_supported_on_device"
        case .failed: return "encode_failed"
        case .cancelled: return "cancelled"
        }
    }

    // MARK: Upload

    private func upload(_ call: NativeExtCall) -> NativeExtResult {
        let p = call.params
        guard let id = p["id"] as? String, MPCore.isId(id), let f = files[id] else { return .error(code: "not_found", message: "unknown file") }
        guard f.state == "ready" else { return .error(code: "bad_value", message: "only a ready file can be uploaded") }
        guard indexReady(), store.allows("accept") else {
            return .error(code: "storage_failed", message: "the upload index is not readable yet (the device has not been unlocked); nothing was queued")
        }
        guard let url = p["url"] as? String else { return .error(code: "bad_request", message: "url") }
        var field: String?
        if let ff = p["form_field"] as? String {
            guard MPCore.formName(ff) else { return .error(code: "bad_value", message: "form_field is 1 to 64 of A-Z a-z 0-9 . _ -") }
            field = ff
        }
        guard let type = MPCore.contentType(p["content_type"] as? String, fallback: f.mime) else {
            return .error(code: "bad_value", message: "content_type is a MIME type without parameters")
        }
        let method = p["method"] as? String ?? (field == nil ? "PUT" : "POST")
        let r = MPUpload(id: UUID().uuidString.lowercased(), fileId: id, path: id + "/" + f.name, name: f.name, mime: f.mime,
                         bytes: f.bytes, url: url, route: "upload", method: method, field: field, contentType: type,
                         state: "uploading", attempts: 0, nextAttemptAt: nil, reason: nil, httpStatus: nil,
                         releaseAfter: p["release_after"] as? Bool ?? false, createdAt: Date())
        store.set(r)
        // Durable before it is promised: nothing is queued when the index cannot be written.
        guard store.persist() else {
            store.remove(r.id)
            store.persist()
            return .error(code: "storage_failed", message: "the upload index could not be saved; nothing was queued")
        }
        beginAssertion()
        uploader.drain()
        return .ok(uploadSnapshot(store[r.id] ?? r))
    }

    private func uploadChanged(_ id: String) {
        store.persist()
        guard let r = store[id] else { return }
        if r.state == "uploaded", r.releaseAfter, files[r.fileId] != nil, !inUse(r.fileId) { releaseFile(r.fileId) }
        ctx.emit("job", uploadSnapshot(r))
    }

    private func uploadProgress(_ id: String, _ sent: Int64, _ total: Int64) {
        guard let r = store[id] else { return }
        var s = uploadSnapshot(r)
        s["sentBytes"] = sent
        s["progress"] = total > 0 ? min(1, Double(sent) / Double(total)) : 0
        ctx.emit("job", s)
    }

    /// Settled upload records from earlier runs are kept a week so the page can read the outcome.
    private func pruneSettledUploads() {
        let cutoff = Date().addingTimeInterval(-7 * 24 * 3600)
        for r in store.records.values where r.state != "uploading" && r.createdAt < cutoff { store.remove(r.id) }
        store.persist()
    }

    /// Everything under files/ goes, except the files an unfinished upload still needs and the
    /// files this run already holds (clean-up can run after picks when the index was read late).
    private func cleanUpAtLaunch() {
        let keep = Set(store.records.values.filter { $0.state == "uploading" }.map { $0.fileId }).union(files.keys)
        let entries = (try? FileManager.default.contentsOfDirectory(atPath: filesRoot.path)) ?? []
        for name in MPCore.cleanup(entries: entries, keep: keep) {
            do {
                try FileManager.default.removeItem(at: filesRoot.appendingPathComponent(name))
            } catch {
                ctx.log("launch clean-up could not delete a file directory: \(error.localizedDescription)")
            }
        }
    }

    /// A file an unfinished upload kept across a restart is listed again, with a new URL token.
    private func readoptUploadFiles() {
        for u in store.records.values where u.state == "uploading" && files[u.fileId] == nil {
            let path = filesRoot.appendingPathComponent(u.path)
            guard FileManager.default.fileExists(atPath: path.path) else { continue }
            let f = FileRecord(id: u.fileId, token: Self.newToken(), pickId: nil, origin: "upload", name: u.name, mime: u.mime,
                               kind: MPCore.kind(mime: u.mime), bytes: u.bytes, state: "ready")
            files[f.id] = f
            server.publish(token: f.token, entry: .init(path: path, mime: f.mime))
        }
    }

    // MARK: Jobs

    private func jobs(_ id: String?) -> NativeExtResult {
        indexReady()
        if let id = id {
            guard MPCore.isId(id) else { return .error(code: "not_found", message: "unknown job") }
            if let t = transcodes[id] { return .ok(jobSnapshot(t)) }
            if let u = store[id] { return .ok(uploadSnapshot(u)) }
            return .error(code: "not_found", message: "unknown job")
        }
        let list = transcodes.values.sorted { $0.id < $1.id }.map(jobSnapshot)
            + store.records.values.sorted { ($0.createdAt, $0.id) < ($1.createdAt, $1.id) }.map(uploadSnapshot)
        var out: [String: Any] = ["jobs": list]
        if !store.durable { out["durable"] = false }
        if store.recovered { out["indexRecovered"] = true }
        if store.index == "unread" { out["indexUnread"] = true }
        return .ok(out)
    }

    private func cancel(_ id: String) -> NativeExtResult {
        guard MPCore.isId(id) else { return .error(code: "not_found", message: "unknown job") }
        if var t = transcodes[id] {
            guard t.state == "queued" || t.state == "transcoding" else { return .ok(jobSnapshot(t)) }
            if t.state == "transcoding" {
                t.state = "cancelled"
                transcodes[id] = t
                transcoder?.cancel()
            } else {
                t.state = "cancelled"
                t.reason = "cancelled"
                transcodes[id] = t
                if var f = files[t.outputId] {
                    f.state = "failed"
                    f.reason = "cancelled"
                    files[f.id] = f
                    ctx.emit("file", fileSnapshot(f))
                }
                ctx.emit("job", jobSnapshot(t))
            }
            return .ok(jobSnapshot(t))
        }
        guard var u = store[id] else { return .error(code: "not_found", message: "unknown job") }
        guard u.state == "uploading" else { return .ok(uploadSnapshot(u)) }
        u.state = "cancelled"
        u.nextAttemptAt = nil
        store.set(u)
        uploader.cancel(id)
        uploadChanged(id)
        return .ok(uploadSnapshot(u))
    }

    // MARK: Snapshots

    private func base() -> String? { port.map { "http://127.0.0.1:\($0)" } }

    private func fileURL(_ r: FileRecord) -> String? {
        guard r.state == "ready", let b = base() else { return nil }
        let encoded = r.name.addingPercentEncoding(withAllowedCharacters: .urlPathAllowed.subtracting(CharacterSet(charactersIn: "/?#"))) ?? "file"
        return b + "/f/" + r.token + "/" + encoded
    }

    private func fileSnapshot(_ r: FileRecord) -> [String: Any] {
        var o: [String: Any] = ["fileId": r.id, "state": r.state == "loaded" ? "loading" : r.state, "name": r.name,
                                "mime": r.mime, "kind": r.kind, "bytes": r.bytes, "origin": r.origin]
        if let p = r.pickId { o["pickId"] = p }
        if let u = fileURL(r) { o["url"] = u }
        if let v = r.reason { o["reason"] = v }
        if let v = r.progress { o["progress"] = v }
        if let v = r.width { o["width"] = v }
        if let v = r.height { o["height"] = v }
        if let v = r.durationMs { o["durationMs"] = v }
        return o
    }

    private func pickSnapshot(_ p: PickRecord) -> [String: Any] {
        var o: [String: Any] = ["pickId": p.id, "state": p.state, "source": p.source,
                                "files": p.fileIds.compactMap { files[$0] }.map(fileSnapshot)]
        if let r = p.reason { o["reason"] = r }
        return o
    }

    private func jobSnapshot(_ j: TranscodeJob) -> [String: Any] {
        var o: [String: Any] = ["jobId": j.id, "kind": "transcode", "state": j.state, "progress": j.progress,
                                "fileId": j.sourceId, "outputFileId": j.outputId, "width": j.target.width,
                                "height": j.target.height, "bitrateKbps": j.target.bitrateKbps, "codec": j.codec]
        if let r = j.reason { o["reason"] = r }
        return o
    }

    private func uploadSnapshot(_ u: MPUpload) -> [String: Any] {
        var o: [String: Any] = ["jobId": u.id, "kind": "upload", "state": u.state, "fileId": u.fileId, "bytes": u.bytes,
                                "attempts": u.attempts, "method": u.method]
        if let r = u.reason { o["reason"] = r }
        if let s = u.httpStatus { o["httpStatus"] = s }
        if let n = u.nextAttemptAt { o["nextAttemptMs"] = Int(n.timeIntervalSince1970 * 1000) }
        if !store.durable { o["durable"] = false }
        return o
    }

    private func portChanged(_ p: UInt16?) {
        guard p != port else { return }
        port = p
        var o: [String: Any] = ["running": p != nil]
        if let b = base() { o["base"] = b }
        ctx.emit("server", o)
    }

    private static func color(_ hex: String) -> UIColor? {
        let s = hex.hasPrefix("#") ? String(hex.dropFirst()) : hex
        guard s.count == 6, let v = UInt32(s, radix: 16) else { return nil }
        return UIColor(red: CGFloat((v >> 16) & 0xff) / 255, green: CGFloat((v >> 8) & 0xff) / 255,
                       blue: CGFloat(v & 0xff) / 255, alpha: 1)
    }

    // MARK: Background execution (finite, never guaranteed)

    private func beginAssertion() {
        guard assertion == .invalid else { return }
        assertion = UIApplication.shared.beginBackgroundTask(withName: "nativeext.mediapicker.upload") { [weak self] in
            guard let self = self else { return }
            self.uploader.expireInFlight()
            if self.uploader.hasWork { self.scheduleProcessing() }
            self.endAssertion()
        }
    }

    private func endAssertion() {
        guard assertion != .invalid else { return }
        let a = assertion
        assertion = .invalid
        UIApplication.shared.endBackgroundTask(a)
    }

    /// A transcode keeps running while iOS grants background time; when it ends, the transcode is
    /// cancelled and reported (reason background_expired) rather than suspended half-written.
    private func beginTranscodeAssertion() {
        guard transcodeAssertion == .invalid else { return }
        transcodeAssertion = UIApplication.shared.beginBackgroundTask(withName: "nativeext.mediapicker.transcode") { [weak self] in
            guard let self = self else { return }
            if let id = self.runningTranscode, var j = self.transcodes[id] {
                j.state = "failed"
                j.reason = "background_expired"
                self.transcodes[id] = j
                self.transcoder?.cancel()
            }
            self.endTranscodeAssertion()
        }
    }

    private func endTranscodeAssertion() {
        guard transcodeAssertion != .invalid else { return }
        let a = transcodeAssertion
        transcodeAssertion = .invalid
        UIApplication.shared.endBackgroundTask(a)
    }

    private func scheduleProcessing() {
        let request = BGProcessingTaskRequest(identifier: "nativeext.\(ctx.extensionId).upload")
        request.requiresNetworkConnectivity = true
        request.requiresExternalPower = false
        do {
            try BGTaskScheduler.shared.submit(request)
        } catch {
            ctx.log("background processing request not accepted: \(error.localizedDescription)")
        }
    }
}
```

```swift ios/app/MediaPickerUI.swift
/// The platform's own pickers, presented stock: PHPickerViewController (photos and videos, no photo
/// library permission needed), UIDocumentPickerViewController (files, audio, any document, as a
/// copy), UIImagePickerController with the camera, and, for `sheet`, a UIAlertController action
/// sheet offering the three. Nothing is restyled except the optional tint.
///
/// Main actor: UIKit presentation and every delegate callback happen there.
@MainActor
final class MediaPickerPresenter: NSObject, PHPickerViewControllerDelegate, UIDocumentPickerDelegate,
    UIImagePickerControllerDelegate, UINavigationControllerDelegate, UIAdaptivePresentationControllerDelegate {
    struct Request {
        let source: String
        let types: MPTypes
        let limit: Int
        let representation: String
        let ordered: Bool
        let cameraMode: String?
        let maxDurationS: Int
        let quality: String
        let tint: UIColor?
    }

    enum Outcome {
        case picked([MPIncoming])
        case cancelled
        case failed(code: String, message: String)
    }

    private var finish: ((Outcome) -> Void)?
    private var request: Request?

    var isPresenting: Bool { finish != nil }

    static var cameraAvailable: Bool { UIImagePickerController.isSourceTypeAvailable(.camera) }

    /// The view controller to present from: the key window of the foreground-active scene, then its
    /// top presented controller. nil when the app is not in the foreground.
    static func presenter() -> UIViewController? {
        let scenes = UIApplication.shared.connectedScenes.compactMap { $0 as? UIWindowScene }
        guard let scene = scenes.first(where: { $0.activationState == .foregroundActive }),
              let root = (scene.windows.first { $0.isKeyWindow } ?? scene.windows.first)?.rootViewController else { return nil }
        var top = root
        while let p = top.presentedViewController, !p.isBeingDismissed { top = p }
        return top
    }

        request = nil
```

```swift ios/app/MediaTranscoder.swift
import AVFoundation
import Foundation
import VideoToolbox

/// Resizes and re-encodes one video with AVAssetReader and AVAssetWriter (not AVAssetExportSession,
/// whose presets fix the bitrate): H.264 or HEVC, the size MPCore.target chose (never upscaled), an
/// average bitrate, an optional lower frame rate, and AAC audio or none.
///
/// Orientation and HDR go through an AVVideoComposition built from the asset: the preferred
/// transform is applied, so the output is upright with an identity transform. H.264 output is SDR
/// (BT.709, 8-bit; the composition tone-maps an HDR source). HEVC output keeps an HDR source's
/// colour (10-bit, Main10, the source's primaries, transfer function and matrix).
///
/// Threading: reading and writing run on `queue`; `progress` and `done` are called on the main queue,
/// `done` exactly once. `cancel()` may be called from the main queue at any time.
final class MediaTranscoder {
    struct Options {
        let target: MPTarget
        let codec: String
        let frameRate: Int
        let keepAudio: Bool
        let audioKbps: Int
    }

    struct Output {
        let width: Int
        let height: Int
        let durationMs: Int
        let codec: String
        let hdr: Bool
    }

    enum Failure: Error {
        case unreadable(String)
        case noVideo
        case notSupported(String)
        case failed(String)
        case cancelled
    }

    private let queue = DispatchQueue(label: "nativeext.mediapicker.transcode")
    private var reader: AVAssetReader?
    private var writer: AVAssetWriter?
    private var cancelled = false
    private var finished = false

    /// Source facts the caller needs before choosing a target: display size, bitrate, frame rate.
    static func probe(_ url: URL) async -> (width: Int, height: Int, kbps: Int, fps: Double, durationMs: Int, hdr: Bool)? {
        let asset = AVURLAsset(url: url)
        guard let track = try? await asset.loadTracks(withMediaType: .video).first,
              let (size, transform, rate, fps) = try? await track.load(.naturalSize, .preferredTransform, .estimatedDataRate, .nominalFrameRate),
              let duration = try? await asset.load(.duration) else { return nil }
        let shown = size.applying(transform)
        let hdr = (try? await track.load(.mediaCharacteristics))?.contains(.containsHDRVideo) ?? false
        return (Int(abs(shown.width).rounded()), Int(abs(shown.height).rounded()), Int(rate / 1000), Double(fps),
                Int(CMTimeGetSeconds(duration) * 1000), hdr)
    }

    /// Whether this device can encode `codec` at the target size (4K needs the 4K output presets).
    static func supports(codec: String, target: MPTarget) -> Bool {
        let presets = AVOutputSettingsAssistant.availableOutputSettingsPresets()
        let short = min(target.width, target.height)
        if codec == "hevc" {
            return short > 1080 ? presets.contains(.hevc3840x2160) : presets.contains(.hevc1920x1080)
        }
        return short > 1080 ? presets.contains(.preset3840x2160) : true
    }

    func start(source: URL, output: URL, options o: Options,
               progress: @escaping (Double) -> Void, done: @escaping (Result<Output, Failure>) -> Void) {
        Task {
            let asset = AVURLAsset(url: source)
            let videoTrack: AVAssetTrack
            let audioTrack: AVAssetTrack?
            let duration: CMTime
            let composition: AVMutableVideoComposition
            let hdr: Bool
            let geometry: (CGSize, CGAffineTransform)
            var audioFormat: (channels: Int, rate: Double) = (2, 44_100)
            do {
                guard let v = try await asset.loadTracks(withMediaType: .video).first else {
                    return self.finish(.failure(.noVideo), done)
                }
                videoTrack = v
                audioTrack = o.keepAudio ? try await asset.loadTracks(withMediaType: .audio).first : nil
                duration = try await asset.load(.duration)
                hdr = (try await v.load(.mediaCharacteristics)).contains(.containsHDRVideo)
                composition = try await AVMutableVideoComposition.videoComposition(withPropertiesOf: asset)
                geometry = try await v.load(.naturalSize, .preferredTransform)
                if let a = audioTrack, let d = try await a.load(.formatDescriptions).first,
                   let asbd = CMAudioFormatDescriptionGetStreamBasicDescription(d) {
                    let r = asbd.pointee.mSampleRate
                    audioFormat = (max(1, Int(asbd.pointee.mChannelsPerFrame)), r == 48_000 || r == 44_100 ? r : 44_100)
                }
            } catch {
                return self.finish(.failure(.unreadable(error.localizedDescription)), done)
            }
            self.queue.async {
                self.run(asset: asset, video: videoTrack, audio: audioTrack, duration: duration, composition: composition,
                         hdr: hdr, geometry: geometry, audioFormat: audioFormat, output: output, options: o, progress: progress, done: done)
            }
        }
    }

    func cancel() {
        queue.async {
            self.cancelled = true
            self.reader?.cancelReading()
            self.writer?.cancelWriting()
        }
    }

    private func finish(_ r: Result<Output, Failure>, _ done: @escaping (Result<Output, Failure>) -> Void) {
        queue.async {
            guard !self.finished else { return }
            self.finished = true
            let result: Result<Output, Failure> = self.cancelled ? .failure(.cancelled) : r
            DispatchQueue.main.async { done(result) }
        }
    }

    private func run(asset: AVAsset, video: AVAssetTrack, audio: AVAssetTrack?, duration: CMTime,
                     composition: AVMutableVideoComposition, hdr: Bool, geometry: (CGSize, CGAffineTransform),
                     audioFormat: (channels: Int, rate: Double), output: URL, options o: Options,
                     progress: @escaping (Double) -> Void, done: @escaping (Result<Output, Failure>) -> Void) {
        guard !cancelled else { return finish(.failure(.cancelled), done) }
        let keepHDR = hdr && o.codec == "hevc"
        try? FileManager.default.removeItem(at: output)
        let reader: AVAssetReader
        let writer: AVAssetWriter
        do {
            reader = try AVAssetReader(asset: asset)
            writer = try AVAssetWriter(outputURL: output, fileType: .mp4)
        } catch {
            return finish(.failure(.failed(error.localizedDescription)), done)
        }
        self.reader = reader
        self.writer = writer
        writer.shouldOptimizeForNetworkUse = true

        composition.renderSize = CGSize(width: o.target.width, height: o.target.height)
        if o.frameRate > 0 {
            let wanted = CMTime(value: 1, timescale: CMTimeScale(o.frameRate))
            if CMTimeCompare(wanted, composition.frameDuration) > 0 { composition.frameDuration = wanted }
        }
        // Scale every instruction's layer to the render size (the composition kept the source's).
        let natural = geometry.0.applying(geometry.1)
        let sx = CGFloat(o.target.width) / abs(natural.width), sy = CGFloat(o.target.height) / abs(natural.height)
        let instructions: [AVMutableVideoCompositionInstruction] = composition.instructions.compactMap { ins in
            guard let i = ins as? AVMutableVideoCompositionInstruction else { return nil }
            for case let layer as AVMutableVideoCompositionLayerInstruction in i.layerInstructions {
                layer.setTransform(geometry.1.concatenating(CGAffineTransform(scaleX: sx, y: sy)), at: .zero)
            }
            return i
        }
        if !instructions.isEmpty { composition.instructions = instructions }
        if keepHDR {
            composition.colorPrimaries = nil
        } else {
            composition.colorPrimaries = AVVideoColorPrimaries_ITU_R_709_2
            composition.colorTransferFunction = AVVideoTransferFunction_ITU_R_709_2
            composition.colorYCbCrMatrix = AVVideoYCbCrMatrix_ITU_R_709_2
        }

        let pixel = keepHDR ? kCVPixelFormatType_420YpCbCr10BiPlanarVideoRange : kCVPixelFormatType_420YpCbCr8BiPlanarVideoRange
        let vOut = AVAssetReaderVideoCompositionOutput(videoTracks: [video],
                                                       videoSettings: [kCVPixelBufferPixelFormatTypeKey as String: pixel])
        vOut.videoComposition = composition
        vOut.alwaysCopiesSampleData = false
        guard reader.canAdd(vOut) else { return finish(.failure(.failed("the video track cannot be read")), done) }
        reader.add(vOut)

        var compression: [String: Any] = [
            AVVideoAverageBitRateKey: o.target.bitrateKbps * 1000,
            AVVideoMaxKeyFrameIntervalDurationKey: 2,
            AVVideoAllowFrameReorderingKey: true,
        ]
        if o.frameRate > 0 { compression[AVVideoExpectedSourceFrameRateKey] = o.frameRate }
        var vSettings: [String: Any] = [
            AVVideoWidthKey: o.target.width,
            AVVideoHeightKey: o.target.height,
        ]
        if o.codec == "hevc" {
            vSettings[AVVideoCodecKey] = AVVideoCodecType.hevc
            compression[AVVideoProfileLevelKey] = keepHDR ? kVTProfileLevel_HEVC_Main10_AutoLevel as String
                : kVTProfileLevel_HEVC_Main_AutoLevel as String
        } else {
            vSettings[AVVideoCodecKey] = AVVideoCodecType.h264
            compression[AVVideoProfileLevelKey] = AVVideoProfileLevelH264HighAutoLevel
            compression[AVVideoH264EntropyModeKey] = AVVideoH264EntropyModeCABAC
        }
        if !keepHDR {
            vSettings[AVVideoColorPropertiesKey] = [
                AVVideoColorPrimariesKey: AVVideoColorPrimaries_ITU_R_709_2,
                AVVideoTransferFunctionKey: AVVideoTransferFunction_ITU_R_709_2,
                AVVideoYCbCrMatrixKey: AVVideoYCbCrMatrix_ITU_R_709_2,
            ]
        }
        vSettings[AVVideoCompressionPropertiesKey] = compression
        let vIn = AVAssetWriterInput(mediaType: .video, outputSettings: vSettings)
        vIn.expectsMediaDataInRealTime = false
        guard writer.canAdd(vIn) else { return finish(.failure(.notSupported("the encoder refused these video settings")), done) }
        writer.add(vIn)

        var aOut: AVAssetReaderTrackOutput?
        var aIn: AVAssetWriterInput?
        if let a = audio {
            let out = AVAssetReaderTrackOutput(track: a, outputSettings: [AVFormatIDKey: kAudioFormatLinearPCM])
            out.alwaysCopiesSampleData = false
            _ = a
            let channels = min(2, audioFormat.channels)
            let input = AVAssetWriterInput(mediaType: .audio, outputSettings: [
                AVFormatIDKey: kAudioFormatMPEG4AAC,
                AVNumberOfChannelsKey: channels,
                AVSampleRateKey: audioFormat.rate,
                AVEncoderBitRateKey: max(32, o.audioKbps) * 1000,
            ])
            input.expectsMediaDataInRealTime = false
            if reader.canAdd(out), writer.canAdd(input) {
                reader.add(out)
                writer.add(input)
                aOut = out
                aIn = input
            }
        }

        guard reader.startReading() else {
            return finish(.failure(.unreadable(reader.error?.localizedDescription ?? "the video cannot be read")), done)
        }
        guard writer.startWriting() else {
            reader.cancelReading()
            return finish(.failure(.failed(writer.error?.localizedDescription ?? "the encoder did not start")), done)
        }
        writer.startSession(atSourceTime: .zero)

        let total = max(CMTimeGetSeconds(duration), 0.001)
        let group = DispatchGroup()
        var lastReported = -1.0
        group.enter()
        vIn.requestMediaDataWhenReady(on: queue) {
            while vIn.isReadyForMoreMediaData {
                guard !self.cancelled, let sample = vOut.copyNextSampleBuffer() else {
                    vIn.markAsFinished()
                    group.leave()
                    return
                }
                let t = CMTimeGetSeconds(CMSampleBufferGetPresentationTimeStamp(sample))
                if !vIn.append(sample) {
                    reader.cancelReading()
                    vIn.markAsFinished()
                    group.leave()
                    return
                }
                let p = min(0.99, max(0, t / total))
                if p - lastReported >= 0.01 {
                    lastReported = p
                    DispatchQueue.main.async { progress(p) }
                }
            }
        }
        if let aIn = aIn, let aOut = aOut {
            group.enter()
            aIn.requestMediaDataWhenReady(on: queue) {
                while aIn.isReadyForMoreMediaData {
                    guard !self.cancelled, let sample = aOut.copyNextSampleBuffer(), aIn.append(sample) else {
                        aIn.markAsFinished()
                        group.leave()
                        return
                    }
                }
            }
        }
        group.notify(queue: queue) {
            if self.cancelled || reader.status == .failed || writer.status == .failed {
                let why = writer.error?.localizedDescription ?? reader.error?.localizedDescription ?? "the transcode failed"
                writer.cancelWriting()
                try? FileManager.default.removeItem(at: output)
                return self.finish(self.cancelled ? .failure(.cancelled) : .failure(.failed(why)), done)
            }
            writer.finishWriting {
                self.queue.async {
                    if writer.status == .completed {
                        self.finish(.success(Output(width: o.target.width, height: o.target.height,
                                                    durationMs: Int(total * 1000), codec: o.codec, hdr: keepHDR)), done)
                    } else {
                        try? FileManager.default.removeItem(at: output)
                        self.finish(.failure(.failed(writer.error?.localizedDescription ?? "the output was not finalized")), done)
                    }
                }
            }
        }
    }
}
```

```swift ios/app/MediaUploader.swift
/// One durable upload. Persisted in `uploads.json` so it survives suspension and termination; its
/// file stays on disk (launch clean-up keeps it) until the upload is settled or cancelled.
struct MPUpload: Codable, Equatable {
    var id: String
    var fileId: String
    /// Relative to the files root: "<fileId>/<name>".
    var path: String
    var name: String
    var mime: String
    var bytes: Int64
    var url: String
    var route: String
    var method: String
    var field: String?
    var contentType: String
    var state: String
    var attempts: Int
    var nextAttemptAt: Date?
    var reason: String?
    var httpStatus: Int?
    var releaseAfter: Bool
    var createdAt: Date
}

/// The upload index. A write that fails leaves the state in memory and visible as `durable: false`;
/// an index that does not decode is copied aside and replaced, and `recovered` says so. An index
/// that exists but cannot be read (before the first unlock, or an I/O error) is `unread`: it is
/// never written over and its records are not known, so nothing that depends on them may run
/// (MPCore.indexPlan) until `load()` reads it.
final class MPUploadStore {
    private let file: URL
    private let directory: URL
    private let read: (URL) throws -> Data?
    private(set) var records: [String: MPUpload] = [:]
    private(set) var durable = true
    private(set) var recovered = false
    /// missing, loaded, recovered or unread.
    private(set) var index = "unread"

    /// `read` returns nil when the file does not exist and throws when it exists but cannot be read.
    init(directory: URL, read: @escaping (URL) throws -> Data? = MPUploadStore.readIfPresent) {
        self.directory = directory
        self.read = read
        file = directory.appendingPathComponent("uploads.json")
        load()
    }

    static func readIfPresent(_ url: URL) throws -> Data? {
        do {
            return try Data(contentsOf: url)
        } catch let e as CocoaError where e.code == .fileReadNoSuchFile {
            return nil
        } catch let e as NSError where e.domain == NSPOSIXErrorDomain && e.code == Int(ENOENT) {
            return nil
        }
    }

    /// Reads the index when it is not read yet; true once it is known (missing, loaded or recovered).
    @discardableResult
    func load() -> Bool {
        guard index == "unread" else { return true }
        let data: Data?
        do {
            data = try read(file)
        } catch {
            return false
        }
        guard let data = data else {
            index = "missing"
            return true
        }
        let dec = JSONDecoder()
        dec.dateDecodingStrategy = .millisecondsSince1970
        if let list = try? dec.decode([MPUpload].self, from: data) {
            for r in list where MPCore.isId(r.id) && MPCore.isId(r.fileId) { records[r.id] = r }
            index = "loaded"
        } else {
            let aside = directory.appendingPathComponent("uploads.unreadable-\(Int(Date().timeIntervalSince1970)).json")
            try? FileManager.default.moveItem(at: file, to: aside)
            recovered = true
            index = "recovered"
        }
        return true
    }

    func allows(_ action: String) -> Bool { MPCore.indexPlan(index).contains(action) }

    subscript(id: String) -> MPUpload? { records[id] }

    func set(_ r: MPUpload) { records[r.id] = r }

    func remove(_ id: String) { records[id] = nil }

    @discardableResult
    func persist() -> Bool {
        // An unread index is never written over: it holds uploads this run does not know.
        guard allows("persist") else {
            durable = false
            return false
        }
        let enc = JSONEncoder()
        enc.dateEncodingStrategy = .millisecondsSince1970
        enc.outputFormatting = [.sortedKeys]
        let list = records.values.sorted { ($0.createdAt, $0.id) < ($1.createdAt, $1.id) }
        do {
            let data = try enc.encode(list)
            try data.write(to: file, options: [.atomic, .completeFileProtectionUntilFirstUserAuthentication])
            durable = true
        } catch {
            durable = false
        }
        return durable
    }
}

/// Streams a multipart/form-data body (prefix, the file, suffix) through a bound stream pair, so a
/// large video is never copied or held in memory.
final class MPMultipartBody {
    let length: Int64
    private let prefix: Data
    private let suffix: Data
    private let file: URL

    init(file: URL, bytes: Int64, prefix: String, suffix: String) {
        self.file = file
        self.prefix = Data(prefix.utf8)
        self.suffix = Data(suffix.utf8)
        length = Int64(self.prefix.count) + bytes + Int64(self.suffix.count)
    }

    func makeStream() -> InputStream? {
        var input: InputStream?
        var output: OutputStream?
        Stream.getBoundStreams(withBufferSize: 256 * 1024, inputStream: &input, outputStream: &output)
        guard let i = input, let o = output, let source = InputStream(url: file) else { return nil }
        let prefix = self.prefix, suffix = self.suffix
        Thread.detachNewThread {
            o.open()
            source.open()
            defer {
                source.close()
                o.close()
            }
            func write(_ d: Data) -> Bool {
                var off = 0
                while off < d.count {
                    let n = d.withUnsafeBytes { o.write($0.baseAddress!.advanced(by: off).assumingMemoryBound(to: UInt8.self), maxLength: d.count - off) }
                    if n <= 0 { return false }
                    off += n
                }
                return true
            }
            guard write(prefix) else { return }
            var buf = [UInt8](repeating: 0, count: 256 * 1024)
            while true {
                let n = source.read(&buf, maxLength: buf.count)
                if n < 0 { return }
                if n == 0 { break }
                if !write(Data(buf[0..<n])) { return }
            }
            _ = write(suffix)
        }
        return i
    }
}

/// Uploads queued files with an in-process ephemeral session whose delegate refuses every HTTP
/// redirect, so the body reaches only the host of the validated URL: `productionConfiguration`,
/// the strict `destination` parse, the redirect delegate and MPCore.classify's outcome table.
/// A background URLSession is not used: it follows redirects without asking
/// (NativeExtContext.backgroundSessionIdentifier, platform limit).
///
/// Uploads run only while this process runs: in the foreground, during the finite background time
/// iOS may grant, and during a BGProcessingTask launch if iOS grants one. A suspended or terminated
/// upload keeps its file and record; the next run restarts it from byte 0. Resume data (iOS 17
/// resumable uploads) is never kept: a resumed task sends the rest of the body to the upload
/// resource the server named, a URL the bridge's https_url rule never checked.
///
/// Main thread only: every method, the delegate queue (`.main`) and the backoff timer share it.
final class MediaUploader: NSObject, URLSessionTaskDelegate, URLSessionDataDelegate {
    private struct Attempt {
        let id: String
        let token: String
        let task: URLSessionTask
        var spansBackground: Bool
        let body: MPMultipartBody?
    }

    private let store: MPUploadStore
    private let filesRoot: URL
    private let isApproved: (_ url: String, _ route: String) -> Bool
    private let changed: (_ id: String) -> Void
    private let progressed: (_ id: String, _ sent: Int64, _ total: Int64) -> Void
    private let configuration: URLSessionConfiguration
    private let now: () -> Date
    private let maxAttempts = 5
    private var current: Attempt?
    private var refusedToken: String?
    private var inBackground: Bool
    private var timer: Timer?
    private var lastProgress: (Date, Int64) = (.distantPast, 0)
    private lazy var session = URLSession(configuration: configuration, delegate: self, delegateQueue: .main)

    var onIdle: (() -> Void)?

    init(store: MPUploadStore, filesRoot: URL,
         isApproved: @escaping (_ url: String, _ route: String) -> Bool,
         changed: @escaping (_ id: String) -> Void,
         progressed: @escaping (_ id: String, _ sent: Int64, _ total: Int64) -> Void,
         inBackground: Bool, configuration: URLSessionConfiguration? = nil, now: @escaping () -> Date = Date.init) {
        self.store = store
        self.filesRoot = filesRoot
        self.isApproved = isApproved
        self.changed = changed
        self.progressed = progressed
        self.inBackground = inBackground
        self.configuration = configuration ?? MediaUploader.productionConfiguration()
        self.now = now
        super.init()
    }

    /// An ephemeral session with no cookies, cache or credentials, and a resource timeout long enough for a large video.
    static func productionConfiguration() -> URLSessionConfiguration {
        let c = URLSessionConfiguration.ephemeral
        c.waitsForConnectivity = true
        c.timeoutIntervalForRequest = 60
        c.timeoutIntervalForResource = 6 * 3600
        c.httpCookieStorage = nil
        c.httpShouldSetCookies = false
        c.urlCache = nil
        c.urlCredentialStorage = nil
        c.httpMaximumConnectionsPerHost = 1
        return c
    }

    var hasWork: Bool { store.records.values.contains { $0.state == "uploading" } }
    var isBusy: Bool { current != nil }
    var inFlightId: String? { current?.id }

    func drain() {
        assert(Thread.isMainThread)
        guard current == nil else { return }
        timer?.invalidate()
        timer = nil
        let t = now()
        let queued = store.records.values.filter { $0.state == "uploading" }.sorted { ($0.createdAt, $0.id) < ($1.createdAt, $1.id) }
        for candidate in queued {
            guard current == nil else { return }
            guard let r = store[candidate.id], r.state == "uploading" else { continue }
            if let due = r.nextAttemptAt, due > t { continue }
            if start(r) { return }
        }
        guard current == nil else { return }
        scheduleTimer()
        onIdle?()
    }

    func becameActive() {
        inBackground = false
        for r in store.records.values where r.state == "uploading" && r.nextAttemptAt != nil {
            var u = r
            u.nextAttemptAt = nil
            store.set(u)
        }
        drain()
    }

    func didEnterBackground() {
        inBackground = true
        current?.spansBackground = true
    }

    /// Background time ran out or was not granted: the attempt is abandoned uncounted.
    func expireInFlight() {
        guard let a = current else { return }
        current = nil
        a.task.cancel()
        if var r = store[a.id], r.state == "uploading" {
            r.nextAttemptAt = nil
            store.set(r)
        }
        changed(a.id)
    }

    /// The page cancelled: the attempt in flight (if it is this one) stops; the caller settles it.
    func cancel(_ id: String) {
        guard let a = current, a.id == id else { return }
        current = nil
        a.task.cancel()
        drain()
    }

    func fileURL(_ r: MPUpload) -> URL { filesRoot.appendingPathComponent(r.path) }

    private func start(_ r: MPUpload) -> Bool {
        let id = r.id
        guard isApproved(r.url, r.route), let target = MediaUploader.destination(r.url) else {
            settle(id, state: "failed", reason: "url_not_approved", status: nil)
            return false
        }
        let file = fileURL(r)
        let size = ((try? FileManager.default.attributesOfItem(atPath: file.path))?[.size] as? NSNumber)?.int64Value ?? -1
        guard size >= 0 else {
            settle(id, state: "failed", reason: "no_file", status: nil)
            return false
        }
        var request = URLRequest(url: target)
        request.httpMethod = r.method
        let token = id + "#" + UUID().uuidString.lowercased()
        let task: URLSessionTask
        var body: MPMultipartBody?
        if let field = r.field {
            let boundary = "nx-" + UUID().uuidString.lowercased()
            let (p, s) = MPCore.multipart(boundary: boundary, field: field, filename: r.name, contentType: r.contentType)
            let b = MPMultipartBody(file: file, bytes: size, prefix: p, suffix: s)
            request.setValue("multipart/form-data; boundary=\(boundary)", forHTTPHeaderField: "Content-Type")
            request.setValue(String(b.length), forHTTPHeaderField: "Content-Length")
            body = b
            task = session.uploadTask(withStreamedRequest: request)
        } else {
            request.setValue(r.contentType, forHTTPHeaderField: "Content-Type")
            task = session.uploadTask(with: request, fromFile: file)
        }
        task.taskDescription = token
        refusedToken = nil
        current = Attempt(id: id, token: token, task: task, spansBackground: inBackground, body: body)
        var u = r
        u.bytes = size
        u.nextAttemptAt = nil
        if u != r {
            store.set(u)
            changed(id)
        }
        task.resume()
        return true
    }

    /// Strict destination rule: the URL is used only when its parse agrees with the approved text.
    static func destination(_ s: String) -> URL? {
        guard isStrictURLText(s) else { return nil }
        let hostCharacters = CharacterSet(charactersIn: "abcdefghijklmnopqrstuvwxyz0123456789.-")
        guard let url = URL(string: s), url.scheme?.lowercased() == "https", url.user == nil, url.password == nil,
              url.fragment == nil, url.port == nil || url.port == 443,
              let host = url.host?.lowercased(), !host.isEmpty,
              host.unicodeScalars.allSatisfy({ hostCharacters.contains($0) }) else { return nil }
        let rest = s.lowercased().dropFirst("https://".count)
        guard s.lowercased().hasPrefix("https://"), rest.hasPrefix(host) else { return nil }
        let after = rest.dropFirst(host.count)
        guard after.isEmpty || after.hasPrefix("/") || after == ":443" || after.hasPrefix(":443/") else { return nil }
        return url
    }

    private static let urlTextCharacters: Set<UInt8> = Set(
        "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-._~:/?#[]@!$&'()*+,;=%".utf8)

    static func isStrictURLText(_ s: String) -> Bool {
        guard !s.isEmpty, s.unicodeScalars.allSatisfy({ $0.isASCII }) else { return false }
        let bytes = Array(s.utf8)
        let hex = Set("0123456789ABCDEFabcdef".utf8)
        var i = 0
        while i < bytes.count {
            let b = bytes[i]
            guard urlTextCharacters.contains(b) else { return false }
            if b == UInt8(ascii: "%") {
                guard i + 2 < bytes.count, hex.contains(bytes[i + 1]), hex.contains(bytes[i + 2]) else { return false }
                i += 3
            } else {
                i += 1
            }
        }
        return true
    }

    func complete(token: String?, statusCode: Int?, error: Error?) {
        guard let a = current, token == a.token else { return }
        current = nil
        guard let r = store[a.id], r.state == "uploading" else { return drain() }
        let refused = refusedToken == a.token
        refusedToken = nil
        switch MPCore.classify(status: statusCode, transportError: error != nil, refused: refused, spansBackground: a.spansBackground) {
        case .uploaded:
            settle(a.id, state: "uploaded", reason: nil, status: statusCode)
        case .failed(let why):
            settle(a.id, state: "failed", reason: why, status: statusCode)
        case .requeue:
            var u = r
            u.nextAttemptAt = nil
            store.set(u)
            changed(a.id)
        case .retry(let why):
            var u = r
            u.attempts += 1
            u.httpStatus = error == nil ? statusCode : nil
            if u.attempts >= maxAttempts {
                u.state = "failed"
                u.reason = why
                u.nextAttemptAt = nil
            } else {
                u.nextAttemptAt = now().addingTimeInterval(MPCore.backoff(attempt: u.attempts, base: 30, cap: 15 * 60))
            }
            store.set(u)
            changed(a.id)
        }
        drain()
    }

    private func settle(_ id: String, state: String, reason: String?, status: Int?) {
        guard var r = store[id] else { return }
        r.state = state
        r.reason = reason
        r.httpStatus = status
        r.nextAttemptAt = nil
        store.set(r)
        changed(id)
    }

    private func scheduleTimer() {
        let t = now()
        guard let due = store.records.values.filter({ $0.state == "uploading" }).compactMap({ $0.nextAttemptAt })
            .filter({ $0 > t }).min() else { return }
        let next = Timer(timeInterval: due.timeIntervalSince(t), repeats: false) { [weak self] _ in self?.drain() }
        RunLoop.main.add(next, forMode: .common)
        timer = next
    }

    // MARK: URLSession delegate (main queue)

    /// Every redirect is refused, so the 3xx becomes the task's response.
    func urlSession(_ session: URLSession, task: URLSessionTask, willPerformHTTPRedirection response: HTTPURLResponse,
                    newRequest request: URLRequest, completionHandler: @escaping (URLRequest?) -> Void) {
        if let a = current, task.taskDescription == a.token { refusedToken = a.token }
        completionHandler(nil)
    }

    func urlSession(_ session: URLSession, task: URLSessionTask, needNewBodyStream completionHandler: @escaping (InputStream?) -> Void) {
        guard let a = current, task.taskDescription == a.token, let body = a.body else { return completionHandler(nil) }
        completionHandler(body.makeStream())
    }

    func urlSession(_ session: URLSession, task: URLSessionTask, didSendBodyData bytesSent: Int64,
                    totalBytesSent: Int64, totalBytesExpectedToSend: Int64) {
        guard let a = current, task.taskDescription == a.token else { return }
        let t = now()
        // At most every half second or every 1%, so the page is not flooded.
        let total = totalBytesExpectedToSend > 0 ? totalBytesExpectedToSend : (store[a.id]?.bytes ?? 0)
        let step = max(Int64(1), total / 100)
        guard t.timeIntervalSince(lastProgress.0) >= 0.5 || totalBytesSent - lastProgress.1 >= step else { return }
        lastProgress = (t, totalBytesSent)
        progressed(a.id, totalBytesSent, total)
    }

    func urlSession(_ session: URLSession, task: URLSessionTask, didCompleteWithError error: Error?) {
        complete(token: task.taskDescription, statusCode: (task.response as? HTTPURLResponse)?.statusCode, error: error)
    }
}
```

```java android/mediapicker/java/despia/ext/mediapicker/MediaCore.java
    static Head parseHead(byte[] bytes, int count) {
        int end = -1;
        for (int i = 0; i + 3 < count; i++) {
            if (bytes[i] == 13 && bytes[i + 1] == 10 && bytes[i + 2] == 13 && bytes[i + 3] == 10) {
                end = i;
                break;
            }
        }
        if (end < 0) return count >= MAX_HEAD ? new Head(431, null, 0) : new Head(0, null, 0);
        if (end + 4 > MAX_HEAD) return new Head(431, null, 0);
        for (int i = 0; i < end; i++) {
            int b = bytes[i] & 0xff;
            if (b >= 0x7F) return new Head(400, null, 0);
            if (b == 13 && bytes[i + 1] != 10) return new Head(400, null, 0);
            if (b == 10 && (i == 0 || bytes[i - 1] != 13)) return new Head(400, null, 0);
            if (b < 0x20 && b != 9 && b != 10 && b != 13) return new Head(400, null, 0);
        }
        String text = new String(bytes, 0, end, StandardCharsets.US_ASCII);
        String[] lines = text.split("\r\n", -1);
        String[] first = lines[0].split(" ", -1);
        if (first.length != 3) return new Head(400, null, 0);
        String method = first[0], target = first[1], version = first[2];
        if (method.isEmpty()) return new Head(400, null, 0);
        for (int i = 0; i < method.length(); i++) {
            char c = method.charAt(i);
            if (c < 'A' || c > 'Z') return new Head(400, null, 0);
        }
        if (!target.startsWith("/") || !(version.equals("HTTP/1.1") || version.equals("HTTP/1.0"))) return new Head(400, null, 0);
        Map<String, String> headers = new LinkedHashMap<>();
        for (int li = 1; li < lines.length; li++) {
            String line = lines[li];
            int colon = line.indexOf(':');
            if (colon <= 0 || line.charAt(0) == ' ' || line.charAt(0) == '\t') return new Head(400, null, 0);
            String name = line.substring(0, colon).toLowerCase(Locale.ROOT);
            for (int i = 0; i < name.length(); i++) {
                char c = name.charAt(i);
                if (c <= 0x20 || c >= 0x7F || c == ':') return new Head(400, null, 0);
            }
            String value = trimSpaces(line.substring(colon + 1));
            if (name.equals("range") && headers.containsKey(name)) return new Head(400, null, 0);
            if (!headers.containsKey(name)) headers.put(name, value);
        }
        return new Head(0, new Request(method, target, headers), end + 4);
    }

        if (first >= size) return unsatisfiable;
        return new long[]{206, first, Math.min(last, size - 1)};
```

```java android/mediapicker/java/despia/ext/mediapicker/MediaPickerExtension.java
/**
 * Native picker for every kind of file, native video transcoding and durable upload; the Android
 * twin of MediaPickerExtension.swift, with the same routes, events, records and reasons.
 *
 * <p>Pickers, all the platform's own: the system Photo Picker (PickVisualMedia and
 * PickMultipleVisualMedia; no media permission needed, backported by Google Play system updates and
 * falling back to ACTION_OPEN_DOCUMENT where absent), ACTION_OPEN_DOCUMENT (OpenDocument and
 * OpenMultipleDocuments) for files and audio, and the system camera app (TakePicture and
 * CaptureVideo, writing to a CaptureProvider URI). {@code source: auto} shows a stock Material
 * dialog offering the three. Launchers are registered on CREATED under {@link ExtContext#resultKey}.
 *
 * <p>Picked files are copied into files/nativeext/mediapicker/files/&lt;fileId&gt;/ and served on a
 * loopback URL (MediaServer); no byte crosses the bridge. Everything runs on the main thread except
 * the copies, which run on {@link #io} and come back to it.
 */
@UnstableApi
public final class MediaPickerExtension implements NativeExtension {

    // ------------------------------------------------------------------ lifecycle

    @Override
    public void onCreate(ExtContext context) {
        ctx = context;
        policy = context;
        instance = this;
        app = context.app();
        filesRoot = MediaStore.filesRoot(app);
        server = new MediaServer(this::portChanged);
        pruneSettledUploads();
        cleanUpAtLaunch();
        readoptUploadFiles();
        reconcileUploads();
    }

    @Override
    public void onActivityEvent(Activity activity, ActivityEvent event) {
        if (!(activity instanceof ComponentActivity)) return;
        ComponentActivity a = (ComponentActivity) activity;
        switch (event) {
            case CREATED:
                register(a);
                break;
            case RESUMED:
                resumed = a;
                server.ensureRunning();
                break;
            case PAUSED:
                if (resumed == a) resumed = null;
                break;
            case DESTROYED:
                if (registeredOn == a) {
                    unregister();
                    // Recreated (configuration, or the system reclaimed it): the answer reaches the
                    // launchers the new activity registers under the same keys, so the pick waits.
                    // Finishing: the answer can no longer arrive; the pick ends, never left presenting.
                    if (pending != null && a.isFinishing()) {
                        failPick(pending, "activity_destroyed");
                        pending = null;
                    }
                }
                break;
            default:
                break;
        }
    }

    private void register(ComponentActivity a) {
        unregister();
        registeredOn = a;
        androidx.activity.result.ActivityResultRegistry reg = a.getActivityResultRegistry();
        pickOne = reg.register(ctx.resultKey("pick_one"), new PickVisualMedia(),
                uri -> picked(uri == null ? Collections.emptyList() : Collections.singletonList(uri), "pick"));
        pickMany = reg.register(ctx.resultKey("pick_many"), new ActivityResultContracts.PickMultipleVisualMedia(),
                uris -> picked(uris, "pick"));
        openOne = reg.register(ctx.resultKey("open_one"), new ActivityResultContracts.OpenDocument(),
                uri -> picked(uri == null ? Collections.emptyList() : Collections.singletonList(uri), "pick"));
        openMany = reg.register(ctx.resultKey("open_many"), new ActivityResultContracts.OpenMultipleDocuments(),
                uris -> picked(uris, "pick"));
        takePicture = reg.register(ctx.resultKey("take_picture"), new ActivityResultContracts.TakePicture(), this::captured);
        captureVideo = reg.register(ctx.resultKey("capture_video"), new ActivityResultContracts.CaptureVideo() {
            @NonNull
            @Override
            public Intent createIntent(@NonNull Context c, @NonNull Uri input) {
                Intent i = super.createIntent(c, input);
                Pending p = pending;
                if (p != null && p.maxDurationS > 0) i.putExtra(android.provider.MediaStore.EXTRA_DURATION_LIMIT, p.maxDurationS);
                // EXTRA_VIDEO_QUALITY takes 0 (low) or 1 (high); medium has no platform value and maps to high.
                if (p != null) i.putExtra(android.provider.MediaStore.EXTRA_VIDEO_QUALITY, "low".equals(p.quality) ? 0 : 1);
                return i;
            }
        }, this::captured);
        cameraPermission = reg.register(ctx.resultKey("camera_permission"), new ActivityResultContracts.RequestPermission(), granted -> {
            Pending p = pending;
            if (p != null && p.sheetCamera != null) {
                // The camera was chosen from the sheet: the pick was already answered, so the
                // outcome is the pick's own end.
                boolean video = p.sheetCamera;
                p.sheetCamera = null;
                if (!granted) {
                    pending = null;
                    endPick(p.pickId, "failed", "permission_denied");
                    return;
                }
                startCamera(p, video);
                return;
            }
            if (p == null || p.reply == null) return;
            if (!p.call.isActive()) {
                // The route already timed out: its answer was sent; the pick never existed for the page.
                pending = null;
                picks.remove(p.pickId);
                return;
            }
            if (!granted) {
                pending = null;
                p.reply.reply(ExtResult.error("permission_denied", "camera access was denied"));
                return;
            }
            present(p);
        });
    }

    private void unregister() {
        for (ActivityResultLauncher<?> l : Arrays.asList(pickOne, pickMany, openOne, openMany, takePicture, captureVideo, cameraPermission)) {
            if (l != null) l.unregister();
        }
        pickOne = pickMany = null;
        openOne = openMany = null;
        takePicture = captureVideo = null;
        cameraPermission = null;
        registeredOn = null;
    }

    // ------------------------------------------------------------------ routes

    @Override
    public void handle(ExtCall call, ExtResult.Callback reply) {
        Map<String, Object> p = call.params;
        switch (call.route) {
            case "pick":
                pick(call, reply);
                return;
            case "result":
                reply.reply(result(str(p, "pick", "")));
                return;
            case "files":
                reply.reply(listFiles(str(p, "id", null)));
                return;
            case "release":
                reply.reply(release(str(p, "id", null), bool(p, "all", false)));
                return;
            case "transcode":
                transcode(call, reply);
                return;
            case "upload":
                reply.reply(upload(p));
                return;
            case "jobs":
                reply.reply(jobs(str(p, "id", null)));
                return;
            case "cancel":
                reply.reply(cancel(str(p, "id", "")));
                return;
            default:
                reply.reply(ExtResult.error("not_registered", call.route));
        }
    }

    private static String str(Map<String, Object> p, String k, String d) {
        Object v = p.get(k);
        return v instanceof String ? (String) v : d;
    }

    private static int num(Map<String, Object> p, String k, int d) {
        Object v = p.get(k);
        return v instanceof Number ? ((Number) v).intValue() : d;
    }

    private static boolean bool(Map<String, Object> p, String k, boolean d) {
        Object v = p.get(k);
        return v instanceof Boolean ? (Boolean) v : d;
    }

    private void pick(ExtCall call, ExtResult.Callback reply) {
        Map<String, Object> p = call.params;
        if (pending != null) {
            reply.reply(ExtResult.error("busy", "a picker is already open"));
            return;
        }
        MediaCore.Types types = MediaCore.parseTypes(str(p, "types", null));
        if (types == null) {
            reply.reply(ExtResult.error("bad_value", "types is a comma list of image, video, audio, document, any and MIME types"));
            return;
        }
        String source = MediaCore.source(str(p, "source", "auto"), types);
        if (source == null) {
            reply.reply(ExtResult.error("bad_value", "that source cannot offer these types"));
            return;
        }
        String cameraMode = MediaCore.cameraMode(types, str(p, "camera", "both"));
        boolean hasCamera = app.getPackageManager().hasSystemFeature(PackageManager.FEATURE_CAMERA_ANY);
        if ("camera".equals(source)) {
            if (!hasCamera) {
                reply.reply(ExtResult.error("camera_unavailable", "this device has no camera"));
                return;
            }
            if (cameraMode == null) {
                reply.reply(ExtResult.error("bad_value", "camera does not match types"));
                return;
            }
        }
        if (registeredOn == null || resumed == null) {
            reply.reply(ExtResult.error("unavailable", "the app is not in the foreground"));
            return;
        }
        int platformMax = 0;
        if ("library".equals(source) && Build.VERSION.SDK_INT >= 33) platformMax = android.provider.MediaStore.getPickImagesMaxLimit();
        int[] limit = MediaCore.limit(num(p, "limit", 0), bool(p, "multiple", false), platformMax);
        Pending pd = new Pending();
        pd.pickId = UUID.randomUUID().toString();
        pd.source = source;
        pd.types = types;
        pd.limit = limit[0];
        pd.cameraMode = hasCamera ? cameraMode : null;
        pd.maxDurationS = num(p, "max_duration_s", 0);
        pd.quality = str(p, "camera_quality", "high");
        JSONObject rec = new JSONObject();
        put(rec, "pickId", pd.pickId);
        put(rec, "state", "presenting");
        put(rec, "source", source);
        put(rec, "maxFileMB", num(p, "max_file_mb", 0));
        put(rec, "maxTotalMB", num(p, "max_total_mb", 0));
        put(rec, "limit", pd.limit);
        put(rec, "fileIds", new JSONArray());
        put(rec, "representation", str(p, "representation", "current"));
        put(rec, "ordered", bool(p, "ordered", false));
        put(rec, "tab", str(p, "tab", "photos"));
        String accent = str(p, "accent_color", null);
        if (accent != null) {
            Long c = color(accent);
            if (c == null) {
                reply.reply(ExtResult.error("bad_value", "accent_color is #RRGGBB"));
                return;
            }
            put(rec, "accent", c);
        }
        picks.put(pd.pickId, rec);
        JSONObject out = new JSONObject();
        put(out, "pickId", pd.pickId);
        put(out, "state", "presenting");
        put(out, "source", source);
        put(out, "limit", pd.limit);
        put(out, "limitLowered", limit[1] == 1);
        if ("camera".equals(source) && needsCameraPermission()) {
            // Answered when the permission is settled: allowed → presented; denied → error.
            pd.call = call;
            pd.reply = (ExtResult r) -> {
                if (!r.isOk()) picks.remove(pd.pickId);
                reply.reply(r.isOk() ? ExtResult.ok(out) : r);
            };
            pending = pd;
            cameraPermission.launch(Manifest.permission.CAMERA);
            return;
        }
        pending = pd;
        if (!present(pd)) {
            pending = null;
            picks.remove(pd.pickId);
            reply.reply(ExtResult.error("unavailable", "the picker could not be shown"));
            return;
        }
        reply.reply(ExtResult.ok(out));
    }

    /**
     * When the app declares CAMERA (requires.permissions: the dashboard owns it), the system camera
     * intent is refused until it is granted (MediaStore.ACTION_IMAGE_CAPTURE reference), so it is asked
     * first; an app that does not declare it needs nothing.
     */
    private boolean needsCameraPermission() {
        if (ContextCompat.checkSelfPermission(app, Manifest.permission.CAMERA) == PackageManager.PERMISSION_GRANTED) return false;
        try {
            PackageInfo info = app.getPackageManager().getPackageInfo(app.getPackageName(), PackageManager.GET_PERMISSIONS);
            return info.requestedPermissions != null && Arrays.asList(info.requestedPermissions).contains(Manifest.permission.CAMERA);
        } catch (PackageManager.NameNotFoundException e) {
            return false;
        }
    }

    /** Shows the picker for the pending pick; false when nothing could be shown. */
    private boolean present(Pending pd) {
        if (pd.reply != null) {
            ExtResult.Callback r = pd.reply;
            pd.reply = null;
            pd.call = null;
            boolean ok = launch(pd);
            r.reply(ok ? ExtResult.ok(null) : ExtResult.error("unavailable", "the picker could not be shown"));
            if (!ok) pending = null;
            return ok;
        }
        return launch(pd);
    }

    private boolean launch(Pending pd) {
        try {
            switch (pd.source) {
                case "library":
                    library(pd);
                    return true;
                case "files":
                    documents(pd);
                    return true;
                case "camera":
                    if ("both".equals(pd.cameraMode)) {
                        sheet(pd, false);
                    } else {
                        camera(pd, "video".equals(pd.cameraMode));
                    }
                    return true;
                default:
                    sheet(pd, true);
                    return true;
            }
        } catch (RuntimeException e) {
            ctx.log("picker not shown: " + e);
            return false;
        }
    }

    private void library(Pending pd) {
        JSONObject rec = picks.get(pd.pickId);
        PickVisualMedia.VisualMediaType type = visualType(pd.types);
        PickVisualMediaRequest.Builder b = new PickVisualMediaRequest.Builder().setMediaType(type);
        if (pd.limit != 1 && pd.limit >= 2) b.setMaxItems(pd.limit);
        if (rec != null) {
            if (rec.optBoolean("ordered") && pd.limit != 1) b.setOrderedSelection(true);
            b.setDefaultTab("albums".equals(rec.optString("tab")) ? PickVisualMedia.DefaultTab.AlbumsTab.INSTANCE
                    : PickVisualMedia.DefaultTab.PhotosTab.INSTANCE);
            if (rec.has("accent")) b.setAccentColor(rec.optLong("accent"));
            // compatible: declare no HDR capability, so the picker hands over an SDR transcode of HDR
            // video (API 33+, where the picker supports it); current/automatic: the original file.
            if ("compatible".equals(rec.optString("representation")) && Build.VERSION.SDK_INT >= 33) {
                b.setMediaCapabilitiesForTranscoding(new PickVisualMedia.MediaCapabilities.Builder().build());
            }
        }
        if (pd.limit == 1) pickOne.launch(b.build()); else pickMany.launch(b.build());
    }

    static PickVisualMedia.VisualMediaType visualType(MediaCore.Types t) {
        boolean img = t.wantsImages(), vid = t.wantsVideos();
        if (!t.isAny() && t.mimes.size() == 1 && t.categories.isEmpty() && !t.mimes.get(0).endsWith("/*")) {
            return new PickVisualMedia.SingleMimeType(t.mimes.get(0));
        }
        if (img && !vid) return PickVisualMedia.ImageOnly.INSTANCE;
        if (vid && !img) return PickVisualMedia.VideoOnly.INSTANCE;
        return PickVisualMedia.ImageAndVideo.INSTANCE;
    }

    /** ACTION_OPEN_DOCUMENT MIME filters for the types; the twin of iOS contentTypes. */
    static String[] documentTypes(MediaCore.Types t) {
        if (t.isAny() || t.categories.contains("document")) return new String[]{"*/*"};
        List<String> out = new ArrayList<>();
        if (t.categories.contains("image")) out.add("image/*");
        if (t.categories.contains("video")) out.add("video/*");
        if (t.categories.contains("audio")) out.add("audio/*");
        out.addAll(t.mimes);
        return out.isEmpty() ? new String[]{"*/*"} : out.toArray(new String[0]);
    }

    private void documents(Pending pd) {
        String[] mimes = documentTypes(pd.types);
        if (pd.limit == 1) openOne.launch(mimes); else openMany.launch(mimes);
    }

    private void camera(Pending pd, boolean video) {
        File dir = new File(MediaStore.dir(app), "capture");
        //noinspection ResultOfMethodCallIgnored
        dir.mkdirs();
        String ext = video ? ".mp4" : ".jpg";
        File f = new File(dir, UUID.randomUUID() + ext);
        pd.capture = f;
        pd.captureMime = video ? "video/mp4" : "image/jpeg";
        Uri uri = FileProvider.getUriForFile(app, app.getPackageName() + ".nx.mediapicker.capture", f);
        if (video) captureVideo.launch(uri); else takePicture.launch(uri);
    }

    /**
     * A camera chosen from the sheet (source auto, or camera with mode both) gets the same CAMERA
     * check as source camera: an app that declares CAMERA cannot start the capture intents until
     * it is granted, and they would throw inside the dialog's click listener.
     */
    private void cameraFromSheet(Pending pd, boolean video) {
        if (needsCameraPermission()) {
            pd.sheetCamera = video;
            try {
                cameraPermission.launch(Manifest.permission.CAMERA);
            } catch (RuntimeException e) {
                pd.sheetCamera = null;
                ctx.log("camera permission not asked: " + e);
                if (pending == pd) pending = null;
                endPick(pd.pickId, "failed", "camera_unavailable");
            }
            return;
        }
        startCamera(pd, video);
    }

    /** Starts a capture after the dialog or the permission answer; a refusal ends the pick. */
    private void startCamera(Pending pd, boolean video) {
        try {
            camera(pd, video);
        } catch (RuntimeException e) {
            ctx.log("camera not started: " + e);
            if (pending == pd) pending = null;
            endPick(pd.pickId, "failed", "camera_unavailable");
        }
    }

    /** Stock Material dialog listing the sources this pick can use; Cancel ends the pick. */
    private void sheet(Pending pd, boolean withLibraryAndFiles) {
        List<String> labels = new ArrayList<>();
        List<Runnable> actions = new ArrayList<>();
        boolean visual = pd.types.wantsImages() || pd.types.wantsVideos();
        if (withLibraryAndFiles && visual) {
            labels.add(app.getString(R.string.nx_mediapicker_photo_library));
            actions.add(() -> library(pd));
        }
        if (pd.cameraMode != null && (visual || !withLibraryAndFiles)) {
            if (!"video".equals(pd.cameraMode)) {
                labels.add(app.getString(R.string.nx_mediapicker_camera_photo));
                actions.add(() -> cameraFromSheet(pd, false));
            }
            if (!"photo".equals(pd.cameraMode)) {
                labels.add(app.getString(R.string.nx_mediapicker_camera_video));
                actions.add(() -> cameraFromSheet(pd, true));
            }
        }
        if (withLibraryAndFiles) {
            labels.add(app.getString(R.string.nx_mediapicker_files));
            actions.add(() -> documents(pd));
        }
        final boolean[] chosen = {false};
        new MaterialAlertDialogBuilder(resumed)
                .setTitle(R.string.nx_mediapicker_choose)
                .setItems(labels.toArray(new CharSequence[0]), (d, which) -> {
                    chosen[0] = true;
                    actions.get(which).run();
                })
                .setNegativeButton(android.R.string.cancel, null)
                .setOnDismissListener(d -> {
                    if (!chosen[0] && pending == pd) {
                        pending = null;
                        endPick(pd.pickId, "cancelled", null);
                    }
                })
                .show();
    }

    private void captured(Boolean ok) {
        Pending pd = pending;
        if (pd == null || pd.capture == null) return;
        pending = null;
        File f = pd.capture;
        if (ok == null || !ok || !f.isFile() || f.length() == 0) {
            //noinspection ResultOfMethodCallIgnored
            f.delete();
            endPick(pd.pickId, "cancelled", null);
            return;
        }
        accept(pd, Collections.singletonList(new Incoming(null, f, pd.captureMime)), "camera");
    }

    private void picked(List<Uri> uris, String origin) {
        Pending pd = pending;
        if (pd == null) return;
        pending = null;
        if (uris == null || uris.isEmpty()) {
            endPick(pd.pickId, "cancelled", null);
            return;
        }
        List<Incoming> in = new ArrayList<>();
        for (Uri u : uris) in.add(new Incoming(u, null, null));
        accept(pd, in, origin);
    }

    private static final class Incoming {
        final Uri uri;
        final File file;
        final String mime;

        Incoming(Uri uri, File file, String mime) {
            this.uri = uri;
            this.file = file;
            this.mime = mime;
        }
    }

    private void accept(Pending pd, List<Incoming> items, String origin) {
        JSONObject pick = picks.get(pd.pickId);
        if (pick == null) return;
        JSONArray ids = pick.optJSONArray("fileIds");
        List<Incoming> accepted = items;
        int over = 0;
        // The document picker on Android has no limit of its own: the rest fail limit_exceeded.
        if (pd.limit > 0 && items.size() > pd.limit) {
            accepted = items.subList(0, pd.limit);
            over = items.size() - pd.limit;
        }
        for (Incoming i : accepted) {
            JSONObject f = newFile(pd.pickId, origin, "file", "application/octet-stream");
            files.put(f.optString("fileId"), f);
            ids.put(f.optString("fileId"));
            importItem(i, f.optString("fileId"));
        }
        for (int k = 0; k < over; k++) {
            JSONObject f = newFile(pd.pickId, origin, "file", "application/octet-stream");
            put(f, "state", "failed");
            put(f, "reason", "limit_exceeded");
            files.put(f.optString("fileId"), f);
            ids.put(f.optString("fileId"));
        }
        put(pick, "state", "loading");
        ctx.emit("pick", pickSnapshot(pick));
        settlePickIfDone(pd.pickId);
    }

    private JSONObject newFile(String pickId, String origin, String name, String mime) {
        JSONObject f = new JSONObject();
        String id = UUID.randomUUID().toString();
        byte[] b = new byte[32];
        random.nextBytes(b);
        tokens.put(id, MediaCore.token(b));
        put(f, "fileId", id);
        if (pickId != null) put(f, "pickId", pickId);
        put(f, "origin", origin);
        put(f, "name", name);
        put(f, "mime", mime);
        put(f, "kind", MediaCore.kind(mime));
        put(f, "bytes", 0L);
        put(f, "state", "loading");
        return f;
    }

    private File dir(String id) {
        return new File(filesRoot, id);
    }

    /** Copies one item into its own directory on {@link #io}; the result comes back on main. */
    private void importItem(Incoming item, String id) {
        File d = dir(id);
        io.execute(() -> {
            String name, mime, error = null;
            File dest = null;
            //noinspection ResultOfMethodCallIgnored
            d.mkdirs();
            ContentResolver cr = app.getContentResolver();
            if (item.file != null) {
                mime = item.mime;
                name = MediaCore.safeName(item.file.getName(), "");
                dest = new File(d, name);
                if (!item.file.renameTo(dest)) error = "import_failed";
            } else {
                String type = cr.getType(item.uri);
                mime = type == null ? "application/octet-stream" : type.toLowerCase(Locale.ROOT);
                String ext = MimeTypeMap.getSingleton().getExtensionFromMimeType(mime);
                String raw = displayName(cr, item.uri);
                name = MediaCore.safeName(raw == null ? "file" : raw, ext == null ? "" : "." + ext);
                dest = new File(d, name);
                try (InputStream in = cr.openInputStream(item.uri); OutputStream out = new FileOutputStream(dest)) {
                    if (in == null) throw new IOException("no stream");
                    byte[] buf = new byte[256 * 1024];
                    int n;
                    while ((n = in.read(buf)) > 0) out.write(buf, 0, n);
                } catch (IOException | SecurityException e) {
                    error = "import_failed";
                }
            }
            // Size and duration are read here, off the main thread: MediaMetadataRetriever and the
            // bounds decode can take long on a large file.
            JSONObject meta = new JSONObject();
            if (error == null) {
                String kind = MediaCore.kind(mime);
                put(meta, "kind", kind);
                if ("image".equals(kind)) imageSize(dest, meta);
                if ("video".equals(kind) || "audio".equals(kind)) mediaInfo(dest, meta);
            }
            final String fName = name, fMime = mime, fError = error;
            final File fDest = dest;
            main.post(() -> imported(id, fDest, fName, fMime, fError, meta));
        });
    }

    private static String displayName(ContentResolver cr, Uri u) {
        try (Cursor c = cr.query(u, new String[]{OpenableColumns.DISPLAY_NAME}, null, null, null)) {
            if (c != null && c.moveToFirst()) return c.getString(0);
        } catch (RuntimeException ignored) {
        }
        return u.getLastPathSegment();
    }

    private void imported(String id, File dest, String name, String mime, String error, JSONObject meta) {
        JSONObject f = files.get(id);
        if (f == null || !"loading".equals(f.optString("state"))) {
            // Released while loading: whatever arrived goes.
            deleteTree(dir(id));
            return;
        }
        if (error != null) {
            put(f, "state", "failed");
            put(f, "reason", error);
            deleteTree(dir(id));
        } else {
            put(f, "name", name);
            put(f, "mime", mime);
            put(f, "kind", MediaCore.kind(mime));
            put(f, "bytes", dest.length());
            JSONObject pick = picks.get(f.optString("pickId"));
            int maxFile = pick == null ? 0 : pick.optInt("maxFileMB");
            String verdict = MediaCore.admit(Collections.singletonList(dest.length()), maxFile, 0).get(0);
            if (verdict != null) {
                put(f, "state", "failed");
                put(f, "reason", verdict);
                deleteTree(dir(id));
            } else {
                boolean holdForTotal = pick != null && pick.optInt("maxTotalMB") > 0;
                put(f, "state", holdForTotal ? "loaded" : "ready");
                for (String k : new String[]{"width", "height", "durationMs"}) if (meta.has(k)) put(f, k, meta.opt(k));
                if (!holdForTotal) server.publish(tokens.get(id), new MediaServer.Entry(dest, mime));
            }
        }
        if (!"loaded".equals(f.optString("state"))) ctx.emit("file", fileSnapshot(f));
        String pid = f.optString("pickId", null);
        if (pid != null) settlePickIfDone(pid);
    }

    private void settlePickIfDone(String pickId) {
        JSONObject pick = picks.get(pickId);
        if (pick == null || !"loading".equals(pick.optString("state"))) return;
        JSONArray ids = pick.optJSONArray("fileIds");
        List<JSONObject> held = new ArrayList<>();
        for (int i = 0; i < ids.length(); i++) {
            JSONObject f = files.get(ids.optString(i));
            if (f == null) continue;
            if ("loading".equals(f.optString("state"))) return;
            if ("loaded".equals(f.optString("state"))) held.add(f);
        }
        if (pick.optInt("maxTotalMB") > 0) {
            List<Long> sizes = new ArrayList<>();
            for (JSONObject f : held) sizes.add(f.optLong("bytes"));
            List<String> verdicts = MediaCore.admit(sizes, 0, pick.optInt("maxTotalMB"));
            for (int i = 0; i < held.size(); i++) {
                JSONObject f = held.get(i);
                String id = f.optString("fileId");
                if (verdicts.get(i) != null) {
                    put(f, "state", "failed");
                    put(f, "reason", verdicts.get(i));
                    deleteTree(dir(id));
                } else {
                    put(f, "state", "ready");
                    server.publish(tokens.get(id), new MediaServer.Entry(new File(dir(id), f.optString("name")), f.optString("mime")));
                }
                ctx.emit("file", fileSnapshot(f));
            }
        }
        put(pick, "state", "done");
        ctx.emit("pick", pickSnapshot(pick));
    }

    private void endPick(String pickId, String state, String reason) {
        JSONObject pick = picks.get(pickId);
        if (pick == null) return;
        put(pick, "state", state);
        if (reason != null) put(pick, "reason", reason);
        ctx.emit("pick", pickSnapshot(pick));
    }

    private void failPick(Pending pd, String reason) {
        if (pd.reply != null) {
            ExtResult.Callback r = pd.reply;
            pd.reply = null;
            r.reply(ExtResult.error("unavailable", "the activity ended before the camera was allowed"));
            return;
        }
        endPick(pd.pickId, "failed", reason);
    }

    private static void imageSize(File f, JSONObject rec) {
        BitmapFactory.Options o = new BitmapFactory.Options();
        o.inJustDecodeBounds = true;
        BitmapFactory.decodeFile(f.getAbsolutePath(), o);
        if (o.outWidth <= 0 || o.outHeight <= 0) return;
        int w = o.outWidth, h = o.outHeight;
        try {
            int orientation = new ExifInterface(f.getAbsolutePath()).getAttributeInt(ExifInterface.TAG_ORIENTATION, 1);
            // EXIF 5 to 8 rotate by 90 degrees: the size as displayed, as on iOS.
            if (orientation >= 5 && orientation <= 8) {
                int t = w;
                w = h;
                h = t;
            }
        } catch (IOException ignored) {
        }
        put(rec, "width", w);
        put(rec, "height", h);
    }

    private static void mediaInfo(File f, JSONObject rec) {
        MediaMetadataRetriever r = new MediaMetadataRetriever();
        try {
            r.setDataSource(f.getAbsolutePath());
            String d = r.extractMetadata(MediaMetadataRetriever.METADATA_KEY_DURATION);
            if (d != null) put(rec, "durationMs", Long.parseLong(d.trim()));
        } catch (RuntimeException ignored) {
        } finally {
            try {
                r.release();
            } catch (Exception ignored) {
            }
        }
        if ("video".equals(rec.optString("kind"))) {
            double[] info = Transcoder.probe(null, f);
            if (info != null) {
                put(rec, "width", (int) info[0]);
                put(rec, "height", (int) info[1]);
            }
        }
    }

    private ExtResult result(String pickId) {
        JSONObject p = picks.get(pickId);
        return p == null ? ExtResult.error("not_found", "unknown pick") : ExtResult.ok(pickSnapshot(p));
    }

    private ExtResult listFiles(String id) {
        if (id != null) {
            JSONObject f = MediaCore.isId(id) ? files.get(id) : null;
            return f == null ? ExtResult.error("not_found", "unknown file") : ExtResult.ok(fileSnapshot(f));
        }
        JSONArray list = new JSONArray();
        for (JSONObject f : new TreeMap<>(files).values()) {
            if (!"released".equals(f.optString("state"))) list.put(fileSnapshot(f));
        }
        JSONObject out = new JSONObject();
        put(out, "files", list);
        if (port > 0) put(out, "base", base());
        return ExtResult.ok(out);
    }

    /** Whether a running transcode or an unfinished upload still needs this file. */
    private boolean inUse(String id) {
        for (JSONObject t : transcodes.values()) {
            String s = t.optString("state");
            if ((id.equals(t.optString("fileId")) || id.equals(t.optString("outputFileId")))
                    && ("queued".equals(s) || "transcoding".equals(s))) {
                return true;
            }
        }
        try {
            for (JSONObject u : MediaStore.records(app).values()) {
                if (id.equals(u.optString("fileId")) && "uploading".equals(u.optString("state"))) return true;
            }
        } catch (MediaStore.StorageException e) {
            // Unknown: kept, never deleted under an upload.
            return true;
        }
        return false;
    }

    private ExtResult release(String id, boolean all) {
        List<String> ids = new ArrayList<>();
        if (all) {
            for (JSONObject f : files.values()) {
                String fid = f.optString("fileId");
                if (!"released".equals(f.optString("state")) && !inUse(fid)) ids.add(fid);
            }
        } else {
            JSONObject f = id != null && MediaCore.isId(id) ? files.get(id) : null;
            if (f == null || "released".equals(f.optString("state"))) return ExtResult.error("not_found", "unknown file");
            if (inUse(id)) return ExtResult.error("busy", "a transcode or an upload still needs this file; cancel it first");
            ids.add(id);
        }
        Collections.sort(ids);
        int failed = 0;
        for (String fid : ids) if (!releaseFile(fid)) failed++;
        if (failed > 0) {
            return ExtResult.error("release_failed", failed + " file(s) could not be deleted; the next launch deletes them");
        }
        JSONObject out = new JSONObject();
        put(out, "released", new JSONArray(ids));
        return ExtResult.ok(out);
    }

    private boolean releaseFile(String id) {
        JSONObject f = files.get(id);
        if (f == null) return true;
        String token = tokens.get(id);
        if (token != null) server.withdraw(token);
        put(f, "state", "released");
        f.remove("reason");
        boolean ok = deleteTree(dir(id));
        ctx.emit("file", fileSnapshot(f));
        return ok;
    }

    private static boolean deleteTree(File f) {
        File[] kids = f.listFiles();
        if (kids != null) for (File k : kids) deleteTree(k);
        return f.delete() || !f.exists();
    }

    /** Checks the call on main, probes the source on {@link #io}, then answers from main. */
    private void transcode(ExtCall call, ExtResult.Callback reply) {
        Map<String, Object> p = call.params;
        String id = str(p, "id", "");
        JSONObject src = MediaCore.isId(id) ? files.get(id) : null;
        if (src == null) {
            reply.reply(ExtResult.error("not_found", "unknown file"));
            return;
        }
        if (!"ready".equals(src.optString("state")) || !"video".equals(src.optString("kind"))) {
            reply.reply(ExtResult.error("bad_value", "only a ready video can be transcoded"));
            return;
        }
        Integer bitrate = MediaCore.bitrate(str(p, "bitrate_kbps", null));
        if (bitrate == null) {
            reply.reply(ExtResult.error("bad_value", "bitrate_kbps is 100 to 400000"));
            return;
        }
        File source = new File(dir(id), src.optString("name"));
        io.execute(() -> {
            // MediaMetadataRetriever can take long on a large file: never on the main thread.
            double[] info = Transcoder.probe(app, source);
            main.post(() -> {
                if (!call.isActive()) return;
                reply.reply(transcodeProbed(p, id, info));
            });
        });
    }

    private ExtResult transcodeProbed(Map<String, Object> p, String id, double[] info) {
        JSONObject src = files.get(id);
        if (src == null || !"ready".equals(src.optString("state"))) return ExtResult.error("not_found", "the file was released");
        Integer bitrate = MediaCore.bitrate(str(p, "bitrate_kbps", null));
        String codec = str(p, "codec", "h264");
        String preset = str(p, "preset", "720p");
        int frameRate = num(p, "frame_rate", 0);
        if (info == null) return ExtResult.error("unreadable", "the video's tracks cannot be read");
        int[] target = MediaCore.target((int) info[0], (int) info[1], preset, codec, bitrate, (int) info[2],
                frameRate > 0 ? frameRate : info[3]);
        if (target == null) return ExtResult.error("bad_value", "unknown preset or a video without a size");
        if (!Transcoder.supports(codec, target[0], target[1])) {
            return ExtResult.error("not_supported_on_device", "this device cannot encode " + codec + " at " + target[0] + "x" + target[1]);
        }
        JSONObject out = newFile(null, "transcode", "video-" + UUID.randomUUID().toString().substring(0, 8) + ".mp4", "video/mp4");
        put(out, "progress", 0.0);
        files.put(out.optString("fileId"), out);
        JSONObject job = new JSONObject();
        put(job, "jobId", UUID.randomUUID().toString());
        put(job, "kind", "transcode");
        put(job, "state", "queued");
        put(job, "progress", 0.0);
        put(job, "fileId", id);
        put(job, "outputFileId", out.optString("fileId"));
        put(job, "width", target[0]);
        put(job, "height", target[1]);
        put(job, "bitrateKbps", target[2]);
        put(job, "codec", codec);
        put(job, "frameRate", frameRate);
        put(job, "keepAudio", "keep".equals(str(p, "audio", "keep")));
        put(job, "audioKbps", num(p, "audio_bitrate_kbps", 128));
        transcodes.put(job.optString("jobId"), job);
        nextTranscode();
        return ExtResult.ok(jobSnapshot(job));
    }

    private void nextTranscode() {
        if (runningTranscode != null) return;
        JSONObject job = null;
        for (JSONObject j : transcodes.values()) {
            if ("queued".equals(j.optString("state"))) {
                job = j;
                break;
            }
        }
        if (job == null) {
            TranscodeService.end(app);
            return;
        }
        JSONObject src = files.get(job.optString("fileId"));
        JSONObject out = files.get(job.optString("outputFileId"));
        if (src == null || out == null) {
            put(job, "state", "failed");
            put(job, "reason", "unreadable");
            nextTranscode();
            return;
        }
        String jobId = job.optString("jobId");
        File outDir = dir(out.optString("fileId"));
        //noinspection ResultOfMethodCallIgnored
        outDir.mkdirs();
        put(job, "state", "transcoding");
        runningTranscode = jobId;
        transcoder = new Transcoder();
        TranscodeService.begin(app, 0);
        ctx.emit("job", jobSnapshot(job));
        final JSONObject j = job;
        transcoder.start(app, new File(dir(src.optString("fileId")), src.optString("name")), new File(outDir, out.optString("name")),
                new int[]{j.optInt("width"), j.optInt("height"), j.optInt("bitrateKbps")}, j.optString("codec"), j.optInt("frameRate"),
                j.optBoolean("keepAudio"), j.optInt("audioKbps"), new Transcoder.Listener() {
                    int lastPercent = -1;

                    @Override
                    public void progress(double fraction) {
                        if (!"transcoding".equals(j.optString("state"))) return;
                        put(j, "progress", fraction);
                        ctx.emit("job", jobSnapshot(j));
                        int pc = (int) (fraction * 100);
                        if (pc != lastPercent) {
                            lastPercent = pc;
                            TranscodeService.begin(app, pc);
                        }
                    }

                    @Override
                    public void done(String reason, int width, int height, long durationMs) {
                        transcodeDone(jobId, reason, width, height, durationMs);
                    }
                });
    }

    private void transcodeDone(String jobId, String reason, int width, int height, long durationMs) {
        runningTranscode = null;
        transcoder = null;
        JSONObject j = transcodes.get(jobId);
        if (j == null) {
            nextTranscode();
            return;
        }
        JSONObject out = files.get(j.optString("outputFileId"));
        if (reason == null) {
            put(j, "state", "done");
            put(j, "progress", 1.0);
            if (out != null && "loading".equals(out.optString("state"))) {
                File f = new File(dir(out.optString("fileId")), out.optString("name"));
                put(out, "state", "ready");
                out.remove("progress");
                put(out, "bytes", f.length());
                put(out, "width", width);
                put(out, "height", height);
                put(out, "durationMs", durationMs);
                server.publish(tokens.get(out.optString("fileId")), new MediaServer.Entry(f, "video/mp4"));
            }
        } else {
            // A cancel or the foreground time limit already set the state; keep it.
            String s = j.optString("state");
            if (!"cancelled".equals(s) && !"failed".equals(s)) put(j, "state", "cancelled".equals(reason) ? "cancelled" : "failed");
            if (!j.has("reason")) put(j, "reason", reason);
            if (out != null && "loading".equals(out.optString("state"))) {
                put(out, "state", "failed");
                put(out, "reason", j.optString("reason"));
                out.remove("progress");
                deleteTree(dir(out.optString("fileId")));
            }
        }
        if (out != null) ctx.emit("file", fileSnapshot(out));
        ctx.emit("job", jobSnapshot(j));
        nextTranscode();
    }

    /** TranscodeService.onTimeout: the platform's foreground time for media processing is used up. */
    static void transcodeTimedOut() {
        MediaPickerExtension e = instance;
        if (e == null) return;
        e.main.post(() -> {
            if (e.runningTranscode == null || e.transcoder == null) return;
            JSONObject j = e.transcodes.get(e.runningTranscode);
            if (j != null) {
                put(j, "state", "failed");
                put(j, "reason", "background_expired");
            }
            e.transcoder.cancel();
        });
    }

    // ------------------------------------------------------------------ upload

    private ExtResult upload(Map<String, Object> p) {
        String id = str(p, "id", "");
        JSONObject f = MediaCore.isId(id) ? files.get(id) : null;
        if (f == null) return ExtResult.error("not_found", "unknown file");
        if (!"ready".equals(f.optString("state"))) return ExtResult.error("bad_value", "only a ready file can be uploaded");
        String url = str(p, "url", null);
        if (url == null) return ExtResult.error("bad_request", "url");
        String field = str(p, "form_field", null);
        if (field != null && !MediaCore.formName(field)) return ExtResult.error("bad_value", "form_field is 1 to 64 of A-Z a-z 0-9 . _ -");
        String type = MediaCore.contentType(str(p, "content_type", null), f.optString("mime"));
        if (type == null) return ExtResult.error("bad_value", "content_type is a MIME type without parameters");
        JSONObject r = new JSONObject();
        String jobId = UUID.randomUUID().toString();
        String gen = UUID.randomUUID().toString();
        put(r, "jobId", jobId);
        put(r, "kind", "upload");
        put(r, "fileId", id);
        put(r, "path", id + "/" + f.optString("name"));
        put(r, "name", f.optString("name"));
        put(r, "mime", f.optString("mime"));
        put(r, "bytes", f.optLong("bytes"));
        put(r, "url", url);
        put(r, "route", "upload");
        put(r, "method", str(p, "method", field == null ? "PUT" : "POST"));
        if (field != null) put(r, "field", field);
        put(r, "contentType", type);
        put(r, "state", "uploading");
        put(r, "attempts", 0);
        put(r, "releaseAfter", bool(p, "release_after", false));
        put(r, "createdAt", System.currentTimeMillis());
        put(r, "gen", gen);
        // Durable before it is promised: nothing is queued when the index cannot be written.
        try {
            MediaStore.put(app, r);
        } catch (MediaStore.StorageException e) {
            return ExtResult.error("storage_failed", "the upload index could not be saved; nothing was queued");
        }
        UploadWorker.schedule(app, jobId, gen);
        return ExtResult.ok(uploadSnapshot(r));
    }

    /** From a worker thread or main: the settled record; the page hears it on main. */
    static void uploadChanged(JSONObject r) {
        MediaPickerExtension e = instance;
        if (e == null) return;
        e.main.post(() -> {
            if ("uploaded".equals(r.optString("state")) && r.optBoolean("releaseAfter")) {
                String fid = r.optString("fileId");
                if (e.files.containsKey(fid) && !e.inUse(fid)) e.releaseFile(fid);
            }
            e.ctx.emit("job", e.uploadSnapshot(r));
        });
    }

    static void uploadProgress(String id, long sent, long total) {
        MediaPickerExtension e = instance;
        if (e == null) return;
        e.main.post(() -> {
            JSONObject r;
            try {
                r = MediaStore.get(e.app, id);
            } catch (MediaStore.StorageException se) {
                return;
            }
            if (r == null || !"uploading".equals(r.optString("state"))) return;
            JSONObject s = e.uploadSnapshot(r);
            put(s, "sentBytes", sent);
            put(s, "progress", total > 0 ? Math.min(1.0, (double) sent / total) : 0.0);
            e.ctx.emit("job", s);
        });
    }

    private void pruneSettledUploads() {
        long cutoff = System.currentTimeMillis() - 7L * 24 * 3600 * 1000;
        try {
            for (JSONObject r : MediaStore.records(app).values()) {
                if (!"uploading".equals(r.optString("state")) && r.optLong("createdAt") < cutoff) MediaStore.remove(app, r.optString("jobId"));
            }
        } catch (MediaStore.StorageException e) {
            ctx.log("upload index not pruned: " + e.getMessage());
        }
    }

    /** Everything under files/ goes, except the files an unfinished upload still needs; capture/ too. */
    private void cleanUpAtLaunch() {
        Set<String> keep = new HashSet<>();
        try {
            for (JSONObject r : MediaStore.records(app).values()) if ("uploading".equals(r.optString("state"))) keep.add(r.optString("fileId"));
        } catch (MediaStore.StorageException e) {
            // The index cannot be read: nothing is deleted, so no upload loses its file.
            return;
        }
        String[] names = filesRoot.list();
        for (String n : MediaCore.cleanup(names == null ? Collections.emptyList() : Arrays.asList(names), keep)) {
            if (!deleteTree(new File(filesRoot, n))) ctx.log("launch clean-up could not delete a file directory");
        }
        deleteTree(new File(MediaStore.dir(app), "capture"));
    }

    private void readoptUploadFiles() {
        try {
            for (JSONObject u : MediaStore.records(app).values()) {
                String fid = u.optString("fileId");
                if (!"uploading".equals(u.optString("state")) || files.containsKey(fid)) continue;
                File path = new File(filesRoot, u.optString("path"));
                if (!path.isFile()) continue;
                JSONObject f = newFile(null, "upload", u.optString("name"), u.optString("mime"));
                String token = tokens.remove(f.optString("fileId"));
                put(f, "fileId", fid);
                tokens.put(fid, token);
                put(f, "bytes", path.length());
                put(f, "state", "ready");
                files.put(fid, f);
                server.publish(token, new MediaServer.Entry(path, u.optString("mime")));
            }
        } catch (MediaStore.StorageException e) {
            ctx.log("upload files not re-listed: " + e.getMessage());
        }
    }

    /**
     * Launch reconciliation: an "uploading" record whose
     * generation has no unfinished work (its request was never committed, or the work was lost)
     * is scheduled again with the same generation.
     */
    private void reconcileUploads() {
        Map<String, JSONObject> recs;
        try {
            recs = MediaStore.records(app);
        } catch (MediaStore.StorageException e) {
            return;
        }
        for (JSONObject r : recs.values()) {
            if (!"uploading".equals(r.optString("state"))) continue;
            String id = r.optString("jobId"), gen = r.optString("gen");
            ListenableFuture<List<WorkInfo>> infos = WorkManager.getInstance(app).getWorkInfosForUniqueWork(UploadWorker.uniqueName(id));
            infos.addListener(() -> {
                List<WorkInfo> list;
                try {
                    list = infos.get();
                } catch (Exception failed) {
                    list = Collections.emptyList();
                }
                for (WorkInfo w : list) if (!w.getState().isFinished() && w.getTags().contains(UploadWorker.GEN_TAG + gen)) return;
                UploadWorker.schedule(app, id, gen);
            }, ContextCompat.getMainExecutor(app));
        }
    }

    // ------------------------------------------------------------------ jobs

    private ExtResult jobs(String id) {
        if (id != null) {
            if (!MediaCore.isId(id)) return ExtResult.error("not_found", "unknown job");
            JSONObject t = transcodes.get(id);
            if (t != null) return ExtResult.ok(jobSnapshot(t));
            try {
                JSONObject u = MediaStore.get(app, id);
                if (u != null) return ExtResult.ok(uploadSnapshot(u));
            } catch (MediaStore.StorageException e) {
                return ExtResult.error("storage_failed", "the upload index could not be read");
            }
            return ExtResult.error("not_found", "unknown job");
        }
        JSONArray list = new JSONArray();
        for (JSONObject t : new TreeMap<>(transcodes).values()) list.put(jobSnapshot(t));
        try {
            List<JSONObject> ups = new ArrayList<>(MediaStore.records(app).values());
            ups.sort((a, b) -> a.optLong("createdAt") != b.optLong("createdAt") ? Long.compare(a.optLong("createdAt"), b.optLong("createdAt"))

        } catch (MediaStore.StorageException e) {
            return ExtResult.error("storage_failed", "the upload index could not be read");
        }
        JSONObject out = new JSONObject();
        put(out, "jobs", list);
        if (MediaStore.recovered()) put(out, "indexRecovered", true);
        return ExtResult.ok(out);

    private ExtResult cancel(String id) {
        if (!MediaCore.isId(id)) return ExtResult.error("not_found", "unknown job");
        JSONObject t = transcodes.get(id);
        if (t != null) {
            String s = t.optString("state");
            if (!"queued".equals(s) && !"transcoding".equals(s)) return ExtResult.ok(jobSnapshot(t));
            put(t, "state", "cancelled");
            put(t, "reason", "cancelled");
            if ("transcoding".equals(s) && transcoder != null) {
                transcoder.cancel();
            } else {
                JSONObject out = files.get(t.optString("outputFileId"));
                if (out != null) {
                    put(out, "state", "failed");
                    put(out, "reason", "cancelled");
                    ctx.emit("file", fileSnapshot(out));
                }
                ctx.emit("job", jobSnapshot(t));
            }
            return ExtResult.ok(jobSnapshot(t));
        }
        JSONObject u;
        try {
            u = MediaStore.get(app, id);
            if (u == null) return ExtResult.error("not_found", "unknown job");
            if (!"uploading".equals(u.optString("state"))) return ExtResult.ok(uploadSnapshot(u));
            put(u, "state", "cancelled");
            // A new generation: a run already sending can no longer settle this record.
            put(u, "gen", UUID.randomUUID().toString());
            MediaStore.put(app, u);
        } catch (MediaStore.StorageException e) {
            return ExtResult.error("storage_failed", "the cancel could not be saved");
        }
        UploadWorker.cancel(app, id);
        ctx.emit("job", uploadSnapshot(u));
        return ExtResult.ok(uploadSnapshot(u));
    }
```

```java android/mediapicker/java/despia/ext/mediapicker/MediaServer.java
package despia.ext.mediapicker;

import android.os.Handler;
import android.os.Looper;

import java.io.File;
import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
import java.io.RandomAccessFile;
import java.net.InetAddress;
import java.net.InetSocketAddress;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.SynchronousQueue;
import java.util.concurrent.ThreadPoolExecutor;
import java.util.concurrent.TimeUnit;

/**
 * Serves picked files to the page over HTTP on 127.0.0.1 only, so {@code <img>}, {@code <video>},
 * {@code <audio>} and {@code fetch()} read them straight from disk with byte ranges, never through the
 * bridge (the iOS twin is MediaFileServer.swift; both answer with MediaCore's response heads).
 *
 * <p>Why loopback: the extension API offers no hook into the WebView's request handling
 * (no shouldInterceptRequest is reachable from ExtContext), and a bridge reply is a JavaScript string,
 * which would mean base64 for every byte. The base app allows cleartext and sets
 * MIXED_CONTENT_ALWAYS_ALLOW on its WebView (MainActivity.java), so an http://127.0.0.1 URL loads in
 * an https page.
 *
 * <p>Security: bound to 127.0.0.1; read-only (GET, HEAD, OPTIONS); every URL carries a 256-bit random
 * token that exists only while its file is held; no cookie or credential is read or set, so the URL
 * is the capability and {@code Access-Control-Allow-Origin: *} grants nothing a page without the URL
 * could use. Any app on the device can connect to the port, but without a token it gets 404.
 */
final class MediaServer {
    interface PortListener {
        /** Main thread: the port now serving, or -1 while none is bound. */
        void port(int port);
    }

    static final int CHUNK = 256 * 1024;
    /** A connection that sends no complete head in this time is closed. */
    static final int HEAD_TIMEOUT_MS = 10_000;
    /** Concurrent connections; a media element opens a few, more are refused at once. */
    static final int MAX_CONNECTIONS = 16;

    static final class Entry {
        final File file;
        final String mime;

        Entry(File file, String mime) {
            this.file = file;
            this.mime = mime;
        }
    }

    private final Map<String, Entry> table = new ConcurrentHashMap<>();
    private final Handler main = new Handler(Looper.getMainLooper());
    private final PortListener listener;
    private final ExecutorService pool = new ThreadPoolExecutor(0, MAX_CONNECTIONS, 30, TimeUnit.SECONDS,
            new SynchronousQueue<>(), r -> {
                Thread t = new Thread(r, "nx-mediapicker-http");
                t.setDaemon(true);
                return t;
            });
    private ServerSocket socket;
    private Thread acceptor;
    private int preferredPort;

    MediaServer(PortListener listener) {
        this.listener = listener;
    }

    /** Starts listening if not already; the last port first, so URLs the page holds stay valid. */
    synchronized void ensureRunning() {
        if (socket != null && !socket.isClosed()) return;
        ServerSocket s = null;
        for (int attempt = 0; attempt < 2 && s == null; attempt++) {
            int port = attempt == 0 ? preferredPort : 0;
            try {
                ServerSocket t = new ServerSocket();
                t.setReuseAddress(true);
                t.bind(new InetSocketAddress(InetAddress.getByAddress(new byte[]{127, 0, 0, 1}), port), 16);
                s = t;
            } catch (IOException e) {
                if (port == 0) break;
            }
        }
        if (s == null) {
            report(-1);
            return;
        }
        socket = s;
        preferredPort = s.getLocalPort();
        final ServerSocket bound = s;
        acceptor = new Thread(() -> accept(bound), "nx-mediapicker-accept");
        acceptor.setDaemon(true);
        acceptor.start();
        report(preferredPort);
    }

    synchronized int port() {
        return socket != null && !socket.isClosed() ? socket.getLocalPort() : -1;
    }

    void publish(String token, Entry e) {
        if (!MediaCore.isToken(token)) throw new IllegalArgumentException("token");
        table.put(token, e);
    }

    void withdraw(String token) {
        table.remove(token);
    }

    synchronized void stop() {
        if (socket != null) {
            try {
                socket.close();
            } catch (IOException ignored) {
            }
        }
        socket = null;
        report(-1);
    }

    private void report(int port) {
        main.post(() -> listener.port(port));
    }

    private void accept(ServerSocket s) {
        while (!s.isClosed()) {
            Socket c;
            try {
                c = s.accept();
            } catch (IOException e) {
                break;
            }
            // Belt and braces: the socket is bound to 127.0.0.1; anything else is closed unanswered.
            if (!c.getInetAddress().isLoopbackAddress()) {
                close(c);
                continue;
            }
            try {
                pool.execute(() -> serve(c));
            } catch (java.util.concurrent.RejectedExecutionException full) {
                respond(c, MediaCore.responseHead(503, null, 0, null, "GET", false));
            }
        }
        synchronized (this) {
            if (socket == s) {
                socket = null;
                report(-1);
            }
        }
    }

    private void serve(Socket c) {
        try {
            c.setSoTimeout(HEAD_TIMEOUT_MS);
            InputStream in = c.getInputStream();
            byte[] buf = new byte[MediaCore.MAX_HEAD];
            int n = 0;
            MediaCore.Head head;
            while (true) {
                int r = in.read(buf, n, buf.length - n);
                if (r < 0) {
                    close(c);
                    return;
                }
                n += r;
                head = MediaCore.parseHead(buf, n);
                if (!head.needMore()) break;
            }
            if (head.request == null) {
                respond(c, MediaCore.responseHead(head.status, null, 0, null, "GET", false));
                return;
            }
            MediaCore.Request req = head.request;
            String token = MediaCore.tokenFromTarget(req.target);
            Entry e = token == null ? null : table.get(token);
            RandomAccessFile f = null;
            long size = 0;
            if (e != null) {
                try {
                    f = new RandomAccessFile(e.file, "r");
                    size = f.length();
                } catch (IOException missing) {
                    f = null;
                }
            }
            long[] range = MediaCore.range(req.headers.get("range"), size);
            int status = MediaCore.status(req.method, f != null, (int) range[0]);
            boolean pn = "true".equals(req.headers.get("access-control-request-private-network"));
            String text = MediaCore.responseHead(status, e == null ? null : e.mime, size, status == 206 ? range : null, req.method, pn);
            if (!"GET".equals(req.method) || (status != 200 && status != 206) || f == null || range[2] < range[1]) {
                if (f != null) f.close();
                respond(c, text);
                return;
            }
            c.setSoTimeout(0);
            try (RandomAccessFile file = f) {
                OutputStream out = c.getOutputStream();
                out.write(text.getBytes(StandardCharsets.US_ASCII));
                file.seek(range[1]);
                long remaining = range[2] - range[1] + 1;
                byte[] chunk = new byte[CHUNK];
                while (remaining > 0) {
                    int r = file.read(chunk, 0, (int) Math.min(chunk.length, remaining));
                    // The file shrank or was released while being read: end the response short.
                    if (r <= 0) break;
                    out.write(chunk, 0, r);
                    remaining -= r;
                }
                out.flush();
            }
        } catch (IOException ignored) {
            // The page closed the connection (a media element seeking does this all the time).
        } finally {
            close(c);
        }
    }

    private static void respond(Socket c, String head) {
        try {
            OutputStream out = c.getOutputStream();
            out.write(head.getBytes(StandardCharsets.US_ASCII));
            out.flush();
        } catch (IOException ignored) {
        } finally {
            close(c);
        }
    }

    private static void close(Socket c) {
        try {
            c.close();
        } catch (IOException ignored) {
        }
    }
}
```

```java android/mediapicker/java/despia/ext/mediapicker/MediaStore.java
package despia.ext.mediapicker;

import android.content.Context;

import org.json.JSONException;
import org.json.JSONObject;

import java.io.File;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.util.Iterator;
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/**
 * The upload index, files/nativeext/mediapicker/uploads.json, written atomically (temp file, fsync,
 * rename) so it survives process death; the files themselves live under files/&lt;fileId&gt;/.
 *
 * <p>Authority over an upload record: the generation written when the upload was queued and the
 * run claim taken by the worker run that sends it. WorkManager does not interrupt a stopped Worker's
 * thread and may start the next run while it is still blocked, so only the run holding the claim
 * writes a state.
 *
 * <p>Every method is synchronized on the class: the main thread (routes) and worker threads share it.
 */
final class MediaStore {
    static final class StorageException extends Exception {
        StorageException(String m, Throwable cause) {
            super(m, cause);
        }
    }

    private static Map<String, JSONObject> cache;
    /** id → run currently holding the claim (in this process). */
    private static final Map<String, String> CLAIMS = new ConcurrentHashMap<>();
    /** Whether the last read found an index that did not decode (kept aside as uploads.json.bad). */
    private static boolean recovered;

    private MediaStore() {
    }

    static File dir(Context c) {
        File d = new File(new File(c.getFilesDir(), "nativeext"), "mediapicker");
        //noinspection ResultOfMethodCallIgnored
        d.mkdirs();
        return d;
    }

    static File filesRoot(Context c) {
        File d = new File(dir(c), "files");
        //noinspection ResultOfMethodCallIgnored
        d.mkdirs();
        return d;
    }

    private static File index(Context c) {
        return new File(dir(c), "uploads.json");
    }

    static synchronized boolean recovered() {
        return recovered;
    }

    private static Map<String, JSONObject> load(Context c) throws StorageException {
        if (cache != null) return cache;
        Map<String, JSONObject> out = new LinkedHashMap<>();
        File f = index(c);
        if (f.isFile()) {
            try (InputStream in = new FileInputStream(f)) {
                byte[] b = new byte[(int) f.length()];
                int n = 0;
                while (n < b.length) {
                    int r = in.read(b, n, b.length - n);
                    if (r < 0) break;
                    n += r;
                }
                JSONObject all = new JSONObject(new String(b, 0, n, StandardCharsets.UTF_8));
                for (Iterator<String> it = all.keys(); it.hasNext(); ) {
                    String k = it.next();
                    out.put(k, all.getJSONObject(k));
                }
            } catch (JSONException bad) {
                // Unreadable: kept aside for inspection, never silently replaced in place.
                //noinspection ResultOfMethodCallIgnored
                f.renameTo(new File(dir(c), "uploads.json.bad"));
                recovered = true;
            } catch (IOException e) {
                throw new StorageException("upload index unreadable", e);
            }
        }
        cache = out;
        return out;
    }

    private static void save(Context c, Map<String, JSONObject> all) throws StorageException {
        JSONObject o = new JSONObject();
        try {
            for (Map.Entry<String, JSONObject> e : all.entrySet()) o.put(e.getKey(), e.getValue());
        } catch (JSONException e) {
            throw new StorageException("upload index not JSON", e);
        }
        File tmp = new File(dir(c), "uploads.json.tmp");
        try (FileOutputStream out = new FileOutputStream(tmp)) {
            out.write(o.toString().getBytes(StandardCharsets.UTF_8));
            out.getFD().sync();
        } catch (IOException e) {
            throw new StorageException("upload index not written", e);
        }
        if (!tmp.renameTo(index(c))) throw new StorageException("upload index not replaced", null);
    }

    private static JSONObject copy(JSONObject r) {
        try {
            return r == null ? null : new JSONObject(r.toString());
        } catch (JSONException e) {
            return null;
        }
    }

    static synchronized Map<String, JSONObject> records(Context c) throws StorageException {
        Map<String, JSONObject> out = new LinkedHashMap<>();
        for (Map.Entry<String, JSONObject> e : load(c).entrySet()) out.put(e.getKey(), copy(e.getValue()));
        return out;
    }

    static synchronized JSONObject get(Context c, String id) throws StorageException {
        return copy(load(c).get(id));
    }

    /** Saves a new or replaced record; on a write failure the index in memory is restored. */
    static synchronized void put(Context c, JSONObject r) throws StorageException {
        Map<String, JSONObject> all = load(c);
        String id = r.optString("jobId");
        JSONObject before = all.get(id);
        all.put(id, copy(r));
        try {
            save(c, all);
        } catch (StorageException e) {
            if (before == null) all.remove(id); else all.put(id, before);
            throw e;
        }
    }

    static synchronized void remove(Context c, String id) throws StorageException {
        Map<String, JSONObject> all = load(c);
        JSONObject before = all.remove(id);
        if (before == null) return;
        try {
            save(c, all);
        } catch (StorageException e) {
            all.put(id, before);
            throw e;
        }
    }

    /**
     * The worker's claim: the record when it is "uploading" with this generation and no other live
     * run in this process holds it; null otherwise (nothing to do, nothing written).
     */
    static synchronized JSONObject claim(Context c, String id, String gen, String run) throws StorageException {
        JSONObject r = load(c).get(id);
        if (r == null || !"uploading".equals(r.optString("state")) || !gen.equals(r.optString("gen"))) return null;
        CLAIMS.put(id, run);
        return copy(r);
    }

    static void release(String id, String run) {
        CLAIMS.remove(id, run);
    }

    /**
     * Writes a state for the run holding the claim, merging {@code extra}; null, writing nothing, when
     * the claim or the generation moved on (a cancel, a replacement).
     */
    static synchronized JSONObject settle(Context c, String id, String gen, String run, String state, JSONObject extra)
            throws StorageException {
        Map<String, JSONObject> all = load(c);
        JSONObject r = all.get(id);
        if (r == null || !run.equals(CLAIMS.get(id)) || !gen.equals(r.optString("gen"))) return null;
        if (!"uploading".equals(r.optString("state"))) return null;
        JSONObject next = copy(r);
        try {
            next.put("state", state);
            if (extra != null) {
                for (Iterator<String> it = extra.keys(); it.hasNext(); ) {
                    String k = it.next();
                    next.put(k, extra.get(k));
                }
            }
        } catch (JSONException e) {
            throw new StorageException("record not JSON", e);
        }
        all.put(id, next);
        try {
            save(c, all);
        } catch (StorageException e) {
            all.put(id, r);
            throw e;
        }
        return copy(next);
    }
}
```

```java android/mediapicker/java/despia/ext/mediapicker/TranscodeService.java
 * so leaving the app does not stop a long video. The transcode itself runs in the extension (Media3
 * Transformer on the main looper); this service only holds the foreground state and shows progress.

 * <p>Type: mediaProcessing on Android 15 and later (API 35, the type made for transcoding); before
 * that the platform has no such type and dataSync is used, whose documented uses include local file
 * processing (developer.android.com/develop/background-work/services/fgs/service-types, read

    static final String CHANNEL = "nx_mediapicker";
    static final int NOTIFICATION = 0x6d70;

    static void begin(Context c, int percent) {
        Intent i = new Intent(c, TranscodeService.class).putExtra("percent", percent);
        try {
            ContextCompat.startForegroundService(c, i);
        } catch (RuntimeException notAllowed) {
            // Started from the background (ForegroundServiceStartNotAllowedException): the transcode
            // still runs while the process lives; the platform decides how long.
        }
    }

    static void end(Context c) {
        c.stopService(new Intent(c, TranscodeService.class));
    }

    @Override
    public int onStartCommand(Intent intent, int flags, int startId) {
        int percent = intent == null ? 0 : intent.getIntExtra("percent", 0);
        NotificationManager nm = getSystemService(NotificationManager.class);
        if (Build.VERSION.SDK_INT >= 26 && nm != null && nm.getNotificationChannel(CHANNEL) == null) {
            nm.createNotificationChannel(new NotificationChannel(CHANNEL, getString(R.string.nx_mediapicker_channel),
                    NotificationManager.IMPORTANCE_LOW));
        }
        Notification n = new NotificationCompat.Builder(this, CHANNEL)
                .setSmallIcon(android.R.drawable.stat_sys_upload)
                .setContentTitle(getString(R.string.nx_mediapicker_transcoding))
                .setProgress(100, percent, percent <= 0)
                .setOngoing(true)
                .setOnlyAlertOnce(true)
                .setSilent(true)
                .build();
        int type = 0;
        if (Build.VERSION.SDK_INT >= 35) {
            type = ServiceInfo.FOREGROUND_SERVICE_TYPE_MEDIA_PROCESSING;
        } else if (Build.VERSION.SDK_INT >= 29) {
            type = ServiceInfo.FOREGROUND_SERVICE_TYPE_DATA_SYNC;
        }
        try {
            ServiceCompat.startForeground(this, NOTIFICATION, n, type);
        } catch (RuntimeException notAllowed) {
            stopSelf();
        }
        return START_NOT_STICKY;
    }

    @Override
    public void onTimeout(int startId, int fgsType) {
        MediaPickerExtension.transcodeTimedOut();
        stopSelf();
    }

    @Override
    public IBinder onBind(Intent intent) {
        return null;
    }
```

```java android/mediapicker/java/despia/ext/mediapicker/Transcoder.java
 * at the target bitrate, optional frame-rate cap, AAC audio at the given bitrate or no audio.
 * HDR is kept for HEVC when the device can encode it and tone-mapped to SDR for H.264 (OpenGL).
 *
 * <p>Version: media3-transformer 1.10.1, the version the base app already resolves for
 * media3-exoplayer (app/build.gradle). The latest stable is 1.11.1 (developer.android.com/jetpack/
 * androidx/releases/media3, read 2026-11-20); an extension may not change the media3 version the
 * base app resolves, so this follows when the base app moves every media3 artifact to 1.11.1.
 *
 * <p>Main thread only: Transformer runs on the thread that built it; progress is polled.
 */
@UnstableApi
final class Transcoder {
    interface Listener {
        void progress(double fraction);

        /** {@code reason} null on success. */
        void done(String reason, int width, int height, long durationMs);
    }

    static final long POLL_MS = 500;

    private final Handler main = new Handler(Looper.getMainLooper());
    private Transformer transformer;
    private boolean finished;
    private boolean cancelled;
    private Listener listener;

    /** Width, height (as displayed), source kbps, fps and duration in ms; null when unreadable. */
    static double[] probe(Context c, File f) {
        MediaMetadataRetriever r = new MediaMetadataRetriever();
        try {
            r.setDataSource(f.getAbsolutePath());
            int w = parse(r.extractMetadata(MediaMetadataRetriever.METADATA_KEY_VIDEO_WIDTH));
            int h = parse(r.extractMetadata(MediaMetadataRetriever.METADATA_KEY_VIDEO_HEIGHT));
            int rot = parse(r.extractMetadata(MediaMetadataRetriever.METADATA_KEY_VIDEO_ROTATION));
            if (rot == 90 || rot == 270) {
                int t = w;
                w = h;
                h = t;
            }
            long kbps = parse(r.extractMetadata(MediaMetadataRetriever.METADATA_KEY_BITRATE)) / 1000L;
            long dur = parse(r.extractMetadata(MediaMetadataRetriever.METADATA_KEY_DURATION));
            double fps = 30;
            if (android.os.Build.VERSION.SDK_INT >= 23) {
                String frames = r.extractMetadata(MediaMetadataRetriever.METADATA_KEY_CAPTURE_FRAMERATE);
                if (frames != null) {
                    try {
                        fps = Double.parseDouble(frames);
                    } catch (NumberFormatException ignored) {
                    }
                }
            }
            if (w <= 0 || h <= 0) return null;
            return new double[]{w, h, kbps, fps, dur};
        } catch (RuntimeException e) {
            return null;
        } finally {
            try {
                r.release();
            } catch (Exception ignored) {
            }
        }
    }

    private static int parse(String s) {
        if (s == null) return 0;
        try {
            return Integer.parseInt(s.trim());
        } catch (NumberFormatException e) {
            return 0;
        }
    }

    /** Whether any hardware or software encoder of the codec takes this size. */
    static boolean supports(String codec, int width, int height) {
        String mime = "hevc".equals(codec) ? MediaFormat.MIMETYPE_VIDEO_HEVC : MediaFormat.MIMETYPE_VIDEO_AVC;
        for (MediaCodecInfo info : new MediaCodecList(MediaCodecList.REGULAR_CODECS).getCodecInfos()) {
            if (!info.isEncoder()) continue;
            for (String t : info.getSupportedTypes()) {
                if (!t.equalsIgnoreCase(mime)) continue;
                MediaCodecInfo.VideoCapabilities v = info.getCapabilitiesForType(t).getVideoCapabilities();
                if (v != null && (v.isSizeSupported(width, height) || v.isSizeSupported(height, width))) return true;
            }
        }
        return false;
    }

    void start(Context c, File source, File output, int[] target, String codec, int frameRate, boolean keepAudio,
               int audioKbps, Listener l) {
        listener = l;
        int width = target[0], height = target[1], kbps = target[2];
        boolean hevc = "hevc".equals(codec);
        DefaultEncoderFactory encoders = new DefaultEncoderFactory.Builder(c.getApplicationContext())
                .setRequestedVideoEncoderSettings(new VideoEncoderSettings.Builder().setBitrate(kbps * 1000).build())
                .setRequestedAudioEncoderSettings(new AudioEncoderSettings.Builder().setBitrate(audioKbps * 1000).build())
                .build();
        transformer = new Transformer.Builder(c.getApplicationContext())
                .setVideoMimeType(hevc ? MimeTypes.VIDEO_H265 : MimeTypes.VIDEO_H264)
                .setAudioMimeType(MimeTypes.AUDIO_AAC)
                .setEncoderFactory(encoders)
                .addListener(new Transformer.Listener() {
                    @Override
                    public void onCompleted(Composition composition, ExportResult result) {
                        finish(l, null, width, height, result.durationMs);
                    }

                    @Override
                    public void onError(Composition composition, ExportResult result, ExportException e) {
                        output.delete();
                        finish(l, cancelled ? "cancelled" : reason(e), 0, 0, 0);
                    }
                })
                .build();
        ImmutableList.Builder<androidx.media3.common.Effect> video = ImmutableList.builder();
        if (frameRate > 0) video.add(FrameDropEffect.createDefaultFrameDropEffect(frameRate));
        video.add(Presentation.createForWidthAndHeight(width, height, Presentation.LAYOUT_SCALE_TO_FIT));
        EditedMediaItem item = new EditedMediaItem.Builder(MediaItem.fromUri(Uri.fromFile(source)))
                .setRemoveAudio(!keepAudio)
                .setEffects(new Effects(ImmutableList.of(), video.build()))
                .build();
        Composition composition = new Composition.Builder(new EditedMediaItemSequence.Builder(item).build())
                .setHdrMode(hevc ? Composition.HDR_MODE_KEEP_HDR : Composition.HDR_MODE_TONE_MAP_HDR_TO_SDR_USING_OPEN_GL)
                .build();
        transformer.start(composition, output.getAbsolutePath());
        poll(l);
    }

    private void poll(Listener l) {
        main.postDelayed(() -> {
            if (finished || transformer == null) return;
            ProgressHolder p = new ProgressHolder();
            if (transformer.getProgress(p) == Transformer.PROGRESS_STATE_AVAILABLE) l.progress(Math.min(0.99, p.progress / 100.0));
            poll(l);
        }, POLL_MS);
    }

    void cancel() {
        if (finished || transformer == null) return;
        cancelled = true;
        transformer.cancel();
        // Transformer.cancel() calls no listener: settle here.
        finish(null, "cancelled", 0, 0, 0);
    }

    private void finish(Listener l, String reason, int w, int h, long durationMs) {
        if (finished) return;
        finished = true;
        Listener to = l != null ? l : listener;
        if (to != null) to.done(reason, w, h, durationMs);
    }

    private static String reason(ExportException e) {
        int code = e.errorCode;
        if (code == ExportException.ERROR_CODE_ENCODER_INIT_FAILED || code == ExportException.ERROR_CODE_ENCODING_FORMAT_UNSUPPORTED) {
            return "not_supported_on_device";
        }
        if (code == ExportException.ERROR_CODE_DECODING_FORMAT_UNSUPPORTED || code == ExportException.ERROR_CODE_IO_FILE_NOT_FOUND) {
            return "unreadable";
        }
        return "encode_failed";
    }
}
```

```java android/mediapicker/java/despia/ext/mediapicker/UploadWorker.java
package despia.ext.mediapicker;

import android.content.Context;
import android.os.SystemClock;

import androidx.annotation.NonNull;
import androidx.work.Constraints;
import androidx.work.Data;
import androidx.work.ExistingWorkPolicy;
import androidx.work.NetworkType;
import androidx.work.OneTimeWorkRequest;
import androidx.work.Operation;
import androidx.work.WorkManager;
import androidx.work.Worker;
import androidx.work.WorkerParameters;

import com.despia.nativeext.ExtContext;

import org.json.JSONException;
import org.json.JSONObject;

import java.io.File;
import java.io.FileInputStream;
import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
import java.net.HttpURLConnection;
import java.net.MalformedURLException;
import java.net.URI;
import java.net.URISyntaxException;
import java.net.URL;
import java.nio.charset.StandardCharsets;
import java.util.Locale;
import java.util.UUID;
import java.util.concurrent.TimeUnit;

/**
 * Uploads one picked or transcoded file to the page's https URL; survives process death and reboot.
 *
 * <p>Design: WorkManager unique work per upload with REPLACE, a generation per enqueue and
 * a run claim in {@link MediaStore#claim}, the URL re-checked with {@link ExtContext#isApprovedUrl}
 * before every attempt and parsed by {@link #destination} only when the parse agrees with the
 * approved text, redirects never followed, 3xx and 4xx final, network errors and 5xx counted up to
 * {@link #MAX_ATTEMPTS} with WorkManager's exponential backoff (30 s base, the same as iOS), and a
 * stop by WorkManager rerun without counting. Delivery is at least once.
 *
 * <p>Platform limit (named, not hidden): WorkManager stops a run after its execution window
 * (10 minutes for a regular worker, developer.android.com/develop/background-work/background-tasks/
 * persistent/how-to/long-running, read 2026-11-20); the stopped run is retried from the first byte,
 * because a plain PUT or POST has no resumable protocol. A long-running foreground worker would lift
 * the window, but it needs WorkManager's own SystemForegroundService declared with a dataSync type,
 * and an extension can only declare components in its own package, so this worker stays a regular
 * one.
 */
public final class UploadWorker extends Worker {
    static final int MAX_ATTEMPTS = 5;
    static final int MAX_POLICY_WAITS = 10;
    static final int CONNECT_TIMEOUT_MS = 30_000;
    static final int READ_TIMEOUT_MS = 60_000;
    static final String TAG = "nx-mediapicker";
    static final String GEN_TAG = "nx-gen:";

    private volatile HttpURLConnection inFlight;

    public UploadWorker(@NonNull Context context, @NonNull WorkerParameters params) {
        super(context, params);
    }

    static String uniqueName(String id) {
        return "nx-mediapicker-" + id;
    }

    static Operation schedule(Context c, String id, String gen) {
        Data in = new Data.Builder().putString("id", id).putString("gen", gen).build();
        OneTimeWorkRequest.Builder b = new OneTimeWorkRequest.Builder(UploadWorker.class)
                .setInputData(in)
                .addTag(TAG)
                .addTag(GEN_TAG + gen)
                .setBackoffCriteria(androidx.work.BackoffPolicy.EXPONENTIAL, 30, TimeUnit.SECONDS)
                .setConstraints(new Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).build());
        return WorkManager.getInstance(c).enqueueUniqueWork(uniqueName(id), ExistingWorkPolicy.REPLACE, b.build());
    }

    static void cancel(Context c, String id) {
        WorkManager.getInstance(c).cancelUniqueWork(uniqueName(id));
    }

    @NonNull
    @Override
    public Result doWork() {
        Context c = getApplicationContext();
        String id = getInputData().getString("id");
        String gen = getInputData().getString("gen");
        if (id == null || gen == null) return Result.failure();
        String run = UUID.randomUUID().toString();
        JSONObject r;
        try {
            r = MediaStore.claim(c, id, gen, run);
        } catch (MediaStore.StorageException e) {
            return Result.retry();
        }
        if (r == null) return Result.failure();
        try {
            return upload(c, id, gen, run, r);
        } finally {
            MediaStore.release(id, run);
        }
    }

    @Override
    public void onStopped() {
        HttpURLConnection conn = inFlight;
        if (conn != null) conn.disconnect();
    }

    private Result upload(Context c, String id, String gen, String run, JSONObject r) {
        ExtContext policy = MediaPickerExtension.policy();
        if (policy == null) {
            if (getRunAttemptCount() < MAX_POLICY_WAITS) return Result.retry();
            return finish(c, id, gen, run, "failed", fields("reason", "policy_unavailable"), Result.failure());
        }
        String target = r.optString("url", "");
        URL url = policy.isApprovedUrl(target, r.optString("route", "upload"), "url") ? destination(target) : null;
        if (url == null) return finish(c, id, gen, run, "failed", fields("reason", "url_not_approved"), Result.failure());
        File f = new File(MediaStore.filesRoot(c), r.optString("path"));
        if (!f.isFile() || f.length() == 0) return finish(c, id, gen, run, "failed", fields("reason", "no_file"), Result.failure());
        if (isStopped()) return Result.retry();
        String field = r.optString("field", "");
        String[] framing = field.isEmpty() ? null
                : MediaCore.multipart("nx-" + UUID.randomUUID(), field, r.optString("name"), r.optString("contentType"));
        byte[] prefix = framing == null ? new byte[0] : framing[0].getBytes(StandardCharsets.UTF_8);
        byte[] suffix = framing == null ? new byte[0] : framing[1].getBytes(StandardCharsets.UTF_8);
        long total = prefix.length + f.length() + suffix.length;
        HttpURLConnection conn = null;
        try {
            conn = (HttpURLConnection) url.openConnection();
            inFlight = conn;
            if (isStopped()) return Result.retry();
            conn.setConnectTimeout(CONNECT_TIMEOUT_MS);
            conn.setReadTimeout(READ_TIMEOUT_MS);
            conn.setUseCaches(false);
            conn.setRequestMethod(r.optString("method", "PUT"));
            conn.setDoOutput(true);
            conn.setInstanceFollowRedirects(false);
            conn.setFixedLengthStreamingMode(total);
            if (framing == null) {
                conn.setRequestProperty("Content-Type", r.optString("contentType"));
            } else {
                String boundary = framing[1].substring(4, framing[1].length() - 4);
                conn.setRequestProperty("Content-Type", "multipart/form-data; boundary=" + boundary);
            }
            conn.setRequestProperty("X-Upload-Id", id);
            long sent = 0, lastReport = 0, lastAt = 0;
            try (InputStream in = new FileInputStream(f); OutputStream out = conn.getOutputStream()) {
                out.write(prefix);
                sent += prefix.length;
                byte[] buf = new byte[64 * 1024];
                int n;
                while ((n = in.read(buf)) > 0) {
                    out.write(buf, 0, n);
                    sent += n;
                    long now = SystemClock.uptimeMillis();
                    // Throttled: every 1% or half second, whichever comes later.
                    if (sent - lastReport >= total / 100 && now - lastAt >= 500) {
                        lastReport = sent;
                        lastAt = now;
                        setProgressAsync(new Data.Builder().putLong("sent", sent).putLong("total", total).build());
                        MediaPickerExtension.uploadProgress(id, sent, total);
                    }
                }
                out.write(suffix);
            }
            int code = conn.getResponseCode();
            JSONObject status = fields("httpStatus", code);
            String verdict = MediaCore.classify(code, false, code >= 300 && code < 400, false);
            if (verdict.equals("uploaded")) return finish(c, id, gen, run, "uploaded", put(status, "reason", JSONObject.NULL), Result.success());
            if (verdict.startsWith("failed:")) return finish(c, id, gen, run, "failed", put(status, "reason", verdict.substring(7)), Result.failure());
            return counted(c, id, gen, run, r, "http", code);
        } catch (IOException e) {
            if (isStopped()) return Result.retry();
            return counted(c, id, gen, run, r, "network", null);
        } finally {
            inFlight = null;
            if (conn != null) conn.disconnect();
        }
    }

    private Result counted(Context c, String id, String gen, String run, JSONObject r, String reason, Integer code) {
        int attempts = r.optInt("attempts", 0) + 1;
        JSONObject extra = put(fields("attempts", attempts), "httpStatus", code == null ? JSONObject.NULL : code);
        if (attempts < MAX_ATTEMPTS) return finish(c, id, gen, run, "uploading", put(extra, "reason", reason), Result.retry());
        return finish(c, id, gen, run, "failed", put(extra, "reason", reason), Result.failure());
    }

    private static Result finish(Context c, String id, String gen, String run, String state, JSONObject extra, Result saved) {
        JSONObject now;
        try {
            now = MediaStore.settle(c, id, gen, run, state, extra);
        } catch (MediaStore.StorageException e) {
            return Result.retry();
        }
        if (now == null) return Result.failure();
        MediaPickerExtension.uploadChanged(now);
        return saved;
    }

    /** Strict parse: the URL is used only when its parse agrees with the approved text. */
    static URL destination(String s) {
        if (!strictUrlText(s)) return null;
        try {
            URI u = new URI(s);
            if (!"https".equalsIgnoreCase(u.getScheme()) || u.getRawUserInfo() != null || u.getRawFragment() != null) return null;
            if (u.getPort() != -1 && u.getPort() != 443) return null;
            String host = u.getHost() == null ? null : u.getHost().toLowerCase(Locale.ROOT);
            if (host == null || host.isEmpty() || !host.matches("[a-z0-9.-]+")) return null;
            String lower = s.toLowerCase(Locale.ROOT);
            if (!lower.startsWith("https://" + host)) return null;
            String after = lower.substring(("https://" + host).length());
            if (!(after.isEmpty() || after.startsWith("/") || after.equals(":443") || after.startsWith(":443/"))) return null;
            return u.toURL();
        } catch (URISyntaxException | MalformedURLException | IllegalArgumentException e) {
            return null;
        }
    }

    private static final String URL_TEXT_CHARS =
            "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-._~:/?#[]@!$&'()*+,;=%";
    private static final String HEX_DIGITS = "0123456789ABCDEFabcdef";

    static boolean strictUrlText(String s) {
        if (s == null || s.isEmpty()) return false;
        for (int i = 0; i < s.length(); ) {
            char ch = s.charAt(i);
            if (ch > 0x7e || URL_TEXT_CHARS.indexOf(ch) < 0) return false;
            if (ch == '%') {
                if (i + 2 >= s.length() || HEX_DIGITS.indexOf(s.charAt(i + 1)) < 0 || HEX_DIGITS.indexOf(s.charAt(i + 2)) < 0) {
                    return false;
                }
                i += 3;
            } else {
                i++;
            }
        }
        return true;
    }

    static JSONObject fields(String k, Object v) {
        return put(new JSONObject(), k, v);
    }

    static JSONObject put(JSONObject o, String k, Object v) {
        try {
            o.put(k, v);
        } catch (JSONException ignored) {
        }
        return o;
    }
}
```

Every route answers at once, once. What happens later arrives as an event and stays readable through a route. A route answers in `mediaPicker<Route>` and `onMediaPicker<Route>`, for example `mediaPickerPick` and `onMediaPickerPick`.

### Routes

| Route       | Parameters | Answer `data` |
| ----------- | ---------- | ------------- |
| `pick`      | `types` (comma list of `image`, `video`, `audio`, `document`, `any` and MIME types such as `application/pdf` or `audio/*`), `source` (`auto`, `library`, `camera`, `files`), `multiple`, `limit` (0 for the platform's maximum, up to 500), `max_file_mb` and `max_total_mb` (0 to 4096), `representation` (`current`, `compatible`, `automatic`), `ordered`, `camera` (`photo`, `video`, `both`), `max_duration_s` (0 to 3600), `camera_quality` (`low`, `medium`, `high`), `accent_color` (`#RRGGBB`), `tab` (`photos`, `albums`) | `pickId`, `state` (`presenting`), `source`, `limit`, `limitLowered` |
| `result`    | `pick` (required) | The pick: `pickId`, `state` (`presenting`, `loading`, `done`, `cancelled` or `failed`), `source`, `files` |
| `files`     | `id` (optional) | One file, or `files` and `base`. A released file answers with `state: "released"` and no `url`. The list leaves released files out |
| `release`   | `id`, or `all: true` | `released`: the ids. Answers `busy` while a transcode or an upload still needs the file |
| `transcode` | `id` (required), `preset` (`480p`, `540p`, `720p`, `1080p`, `1440p`, `2160p`, `source`), `codec` (`h264`, `hevc`), `bitrate_kbps` (text, 100 to 400000; empty for the default for the size), `frame_rate` (a cap, up to 120), `audio` (`keep`, `remove`), `audio_bitrate_kbps` (32 to 320) | The job: `jobId`, `kind: "transcode"`, `state`, `outputFileId`, `width`, `height`, `bitrateKbps`, `codec`. `state` is `queued` behind a running transcode, or `transcoding` when it started at once |
| `upload`    | `id` (required), `url` (required, https, an approved host), `method` (`PUT`, `POST`), `form_field` (a multipart field; without it the body is the raw file), `content_type`, `release_after` | The job, with `state: "uploading"` |
| `jobs`      | `id` (optional) | One job, or `jobs`. Carries `indexUnread: true` while the upload index cannot be read yet |
| `cancel`    | `id` (required) | The job, now `cancelled`. A finished job is returned unchanged |

### The file object

`fileId`, `pickId`, `state`, `name`, `mime`, `kind`, `bytes`, `origin`, `url`, `width`, `height`, `durationMs`, `progress` and `reason`. `state` is `loading`, `ready`, `failed` or `released`. `url` exists only while `state` is `ready`. After release the old URL answers 404.

### Events

| Event    | Callback                     | Scope      | When                                                                 |
| -------- | ---------------------------- | ---------- | -------------------------------------------------------------------- |
| `pick`   | `onMediaPickerPickEvent`     | `document` | The state of a pick changed                                          |
| `file`   | `onMediaPickerFileEvent`     | `document` | A file is loading (with progress), ready (with its `url`), failed (with `reason`) or released |
| `job`    | `onMediaPickerJobEvent`      | `document` | Transcode and upload progress and outcome                            |
| `server` | `onMediaPickerServerEvent`   | `document` | `running` and `base`, when the local port changes. Rebuild URLs from `files` then |

### Reasons and error codes

- **File and transcode reasons:** `too_large`, `total_exceeded`, `limit_exceeded`, `import_failed`, `cancelled`, `not_supported_on_device`, `unreadable`, `encode_failed`, `no_video` and `background_expired` (iOS: the background time ran out).
- **Pick reasons:** `cancelled`, `capture_failed`, `activity_destroyed`, `permission_denied` (a camera chosen from the sheet was not allowed) and `camera_unavailable`.
- **Upload reasons:** `http`, `network`, `redirect_refused`, `url_not_approved`, `no_file` and `policy_unavailable`.
- **Route errors:** `bad_request`, `bad_value`, `not_found`, `busy`, `permission_denied`, `camera_unavailable`, `unavailable`, `timeout`, `release_failed`, `storage_failed` (the upload index could not be written, or on iOS exists but cannot be read yet, before the first unlock), `unreadable` and `not_supported_on_device`.

See also the [standard codes](/experiments/v3-extensions#error-codes).

## How files reach the page

A reply is a JavaScript string, so file bytes never belong in one. The extension serves each file from your own phone on `http://127.0.0.1:<port>/f/<token>/<name>`, straight from the file on disk.

- It answers `GET`, `HEAD` and `OPTIONS`, with single byte ranges, so a `<video>` can seek and `fetch(url).then(r => r.blob())` works from your https page. Files stream in 256 KiB chunks and are never held whole in memory.
- The URL is the access: it holds a random 256-bit token, and the token is withdrawn the moment the file is released. The server listens on the loopback interface only.
- Limits: a connection that sends no complete request in 10 seconds is closed, and at most 16 connections are open at once.

## Pickers

- **iOS.** `PHPickerViewController` for photos and videos (no photo library permission), the document picker for files and audio, `UIImagePickerController` for the camera, and for `source: "auto"` an action sheet. Nothing is restyled except the optional tint.
- **Android.** The system Photo Picker, `ACTION_OPEN_DOCUMENT` for documents, and the system camera app writing to a `CaptureProvider` URI that is not exported. `source: "auto"` shows a Material dialog list.

## Video tools

- **iOS.** AVAssetReader and AVAssetWriter: H.264 or HEVC, bitrate, a frame-rate cap and AAC audio. HDR is kept only for HEVC. Support is checked before a job is queued. A transcode keeps running for a while after the person leaves the app. When iOS ends that time, the job fails with `background_expired`.
- **Android.** Media3 Transformer inside a foreground service, with encoder support checked first.
- **Sizes.** The short side is the preset's or the source's, whichever is smaller. Video is never upscaled. The long side keeps the aspect ratio, and both are even.
- **Bitrates.** The default for H.264, in kbps: 2000 at 480p, 2500 at 540p, 5000 at 720p, 8000 at 1080p, 16000 at 1440p and 35000 above. HEVC uses 0.6 times that. Above 31 fps it is 1.5 times. It never goes above the source's own bitrate.

## Durable upload

- Redirects are never followed, and the URL is checked against the approved hosts again before each attempt.
- Retries are scheduled by the platform. On iOS, backoff is `30 * 2^(n-1)` seconds up to 15 minutes, 5 counted attempts, and a background processing task named `upload` finishes the job after the app was killed. On Android, WorkManager runs it.
- **Resume** means the upload continues after a kill or reboot, restarting the body from its first byte. A plain `PUT` or `POST` has no resumable protocol.
- The upload index is written before the route answers. A write that fails answers `storage_failed` and queues nothing. Finished records are kept 7 days.
- On iOS the index is protected until the first unlock. Until it can be read, nothing is pruned or written, and `upload` answers `storage_failed`. It is read again on unlock, on foreground and on each `upload` or `jobs` call.

## Clean-up

A file is deleted when the page releases it, when an upload with `release_after` finishes, or at the next launch. The exception is a file an unfinished upload still needs. It is listed again with a new URL token. Files are excluded from iCloud backup. Camera captures that were never picked up are deleted at launch.

## Platform limits

- **Android WorkManager.** A regular worker is stopped after 10 minutes, and the upload restarts from its first byte.
- **iOS.** A background session would follow redirects, so uploads run in the app's own session, plus the background processing task. iOS does not guarantee when it runs.
- **Android camera quality.** `EXTRA_VIDEO_QUALITY` takes only 0 or 1, so `medium` maps to 1.
- **Media3.** The sample uses the version your app's base build resolves (1.10.1).
