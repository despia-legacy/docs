This sample connects the phone to Meta glasses through Meta's Wearables Device Access Toolkit (DAT). Your page starts and stops the glasses' camera stream and shows it live. It can take a photo and record a short clip. A simulated pair of glasses (the Mock Device Kit) stands in for real glasses in debug builds.

The frames never cross the bridge. The extension serves them on a local address, and your page shows them in an `<img>`.

<Warning>
  **Experimental. V3 only.** This is a template, not a Despia feature. It is never migrated to V4. You own and maintain this code once it is in your app. Despia does not support customised code. Read [V3 Extensions](/experiments/v3-extensions) first.
</Warning>

<Note>
  **Tested on:** build only. The iOS and Android apps holding the sample were built with Meta DAT 1.0.1. The update to DAT 1.1.0, which this page ships, was checked by compiling the Swift and Java sources against the 1.1.0 SDK, and the 1.1.0 apps have not been built yet. It has not run against real glasses.
</Note>

## Files

Copy every file to the path in its title, keeping the bytes unchanged. Paths are under `public/despia/metaglasses/` in your web app, except `extensions.json`, which goes in `public/despia/`. `public/` is the folder your site serves from its root (in SvelteKit, write `static/`). Despia reviews and approves these exact files before a build includes them. The approval policy is a file you send to Despia with your approval request. It is not served from your site.

Before you build, set `client_id`, `ios_bundle_id` and `android_package` in `public/despia/extensions.json` to your own. If your app has other extensions, list `"metaglasses"` beside them.

## Your own values

- **URL scheme.** `nxglasses` appears three times in `manifest.json`: in `MWDAT.AppLinkURLScheme` (as `nxglasses://`), in iOS `claims.url_schemes` and in Android `claims.intent_schemes`. Replace all three with one scheme of your own. The Meta AI app returns to this scheme after registration and after the camera permission.
- **Meta app credentials.**
  - For Developer Mode, keep `MetaAppID` as `"0"`, `ClientToken` and `TeamID` empty, and turn on Developer Mode in Meta AI (Settings, then your glasses).
  - For production, set `MetaAppID` and `ClientToken` from your app in Meta's Wearables Developer Center, and set `TeamID` to your Apple Developer Team ID. The same two Meta values go into the Android values `com.meta.wearable.mwdat.APPLICATION_ID` and `CLIENT_TOKEN` in `android.meta_data` (`"0"` in the sample).
  - These values ship inside your app, and `manifest.json` is served from your own origin, so anyone can read them. They are not secrets. Never put a Meta server-side secret in this file or anywhere in your web app.
  - You sign up with Meta and accept its terms on Meta's site yourself.
- **Purpose strings.** Set `NSBluetoothAlwaysUsageDescription` and `NSLocalNetworkUsageDescription` with your other purpose strings in Despia.

```swift ios/app/GlassesCore.swift
import Foundation

/// Every decision of the Meta glasses extension that needs no system framework: the loopback HTTP
/// request rules, the byte-range rule, the response heads, the stream parameters and the session
/// and clip state machine. Foundation only, so the shared rules
/// run against this file with plain swiftc. The Java twin is
/// android/glasses/java/despia/ext/metaglasses/GlassesCore.java; both give the same answer for
/// every vector.
enum GlassesCore {
    /// Longest request head (request line and headers) the server reads before refusing.
    static let maxHead = 8192
    /// Longest request target accepted.
    static let maxTarget = 512
    /// The multipart boundary of the live stream.
    static let boundary = "nxframe"

    struct Request: Equatable {
        let method: String
        let path: String
        let range: String?
    }

    /// Parses a request head (everything before the blank line, CRLF line ends). nil for anything
    /// that is not a well-formed GET, HEAD or OPTIONS request with an origin-form target.
    static func parseRequest(_ head: String) -> Request? {
        guard head.utf16.count <= maxHead else { return nil }
        let lines = head.components(separatedBy: "\r\n")
        let parts = lines[0].components(separatedBy: " ")
        guard parts.count == 3 else { return nil }
        let method = parts[0]
        guard ["GET", "HEAD", "OPTIONS"].contains(method), ["HTTP/1.1", "HTTP/1.0"].contains(parts[2]) else { return nil }
        let target = parts[1]
        guard !target.isEmpty, target.utf16.count <= maxTarget, target.hasPrefix("/") else { return nil }
        guard target.unicodeScalars.allSatisfy({ $0.value > 0x20 && $0.value < 0x7f }) else { return nil }
        let path = target.firstIndex(of: "?").map { String(target[..<$0]) } ?? target
        var range: String?
        for line in lines.dropFirst() where !line.isEmpty {
            guard let colon = line.firstIndex(of: ":"), colon != line.startIndex else { return nil }
            let name = line[..<colon].trimmingCharacters(in: .whitespaces).lowercased()
            if name == "range" {
                if range != nil { return nil }
                range = line[line.index(after: colon)...].trimmingCharacters(in: .whitespaces)
            }
        }
        return Request(method: method, path: path, range: range)
    }

    struct Target: Equatable {
        /// live, frame, media, forbidden or not_found.
        let kind: String
        var id: String? = nil
        var ext: String? = nil
    }

    /// Classifies a path against the current stream token. The token is the first segment and is
    /// compared in constant time; a wrong or missing token is forbidden before anything else is
    /// looked at, so the path does not reveal which files exist.
    static func classify(_ path: String, token: String) -> Target {
        guard path.hasPrefix("/") else { return Target(kind: "not_found") }
        let body = path.dropFirst()
        let first = body.firstIndex(of: "/").map { String(body[..<$0]) } ?? String(body)
        guard isToken(token), constantTimeEquals(first, token) else { return Target(kind: "forbidden") }
        let rest = String(body.dropFirst(first.count))
        if rest == "/live.mjpg" { return Target(kind: "live") }
        if rest == "/frame.jpg" { return Target(kind: "frame") }
        if rest.hasPrefix("/media/") {
            let file = String(rest.dropFirst("/media/".count))
            if let dot = file.lastIndex(of: "."), dot != file.startIndex {
                let id = String(file[..<dot])
                let ext = String(file[file.index(after: dot)...])
                if isMediaId(id), ext == "jpg" || ext == "mp4" { return Target(kind: "media", id: id, ext: ext) }
            }
        }
        return Target(kind: "not_found")
    }

    /// A stream token: exactly 32 lower-case hex digits (128 bits).
    static func isToken(_ s: String) -> Bool {
        s.utf8.count == 32 && s.utf8.allSatisfy { ($0 >= 0x30 && $0 <= 0x39) || ($0 >= 0x61 && $0 <= 0x66) }
    }

    /// A media id: 1 to 32 characters of a-z and 0-9.
    static func isMediaId(_ s: String) -> Bool {
        !s.isEmpty && s.utf8.count <= 32 && s.utf8.allSatisfy { ($0 >= 0x30 && $0 <= 0x39) || ($0 >= 0x61 && $0 <= 0x7a) }
    }

    static func constantTimeEquals(_ a: String, _ b: String) -> Bool {
        let x = Array(a.utf8), y = Array(b.utf8)
        guard x.count == y.count else { return false }
        var diff: UInt8 = 0
        for i in 0..<x.count { diff |= x[i] ^ y[i] }
        return diff == 0
    }

    /// A new random token from the system's cryptographic generator.
    static func newToken() -> String {
        var rng = SystemRandomNumberGenerator()
        return (0..<16).map { _ in String(format: "%02x", UInt8.random(in: 0...255, using: &rng)) }.joined()
    }

    /// The byte range to send for a Range header and a file size: start and end inclusive, and
    /// partial true when the answer is 206 Partial Content with a Content-Range, false when it is
    /// 200 with the whole file. A nil header, one that is not a single satisfiable-form bytes
    /// range, or an empty file: the whole file ((0, total-1, false), or (0, -1, false) for an empty
    /// file); RFC 9110 section 14.2 lets a server ignore a Range it does not support. An
    /// unsatisfiable single range: nil (answer 416).
    static func range(_ header: String?, total: Int64) -> (Int64, Int64, Bool)? {
        let whole = (Int64(0), total - 1, false)
        guard let header, total > 0 else { return whole }
        let h = header.trimmingCharacters(in: .whitespaces)
        guard h.hasPrefix("bytes=") else { return whole }
        let spec = h.dropFirst(6).trimmingCharacters(in: .whitespaces)
        guard !spec.contains(","), let dash = spec.firstIndex(of: "-") else { return whole }
        let a = spec[..<dash].trimmingCharacters(in: .whitespaces)
        let b = spec[spec.index(after: dash)...].trimmingCharacters(in: .whitespaces)
        guard digits(a), digits(b), !(a.isEmpty && b.isEmpty) else { return whole }
        if a.isEmpty {
            let n = Int64(b)!
            if n == 0 { return nil }
            return (max(0, total - n), total - 1, true)
        }
        let start = Int64(a)!
        if start >= total { return nil }
        let end = b.isEmpty ? total - 1 : min(Int64(b)!, total - 1)
        if end < start { return whole }
        return (start, end, true)
    }

    private static func digits(_ s: String) -> Bool {
        s.utf8.count <= 18 && s.utf8.allSatisfy { $0 >= 0x30 && $0 <= 0x39 }
    }

    static func reason(_ status: Int) -> String {
        switch status {
        case 200: return "OK"
        case 204: return "No Content"
        case 206: return "Partial Content"
        case 400: return "Bad Request"
        case 403: return "Forbidden"
        case 404: return "Not Found"
        case 405: return "Method Not Allowed"
        case 416: return "Range Not Satisfiable"
        case 503: return "Service Unavailable"
        default: return "Error"
        }
    }

    /// A response head, byte for byte the same as the Java twin's. The page is on another origin
    /// (its own https site), so every answer allows any origin without credentials: the token in
    /// the path is the capability. Access-Control-Allow-Private-Network answers a Private Network
    /// Access preflight. Nothing is cached.
    static func responseHead(_ status: Int, contentType: String?, length: Int64, contentRange: String?) -> String {
        var s = "HTTP/1.1 \(status) \(reason(status))\r\n"
        if let contentType { s += "Content-Type: \(contentType)\r\n" }
        if length >= 0 { s += "Content-Length: \(length)\r\n" }
        if let contentRange { s += "Content-Range: \(contentRange)\r\n" }
        s += "Accept-Ranges: bytes\r\n"
        s += "Cache-Control: no-store\r\n"
        s += "Access-Control-Allow-Origin: *\r\n"
        s += "Access-Control-Allow-Methods: GET, HEAD, OPTIONS\r\n"
        s += "Access-Control-Allow-Headers: Range\r\n"
        s += "Access-Control-Allow-Private-Network: true\r\n"
        s += "Connection: close\r\n\r\n"
        return s
    }

    static func liveHead() -> String {
        responseHead(200, contentType: "multipart/x-mixed-replace; boundary=\(boundary)", length: -1, contentRange: nil)
    }

    static func partHead(_ length: Int) -> String {
        "--\(boundary)\r\nContent-Type: image/jpeg\r\nContent-Length: \(length)\r\n\r\n"
    }

    /// Frame rates DAT accepts (Meta, "Camera Streaming": 2, 7, 15, 24, 30).
    static let frameRates = [2, 7, 15, 24, 30]

    /// The accepted rate nearest to the asked one, ties to the lower; never a rate DAT refuses.
    static func frameRate(_ asked: Int) -> Int {
        var best = frameRates[0]
        for r in frameRates where abs(r - asked) < abs(best - asked) { best = r }
        return best
    }

    /// Frame size of a quality (Meta, "Camera Streaming"): width x height, portrait.
    static func frameSize(_ quality: String) -> (Int, Int) {
        switch quality {
        case "high": return (720, 1280)
        case "low": return (360, 640)
        default: return (504, 896)
        }
    }

    /// The stream's state machine, on the main actor. Each start gets a new generation; every SDK
    /// callback carries the generation it was made for, and a callback for any other generation
    /// changes nothing (counted in staleDrops). A clip is open only while the stream streams, and
    /// at most one at a time.
    struct Session {
        /// idle, starting, streaming, paused.
        var state = "idle"
        var gen: Int64 = 0
        var staleDrops = 0
        var clip: String?
        var clipGen: Int64 = 0

        /// A start: the new generation, or -1 when a stream already starts or runs.
        mutating func begin() -> Int64 {
            guard state == "idle" else { return -1 }
            gen += 1
            state = "starting"
            return gen
        }

        private mutating func current(_ g: Int64) -> Bool {
            if g != gen || state == "idle" {
                staleDrops += 1
                return false
            }
            return true
        }

        mutating func streaming(_ g: Int64) -> Bool {
            guard current(g) else { return false }
            let changed = state != "streaming"
            state = "streaming"
            return changed
        }

        mutating func paused(_ g: Int64) -> Bool {
            guard current(g) else { return false }
            let changed = state != "paused"
            state = "paused"
            return changed
        }

        /// The stream ended for generation g. The id of a clip to finish now, "" when none was
        /// open, nil for a stale call.
        mutating func ended(_ g: Int64) -> String? {
            guard current(g) else { return nil }
            return endAll()
        }

        /// An explicit stop: same result as ended, and later callbacks are stale.
        mutating func stop() -> String {
            if state == "idle" { return "" }
            return endAll()
        }

        private mutating func endAll() -> String {
            state = "idle"
            gen += 1
            let c = clip ?? ""
            clip = nil
            clipGen += 1
            return c
        }

        /// Open a clip: its generation, or -1 when the stream does not stream or a clip is open.
        mutating func clipBegin(_ id: String) -> Int64 {
            guard state == "streaming", clip == nil else { return -1 }
            clip = id
            clipGen += 1
            return clipGen
        }

        /// Close the clip of generation cg (record_stop or its time limit). The id, or nil.
        mutating func clipEnd(_ cg: Int64) -> String? {
            guard let c = clip, cg == clipGen else {
                staleDrops += 1
                return nil
            }
            clip = nil
            clipGen += 1
            return c
        }
    }
}
```

```swift ios/app/GlassesExtension.swift
#if NATIVE_EXT_ENABLED
import AVFoundation
import CoreBluetooth
import Foundation
import MWDATCamera
import MWDATCore
import MWDATMockDevice
import UIKit

/// Meta Ray-Ban glasses camera through Meta's Wearables Device Access Toolkit (DAT) 1.1.0.
///
/// The page starts and stops the glasses' camera stream and shows it from a loopback URL
/// (`GlassesServer`): `<img src=live>` is a multipart JPEG stream that always carries the newest
/// frame. Photos and short clips are saved in the extension's directory and served from the same
/// server, with byte ranges for `<video>`. Nothing starts at launch: the SDK is configured by the
/// first route call or by the Meta AI app's return URL, the stream by `start`.
///
/// DAT 1.1.0 needs iOS 17.2; the app's deployment target is lower, so every DAT type lives in
/// `GlassesController` (available from 17.2) and an older system answers `platform_limit`.
/// The SDK reads its app id and client token from the MWDAT Info.plist dictionary the customer's
/// project fills (TEMPLATE.md); this code reads none of them.
@MainActor
final class GlassesExtension: NativeExtension {
    private var context: NativeExtContext?
    private var controllerBox: AnyObject?

    init() {}

    func didLaunch(_ context: NativeExtContext) {
        self.context = context
    }

    func handle(_ call: NativeExtCall) async -> NativeExtResult {
        guard #available(iOS 17.2, *) else {
            return .error(code: "platform_limit", message: "Meta's glasses SDK needs iOS 17.2 or later")
        }
        guard let c = controller() else { return .error(code: "init_failed", message: "the extension has no context") }
        return await c.route(call)
    }

    /// The Meta AI app returns to the app's own scheme after registration and permission
    /// requests; only those URLs (with a metaWearablesAction query item) go to the SDK.
    func openURL(_ url: URL) -> Bool {
        guard #available(iOS 17.2, *), GlassesController.isWearablesURL(url), let c = controller() else { return false }
        c.handleURL(url)
        return true
    }

    @available(iOS 17.2, *)
    private func controller() -> GlassesController? {
        if let c = controllerBox as? GlassesController { return c }
        guard let context else { return nil }
        let c = GlassesController(context: context)
        controllerBox = c
        return c
    }
}

@available(iOS 17.2, *)
@MainActor
final class GlassesController {
    static let sdkVersion = "1.1.0"
    #if DEBUG
    static let mockAllowed = true
    #else
    static let mockAllowed = false
    #endif
    /// media_read returns the file in chunks of this many bytes (65536 characters of base64).
    static let mediaChunk = 49152

    private let context: NativeExtContext
    private let mediaDirectory: URL
    private var configured = false
    private var core = GlassesCore.Session()
    private let pipe = GlassesFramePipe()
    private let appTokens = ListenerTokenBag()

    private var server: GlassesServer?
    private var session: DeviceSession?
    private var camera: Camera?
    private var stream: MWDATCamera.Stream?
    private var streamTokens: ListenerTokenBag?
    private var streamSeenActive = false
    private var startError: NativeExtResult?
    private var quality = "medium"
    private var fps = 24

    private var photoBusy = false
    private var photoData: PhotoData?
    private var photoFailed = false
    private var clipTimer: Task<Void, Never>?

    private var mock = false
    private var mockGlasses: (any MockGlasses)?

    init(context: NativeExtContext) {
        self.context = context
        mediaDirectory = context.dataDirectory.appendingPathComponent("media", isDirectory: true)
        pipe.onClipProblem = { [weak self] reason in
            DispatchQueue.main.async { MainActor.assumeIsolated { self?.clipProblem(reason) } }
        }
    }

    nonisolated static func isWearablesURL(_ url: URL) -> Bool {
        URLComponents(url: url, resolvingAgainstBaseURL: false)?.queryItems?.contains { $0.name == "metaWearablesAction" } == true
    }

    func handleURL(_ url: URL) {
        guard configure() else { return }
        Task { @MainActor in
            do {
                _ = try await Wearables.shared.handleUrl(url)
            } catch {
                context.log("handleUrl failed: \(error.localizedDescription)")
            }
        }
    }

    func route(_ call: NativeExtCall) async -> NativeExtResult {
        guard configure() else { return .error(code: "init_failed", message: "the glasses SDK could not start") }
        switch call.route {
        case "status": return .ok(status())
        case "register": return await register(call, on: true)
        case "unregister": return await register(call, on: false)
        case "permission": return await permission(call)
        case "start": return await start(call)
        case "stop":
            teardown("stopped")
            return .ok(status())
        case "photo": return await photo(call)
        case "record_start": return recordStart(call)
        case "record_stop":
            guard core.clip != nil else { return .error(code: "not_recording", message: "no clip is recording") }
            return await stopClip(core.clipGen, reason: "stopped")
        case "frame": return frame()
        case "media": return .ok(["items": mediaList()])
        case "media_read": return mediaRead(call)
        case "media_delete": return mediaDelete(call)
        case "mock": return await mockRoute(call)
        default: return .error(code: "bad_request", message: "unknown route")
        }
    }

    // MARK: - SDK and state

    /// Wearables.configure on first use; never at launch.
    private func configure() -> Bool {
        if configured { return true }
        do {
            try Wearables.configure()
        } catch WearablesError.alreadyConfigured {
            // Configured elsewhere in the app: use it.
        } catch {
            context.log("Wearables.configure failed: \(error.localizedDescription)")
            return false
        }
        configured = true
        Wearables.shared.addRegistrationStateListener { [weak self] s in
            DispatchQueue.main.async {
                MainActor.assumeIsolated { self?.context.emit("registration", ["registration": Self.name(s)]) }
            }
        }.store(in: appTokens)
        return true
    }

    private static func name(_ s: RegistrationState) -> String {
        switch s {
        case .unavailable: return "unavailable"
        case .available: return "available"
        case .registering: return "registering"
        case .registered: return "registered"
        @unknown default: return "unavailable"
        }
    }

    /// The app's Bluetooth authorization. iOS asks the person itself the first time the SDK uses
    /// Bluetooth (NSBluetoothAlwaysUsageDescription); there is no separate request call.
    static func bluetooth() -> String {
        switch CBManager.authorization {
        case .allowedAlways: return "granted"
        case .notDetermined: return "unknown"
        default: return "denied"
        }
    }

    private func status() -> [String: Any] {
        let size = GlassesCore.frameSize(quality)
        let seen = pipe.stats()
        var o: [String: Any] = [
            "sdkVersion": Self.sdkVersion,
            "bluetooth": Self.bluetooth(),
            "registration": Self.name(Wearables.shared.registrationState),
            "devices": Wearables.shared.devices.count,
            "state": core.state, "quality": quality, "fps": fps,
            "width": seen.width > 0 ? seen.width : size.0, "height": seen.height > 0 ? seen.height : size.1,
            "frames": seen.frames, "staleDrops": core.staleDrops,
            "clip": core.clip ?? NSNull(), "photoBusy": photoBusy, "mock": mock,
        ]
        if let server {
            o["live"] = server.base + "/live.mjpg"
            o["frame"] = server.base + "/frame.jpg"
            o["mediaBase"] = server.base + "/media/"
        } else {
            o["live"] = NSNull()
            o["frame"] = NSNull()
            o["mediaBase"] = NSNull()
        }
        return o
    }

    private func emitState(_ reason: String) {
        var o = status()
        o["reason"] = reason
        context.emit("state", o)
    }

    private func register(_ call: NativeExtCall, on: Bool) async -> NativeExtResult {
        let s = Wearables.shared.registrationState
        do {
            if on && s != .registered { try await Wearables.shared.startRegistration() }
            if !on && s == .registered { try await Wearables.shared.startUnregistration() }
        } catch RegistrationError.metaAINotInstalled, UnregistrationError.metaAINotInstalled {
            return .error(code: "meta_ai_missing", message: "the Meta AI app is not installed")
        } catch RegistrationError.unauthorized {
            // DAT 1.1.0: thrown without opening Meta AI when the app may not register.
            return .error(code: "registration_unauthorized", message: "this app is not authorized to register with Meta Wearables")
        } catch RegistrationError.alreadyRegistered, UnregistrationError.alreadyUnregistered {
            // Already in the asked state.
        } catch {
            return .error(code: "registration_failed", message: error.localizedDescription)
        }
        // The outcome arrives as the registration event once the Meta AI app returns.
        return .ok(["registration": Self.name(Wearables.shared.registrationState)])
    }

    private func permission(_ call: NativeExtCall) async -> NativeExtResult {
        let prompt = call.params["prompt"] as? Bool ?? false
        guard Wearables.shared.registrationState == .registered else {
            // The camera permission belongs to a registered app; Meta AI cannot answer it before.
            return .ok(["bluetooth": Self.bluetooth(), "camera": "unknown"])
        }
        do {
            var status = try await Wearables.shared.checkPermissionStatus(.camera)
            if status != .granted && prompt {
                guard call.isActive else { return .error(code: "timeout", message: "the permission check took too long") }
                // Switches to the Meta AI app; returns once the person answered there.
                status = try await Wearables.shared.requestPermission(.camera)
            }
            return .ok(["bluetooth": Self.bluetooth(), "camera": status == .granted ? "granted" : "denied"])
        } catch {
            // DAT declares throws(PermissionError), so this is the only error kind.
            switch error {
            case .metaAINotInstalled: return .error(code: "meta_ai_missing", message: error.description)
            case .noDevice, .noDeviceWithConnection: return .error(code: "no_device", message: error.description)
            case .requestInProgress: return .error(code: "busy", message: error.description)
            case .requestTimeout: return .error(code: "timeout", message: error.description)
            default: return .error(code: "permission_failed", message: error.description)
            }
        }
    }

    // MARK: - Stream

    private func start(_ call: NativeExtCall) async -> NativeExtResult {
        guard Wearables.shared.registrationState == .registered else {
            return .error(code: "registration_required", message: "connect the app to Meta AI first (register)")
        }
        guard core.state == "idle" else { return .error(code: "busy", message: "the stream is already \(core.state)") }
        let wantQuality = call.params["quality"] as? String ?? "medium"
        let wantFps = GlassesCore.frameRate(call.params["fps"] as? Int ?? 24)
        if server == nil {
            do {
                try FileManager.default.createDirectory(at: mediaDirectory, withIntermediateDirectories: true)
                server = try GlassesServer(mediaDirectory: mediaDirectory)
            } catch {
                return .error(code: "server_failed", message: "the local stream server could not start")
            }
        }
        let s: DeviceSession
        do {
            s = try Wearables.shared.createSession(deviceSelector: AutoDeviceSelector(wearables: Wearables.shared))
        } catch {
            return Self.sessionError(error)
        }
        let g = core.begin()
        quality = wantQuality
        fps = wantFps
        session = s
        startError = nil
        streamSeenActive = false
        let bag = ListenerTokenBag()
        streamTokens = bag
        s.errorPublisher.listen { [weak self] e in
            DispatchQueue.main.async { MainActor.assumeIsolated { self?.failStartOrEnd(g, Self.sessionError(e), "session_error") } }
        }.store(in: bag)
        s.statePublisher.listen { [weak self] st in
            DispatchQueue.main.async { MainActor.assumeIsolated { self?.onSessionState(g, st) } }
        }.store(in: bag)
        emitState("starting")
        do {
            try s.start()
        } catch {
            teardown("start_failed")
            return Self.sessionError(error)
        }
        // A capability can be added only once the session reports started (Meta, "Camera Streaming").
        let started = await waitUntil(call) { [weak self] in self?.session?.state == .started || self?.core.gen != g }
        if let e = startFailure(g) { return e }
        guard started, call.isActive else {
            teardown("start_failed")
            return .error(code: "timeout", message: "the glasses did not connect in time")
        }
        let resolution: StreamingResolution = wantQuality == "high" ? .high : wantQuality == "low" ? .low : .medium
        let cam: Camera?
        do {
            // Decoded frames (.raw): the preview needs no decoder of its own.
            cam = try s.addCamera(config: StreamConfiguration(videoCodec: .raw, resolution: resolution, frameRate: UInt(wantFps)))
        } catch {
            teardown("start_failed")
            return Self.sessionError(error)
        }
        guard let cam else {
            teardown("start_failed")
            return .error(code: "stream_failed", message: "the glasses offered no camera")
        }
        camera = cam
        let st = cam.stream
        stream = st
        guard let server else { return .error(code: "server_failed", message: "the local stream server stopped") }
        pipe.begin(g, server: server)
        st.statePublisher.listen { [weak self] x in
            DispatchQueue.main.async { MainActor.assumeIsolated { self?.onStreamState(g, x) } }
        }.store(in: bag)
        st.errorPublisher.listen { [weak self] e in
            DispatchQueue.main.async { MainActor.assumeIsolated { self?.onStreamError(g, e) } }
        }.store(in: bag)
        st.photoDataPublisher.listen { [weak self] p in
            DispatchQueue.main.async { MainActor.assumeIsolated { self?.onPhoto(g, p) } }
        }.store(in: bag)
        st.videoFramePublisher.listen { [pipe] f in pipe.push(f, gen: g) }.store(in: bag)
        st.start()
        let streaming = await waitUntil(call) { [weak self] in self?.core.state == "streaming" || self?.core.gen != g }
        if let e = startFailure(g) { return e }
        guard streaming, call.isActive, core.gen == g else {
            if core.gen == g { teardown("start_failed") }
            return .error(code: "timeout", message: "the glasses did not start streaming in time")
        }
        return .ok(status())
    }

    private func startFailure(_ g: Int64) -> NativeExtResult? {
        guard core.gen != g || core.state == "idle" else { return nil }
        return startError ?? .error(code: "no_device", message: "the stream ended before it started")
    }

    /// Polls cond every 50 ms until it holds, the call ends or its deadline is 100 ms away.
    private func waitUntil(_ call: NativeExtCall, _ cond: () -> Bool) async -> Bool {
        while true {
            if cond() { return true }
            if !call.isActive || DispatchTime.now() + .milliseconds(100) >= call.deadline { return false }
            try? await Task.sleep(nanoseconds: 50_000_000)
        }
    }

    private func onSessionState(_ g: Int64, _ st: DeviceSessionState) {
        guard g == core.gen else { return }
        if st == .stopped && streamSeenActive { ended(g, "session_stopped") }
        if st == .stopped && !streamSeenActive && core.state == "starting" {
            failStartOrEnd(g, .error(code: "no_device", message: "the glasses session stopped before streaming"), "start_failed")
        }
    }

    private func onStreamState(_ g: Int64, _ st: StreamState) {
        switch st {
        case .waitingForDevice, .starting, .streaming, .paused:
            if g == core.gen { streamSeenActive = true }
        default:
            break
        }
        switch st {
        case .streaming:
            if core.streaming(g) { emitState("streaming") }
        case .paused:
            if core.paused(g) { emitState("paused") }
        case .stopped:
            if streamSeenActive && g == core.gen { ended(g, "stream_stopped") }
        default:
            break
        }
    }

    private func onStreamError(_ g: Int64, _ e: StreamError) {
        guard g == core.gen else { return }
        if e == .photoCaptureFailed {
            photoFailed = true
            return
        }
        failStartOrEnd(g, Self.streamError(e), "stream_error")
    }

    private func failStartOrEnd(_ g: Int64, _ error: NativeExtResult, _ reason: String) {
        guard g == core.gen else { return }
        if core.state == "starting" {
            startError = error
            teardown("start_failed")
        } else {
            ended(g, reason)
        }
    }

    /// The SDK ended generation g by itself.
    private func ended(_ g: Int64, _ reason: String) {
        guard let clip = core.ended(g) else { return }
        stopSDK()
        if !clip.isEmpty { Task { _ = await self.finishClip(clip, reason: reason) } }
        emitState(reason)
    }

    /// An explicit stop (route, failed start, mock off): later SDK callbacks are stale.
    private func teardown(_ reason: String) {
        let wasActive = core.state != "idle"
        let clip = core.stop()
        stopSDK()
        if !clip.isEmpty { Task { _ = await self.finishClip(clip, reason: reason) } }
        if wasActive { emitState(reason) }
    }

    private func stopSDK() {
        pipe.end()
        streamTokens?.clear()
        streamTokens = nil
        // camera.stop cascades to its stream; DeviceSession.stop to every capability.
        camera?.stop()
        session?.stop()
        camera = nil
        stream = nil
        session = nil
        server?.endLive()
    }

    // MARK: - Photo and clips

    private func onPhoto(_ g: Int64, _ p: PhotoData) {
        guard g == core.gen, photoBusy else { return }
        photoData = p
    }

    private func photo(_ call: NativeExtCall) async -> NativeExtResult {
        guard core.state == "streaming", let stream else { return .error(code: "not_streaming", message: "start the stream first") }
        guard !photoBusy else { return .error(code: "busy", message: "a photo is already being taken") }
        photoBusy = true
        photoData = nil
        photoFailed = false
        defer {
            photoBusy = false
            photoData = nil
        }
        // In-stream capture: false means no capture started, so no photo will arrive.
        guard stream.capturePhoto(format: .jpeg) else { return .error(code: "capture_failed", message: "the glasses did not start the capture") }
        let gen = core.gen
        let got = await waitUntil(call) { [weak self] in self?.photoData != nil || self?.photoFailed == true || self?.core.gen != gen }
        guard got, let p = photoData else {
            return .error(code: photoFailed ? "capture_failed" : "timeout", message: "no photo arrived from the glasses")
        }
        let id = Self.newId("p")
        let url = mediaDirectory.appendingPathComponent("\(id).jpg")
        let image = UIImage(data: p.data)
        let jpeg: Data? = p.format == .jpeg ? p.data : image?.jpegData(compressionQuality: GlassesMedia.photoQuality)
        guard let jpeg else { return .error(code: "capture_failed", message: "the photo could not be encoded") }
        do {
            try FileManager.default.createDirectory(at: mediaDirectory, withIntermediateDirectories: true)
            try GlassesMedia.write(jpeg, to: url)
        } catch {
            return .error(code: "capture_failed", message: "the photo could not be saved")
        }
        var m = mediaJSON(id, "jpg", url)
        m["width"] = Int(image?.size.width ?? 0) * Int(image?.scale ?? 1)
        m["height"] = Int(image?.size.height ?? 0) * Int(image?.scale ?? 1)
        context.emit("media", m)
        return .ok(m)
    }

    private func recordStart(_ call: NativeExtCall) -> NativeExtResult {
        let seconds = call.params["seconds"] as? Int ?? 10
        let id = Self.newId("c")
        let cg = core.clipBegin(id)
        guard cg >= 0, let server else {
            return core.clip != nil ? .error(code: "busy", message: "a clip is already recording")
                : .error(code: "not_streaming", message: "start the stream first")
        }
        try? FileManager.default.createDirectory(at: mediaDirectory, withIntermediateDirectories: true)
        // Written as .mp4.part and moved when finished, so the server never serves half a file.
        let part = mediaDirectory.appendingPathComponent("\(id).mp4.part")
        try? FileManager.default.removeItem(at: part)
        pipe.setClip(GlassesClipWriter(url: part, fps: fps))
        clipTimer?.cancel()
        clipTimer = Task { [weak self] in
            try? await Task.sleep(nanoseconds: UInt64(seconds) * 1_000_000_000)
            guard !Task.isCancelled else { return }
            _ = await self?.stopClip(cg, reason: "limit")
        }
        return .ok(["id": id, "kind": "mp4", "seconds": seconds, "url": server.base + "/media/\(id).mp4"])
    }

    /// The frame queue saw the clip end on its own (size change, writer failure).
    private func clipProblem(_ reason: String) {
        guard core.clip != nil else { return }
        let cg = core.clipGen
        Task { _ = await self.stopClip(cg, reason: reason) }
    }

    private func stopClip(_ cg: Int64, reason: String) async -> NativeExtResult {
        guard let id = core.clipEnd(cg) else { return .error(code: "not_recording", message: "no clip is recording") }
        return await finishClip(id, reason: reason)
    }

    private func finishClip(_ id: String, reason: String) async -> NativeExtResult {
        clipTimer?.cancel()
        clipTimer = nil
        let writer = pipe.takeClip()
        let ok: Bool
        if let writer {
            ok = await withCheckedContinuation { (c: CheckedContinuation<Bool, Never>) in writer.finish { c.resume(returning: $0) } }
        } else {
            ok = false
        }
        let part = mediaDirectory.appendingPathComponent("\(id).mp4.part")
        let url = mediaDirectory.appendingPathComponent("\(id).mp4")
        if ok, (try? FileManager.default.moveItem(at: part, to: url)) != nil {
            var m = mediaJSON(id, "mp4", url)
            m["durationMs"] = writer?.durationMs ?? 0
            m["reason"] = reason
            context.emit("media", m)
            return .ok(m)
        }
        try? FileManager.default.removeItem(at: part)
        context.emit("media", ["id": id, "kind": "mp4", "failed": true, "reason": reason])
        return .error(code: "record_failed", message: "the clip has no frames or could not be written")
    }

    // MARK: - Frames and media files

    /// The newest frame as base64 JPEG, for pages that cannot load the loopback URL. The page
    /// compares seq with the last one it drew; polling faster than the stream's rate returns the
    /// same frame again.
    private func frame() -> NativeExtResult {
        let (seq, jpeg) = server?.latest() ?? (0, nil)
        let seen = pipe.stats()
        return .ok(["seq": seq, "width": seen.width, "height": seen.height,
                    "jpeg": jpeg?.base64EncodedString() ?? NSNull()])
    }

    private func mediaJSON(_ id: String, _ kind: String, _ url: URL) -> [String: Any] {
        let bytes = ((try? FileManager.default.attributesOfItem(atPath: url.path))?[.size] as? NSNumber)?.int64Value ?? 0
        return ["id": id, "kind": kind, "bytes": bytes,
                "url": server.map { $0.base + "/media/\(id).\(kind)" } ?? NSNull()]
    }

    private func mediaList() -> [[String: Any]] {
        let names = (try? FileManager.default.contentsOfDirectory(atPath: mediaDirectory.path)) ?? []
        return names.sorted().compactMap { n in
            guard let dot = n.lastIndex(of: "."), dot != n.startIndex else { return nil }
            let id = String(n[..<dot])
            let kind = String(n[n.index(after: dot)...])
            guard GlassesCore.isMediaId(id), kind == "jpg" || kind == "mp4", id != core.clip else { return nil }
            return mediaJSON(id, kind, mediaDirectory.appendingPathComponent(n))
        }
    }

    private func mediaFile(_ call: NativeExtCall) -> URL? {
        guard let id = call.params["id"] as? String, GlassesCore.isMediaId(id), id != core.clip,
              let kind = call.params["kind"] as? String else { return nil }
        let url = mediaDirectory.appendingPathComponent("\(id).\(kind)")
        var dir: ObjCBool = false
        return FileManager.default.fileExists(atPath: url.path, isDirectory: &dir) && !dir.boolValue ? url : nil
    }

    private func mediaRead(_ call: NativeExtCall) -> NativeExtResult {
        guard let url = mediaFile(call), let h = try? FileHandle(forReadingFrom: url) else {
            return .error(code: "not_found", message: "no such photo or clip")
        }
        defer { try? h.close() }
        let chunk = Int64(call.params["chunk"] as? Int ?? 0)
        let offset = chunk * Int64(Self.mediaChunk)
        let length = Self.mediaChunk
        let total = Int64((try? h.seekToEnd()) ?? 0)
        let data: Data
        do {
            try h.seek(toOffset: UInt64(min(offset, total)))
            data = try h.read(upToCount: Int(max(0, min(Int64(length), total - offset)))) ?? Data()
        } catch {
            return .error(code: "not_found", message: "the file could not be read")
        }
        return .ok(["id": call.params["id"] ?? "", "kind": call.params["kind"] ?? "", "chunk": chunk, "offset": offset,
                    "length": data.count, "total": total, "eof": offset + Int64(data.count) >= total,
                    "data": data.base64EncodedString()])
    }

    private func mediaDelete(_ call: NativeExtCall) -> NativeExtResult {
        guard let url = mediaFile(call), (try? FileManager.default.removeItem(at: url)) != nil else {
            return .error(code: "not_found", message: "no such photo or clip")
        }
        return .ok(["id": call.params["id"] ?? "", "kind": call.params["kind"] ?? "", "deleted": true])
    }

    // MARK: - Mock Device Kit

    /// Meta's Mock Device Kit: fake registration, a paired Ray-Ban Meta mock and a synthesized
    /// test feed (red left, blue right, moving white bar), so the simulator streams without glasses.
    private func mockRoute(_ call: NativeExtCall) async -> NativeExtResult {
        let on = call.params["enabled"] as? Bool ?? false
        let kit = MockDeviceKit.shared
        if !on {
            teardown("mock_off")
            if let g = mockGlasses { await kit.unpairDevice(g) }
            mockGlasses = nil
            await kit.disable()
            mock = false
            return .ok(status())
        }
        // Simulated glasses never run in a release build: a shipped app reports only real devices.
        guard Self.mockAllowed else { return .error(code: "mock_unavailable", message: "the mock glasses run in debug builds only") }
        if mock { return .ok(status()) }
        let dir = context.dataDirectory.appendingPathComponent("mock", isDirectory: true)
        let feed = dir.appendingPathComponent("feed.mp4")
        let photo = dir.appendingPathComponent("photo.jpg")
        let made: Result<String, Error> = await Task.detached {
            do {
                try FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
                let codec = try GlassesMedia.writeMockFeed(to: feed)
                guard let p = GlassesMedia.mockPhoto() else { throw CocoaError(.fileWriteUnknown) }
                try GlassesMedia.write(p, to: photo)
                return .success(codec)
            } catch {
                return .failure(error)
            }
        }.value
        guard case .success(let codec) = made else { return .error(code: "mock_failed", message: "the mock media could not be written") }
        guard call.isActive else { return .error(code: "timeout", message: "the mock media took too long") }
        kit.enable(config: MockDeviceKitConfig(initiallyRegistered: true, initialPermissionsGranted: true))
        do {
            let g = try kit.pairGlasses(model: .rayBanMeta)
            g.powerOn()
            g.unfold()
            g.don()
            g.services.camera.setCameraFeed(fileURL: feed)
            g.services.camera.setCapturedImage(fileURL: photo)
            mockGlasses = g
        } catch {
            await kit.disable()
            return .error(code: "mock_failed", message: error.localizedDescription)
        }
        mock = true
        var o = status()
        o["mockFeedCodec"] = codec
        return .ok(o)
    }

    // MARK: - Helpers

    private static func newId(_ prefix: String) -> String {
        let ms = UInt64(Date().timeIntervalSince1970 * 1000)
        return prefix + String(ms, radix: 36) + String(format: "%04x", UInt16.random(in: 0...UInt16.max))
    }

    nonisolated private static func sessionError(_ error: Error) -> NativeExtResult {
        guard let e = error as? DeviceSessionError else { return .error(code: "session_failed", message: error.localizedDescription) }
        switch e {
        case .noEligibleDevice: return .error(code: "no_device", message: e.localizedDescription)
        case .notRegistered: return .error(code: "registration_required", message: e.localizedDescription)
        case .sessionAlreadyExists, .capabilityAlreadyActive: return .error(code: "busy", message: e.localizedDescription)
        case .thermalCritical, .thermalEmergency, .peakPowerShutdown, .batteryCritical:
            return .error(code: "device_limit", message: e.localizedDescription)
        default: return .error(code: "session_failed", message: e.localizedDescription)
        }
    }

    nonisolated private static func streamError(_ e: StreamError) -> NativeExtResult {
        switch e {
        case .permissionDenied: return .error(code: "permission_denied", message: e.localizedDescription)
        case .deviceNotFound, .deviceNotConnected: return .error(code: "no_device", message: e.localizedDescription)
        case .hingesClosed: return .error(code: "glasses_folded", message: e.localizedDescription)
        case .thermalHot, .batteryLow, .peakPowerLimit: return .error(code: "device_limit", message: e.localizedDescription)
        case .timeout: return .error(code: "timeout", message: e.localizedDescription)
        default: return .error(code: "stream_failed", message: e.localizedDescription)
        }
    }
}

/// Moves frames off the SDK's thread. The newest frame wins for the preview (a frame still
/// waiting is replaced, so the page never lags); every frame goes to an open clip.
final class GlassesFramePipe: @unchecked Sendable {
    private let queue = DispatchQueue(label: "nx.glasses.frames", qos: .userInitiated)
    private let lock = NSLock()
    private var gen: Int64 = 0
    private var pending: VideoFrame?
    private var scheduled = false
    private var server: GlassesServer?
    private var clip: GlassesClipWriter?
    private var clipReported = false
    private var width = 0
    private var height = 0
    private var frames: Int64 = 0
    var onClipProblem: (@Sendable (String) -> Void)?

    func begin(_ g: Int64, server: GlassesServer) {
        lock.lock()
        gen = g
        self.server = server
        width = 0
        height = 0
        lock.unlock()
    }

    func end() {
        lock.lock()
        gen = 0
        pending = nil
        lock.unlock()
    }

    func stats() -> (width: Int, height: Int, frames: Int64) {
        lock.lock()
        defer { lock.unlock() }
        return (width, height, frames)
    }

    func setClip(_ writer: GlassesClipWriter) {
        lock.lock()
        clip = writer
        clipReported = false
        lock.unlock()
    }

    func takeClip() -> GlassesClipWriter? {
        lock.lock()
        defer { lock.unlock() }
        let c = clip
        clip = nil
        return c
    }

    /// On the SDK's frame thread.
    func push(_ f: VideoFrame, gen g: Int64) {
        lock.lock()
        guard g == gen else {
            lock.unlock()
            return
        }
        if let clip {
            clip.append(f.sampleBuffer)
            if (clip.sizeChanged || clip.failed) && !clipReported {
                clipReported = true
                onClipProblem?(clip.sizeChanged ? "resolution_changed" : "writer_failed")
            }
        }
        pending = f
        let go = !scheduled
        scheduled = true
        lock.unlock()
        if go { queue.async { self.drain() } }
    }

    private func drain() {
        while true {
            lock.lock()
            guard let f = pending, gen != 0 else {
                pending = nil
                scheduled = false
                lock.unlock()
                return
            }
            pending = nil
            let s = server
            let g = gen
            lock.unlock()
            guard let image = f.makeUIImage(), let jpeg = image.jpegData(compressionQuality: GlassesMedia.previewQuality) else { continue }
            lock.lock()
            let current = g == gen
            if current {
                width = Int(image.size.width * image.scale)
                height = Int(image.size.height * image.scale)
                frames += 1
            }
            lock.unlock()
            if current { s?.publish(jpeg) }
        }
    }
}
```

```swift ios/app/GlassesMedia.swift
        ctx.setFillColor(UIColor.blue.cgColor)

            return "h264"

        try? FileManager.default.removeItem(at: url)

        let input = AVAssetWriterInput(mediaType: .video, outputSettings: [
            AVVideoCodecKey: codec, AVVideoWidthKey: mockWidth, AVVideoHeightKey: mockHeight,

        input.expectsMediaDataInRealTime = false
        let adaptor = AVAssetWriterInputPixelBufferAdaptor(assetWriterInput: input, sourcePixelBufferAttributes: [
            kCVPixelBufferPixelFormatTypeKey as String: kCVPixelFormatType_32BGRA,
            kCVPixelBufferWidthKey as String: mockWidth, kCVPixelBufferHeightKey as String: mockHeight,

            guard let pool = adaptor.pixelBufferPool else { throw writer.error ?? feedError("no pixel buffer pool") }

/// An H.264 MP4 clip of the stream's decoded frames. The size is taken from the first frame; DAT
/// may lower the resolution when Bluetooth bandwidth drops (Meta, "Camera Streaming"), and a
/// frame of another size ends the clip (`sizeChanged`). Confined to the frame queue.
final class GlassesClipWriter {
    let url: URL
    private let fps: Int
    private var writer: AVAssetWriter?
    private var input: AVAssetWriterInput?
    private var adaptor: AVAssetWriterInputPixelBufferAdaptor?
    private var width = 0
    private var height = 0
    private var first: CMTime?
    private var last: CMTime = .zero
    private(set) var frames = 0
    private(set) var sizeChanged = false
    private(set) var failed = false
    private var finished = false

    init(url: URL, fps: Int) {
        self.url = url
        self.fps = fps
    }

    /// Appends one decoded frame. False when it was not taken.
    @discardableResult
    func append(_ sample: CMSampleBuffer) -> Bool {
        guard !finished, !failed, let pixels = CMSampleBufferGetImageBuffer(sample) else { return false }
        let w = CVPixelBufferGetWidth(pixels)
        let h = CVPixelBufferGetHeight(pixels)
        if writer == nil && !open(width: w, height: h) { return false }
        guard w == width, h == height else {
            sizeChanged = true
            return false
        }
        guard let input, let adaptor, input.isReadyForMoreMediaData else { return false }
        let pts = CMSampleBufferGetPresentationTimeStamp(sample)
        if first == nil {
            first = pts
            writer?.startSession(atSourceTime: pts)
        }
        guard pts > last || frames == 0 else { return false }
        if adaptor.append(pixels, withPresentationTime: pts) {
            last = pts
            frames += 1
            return true
        }
        failed = true
        return false
    }

    private func open(width w: Int, height h: Int) -> Bool {
        width = w
        height = h
        guard let writer = try? AVAssetWriter(outputURL: url, fileType: .mp4) else {
            failed = true
            return false
        }
        let input = AVAssetWriterInput(mediaType: .video, outputSettings: [
            AVVideoCodecKey: AVVideoCodecType.h264, AVVideoWidthKey: w, AVVideoHeightKey: h,
            AVVideoCompressionPropertiesKey: [AVVideoAverageBitRateKey: max(1_000_000, w * h * 4),
                                              AVVideoExpectedSourceFrameRateKey: fps,
                                              AVVideoMaxKeyFrameIntervalKey: fps],
        ])
        input.expectsMediaDataInRealTime = true
        guard writer.canAdd(input) else {
            failed = true
            return false
        }
        writer.add(input)
        guard writer.startWriting() else {
            failed = true
            return false
        }
        self.writer = writer
        self.input = input
        adaptor = AVAssetWriterInputPixelBufferAdaptor(assetWriterInput: input, sourcePixelBufferAttributes: nil)
        return true
    }

    var durationMs: Int {
        guard let first, frames > 0 else { return 0 }
        return Int(((last - first).seconds * 1000).rounded()) + 1000 / max(1, fps)
    }

    /// Ends the clip. The handler gets true when the MP4 holds at least one frame.
    func finish(_ done: @escaping (Bool) -> Void) {
        guard !finished else { return done(false) }
        finished = true
        guard let writer, let input, frames > 0, !failed else {
            writer?.cancelWriting()
            return done(false)
        }
        input.markAsFinished()
        writer.endSession(atSourceTime: last + CMTime(value: 1, timescale: CMTimeScale(max(1, fps))))
        writer.finishWriting { done(writer.status == .completed) }
    }
}
```

```swift ios/app/GlassesServer.swift
#if NATIVE_EXT_ENABLED
import Foundation
import Network

/// The page's view of the glasses camera: a small HTTP/1.1 server on 127.0.0.1, on a port the
/// system picks. Every path starts with a fresh 128-bit token, so only the page that got the URL
/// from a route can read it.
///
/// - `/<token>/live.mjpg`: multipart/x-mixed-replace of JPEG frames for an `<img>`. Each
///   connection is sent the newest frame only, and only after its previous frame was written, so a
///   slow reader skips frames and the picture never lags.
/// - `/<token>/frame.jpg`: the newest frame once (503 before the first one).
/// - `/<token>/media/<id>.jpg|mp4`: a saved photo or clip, with byte ranges for `<video>`.
///
/// Request parsing, the token check, ranges and every response head are `GlassesCore`, shared
/// byte for byte with the Android twin and run against the vector table. Everything runs on the
/// server's own serial queue.
final class GlassesServer: @unchecked Sendable {
    static let maxConnections = 8
    private static let chunk = 64 * 1024

    let token = GlassesCore.newToken()
    private let mediaDirectory: URL
    private let queue = DispatchQueue(label: "nx.glasses.http")
    private let listener: NWListener
    private var connections: [ObjectIdentifier: NWConnection] = [:]
    private var live: [ObjectIdentifier: LiveClient] = [:]
    private var frame: Data?
    private var seq: Int64 = 0
    private(set) var port: UInt16 = 0

    private final class LiveClient {
        let connection: NWConnection
        var sending = false
        var sent: Int64

        init(_ connection: NWConnection, sent: Int64) {
            self.connection = connection
            self.sent = sent
        }
    }

    /// Binds 127.0.0.1 on an ephemeral port and waits (at most 3 s) until it listens.
    init(mediaDirectory: URL) throws {
        self.mediaDirectory = mediaDirectory
        let params = NWParameters.tcp
        params.requiredLocalEndpoint = NWEndpoint.hostPort(host: .ipv4(.loopback), port: .any)
        params.allowLocalEndpointReuse = true
        listener = try NWListener(using: params)
        let ready = DispatchSemaphore(value: 0)
        var failed = false
        listener.stateUpdateHandler = { [weak self] state in
            switch state {
            case .ready:
                self?.port = self?.listener.port?.rawValue ?? 0
                ready.signal()
            case .failed, .cancelled:
                failed = true
                ready.signal()
            default:
                break
            }
        }
        listener.newConnectionHandler = { [weak self] c in self?.accept(c) }
        listener.start(queue: queue)
        if ready.wait(timeout: .now() + 3) == .timedOut || failed || port == 0 {
            listener.cancel()
            throw NSError(domain: "GlassesServer", code: 1, userInfo: [NSLocalizedDescriptionKey: "the loopback listener did not start"])
        }
    }

    /// http://127.0.0.1:<port>/<token>
    var base: String { "http://127.0.0.1:\(port)/\(token)" }

    /// Makes jpeg the newest frame. Any thread.
    func publish(_ jpeg: Data) {
        queue.async {
            self.frame = jpeg
            self.seq += 1
            for client in self.live.values { self.pump(client) }
        }
    }

    /// The newest frame and its sequence number.
    func latest() -> (Int64, Data?) {
        queue.sync { (seq, frame) }
    }

    /// Ends every live connection (the stream stopped) and forgets the last frame.
    func endLive() {
        queue.async {
            self.frame = nil
            for client in self.live.values { client.connection.cancel() }
            self.live.removeAll()
        }
    }

    func close() {
        queue.async {
            self.listener.cancel()
            for c in self.connections.values { c.cancel() }
            self.connections.removeAll()
            self.live.removeAll()
            self.frame = nil
        }
    }

    // MARK: - Connections (server queue)

    private func accept(_ c: NWConnection) {
        let id = ObjectIdentifier(c)
        guard connections.count < Self.maxConnections else {
            c.start(queue: queue)
            send(c, Data(GlassesCore.responseHead(503, contentType: nil, length: 0, contentRange: nil).utf8), close: true)
            return
        }
        connections[id] = c
        c.stateUpdateHandler = { [weak self] state in
            switch state {
            case .failed, .cancelled:
                self?.connections[id] = nil
                self?.live[id] = nil
            default:
                break
            }
        }
        c.start(queue: queue)
        readHead(c, Data())
    }

    private func readHead(_ c: NWConnection, _ buffer: Data) {
        c.receive(minimumIncompleteLength: 1, maximumLength: 4096) { [weak self] data, _, done, error in
            guard let self else { return }
            var buf = buffer
            if let data { buf.append(data) }
            if let end = buf.range(of: Data("\r\n\r\n".utf8)) {
                let head = String(decoding: buf[buf.startIndex..<end.lowerBound], as: UTF8.self)
                self.respond(c, head: head)
            } else if buf.count > GlassesCore.maxHead + 4 || done || error != nil {
                self.send(c, Data(GlassesCore.responseHead(400, contentType: nil, length: 0, contentRange: nil).utf8), close: true)
            } else {
                self.readHead(c, buf)
            }
        }
    }

    private func head(_ status: Int, _ type: String? = nil, _ length: Int64 = 0, _ range: String? = nil) -> Data {
        Data(GlassesCore.responseHead(status, contentType: type, length: length, contentRange: range).utf8)
    }

    private func respond(_ c: NWConnection, head text: String) {
        guard let req = GlassesCore.parseRequest(text) else { return send(c, head(400), close: true) }
        if req.method == "OPTIONS" { return send(c, head(204, nil, -1), close: true) }
        let body = req.method == "GET"
        let target = GlassesCore.classify(req.path, token: token)
        switch target.kind {
        case "live":
            send(c, Data(GlassesCore.liveHead().utf8), close: !body)
            guard body else { return }
            let client = LiveClient(c, sent: frame == nil ? seq : seq - 1)
            live[ObjectIdentifier(c)] = client
            pump(client)
        case "frame":
            guard let f = frame else { return send(c, head(503), close: true) }
            var out = head(200, "image/jpeg", Int64(f.count))
            if body { out.append(f) }
            send(c, out, close: true)
        case "media":
            media(c, target, range: req.range, body: body)
        case "forbidden":
            send(c, head(403), close: true)
        default:
            send(c, head(404), close: true)
        }
    }

    /// Sends the newest frame to a live client that is not mid-send and has not had it yet.
    private func pump(_ client: LiveClient) {
        guard !client.sending, let f = frame, seq != client.sent else { return }
        client.sending = true
        client.sent = seq
        var part = Data(GlassesCore.partHead(f.count).utf8)
        part.append(f)
        part.append(Data("\r\n".utf8))
        client.connection.send(content: part, completion: .contentProcessed { [weak self] error in
            guard let self else { return }
            client.sending = false
            if error != nil {
                client.connection.cancel()
                self.live[ObjectIdentifier(client.connection)] = nil
                return
            }
            self.pump(client)
        })
    }

    private func media(_ c: NWConnection, _ t: GlassesCore.Target, range header: String?, body: Bool) {
        guard let id = t.id, let ext = t.ext else { return send(c, head(404), close: true) }
        let url = mediaDirectory.appendingPathComponent("\(id).\(ext)")
        guard let attrs = try? FileManager.default.attributesOfItem(atPath: url.path),
              (attrs[.type] as? FileAttributeType) == .typeRegular,
              let size = (attrs[.size] as? NSNumber)?.int64Value,
              let handle = try? FileHandle(forReadingFrom: url) else { return send(c, head(404), close: true) }
        guard let r = GlassesCore.range(header, total: size) else {
            try? handle.close()
            return send(c, head(416, nil, 0, "bytes */\(size)"), close: true)
        }
        let type = ext == "mp4" ? "video/mp4" : "image/jpeg"
        let length = r.1 - r.0 + 1
        let h = head(r.2 ? 206 : 200, type, length, r.2 ? "bytes \(r.0)-\(r.1)/\(size)" : nil)
        guard body, length > 0 else {
            try? handle.close()
            return send(c, h, close: true)
        }
        do {
            try handle.seek(toOffset: UInt64(r.0))
        } catch {
            try? handle.close()
            return send(c, head(404), close: true)
        }
        c.send(content: h, completion: .contentProcessed { [weak self] _ in
            self?.stream(c, handle, left: length)
        })
    }

    private func stream(_ c: NWConnection, _ handle: FileHandle, left: Int64) {
        guard left > 0, let data = try? handle.read(upToCount: Int(min(Int64(Self.chunk), left))), !data.isEmpty else {
            try? handle.close()
            return send(c, Data(), close: true)
        }
        c.send(content: data, completion: .contentProcessed { [weak self] error in
            if error != nil {
                try? handle.close()
                c.cancel()
                return
            }
            self?.stream(c, handle, left: left - Int64(data.count))
        })
    }

    private func send(_ c: NWConnection, _ data: Data, close: Bool) {
        c.send(content: data, isComplete: close, completion: .contentProcessed { _ in
            if close { c.cancel() }
        })
    }
}
```

```java android/glasses/java/despia/ext/metaglasses/DatInterop.java
package despia.ext.metaglasses;

import android.os.Handler;
import android.os.Looper;

import java.util.concurrent.CancellationException;
import java.util.concurrent.atomic.AtomicBoolean;

import kotlin.ResultKt;
import kotlin.Unit;
import kotlin.coroutines.Continuation;
import kotlin.coroutines.CoroutineContext;
import kotlin.coroutines.EmptyCoroutineContext;
import kotlin.coroutines.intrinsics.IntrinsicsKt;
import kotlinx.coroutines.CoroutineScope;
import kotlinx.coroutines.CoroutineScopeKt;
import kotlinx.coroutines.Dispatchers;
import kotlinx.coroutines.Job;
import kotlinx.coroutines.flow.Flow;
import kotlinx.coroutines.flow.FlowKt;

/**
 * The few Kotlin coroutine seams the DAT Android SDK exposes, used from Java: a suspend function
 * called with a hand-made Continuation, and a Flow collected in a scope. The fixture's typed module
 * is Java (the generated module applies no Kotlin plugin), and kotlin-stdlib and
 * kotlinx-coroutines arrive with mwdat-core's compile-scope dependencies.
 */
final class DatInterop {
    private DatInterop() {
    }

    private static final Handler MAIN = new Handler(Looper.getMainLooper());

    /** A suspend function, called with the continuation it must resume. */
    interface SuspendCall<T> {
        Object invoke(Continuation<? super T> continuation);
    }

    /** Receives a suspend call's value or its failure, on the main thread, exactly once. */
    interface Done<T> {
        void done(T value, Throwable error);
    }

    /** Receives each value a Flow emits, on the scope's dispatcher. */
    interface Each<T> {
        void each(T value);
    }

    @SuppressWarnings("unchecked")
    static <T> void call(SuspendCall<T> call, Done<T> done) {
        AtomicBoolean fired = new AtomicBoolean(false);
        Continuation<T> continuation = new Continuation<T>() {
            @Override
            public CoroutineContext getContext() {
                return EmptyCoroutineContext.INSTANCE;
            }

            @Override
            public void resumeWith(Object result) {
                Throwable error = null;
                T value = null;
                try {
                    ResultKt.throwOnFailure(result);
                    value = (T) result;
                } catch (Throwable t) {
                    error = t;
                }
                deliver(fired, done, value, error);
            }
        };
        Object r;
        try {
            r = call.invoke(continuation);
        } catch (Throwable t) {
            deliver(fired, done, null, t);
            return;
        }
        if (r != IntrinsicsKt.getCOROUTINE_SUSPENDED()) deliver(fired, done, (T) r, null);
    }

    private static <T> void deliver(AtomicBoolean fired, Done<T> done, T value, Throwable error) {
        if (!fired.compareAndSet(false, true)) return;
        if (Looper.myLooper() == Looper.getMainLooper()) {
            done.done(value, error);
        } else {
            MAIN.post(() -> done.done(value, error));
        }
    }

    /** Collects a Flow in the scope; cancel the returned job (or the scope) to stop. */
    static <T> Job collect(CoroutineScope scope, Flow<T> flow, Each<T> each) {
        return FlowKt.launchIn(FlowKt.onEach(flow, (value, continuation) -> {
            each.each(value);
            return Unit.INSTANCE;
        }), scope);
    }

    static CoroutineScope mainScope() {

    }
```

```java android/glasses/java/despia/ext/metaglasses/GlassesCore.java
import java.security.SecureRandom;
import java.util.Locale;

/**
 * Every decision of the Meta glasses extension that does not need Android: the loopback HTTP
 * request rules, the byte-range rule, the response heads, the stream parameters and the
 * session and clip state machine. No android.* or androidx.* import, so the shared rules run
 * against this file directly on a plain JVM. The Swift
 * twin is ios/app/GlassesCore.swift; both must give the same answer for every vector.
 */
public final class GlassesCore {
    private GlassesCore() {
    }

    // ---------------------------------------------------------------- loopback HTTP

    /** Longest request head (request line and headers) the server reads before refusing. */
    public static final int MAX_HEAD = 8192;
    /** Longest request target accepted. */
    public static final int MAX_TARGET = 512;
    /** The multipart boundary of the live stream. */
    public static final String BOUNDARY = "nxframe";

    /** A parsed request: method, path without query, and the raw Range header or null. */
    public static final class Request {
        public final String method;
        public final String path;
        public final String range;

        Request(String method, String path, String range) {
            this.method = method;
            this.path = path;
            this.range = range;
        }
    }

    /**
     * Parses a request head (everything before the blank line, CRLF line ends). Returns null for
     * anything that is not a well-formed GET, HEAD or OPTIONS request with an origin-form target.
     */
    public static Request parseRequest(String head) {
        if (head == null || head.length() > MAX_HEAD) return null;
        String[] lines = head.split("\r\n", -1);
        String[] parts = lines[0].split(" ", -1);
        if (parts.length != 3) return null;
        String method = parts[0];
        if (!method.equals("GET") && !method.equals("HEAD") && !method.equals("OPTIONS")) return null;
        if (!parts[2].equals("HTTP/1.1") && !parts[2].equals("HTTP/1.0")) return null;
        String target = parts[1];
        if (target.isEmpty() || target.length() > MAX_TARGET || target.charAt(0) != '/') return null;
        for (int i = 0; i < target.length(); i++) {
            char c = target.charAt(i);
            if (c <= 0x20 || c >= 0x7f) return null;
        }
        int q = target.indexOf('?');
        String path = q >= 0 ? target.substring(0, q) : target;
        String range = null;
        for (int i = 1; i < lines.length; i++) {
            String line = lines[i];
            if (line.isEmpty()) continue;
            int colon = line.indexOf(':');
            if (colon <= 0) return null;
            String name = line.substring(0, colon).trim().toLowerCase(Locale.ROOT);
            if (name.equals("range")) {
                if (range != null) return null;
                range = line.substring(colon + 1).trim();
            }
        }
        return new Request(method, path, range);
    }

    /** What a path asks for. */
    public static final class Target {
        /** live, frame, media, forbidden or not_found. */
        public final String kind;
        /** For media: the id and the extension (jpg or mp4). */
        public final String id;
        public final String ext;

        Target(String kind, String id, String ext) {
            this.kind = kind;
            this.id = id;
            this.ext = ext;
        }
    }

    /**
     * Classifies a path against the current stream token. The token is the first segment and is
     * compared in constant time; a wrong or missing token is forbidden before anything else is
     * looked at, so the path does not reveal which files exist.
     */
    public static Target classify(String path, String token) {
        if (path == null || !path.startsWith("/")) return new Target("not_found", null, null);
        int slash = path.indexOf('/', 1);
        String first = slash < 0 ? path.substring(1) : path.substring(1, slash);
        if (!isToken(token) || !constantTimeEquals(first, token)) return new Target("forbidden", null, null);
        String rest = slash < 0 ? "" : path.substring(slash);
        if (rest.equals("/live.mjpg")) return new Target("live", null, null);
        if (rest.equals("/frame.jpg")) return new Target("frame", null, null);
        if (rest.startsWith("/media/")) {
            String file = rest.substring("/media/".length());
            int dot = file.lastIndexOf('.');
            if (dot > 0) {
                String id = file.substring(0, dot);
                String ext = file.substring(dot + 1);
                if (isMediaId(id) && (ext.equals("jpg") || ext.equals("mp4"))) return new Target("media", id, ext);
            }
        }
        return new Target("not_found", null, null);
    }

    /** A stream token: exactly 32 lower-case hex digits (128 bits). */
    public static boolean isToken(String s) {
        if (s == null || s.length() != 32) return false;
        for (int i = 0; i < 32; i++) {
            char c = s.charAt(i);
            if (!((c >= '0' && c <= '9') || (c >= 'a' && c <= 'f'))) return false;
        }
        return true;
    }

    /** A media id: 1 to 32 characters of a-z and 0-9. */
    public static boolean isMediaId(String s) {
        if (s == null || s.isEmpty() || s.length() > 32) return false;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (!((c >= '0' && c <= '9') || (c >= 'a' && c <= 'z'))) return false;
        }
        return true;
    }

    static boolean constantTimeEquals(String a, String b) {
        if (a.length() != b.length()) return false;
        int diff = 0;
        for (int i = 0; i < a.length(); i++) diff |= a.charAt(i) ^ b.charAt(i);
        return diff == 0;
    }

    /** A new random token from a cryptographic source. */
    public static String newToken(SecureRandom random) {
        byte[] b = new byte[16];
        random.nextBytes(b);
        StringBuilder sb = new StringBuilder(32);
        for (byte x : b) sb.append(String.format(Locale.ROOT, "%02x", x & 0xff));
        return sb.toString();
    }

    /**
     * The byte range to send for a Range header and a file size: {start, end, partial}, start and
     * end inclusive, partial 1 when the answer is 206 Partial Content with a Content-Range and 0
     * when it is 200 with the whole file. A null header, one that is not a single satisfiable-form
     * bytes range, or an empty file: the whole file ({0, total - 1, 0}, or {0, -1, 0} for an empty
     * file); RFC 9110 section 14.2 lets a server ignore a Range it does not support. An
     * unsatisfiable single range: null (answer 416).
     */
    public static long[] range(String header, long total) {
        long[] whole = {0, total - 1, 0};
        if (header == null || total <= 0) return whole;
        String h = header.trim();
        if (!h.startsWith("bytes=")) return whole;
        String spec = h.substring(6).trim();
        if (spec.indexOf(',') >= 0) return whole;
        int dash = spec.indexOf('-');
        if (dash < 0) return whole;
        String a = spec.substring(0, dash).trim();
        String b = spec.substring(dash + 1).trim();
        if (!digits(a) || !digits(b) || (a.isEmpty() && b.isEmpty())) return whole;
        if (a.isEmpty()) {
            long n = Long.parseLong(b);
            if (n == 0) return null;
            return new long[]{Math.max(0, total - n), total - 1, 1};
        }
        long start = Long.parseLong(a);
        if (start >= total) return null;
        long end = b.isEmpty() ? total - 1 : Math.min(Long.parseLong(b), total - 1);
        if (end < start) return whole;
        return new long[]{start, end, 1};
    }

    private static boolean digits(String s) {
        if (s.length() > 18) return false;
        for (int i = 0; i < s.length(); i++) if (s.charAt(i) < '0' || s.charAt(i) > '9') return false;
        return true;
    }

            case 204: return "No Content";

     * the path is the capability. Access-Control-Allow-Private-Network answers a Private Network

    public static String responseHead(int status, String contentType, long length, String contentRange) {

    }

     * The stream's state machine, on the main thread. Each start gets a new generation; every
     * SDK callback carries the generation it was made for, and a callback for any other
     * generation changes nothing (it is counted in staleDrops). A clip is open only while the
     * stream streams, and at most one at a time.
     */
    public static final class Session {
        /** idle, starting, streaming, paused. */
        public String state = "idle";
        public long gen = 0;
        public int staleDrops = 0;
        /** The open clip's id, or null. */
        public String clip = null;
        /** The clip generation; a timer or writer callback for another one changes nothing. */
        public long clipGen = 0;

        /** A start: returns the new generation, or -1 when a stream already starts or runs. */
        public long begin() {
            if (!state.equals("idle")) return -1;
            gen++;
            state = "starting";
            return gen;
        }

        private boolean current(long g) {
            if (g != gen || state.equals("idle")) {
                staleDrops++;
                return false;
            }
            return true;
        }

        /** The SDK reported streaming for generation g. True when this is news for the page. */
        public boolean streaming(long g) {
            if (!current(g)) return false;
            boolean changed = !state.equals("streaming");
            state = "streaming";
            return changed;
        }

        /** The SDK paused the stream (a tap on the glasses, hinges closed). */
        public boolean paused(long g) {
            if (!current(g)) return false;
            boolean changed = !state.equals("paused");
            state = "paused";
            return changed;
        }

        /**
         * The stream ended for generation g (stopped, closed or a critical error). Returns the id
         * of a clip that must be finished now, or "" when none was open; null for a stale call.
         */
        public String ended(long g) {
            if (!current(g)) return null;
            return endAll();
        }

        /** An explicit stop: same result as {@link #ended}, and later callbacks are stale. */
        public String stop() {
            if (state.equals("idle")) return "";
            return endAll();
        }

        private String endAll() {
            state = "idle";
            gen++;
            String c = clip == null ? "" : clip;
            clip = null;
            clipGen++;
            return c;
        }

        /** Open a clip: its generation, or -1 when the stream does not stream or a clip is open. */
        public long clipBegin(String id) {
            if (!state.equals("streaming") || clip != null) return -1;
            clip = id;
            clipGen++;
            return clipGen;
        }

        /** Close the clip of generation cg (record_stop or its time limit). The id, or null. */
        public String clipEnd(long cg) {
            if (clip == null || cg != clipGen) {
                staleDrops++;
                return null;
            }
            String c = clip;
            clip = null;
            clipGen++;
            return c;
        }
    }
```

```java android/glasses/java/despia/ext/metaglasses/GlassesExtension.java
        // registration event with the same error codes iOS returns from register.
        DatInterop.collect(appScope, Wearables.INSTANCE.getRegistrationErrorStream(), e -> {
            // Already in the asked state: not an error, as on iOS.
            if (e == RegistrationError.ALREADY_REGISTERED || e == RegistrationError.ALREADY_UNREGISTERED) return;
            try {
                ctx.emit("registration", new JSONObject()
                        .put("registration", name(Wearables.INSTANCE.getRegistrationState().getValue()))
                        .put("error", registrationError(e)).put("message", describe(e)));
            } catch (JSONException ignored) {
                // A four-field object always builds.
            }
        });
        return true;
    }

    private JSONObject status() throws JSONException {
        JSONObject o = new JSONObject();
        o.put("sdkVersion", SDK_VERSION);
        o.put("bluetooth", Build.VERSION.SDK_INT < BLUETOOTH_RUNTIME_API ? "not_required" : bluetoothGranted() ? "granted" : "denied");
        o.put("registration", initialized ? name(Wearables.INSTANCE.getRegistrationState().getValue()) : "unknown");
        o.put("devices", initialized ? Wearables.INSTANCE.getDevices().getValue().size() : 0);
        o.put("state", core.state);
        o.put("quality", quality);
        o.put("fps", fps);
        int[] asked = GlassesCore.frameSize(quality);
        o.put("width", frameWidth > 0 ? frameWidth : asked[0]);
        o.put("height", frameHeight > 0 ? frameHeight : asked[1]);
        o.put("frames", frames);
        o.put("staleDrops", core.staleDrops);
        o.put("clip", core.clip == null ? JSONObject.NULL : core.clip);
        o.put("photoBusy", photoBusy);
        o.put("mock", mock);
        if (server != null) {
            o.put("live", server.base() + "/live.mjpg");
            o.put("frame", server.base() + "/frame.jpg");
            o.put("mediaBase", server.base() + "/media/");
        } else {
            o.put("live", JSONObject.NULL);
            o.put("frame", JSONObject.NULL);
            o.put("mediaBase", JSONObject.NULL);
        }
        return o;
    }

    private void emitState(String reason) {
        try {
            JSONObject o = status();
            o.put("reason", reason == null ? JSONObject.NULL : reason);
            ctx.emit("state", o);
        } catch (JSONException ignored) {
            // status() builds from plain values.
        }
    }

    private void register(ExtResult.Callback reply, boolean on) throws JSONException {
        if (activity == null) {
            reply.reply(ExtResult.error("unavailable", "no activity is showing"));
            return;
        }
        RegistrationState s = Wearables.INSTANCE.getRegistrationState().getValue();
        if (on && s != RegistrationState.REGISTERED) Wearables.INSTANCE.startRegistration(activity);
        if (!on && s == RegistrationState.REGISTERED) Wearables.INSTANCE.startUnregistration(activity);
        // The outcome arrives as the registration event once the Meta AI app returns.
        reply.reply(ExtResult.ok(new JSONObject().put("registration", name(Wearables.INSTANCE.getRegistrationState().getValue()))));
    }

    private void permission(ExtCall call, ExtResult.Callback reply) {
        if (permissionWait != null) {
            reply.reply(ExtResult.error("busy", "a permission request is already open"));
            return;
        }
        Call w = new Call(call, reply, 0);
        w.prompt = Boolean.TRUE.equals(call.params.get("prompt"));
        permissionWait = w;
        if (!bluetoothGranted()) {
            if (!w.prompt) {
                finishPermission(w, okPermission("denied", "unknown"));
            } else if (bluetoothLauncher == null) {
                finishPermission(w, ExtResult.error("unavailable", "no activity is showing"));
            } else {
                // The system dialog; the answer comes back to onBluetoothResult.
                bluetoothLauncher.launch(BLUETOOTH_CONNECT);
            }
            return;
        }
        checkCamera(w);
    }

    private void onBluetoothResult(Boolean granted) {
        Call w = permissionWait;
        if (w == null) return;
        if (!Boolean.TRUE.equals(granted) || !bluetoothGranted()) {
            finishPermission(w, ExtResult.error("permission_denied", "Bluetooth access was denied"));
        } else if (!w.call.isActive()) {
            finishPermission(w, ExtResult.error("timeout", "the permission request took too long"));
        } else {
            checkCamera(w);
        }
    }

    /** True below Android 12, where Bluetooth needs no runtime grant. */
    private boolean bluetoothGranted() {
        return Build.VERSION.SDK_INT < BLUETOOTH_RUNTIME_API
                || ctx.app().checkSelfPermission(BLUETOOTH_CONNECT) == PackageManager.PERMISSION_GRANTED;
    }

    private void checkCamera(Call w) {
        if (!ensureInit()) {
            finishPermission(w, ExtResult.error("init_failed", "the glasses SDK could not start"));
            return;
        }
        if (Wearables.INSTANCE.getRegistrationState().getValue() != RegistrationState.REGISTERED) {
            // The camera permission belongs to a registered app; Meta AI cannot answer it before.
            finishPermission(w, okPermission("granted", "unknown"));
            return;
        }
        DatInterop.<DatResult<PermissionStatus, PermissionError>>call(
                c -> Wearables.INSTANCE.checkPermissionStatus(Permission.CAMERA, c), (r, error) -> {
                    if (permissionWait != w) return;
                    if (error != null || r == null) {
                        finishPermission(w, ExtResult.error("permission_failed", "the permission check failed"));
                    } else if (!r.isSuccess()) {
                        finishPermission(w, permissionError(r.errorOrNull()));
                    } else if (r.getOrNull() instanceof PermissionStatus.Granted) {
                        finishPermission(w, okPermission("granted", "granted"));
                    } else if (!w.prompt) {
                        finishPermission(w, okPermission("granted", "denied"));
                    } else if (!w.call.isActive()) {
                        finishPermission(w, ExtResult.error("timeout", "the permission check took too long"));
                    } else if (permissionLauncher == null) {
                        finishPermission(w, ExtResult.error("unavailable", "no activity is showing"));
                    } else {
                        // Switches to the Meta AI app; the answer comes back to onPermissionResult.
                        permissionLauncher.launch(Permission.CAMERA);
                    }
                });
    }

    private void onPermissionResult(DatResult<PermissionStatus, PermissionError> r) {
        Call w = permissionWait;
        if (w == null) return;
        if (r == null || !r.isSuccess()) {
            finishPermission(w, r == null ? ExtResult.error("permission_failed", "no answer") : permissionError(r.errorOrNull()));
        } else {
            finishPermission(w, okPermission("granted", r.getOrNull() instanceof PermissionStatus.Granted ? "granted" : "denied"));
        }
    }

    private void finishPermission(Call w, ExtResult result) {
        if (permissionWait == w) permissionWait = null;
        w.reply.reply(result);
    }

    private static ExtResult okPermission(String bluetooth, String camera) {
        try {
            return ExtResult.ok(new JSONObject().put("bluetooth", bluetooth).put("camera", camera));
        } catch (JSONException e) {
            return ExtResult.error("handler_error", "could not build the reply");
        }
    }

    private static ExtResult permissionError(PermissionError e) {
        if (e == PermissionError.META_AI_NOT_INSTALLED) return ExtResult.error("meta_ai_missing", "the Meta AI app is not installed");
        if (e == PermissionError.NO_DEVICE || e == PermissionError.NO_DEVICE_WITH_CONNECTION) {
            return ExtResult.error("no_device", describe(e));
        }
        if (e == PermissionError.REQUEST_IN_PROGRESS) return ExtResult.error("busy", describe(e));
        if (e == PermissionError.REQUEST_TIMEOUT) return ExtResult.error("timeout", describe(e));
        return ExtResult.error("permission_failed", describe(e));
    }

    // -------------------------------------------------------------------------------- stream

    private void start(ExtCall call, ExtResult.Callback reply) throws JSONException {
        if (Wearables.INSTANCE.getRegistrationState().getValue() != RegistrationState.REGISTERED) {
            reply.reply(ExtResult.error("registration_required", "connect the app to Meta AI first (register)"));
            return;
        }
        if (!core.state.equals("idle")) {
            reply.reply(ExtResult.error("busy", "the stream is already " + core.state));
            return;
        }
        Object q = call.params.get("quality");
        Object f = call.params.get("fps");
        String wantQuality = q instanceof String ? (String) q : "medium";
        int wantFps = GlassesCore.frameRate(f instanceof Number ? ((Number) f).intValue() : 24);
        try {
            if (server == null) server = GlassesServer.start(mediaDir());
        } catch (IOException e) {
            reply.reply(ExtResult.error("server_failed", "the local stream server could not start"));
            return;
        }
        DatResult<DeviceSession, DeviceSessionError> r = Wearables.INSTANCE.createSession(new AutoDeviceSelector());
        if (!r.isSuccess()) {
            reply.reply(sessionError(r.errorOrNull()));
            return;
        }
        long g = core.begin();
        quality = wantQuality;
        fps = wantFps;
        frameWidth = 0;
        frameHeight = 0;
        session = r.getOrNull();
        streamSeenActive = false;
        Call s = new Call(call, reply, g);
        starting = s;
        streamScope = DatInterop.mainScope();
        frameScope = DatInterop.backgroundScope();
        DatInterop.collect(streamScope, session.getErrors(), e -> onSessionError(g, e));
        DatInterop.collect(streamScope, session.getState(), st -> onSessionState(g, st));
        session.start();
        long at = call.deadlineUptimeMillis > 0 ? call.deadlineUptimeMillis - 100 : SystemClock.uptimeMillis() + 20000;
        main.postAtTime(() -> {
            if (starting == s) failStart(s, ExtResult.error("timeout", "the glasses did not start streaming in time"));
        }, startTimeout, at);
        emitState("starting");
    }

    private void onSessionState(long g, DeviceSessionState st) {
        if (g != core.gen || session == null) return;
        if (st == DeviceSessionState.STARTED && camera == null) {
            VideoQuality vq = quality.equals("high") ? VideoQuality.HIGH : quality.equals("low") ? VideoQuality.LOW : VideoQuality.MEDIUM;
            // Decoded YUV frames (compressVideo false): the preview needs no decoder of its own.
            DatResult<Camera, DeviceSessionError> c = SessionCameraExtensionsKt.addCamera(session,
                    new StreamConfiguration(null, vq, fps, false));
            if (!c.isSuccess()) {
                failStartOrEnd(g, sessionError(c.errorOrNull()), "camera_failed");
                return;
            }
            camera = c.getOrNull();
            stream = camera.getStream();
            liveGen = g;
            DatInterop.collect(streamScope, stream.getState(), x -> onStreamState(g, x));
            DatInterop.collect(streamScope, stream.getErrorStream(), x -> onStreamError(g, x));
            DatInterop.collect(frameScope, stream.getVideoStream(), x -> onFrame(g, x));
            DatResult<kotlin.Unit, StreamError> sr = stream.start();
            if (!sr.isSuccess()) failStartOrEnd(g, streamError(sr.errorOrNull()), "stream_failed");
        } else if (st == DeviceSessionState.STOPPED && streamSeenActive) {
            ended(g, "session_stopped");
        } else if (st == DeviceSessionState.STOPPED && starting != null && starting.gen == g) {
            failStart(starting, ExtResult.error("no_device", "the glasses session stopped before streaming"));
        }
    }

    private void onSessionError(long g, DeviceSessionError e) {
        if (g != core.gen) return;
        failStartOrEnd(g, sessionError(e), "session_error");
    }

    private void onStreamState(long g, StreamState st) {
        if (st == StreamState.STARTING || st == StreamState.STARTED || st == StreamState.STREAMING || st == StreamState.PAUSED) {
            if (g == core.gen) streamSeenActive = true;
        }
        if (st == StreamState.STREAMING) {
            if (core.streaming(g)) emitState("streaming");
            if (starting != null && starting.gen == g) {
                Call s = starting;
                starting = null;
                main.removeCallbacksAndMessages(startTimeout);
                try {
                    s.reply.reply(ExtResult.ok(status()));
                } catch (JSONException e) {
                    s.reply.reply(ExtResult.error("handler_error", "could not build the reply"));
                }
            }
        } else if (st == StreamState.PAUSED) {
            if (core.paused(g)) emitState("paused");
        } else if ((st == StreamState.STOPPED || st == StreamState.CLOSED) && streamSeenActive && g == core.gen) {
            ended(g, "stream_stopped");
        }
    }

    private void onStreamError(long g, StreamError e) {
        if (g != core.gen) return;
        if (e == StreamError.STREAM_ERROR) {
            // Informational (Meta, "Camera Streaming (Android)"): the stream goes on.
            emitState("stream_warning");
            return;
        }
        failStartOrEnd(g, streamError(e), "stream_error");
    }

    private void failStartOrEnd(long g, ExtResult error, String reason) {
        if (starting != null && starting.gen == g) {
            failStart(starting, error);
        } else {
            ended(g, reason);
        }
    }

    private void failStart(Call s, ExtResult error) {
        if (starting != s) return;
        starting = null;
        main.removeCallbacksAndMessages(startTimeout);
        teardown("start_failed");
        s.reply.reply(error);
    }

    /** The SDK ended generation g by itself. */
    private void ended(long g, String reason) {
        String clip = core.ended(g);
        if (clip == null) return;
        stopSdk();
        if (starting != null && starting.gen == g) {
            Call s = starting;
            starting = null;
            main.removeCallbacksAndMessages(startTimeout);
            s.reply.reply(ExtResult.error("no_device", "the stream ended before it started"));
        }
        if (!clip.isEmpty()) finishClip(clip, reason, null);
        emitState(reason);
    }

    /** An explicit stop (route, failed start or mock off): later SDK callbacks are stale. */
    private void teardown(String reason) {
        boolean wasActive = !core.state.equals("idle");
        String clip = core.stop();
        stopSdk();
        if (!clip.isEmpty()) finishClip(clip, reason, null);
        if (wasActive) emitState(reason);
    }

    private void stopSdk() {
        liveGen = 0;
        DatInterop.cancel(frameScope);
        DatInterop.cancel(streamScope);
        frameScope = null;
        streamScope = null;
        // Camera.stop cascades to its stream; DeviceSession.stop to every capability.
        if (camera != null) camera.stop();
        if (session != null) session.stop();
        camera = null;
        stream = null;
        session = null;
        if (server != null) server.endLive();
    }

    /** On the frame thread (Dispatchers.Default), one frame at a time. */
    private void onFrame(long g, VideoFrame frame) {
        if (g != liveGen || frame.isCompressed()) return;
        ByteBuffer buf = frame.getBuffer();
        int w = frame.getWidth();
        int h = frame.getHeight();
        byte[] jpeg = encoder.jpeg(buf, w, h, GlassesMedia.PREVIEW_QUALITY);
        GlassesServer s = server;
        if (jpeg == null || s == null || g != liveGen) return;
        s.publish(jpeg);
        frameWidth = w;
        frameHeight = h;
        frames++;
        GlassesMedia.ClipRecorder r = recorder;
        if (r == null) return;
        try {
            r.offer(buf, w, h, frame.getPresentationTimeUs());
            if (r.sizeChanged) main.post(() -> clipEnded(r, "resolution_changed"));
        } catch (IOException | RuntimeException e) {
            main.post(() -> clipEnded(r, "encoder_failed"));
        }
    }

    // ------------------------------------------------------------------------ photo and clips

    private void photo(ExtResult.Callback reply) {
        if (!core.state.equals("streaming") || stream == null) {
            reply.reply(ExtResult.error("not_streaming", "start the stream first"));
            return;
        }
        if (photoBusy) {
            reply.reply(ExtResult.error("busy", "a photo is already being taken"));
            return;
        }
        photoBusy = true;
        Stream st = stream;
        DatInterop.<DatResult<PhotoData, CaptureError>>call(st::capturePhoto, (r, error) -> {
            if (error != null || r == null || !r.isSuccess()) {
                photoBusy = false;
                reply.reply(ExtResult.error("capture_failed", r == null ? "the capture failed" : describe(r.errorOrNull())));
                return;
            }
            PhotoData data = r.getOrNull();
            String id = newId("p");
            worker.execute(() -> {
                ExtResult out;
                try {
                    Bitmap bitmap;
                    if (data instanceof PhotoData.Bitmap) {
                        bitmap = ((PhotoData.Bitmap) data).getBitmap();
                    } else {
                        ByteBuffer heic = ((PhotoData.HEIC) data).getData().duplicate();
                        byte[] bytes = new byte[heic.remaining()];
                        heic.get(bytes);
                        bitmap = BitmapFactory.decodeByteArray(bytes, 0, bytes.length);
                    }
                    byte[] jpeg = bitmap == null ? null : GlassesMedia.jpeg(bitmap, GlassesMedia.PHOTO_QUALITY);
                    if (jpeg == null) throw new IOException("the photo could not be encoded");
                    File file = new File(mediaDir(), id + ".jpg");
                    GlassesMedia.write(file, jpeg);
                    JSONObject m = mediaJson(id, "jpg", file);
                    m.put("width", bitmap.getWidth());
                    m.put("height", bitmap.getHeight());
                    out = ExtResult.ok(m);
                } catch (IOException | JSONException | RuntimeException e) {
                    out = ExtResult.error("capture_failed", "the photo could not be saved");
                }
                ExtResult result = out;
                main.post(() -> {
                    photoBusy = false;
                    if (result.isOk()) ctx.emit("media", result.data());
                    reply.reply(result);
                });
            });
        });
    }

    private void recordStart(ExtCall call, ExtResult.Callback reply) throws JSONException {
        Object s = call.params.get("seconds");
        int seconds = s instanceof Number ? ((Number) s).intValue() : 10;
        String id = newId("c");
        long cg = core.clipBegin(id);
        if (cg < 0) {
            reply.reply(core.clip != null ? ExtResult.error("busy", "a clip is already recording")
                    : ExtResult.error("not_streaming", "start the stream first"));
            return;
        }
        // Written as .mp4.part and renamed when finished, so the server never serves half a file.
        recorder = new GlassesMedia.ClipRecorder(new File(mediaDir(), id + ".mp4.part"), fps);
        recorderGen = cg;
        recorderSeconds = seconds;
        main.postAtTime(() -> stopClip(cg, "limit", null), clipTimer, SystemClock.uptimeMillis() + seconds * 1000L);
        reply.reply(ExtResult.ok(new JSONObject().put("id", id).put("kind", "mp4").put("seconds", seconds)
                .put("url", server.base() + "/media/" + id + ".mp4")));
    }

    private void recordStop(ExtResult.Callback reply) {
        if (core.clip == null) {
            reply.reply(ExtResult.error("not_recording", "no clip is recording"));
            return;
        }
        stopClip(core.clipGen, "stopped", reply);
    }

    /** The frame thread saw the clip end on its own (size change, encoder error). */
    private void clipEnded(GlassesMedia.ClipRecorder r, String reason) {
        if (recorder == r) stopClip(recorderGen, reason, null);
    }

    private void stopClip(long cg, String reason, ExtResult.Callback reply) {
        String id = core.clipEnd(cg);
        if (id == null) {
            if (reply != null) reply.reply(ExtResult.error("not_recording", "no clip is recording"));
            return;
        }
        finishClip(id, reason, reply);
    }

    private void finishClip(String id, String reason, ExtResult.Callback reply) {
        GlassesMedia.ClipRecorder r = recorder;
        recorder = null;
        main.removeCallbacksAndMessages(clipTimer);
        File part = new File(mediaDir(), id + ".mp4.part");
        File file = new File(mediaDir(), id + ".mp4");
        worker.execute(() -> {
            boolean ok = r != null && r.finish() && part.renameTo(file);
            main.post(() -> {
                try {
                    if (ok) {
                        JSONObject m = mediaJson(id, "mp4", file).put("durationMs", r.durationMs()).put("reason", reason);
                        ctx.emit("media", m);
                        if (reply != null) reply.reply(ExtResult.ok(m));
                    } else {
                        part.delete();
                        ctx.emit("media", new JSONObject().put("id", id).put("kind", "mp4").put("failed", true).put("reason", reason));
                        if (reply != null) reply.reply(ExtResult.error("record_failed", "the clip has no frames or could not be written"));
                    }
                } catch (JSONException e) {
                    if (reply != null) reply.reply(ExtResult.error("handler_error", "could not build the reply"));
                }
            });
        });
    }

    // ------------------------------------------------------------------- frames and media files

    /**
     * The newest frame as base64 JPEG, for pages that cannot load the loopback URL. The page
     * compares seq with the last one it drew; polling faster than the stream's rate returns the
     * same frame again.
     */
    private void frame(ExtResult.Callback reply) throws JSONException {
        Object[] l = server == null ? new Object[] {0L, null} : server.latest();
        long seq = (Long) l[0];
        byte[] jpeg = (byte[]) l[1];
        JSONObject o = new JSONObject().put("seq", seq).put("width", frameWidth).put("height", frameHeight);
        o.put("jpeg", jpeg != null ? Base64.encodeToString(jpeg, Base64.NO_WRAP) : JSONObject.NULL);
        reply.reply(ExtResult.ok(o));
    }

    private File mediaDir() {
        if (!mediaDir.isDirectory()) mediaDir.mkdirs();
        return mediaDir;
    }

    private JSONObject mediaJson(String id, String kind, File f) throws JSONException {
        JSONObject o = new JSONObject().put("id", id).put("kind", kind).put("bytes", f.length());
        o.put("url", server == null ? JSONObject.NULL : server.base() + "/media/" + id + "." + kind);
        return o;
    }

    private JSONArray mediaList() throws JSONException {
        JSONArray items = new JSONArray();
        File[] files = mediaDir().listFiles();
        if (files == null) return items;
        for (File f : files) {
            String n = f.getName();
            int dot = n.lastIndexOf('.');
            if (dot <= 0) continue;
            String id = n.substring(0, dot);
            String kind = n.substring(dot + 1);
            if (GlassesCore.isMediaId(id) && (kind.equals("jpg") || kind.equals("mp4")) && !id.equals(core.clip)) {
                items.put(mediaJson(id, kind, f));
            }
        }
        return items;
    }

    private File mediaFile(ExtCall call) {
        Object id = call.params.get("id");
        Object kind = call.params.get("kind");
        if (!(id instanceof String) || !GlassesCore.isMediaId((String) id) || !(kind instanceof String)) return null;
        if (id.equals(core.clip)) return null;
        File f = new File(mediaDir(), id + "." + kind);
        return f.isFile() ? f : null;
    }

    private void mediaRead(ExtCall call, ExtResult.Callback reply) throws JSONException {
        File f = mediaFile(call);
        if (f == null) {
            reply.reply(ExtResult.error("not_found", "no such photo or clip"));
            return;
        }
        Object c = call.params.get("chunk");
        long chunk = c instanceof Number ? ((Number) c).longValue() : 0;
        long offset = chunk * MEDIA_CHUNK;
        int length = MEDIA_CHUNK;
        long total = f.length();
        byte[] buf = new byte[(int) Math.max(0, Math.min(length, total - offset))];
        try (RandomAccessFile raf = new RandomAccessFile(f, "r")) {
            raf.seek(Math.min(offset, total));
            raf.readFully(buf);
        } catch (IOException e) {
            reply.reply(ExtResult.error("not_found", "the file could not be read"));
            return;
        }
        reply.reply(ExtResult.ok(new JSONObject().put("id", call.params.get("id")).put("kind", call.params.get("kind"))
                .put("chunk", chunk).put("offset", offset).put("length", buf.length).put("total", total)
                .put("eof", offset + buf.length >= total).put("data", Base64.encodeToString(buf, Base64.NO_WRAP))));
    }

    private void mediaDelete(ExtCall call, ExtResult.Callback reply) throws JSONException {
        File f = mediaFile(call);
        if (f == null || !f.delete()) {
            reply.reply(ExtResult.error("not_found", "no such photo or clip"));
            return;
        }
        reply.reply(ExtResult.ok(new JSONObject().put("id", call.params.get("id")).put("kind", call.params.get("kind")).put("deleted", true)));
    }

    // ----------------------------------------------------------------------- Mock Device Kit

    /**
     * Meta's Mock Device Kit: fake registration, a paired Ray-Ban Meta mock and a synthesized
     * test feed (red left, blue right, moving white bar), so the emulator streams without glasses.
     */
    private void mock(ExtCall call, ExtResult.Callback reply) throws JSONException {
        boolean on = Boolean.TRUE.equals(call.params.get("enabled"));
        MockDeviceKitInterface kit = MockDeviceKit.Companion.getInstance(ctx.app());
        if (!on) {
            teardown("mock_off");
            if (mockGlasses != null) kit.unpairDevice(mockGlasses);
            mockGlasses = null;
            kit.disable();
            mock = false;
            reply.reply(ExtResult.ok(status()));
            return;
        }
        // Simulated glasses never run in a release build: a shipped app reports only real devices.
        if ((ctx.app().getApplicationInfo().flags & ApplicationInfo.FLAG_DEBUGGABLE) == 0) {
            reply.reply(ExtResult.error("mock_unavailable", "the mock glasses run in debug builds only"));
            return;
        }
        if (mock) {
            reply.reply(ExtResult.ok(status()));
            return;
        }
        File dir = new File(ctx.dataDir(), "mock");
        worker.execute(() -> {
            ExtResult failure = null;
            File feed = new File(dir, "feed.mp4");
            File photo = new File(dir, "photo.jpg");
            String codec = null;
            try {
                if (!dir.isDirectory() && !dir.mkdirs()) throw new IOException("no mock directory");
                codec = GlassesMedia.mockFeed(feed);
                byte[] p = GlassesMedia.mockPhoto();
                if (p == null) throw new IOException("the mock photo could not be encoded");
                GlassesMedia.write(photo, p);
            } catch (IOException | RuntimeException e) {
                failure = ExtResult.error("mock_failed", "the mock media could not be written");
            }
            ExtResult f = failure;
            String c = codec;
            main.post(() -> {
                if (f != null) {
                    reply.reply(f);
                    return;
                }
                // DAT 1.1.0 adds isDevMode; null leaves the simulated registration mode as it is.
                kit.enable(new MockDeviceKitConfig(true, true, null));
```

```java android/glasses/java/despia/ext/metaglasses/GlassesMedia.java
 * Frames, clips and the Mock Device Kit's media.
 *
 * <p>Frame layout: with {@code compressVideo = false} DAT hands the app decoded YUV frames
 * (Meta, "Camera Streaming (Android)": "VideoFrame.buffer holds YUV pixel data"). The plane order
 * is not documented; this fixture reads it as I420 (Y, then U, then V, each tightly packed). The
 * mock feed is half red and half blue, so the harness sees a swapped U and V at once (red and blue
 * trade sides). Unverified on real glasses.

    private GlassesMedia() {

    /** JPEG quality of the live preview: small frames for a smooth stream. */
    static final int PREVIEW_QUALITY = 80;
    /** JPEG quality of a saved photo. */
    static final int PHOTO_QUALITY = 92;

    /** Whether buf holds a whole I420 frame of w x h. */
    static boolean isI420(ByteBuffer buf, int w, int h) {
        return w > 0 && h > 0 && w % 2 == 0 && h % 2 == 0 && buf != null && buf.remaining() >= w * h * 3 / 2;
    }

    /** Turns I420 frames into JPEG; reuses its NV21 buffer, so one instance per frame thread. */
    static final class FrameEncoder {
        private byte[] nv21 = new byte[0];
        private final ByteArrayOutputStream out = new ByteArrayOutputStream(128 * 1024);

        synchronized byte[] jpeg(ByteBuffer i420, int w, int h, int quality) {
            if (!isI420(i420, w, h)) return null;
            int ySize = w * h;
            int cSize = ySize / 4;
            if (nv21.length != ySize + 2 * cSize) nv21 = new byte[ySize + 2 * cSize];
            ByteBuffer b = i420.duplicate();
            int base = b.position();
            b.get(nv21, 0, ySize);
            int u = base + ySize;
            int v = u + cSize;
            for (int i = 0, o = ySize; i < cSize; i++) {
                nv21[o++] = b.get(v + i);
                nv21[o++] = b.get(u + i);
            }
            out.reset();
            if (!new YuvImage(nv21, ImageFormat.NV21, w, h, null).compressToJpeg(new Rect(0, 0, w, h), quality, out)) {
                return null;
            }
            return out.toByteArray();
        }
    }

    static byte[] jpeg(Bitmap bitmap, int quality) {
        ByteArrayOutputStream out = new ByteArrayOutputStream(256 * 1024);
        if (!bitmap.compress(Bitmap.CompressFormat.JPEG, quality, out)) return null;
        return out.toByteArray();
    }

    static void write(File f, byte[] data) throws IOException {
        File tmp = new File(f.getPath() + ".part");
        try (FileOutputStream o = new FileOutputStream(tmp)) {
            o.write(data);
            o.getFD().sync();
        }
        if (!tmp.renameTo(f)) {
            tmp.delete();
            throw new IOException("could not save " + f.getName());
        }
    }

    /**
     * An H.264 MP4 clip encoded from I420 frames with the platform encoder. The size is taken
     * from the first frame; DAT may lower the resolution when Bluetooth bandwidth drops (Meta,
     * "Camera Streaming"), and a frame of another size ends the clip ({@link #sizeChanged}). Every
     * method is called with the instance's lock held, from the frame thread or a worker.
     */
    static final class ClipRecorder {
        private final File file;
        private final int fps;
        private MediaCodec codec;
        private MediaMuxer muxer;
        private int track = -1;
        private boolean muxing;
        private int width;
        private int height;
        private long firstPts = -1;
        private long lastPts;
        private boolean done;
        volatile boolean sizeChanged;
        private final MediaCodec.BufferInfo info = new MediaCodec.BufferInfo();

        ClipRecorder(File file, int fps) {
            this.file = file;
            this.fps = fps;
        }

        /** Encodes one frame; false when the frame was not taken (no free input, or the clip ended). */
        synchronized boolean offer(ByteBuffer i420, int w, int h, long ptsUs) throws IOException {
            if (done || !isI420(i420, w, h)) return false;
            if (codec == null) open(w, h);
            if (w != width || h != height) {
                sizeChanged = true;
                return false;
            }
            int index = codec.dequeueInputBuffer(0);
            if (index < 0) {
                drain(false);
                return false;
            }
            Image image = codec.getInputImage(index);
            if (image == null) {
                codec.queueInputBuffer(index, 0, 0, 0, 0);
                return false;
            }
            fill(image, i420, w, h);
            if (firstPts < 0) firstPts = ptsUs;
            lastPts = ptsUs;
            codec.queueInputBuffer(index, 0, w * h * 3 / 2, ptsUs - firstPts, 0);
            drain(false);
            return true;
        }

        private void open(int w, int h) throws IOException {
            width = w;
            height = h;
            MediaFormat f = MediaFormat.createVideoFormat(MediaFormat.MIMETYPE_VIDEO_AVC, w, h);
            f.setInteger(MediaFormat.KEY_COLOR_FORMAT, MediaCodecInfo.CodecCapabilities.COLOR_FormatYUV420Flexible);
            f.setInteger(MediaFormat.KEY_BIT_RATE, Math.max(1_000_000, w * h * 4));
            f.setInteger(MediaFormat.KEY_FRAME_RATE, fps);
            f.setInteger(MediaFormat.KEY_I_FRAME_INTERVAL, 1);
            codec = MediaCodec.createEncoderByType(MediaFormat.MIMETYPE_VIDEO_AVC);
            codec.configure(f, null, null, MediaCodec.CONFIGURE_FLAG_ENCODE);
            codec.start();
            muxer = new MediaMuxer(file.getPath(), MediaMuxer.OutputFormat.MUXER_OUTPUT_MPEG_4);
        }

        private void drain(boolean end) {
            while (true) {
                int out = codec.dequeueOutputBuffer(info, end ? 10_000 : 0);
                if (out == MediaCodec.INFO_TRY_AGAIN_LATER) {
                    if (!end) return;
                    continue;
                }
                if (out == MediaCodec.INFO_OUTPUT_FORMAT_CHANGED) {
                    track = muxer.addTrack(codec.getOutputFormat());
                    muxer.start();
                    muxing = true;
                    continue;
                }
                if (out < 0) continue;
                ByteBuffer data = codec.getOutputBuffer(out);
                boolean config = (info.flags & MediaCodec.BUFFER_FLAG_CODEC_CONFIG) != 0;
                if (data != null && muxing && !config && info.size > 0) {
                    data.position(info.offset);
                    data.limit(info.offset + info.size);
                    muxer.writeSampleData(track, data, info);
                }
                codec.releaseOutputBuffer(out, false);
                if ((info.flags & MediaCodec.BUFFER_FLAG_END_OF_STREAM) != 0) return;
            }
        }

        /** Ends the clip and closes the file. True when the MP4 holds at least one frame. */
        synchronized boolean finish() {
            if (done) return false;
            done = true;
            if (codec == null) return false;
            boolean ok = false;
            try {
                int index = -1;
                for (int i = 0; i < 50 && index < 0; i++) index = codec.dequeueInputBuffer(10_000);
                if (index >= 0) {
                    codec.queueInputBuffer(index, 0, 0, lastPts - firstPts + 1, MediaCodec.BUFFER_FLAG_END_OF_STREAM);
                    drain(true);
                }
                ok = muxing;
            } catch (RuntimeException e) {
                ok = false;
            } finally {
                try {
                    codec.stop();
                } catch (RuntimeException ignored) {
                    // A codec that failed already released its buffers.
                }
                codec.release();
                if (muxing) {
                    try {
                        muxer.stop();
                    } catch (RuntimeException e) {
                        ok = false;
                    }
                }
                muxer.release();
            }
            return ok;
        }

        long durationMs() {
            return firstPts < 0 ? 0 : (lastPts - firstPts) / 1000 + 1000 / Math.max(1, fps);
        }
    }

    /** Copies an I420 buffer into a codec input image of any YUV_420_888 layout. */
    static void fill(Image image, ByteBuffer i420, int w, int h) {
        Image.Plane[] planes = image.getPlanes();
        ByteBuffer src = i420.duplicate();
        int base = src.position();
        int[] offset = {base, base + w * h, base + w * h + w * h / 4};
        for (int p = 0; p < 3; p++) {
            int pw = p == 0 ? w : w / 2;
            int ph = p == 0 ? h : h / 2;
            ByteBuffer dst = planes[p].getBuffer();
            int rowStride = planes[p].getRowStride();
            int pixelStride = planes[p].getPixelStride();
            for (int y = 0; y < ph; y++) {
                int row = offset[p] + y * pw;
                for (int x = 0; x < pw; x++) dst.put(y * rowStride + x * pixelStride, src.get(row + x));
            }
        }
    }
```

```java android/glasses/java/despia/ext/metaglasses/GlassesServer.java
package despia.ext.metaglasses;

import java.io.ByteArrayOutputStream;
import java.io.File;
import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
import java.io.RandomAccessFile;
import java.net.InetAddress;
import java.net.InetSocketAddress;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.security.SecureRandom;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * The page's view of the glasses camera: a tiny HTTP/1.1 server bound to 127.0.0.1 on a port the
 * system picks. Every path starts with a fresh 128-bit token, so only the page that got the URL
 * from a route can read it. Three resources:
 * <ul>
 *   <li>{@code /<token>/live.mjpg}: multipart/x-mixed-replace of JPEG frames for an {@code <img>}.
 *   Each connection is sent the newest frame only; a slow reader skips frames instead of falling
 *   behind, so the picture never lags.</li>
 *   <li>{@code /<token>/frame.jpg}: the newest frame once (503 before the first one).</li>
 *   <li>{@code /<token>/media/<id>.jpg|mp4}: a saved photo or clip, with byte ranges, so a
 *   {@code <video>} can seek.</li>
 * </ul>
 * Request parsing, the token check, ranges and the response heads are {@link GlassesCore}, shared
 * byte for byte with the iOS twin and run against the vector table.
 */
final class GlassesServer {
    /** At most this many connections are served at once; the next one is answered 503. */
    static final int MAX_CONNECTIONS = 8;
    /** A live connection waits this long for a new frame before it checks whether to end. */
    private static final long LIVE_WAIT_MS = 1000;

    private final ServerSocket socket;
    private final File mediaDir;
    final String token;
    private final AtomicInteger open = new AtomicInteger();
    private final Object lock = new Object();
    private byte[] frame;
    private long seq;
    /** Bumped by {@link #endLive}; a live connection opened under an older epoch ends. */
    private long epoch;
    private volatile boolean closed;

    private GlassesServer(ServerSocket socket, File mediaDir, String token) {
        this.socket = socket;
        this.mediaDir = mediaDir;
        this.token = token;
    }

    static GlassesServer start(File mediaDir) throws IOException {
        ServerSocket s = new ServerSocket();
        s.setReuseAddress(true);
        s.bind(new InetSocketAddress(InetAddress.getByName("127.0.0.1"), 0), 16);
        GlassesServer server = new GlassesServer(s, mediaDir, GlassesCore.newToken(new SecureRandom()));
        Thread t = new Thread(server::acceptLoop, "nx-glasses-http");
        t.setDaemon(true);
        t.start();
        return server;
    }

    int port() {
        return socket.getLocalPort();
    }

    /** http://127.0.0.1:<port>/<token> */
    String base() {
        return "http://127.0.0.1:" + port() + "/" + token;
    }

    /** Makes jpeg the newest frame. Called on the frame thread. */
    void publish(byte[] jpeg) {
        synchronized (lock) {
            frame = jpeg;
            seq++;
            lock.notifyAll();
        }
    }

    /** The newest frame and its sequence number (0 and null before the first). */
    Object[] latest() {
        synchronized (lock) {
            return new Object[] {seq, frame};
        }
    }

    /** Ends every open live connection (the stream stopped) and forgets the last frame. */
    void endLive() {
        synchronized (lock) {
            epoch++;
            frame = null;
            lock.notifyAll();
        }
    }

    void close() {
        closed = true;
        endLive();
        try {
            socket.close();
        } catch (IOException ignored) {
            // Closing a listening socket that already failed: nothing to release.
        }
    }

    private void acceptLoop() {
        while (!closed) {
            Socket c;
            try {
                c = socket.accept();
            } catch (IOException e) {
                if (closed) return;
                continue;
            }
            if (open.incrementAndGet() > MAX_CONNECTIONS) {
                open.decrementAndGet();
                refuse(c);
                continue;
            }
            Thread t = new Thread(() -> {
                try {
                    serve(c);
                } finally {
                    open.decrementAndGet();
                    try {
                        c.close();
                    } catch (IOException ignored) {
                        // The peer already went away.
                    }
                }
            }, "nx-glasses-conn");
            t.setDaemon(true);
            t.start();
        }
    }

    private static void refuse(Socket c) {
        try {
            c.getOutputStream().write(ascii(GlassesCore.responseHead(503, null, 0, null)));
        } catch (IOException ignored) {
            // A refused peer that already left.
        } finally {
            try {
                c.close();
            } catch (IOException ignored) {
                // Nothing left to release.
            }
        }
    }

    private void serve(Socket c) {
        try {
            c.setSoTimeout(10000);
            c.setTcpNoDelay(true);
            String head = readHead(c.getInputStream());
            OutputStream out = c.getOutputStream();
            GlassesCore.Request req = head == null ? null : GlassesCore.parseRequest(head);
            if (req == null) {
                out.write(ascii(GlassesCore.responseHead(400, null, 0, null)));
                return;
            }
            if (req.method.equals("OPTIONS")) {
                out.write(ascii(GlassesCore.responseHead(204, null, -1, null)));
                return;
            }
            GlassesCore.Target t = GlassesCore.classify(req.path, token);
            boolean body = req.method.equals("GET");
            switch (t.kind) {
                case "live":
                    live(out, body);
                    return;
                case "frame": {
                    byte[] f = (byte[]) latest()[1];
                    if (f == null) {
                        out.write(ascii(GlassesCore.responseHead(503, null, 0, null)));
                        return;
                    }
                    out.write(ascii(GlassesCore.responseHead(200, "image/jpeg", f.length, null)));
                    if (body) out.write(f);
                    return;
                }
                case "media":
                    media(out, t, req.range, body);
                    return;
                case "forbidden":
                    out.write(ascii(GlassesCore.responseHead(403, null, 0, null)));
                    return;
                default:
                    out.write(ascii(GlassesCore.responseHead(404, null, 0, null)));
            }
        } catch (IOException ignored) {
            // The page closed the connection (an <img> replaced, a <video> seeking): nothing to do.
        }
    }

    private void live(OutputStream out, boolean body) throws IOException {
        out.write(ascii(GlassesCore.liveHead()));
        out.flush();
        if (!body) return;
        long mine;
        long sent;
        synchronized (lock) {
            mine = epoch;
            sent = frame == null ? seq : seq - 1;
        }
        while (!closed) {
            byte[] f;
            synchronized (lock) {
                while (!closed && epoch == mine && seq == sent) {
                    try {
                        lock.wait(LIVE_WAIT_MS);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        return;
                    }
                }
                if (closed || epoch != mine) return;
                f = frame;
                sent = seq;
            }
            if (f == null) continue;
            out.write(ascii(GlassesCore.partHead(f.length)));
            out.write(f);
            out.write(ascii("\r\n"));
            out.flush();
        }
    }

    private void media(OutputStream out, GlassesCore.Target t, String rangeHeader, boolean body) throws IOException {
        File f = new File(mediaDir, t.id + "." + t.ext);
        if (!f.isFile()) {
            out.write(ascii(GlassesCore.responseHead(404, null, 0, null)));
            return;
        }
        long total = f.length();
        long[] r = GlassesCore.range(rangeHeader, total);
        if (r == null) {
            out.write(ascii(GlassesCore.responseHead(416, null, 0, "bytes */" + total)));
            return;
        }
        boolean partial = r[2] == 1;
        String type = t.ext.equals("mp4") ? "video/mp4" : "image/jpeg";
        long length = r[1] - r[0] + 1;
        out.write(ascii(GlassesCore.responseHead(partial ? 206 : 200, type, length,
                partial ? "bytes " + r[0] + "-" + r[1] + "/" + total : null)));
        if (!body || length <= 0) return;
        try (RandomAccessFile raf = new RandomAccessFile(f, "r")) {
            raf.seek(r[0]);
            byte[] buf = new byte[64 * 1024];
            long left = length;
            while (left > 0) {
                int n = raf.read(buf, 0, (int) Math.min(buf.length, left));
                if (n < 0) break;
                out.write(buf, 0, n);
                left -= n;
            }
        }
    }

    /** The request head (up to the blank line, without it), or null when it is too long or cut off. */
    static String readHead(InputStream in) throws IOException {
        ByteArrayOutputStream b = new ByteArrayOutputStream(512);
        int state = 0;
        while (b.size() <= GlassesCore.MAX_HEAD + 4) {
            int c = in.read();
            if (c < 0) return null;
            b.write(c);
            // \r\n\r\n
            if ((state == 0 || state == 2) && c == '\r') state++;
            else if ((state == 1 || state == 3) && c == '\n') state++;
            else state = c == '\r' ? 1 : 0;
            if (state == 4) {
                byte[] all = b.toByteArray();
                return new String(all, 0, all.length - 4, StandardCharsets.ISO_8859_1);
            }
        }
        return null;
    }

    private static byte[] ascii(String s) {
        return s.getBytes(StandardCharsets.US_ASCII);
    }
}
```

## Using it from your web app

```javascript
const NX = "extension://metaglasses/";
const call = (route, params = {}) => {
  const q = new URLSearchParams(params).toString();
  window.despia = NX + route + (q ? "?" + q : "");
};

const img = document.querySelector("#glasses");   // <img id="glasses">
const clip = document.querySelector("#clip");     // <video id="clip" controls playsinline>

window.onGlassesState = (s) => {                  // event: stream state changed
  if (s.state !== "streaming") img.removeAttribute("src");
};
window.onGlassesRegistration = (r) => {          // event: the Meta AI app answered
  if (r.registration === "registered") call("permission", { prompt: true });
};
window.onGlassesMedia = (m) => {                  // event: a clip finished (or failed)
  if (m.kind === "mp4" && !m.failed) clip.src = m.url;
};

window.onGlassesPermission = (r) => {
  if (!r.ok) return console.error(r.code, r.error);   // permission_denied: Bluetooth refused
  if (r.data.camera === "unknown") return call("register"); // not registered yet: opens Meta AI once
  if (r.data.camera === "granted") call("start", { quality: "medium", fps: 24 });
};
window.onGlassesRegister = (r) => { if (!r.ok) console.error(r.code, r.error); };
window.onGlassesStart = (r) => {
  if (!r.ok) return console.error(r.code, r.error);
  img.src = r.data.live;                          // http://127.0.0.1:<port>/<token>/live.mjpg
};
window.onGlassesPhoto = (r) => { if (r.ok) document.querySelector("#photo").src = r.data.url; };
window.onGlassesRecordStart = (r) => { if (!r.ok) console.error(r.code, r.error); };
window.onGlassesStop = () => img.removeAttribute("src");

// Bluetooth (the Android 12+ dialog), then registration in Meta AI, then the camera, then the stream:
call("permission", { prompt: true });
// Later: call("photo"); call("record_start", { seconds: 5 }); call("stop");
// Without glasses, in development: call("mock", { enabled: true }) once Bluetooth is granted.
```

| Event          | Callback                 | Scope      | When                                                              |

## How the picture reaches the page

The extension runs a small HTTP server on `127.0.0.1`, on a port the system picks, under a fresh random token path. `start` answers with `data.live`, and your page sets it as an `<img src>`.

- `/<token>/live.mjpg` is a stream of JPEG frames. Each connection gets the newest frame only, so a slow page skips frames and never falls behind.
- `/<token>/frame.jpg` is the newest frame once.
- `/<token>/media/<id>.jpg` and `/<token>/media/<id>.mp4` are the saved photos and clips. They support byte ranges, so a `<video src>` can seek in a clip.

Each frame costs one JPEG encode on the phone. A clip is H.264 MP4 written from the same frames.

If your page cannot load `http://127.0.0.1` (this is not verified in every web view), poll `frame` and draw `"data:image/jpeg;base64," + r.data.jpeg` when `r.data.seq` changed. Read saved media with `media_read?id=<id>&kind=mp4&chunk=<n>`: each chunk is 49152 bytes until `data.eof` is true.

## Registration and permissions

The app registers once with the Meta AI app. That opens Meta AI, which returns to your app's own URL scheme. The glasses camera permission is asked in Meta AI too. Call `permission` with `prompt: true` first, then `register` when `camera` is `unknown`, then `permission` again.

## Platform limits

- **Meta DAT 1.1.0.** A session created before registration fails and is reported as `registration_required`. Unregistering stops every session. A refused stream start reports a hot device, a low battery or the peak power limit as `device_limit`. A photo times out after 10 seconds.
- **Photo.** `photo` captures from the running stream. Meta's standalone photo capture is experimental and not yet allowed in production releases, so this sample does not use it.
- **Clips.** DAT offers no video recording, so the clip is the app's own encoding of the stream's frames.
- **iOS.** Meta's toolkit needs iOS 17.2.
- **Android.** Meta's toolkit needs Android 10 (API 29).
- **Not verified.** The plane order of Android's uncompressed frames, that an https page may load `http://127.0.0.1` in `<img>` and `<video>` in every web view, Developer Mode on iOS with an empty `TeamID`, and everything on real glasses.
