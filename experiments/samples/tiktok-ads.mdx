Source repository: [TikTok Ads](https://github.com/despia-legacy/tiktok-ads). This repository is private; access is required to read or copy its files.

A native advertiser SDK extension using TikTok App Events SDK 1.7.2 on iOS and 1.7.1 on Android, independently of AppsFlyer. It sends custom and standard events and purchases through the SDK. It does not display Pangle ads.

For the Despia V3 runtime. First-party V4 support comes through the new package registry.

## Web frameworks and app builders

Call the Despia V3 extension bridge from your app's JavaScript. It is independent
of the web UI framework: React, Vue, Svelte, Next.js, TanStack and HTML5 apps use
the same `window.despia = "extension://..."` interface.

For Lovable, Base44, Replit or another app builder, use a project that lets you
add custom JavaScript and serve the extension files at their exact HTTPS paths.
You can edit those files with Claude Code, Codex, Cursor or your usual editor.
The native extension must be approved and included in the installed Despia V3
app. A browser preview alone does not provide native extension features.

## Install

1. Copy manifest.json, ios/ and android/ into public/despia/tiktokads/ in your web app.
2. Add "tiktokads" to public/despia/extensions.json: `{ "extensions": ["tiktokads"] }`. This minimal index requires the no-app-identity runtime change in the build; legacy indexes remain compatible.
3. Replace the native configuration placeholders in TikTokAdsExtension.swift and TikTokAdsExtension.java with the app SDK configuration provided by TikTok. Never embed a server-side Marketing API credential. Do not log this configuration or put it in a page URL.
4. Approve the source and dependency closure, rebuild and install the native app.

The Swift package is pinned to commit 2a3a35560c2c0547f74869c58160946e29c0932c. Android uses com.github.tiktok:tiktok-business-android-sdk:1.7.1 from JitPack, plus the vendor's Android lifecycle, Billing and Install Referrer dependencies. Approval fetches and pins them. Automatic event logging, payment tracking and enhanced data postback are requested off in native configuration. No SDK is initialized on app launch by this extension.

## Call from the page

```javascript
window.onTiktokadsConfigureResult = result => console.log(result);
window.despia = "extension://tiktokads/configure";
// Wait for successful configuration, then apply the user's collection choice:
window.despia = "extension://tiktokads/consent?enabled=true";
window.despia = "extension://tiktokads/event?name=LaunchAPP";
window.despia = "extension://tiktokads/purchase?amount=12.50&currency=USD"
  + "&properties=" + encodeURIComponent(JSON.stringify({content_id: "example-product"}));
```

Wait for each successful answer before the next dependent call. Default output is `window.tiktokads<Route>Result` and callback `onTiktokads<Route>Result`. All answers use the standard V3 envelope.

| Route | Parameters | Successful data |
| --- | --- | --- |
| configure | None | configured, enabled. Initializes SDK with transmission disabled. |
| status | None | configured, enabled, sdk |
| consent | enabled boolean required | iOS: enabled. Android: configured, enabled. |
| event | name required, optional properties JSON object string, value numeric string, event_id string | accepted: true |
| purchase | amount numeric string and currency uppercase three-letter code required, optional properties, event_id | accepted: true. Uses TikTok Purchase event. |
| user | Optional id, omit to log out | accepted: true |
| flush | None | accepted: true. Requests SDK transmission, not a server receipt. |

Properties are a JSON object and preserve nested ecommerce objects, arrays and null values for the SDK. The route limits the encoded properties string to 4096 characters. Explicit value and amount parameters must be finite numbers. Read manifest.json for each string length limit. Errors include not_configured, already_configured, consent_required, bad_request, sdk_error and busy during initialization. iOS can time out if initialization finishes after the bridge deadline. No event is started after that late initialization answer.

## Privacy and platform behavior

This extension never requests ATT. TikTok's current iOS SDK does not automatically show that dialog. Use Despia's existing trackingconsent:// call separately, with the tracking_usage purpose description enabled in the native build. Collection consent is separate from ATT. Reapply the app's saved choice after every process launch.

The adapter refuses bridge event calls while disabled. iOS uses TikTok setTrackingEnabled(false), which can cache SDK events for later according to the vendor API. Android has startTrack but no matching stopTrack API in 1.7.1. On a false consent call this adapter destroys its SDK instance and requires configure again before collection resumes. Neither path erases events already transmitted or guarantees cancellation of an in-flight request. Review the vendor's collection and retention behavior for your app.

Android Advertising ID collection is disabled in this starter. Native configuration can be adapted to the app's permitted collection model and base app Advertising ID permission. The SDK includes Android install referrer support. iOS SKAdNetwork support uses the SDK's defaults; configure campaign conversion settings in TikTok. Avoid competing conversion-value owners or duplicated purchase events.

SKAdNetworkItems under ios.app.info_plist is customer-editable and starts empty. This Apple key describes the ad networks used by a source app displaying ads. It is not an Android setting or a substitute for the advertised app's SDK and campaign configuration. Add only current identifiers your own integration requires, then approve and rebuild. Purpose strings stay owned by Despia's permission configuration.

An existing initialized TikTok SDK is left to its original integration: configure returns already_configured. Adapt the native code if the app deliberately shares that SDK. The SDK can use app-wide lifecycle and exception handling, so test it with the app's other native integrations.

Current V3 iOS target is 16.6 and later. Android module minSdk24 and compileSdk36. Billing is a vendor dependency, not a purchase UI supplied by this extension; review its merged permission and the base billing configuration during approval.
