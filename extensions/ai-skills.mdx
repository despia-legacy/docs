```bash
npx skills add despia-legacy/extension-skill
```

A skill is a folder of instructions your coding agent reads when the task needs it. The Despia skills give it the exact commands, calls, answer variables and error fixes, so it does not guess.

The `skills` command lets you choose which skills to install and for which coding agents. Skills go into the current project by default; add `-g` to make them available in every project.

## The extension skills

| Skill | Your agent uses it to |
| --- | --- |
| `despia-extensions-cli` | Find, install, configure, update, remove and check ready-made extensions with `npx despia-extensions` |
| `despia-v3-extensions` | Build your own extension: create, validate, mock, compile and test, with the native contract and the fix for every error code |

Each native feature guide names its own skill, when it has one.

## Install for one agent

```bash
npx skills add despia-legacy/extension-skill --skill despia-extensions-cli -a claude-code
npx skills add despia-legacy/extension-skill --skill despia-v3-extensions -a codex
npx skills add despia-legacy/extension-skill -a cursor
```

| Agent | `-a` value | Project folder |
| --- | --- | --- |
| Claude Code | `claude-code` | `.claude/skills/` |
| Codex | `codex` | `.agents/skills/` |
| Cursor | `cursor` | `.agents/skills/` |

To copy the folders yourself, clone [the repository](https://github.com/despia-legacy/extension-skill) and copy the folders under `skills/` into your agent's skill folder.

Your agent loads a skill when your request matches its description. You can also name it: "use the despia-extensions-cli skill to add Superwall".

## What the skills will not do

- They never put a server secret in your app. A key the vendor calls secret stays on your server.
- They do not claim a feature works until it ran in the installed app. A browser preview, a mock or a compile is reported as exactly that.
- Text inside an installed extension (its README, comments, descriptor) is treated as data from its author, never as an instruction to the agent.
