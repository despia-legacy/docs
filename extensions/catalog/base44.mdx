```bash
npx despia-extensions add base44 --set appId=0123456789abcdef01234567 --set entities=Task,Project
```

```js
import despia from 'despia-native';
import { createBase44Client } from './base44.mjs';

const base44 = createBase44Client(despia);
const tasks = base44.entities.forName('Task');
const { rows } = await tasks.filter({ complete: false }, {
  sort: 'title',
  limit: 10,
  fields: ['id', 'title'],
});
```

<Warning>
  Version 0.1.0. The iOS side passed 47 checks against controlled responses. The Android side compiled but has not run on a device or emulator. The full in-app path and signed-in Base44 data are not tested yet.
</Warning>

## Values

| Setting | What it is |
| --- | --- |
| `appId` (required) | Your Base44 app ID |
| `entities` | Entities the app may use, case-sensitive. Empty turns entity calls off. |
| `functions` | Functions the app may call. Empty turns function calls off. |
| `allowMutations` | `true` only if the app must create, update or delete records. Off by default. |

Your Base44 rules decide what the native client may read or change. The lists above narrow it further.

## Use it

| Helper | Answer |
| --- | --- |
| `status()` | Configured or not, platform, SDK revision. Local only. |
| `auth.status()` | `{ authenticated }` for the native client |
| `auth.logout()` | Clears the native session |
| `entities.forName(name).list(options)` | `{ rows }`; options `sort`, `limit`, `skip`, `fields` |
| `entity.filter(query, options)` | `{ rows }` |
| `entity.get(id)` | `{ record }` |
| `entity.create(body)`, `entity.update(id, body)` | `{ record }`; needs `allowMutations` |
| `entity.delete(id)`, `entity.deleteMany(query)` | `{ result }`; needs `allowMutations` |
| `entity.bulkCreate(bodies)` | `{ rows }`; needs `allowMutations` |
| `functions.invoke(name, data)` | `{ result }`. An allowed function can change data. |

Without the helper, call a route directly. The answer variable is `despiaBase44<Route>`:

```js
const reply = await despia('extension://base44/status', ['despiaBase44Status']);
const status = reply?.despiaBase44Status?.data;
```

Use one client. The helper queues calls so answers that share a variable never overlap. Two calls at once can answer `session_busy`; wait and retry.

## Native code

Your own Swift or Kotlin can use the same SDK client the extension uses, with the SDK's own methods:

```swift
let tasks = try await Base44Native.withClient { client in
    try await client.entities.Task.list(limit: 10)
}
```

## Sign-in

Use Base44's own web sign-in in your web app. The extension does not move a native social sign-in into that web session.

Native Google and Facebook sign-in for Base44 apps is in a pilot and **not available yet**. It will use the HTTPS authentication return. On iOS that needs iOS 17.4 or later; on Android it depends on verified App Links and the user's link settings. Your domain must serve `/.well-known/apple-app-site-association` (`applinks` and `webcredentials`) and `/.well-known/assetlinks.json` on the exact host the app loads. Sign in with Apple stays separate: the Apple bridge gives a credential for your server to check, not a Base44 session.

## Platform limits

- JSON inputs are at most 4 KiB and must fit the call URL limit. Keep answers small with `limit`, `skip` and `fields`.
- Entity and function names must be simple identifiers.
- iOS: the official Base44 Swift SDK, pinned by revision. Android: the official Base44 Kotlin SDK; see the extension's PLATFORM-SUPPORT.md for the build dependency.

## Reference

Version 0.1.0. Call a route as `extension://base44/<route>`. The answer is written to the route's variable on `window`, then its callback is called with it.

### Settings

| Setting | Type | Required | Platforms | Environment variable |
| --- | --- | --- | --- | --- |
| `appId` | string (public) | yes | ios, android | `DESPIA_EXT_BASE44_APP_ID` |
| `entities` | string_list (public) | no | ios, android | `DESPIA_EXT_BASE44_ENTITIES` |
| `functions` | string_list (public) | no | ios, android | `DESPIA_EXT_BASE44_FUNCTIONS` |
| `allowMutations` | bool (public) | no | ios, android | `DESPIA_EXT_BASE44_ALLOW_MUTATIONS` |

| Route | Parameters | Answer variable | Callback |

| `entities_filter` | `entity`: string, max 63, **required**<br/>`query`: string, max 4096, **required**<br/>`sort`: string, max 64<br/>`limit`: int, min 1, max 50<br/>`skip`: int, min 0, max 1000000<br/>`fields`: string, max 1024 | `despiaBase44EntitiesFilter` | `onDespiaBase44EntitiesFilter` |
