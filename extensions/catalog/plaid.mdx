```bash
npx despia-extensions add plaid
```

```js
import despia from 'despia-native';

const opened = await despia('extension://plaid/open', ['plaidOpen']);
const reply = opened.plaidOpen;
if (reply === undefined) throw new Error('The native route did not answer');
if (!reply.ok) throw new Error(`${reply.code}: ${reply.error}`);
const sessionId = reply.data.session_id;
```

The app's native code asks **your server** for a Link token, opens Plaid Link, and sends the public token back to your server to exchange. No Plaid token ever reaches your web page. The page sees only the state of the operation and your own connection ID.

<Warning>
  Source preview. The Android side compiled against the pinned Plaid SDK. The iOS build and a live Plaid Sandbox flow are not tested yet.
</Warning>

## Install

1. Run `npx despia-extensions add plaid`.
2. Write the native backend provider in two files: `AppPlaidBackend.swift` and `AppPlaidBackend.java`. They call your authenticated HTTPS backend to create a Link token and exchange the public token. `update` never replaces these two files. Until you write them, `open` answers `not_configured`.
3. Rebuild and install the app.

| Setting | What it is |
| --- | --- |
| `plaidClientId` | **Secret.** Server only, as `PLAID_CLIENT_ID` |
| `plaidSecret` | **Secret.** Server only, as `PLAID_SECRET` |

The extension has no public values. Both Plaid credentials stay on your server.

## Wait for the result

`open` returns at once; it does not wait for the bank screen. Poll `status` until the state ends:

```js
for (let attempt = 0; attempt < 120; attempt += 1) {
  const result = await despia(`extension://plaid/status?id=${encodeURIComponent(sessionId)}`, ['plaidStatus']);
  const state = result.plaidStatus?.data?.state;
  if (['linked', 'cancelled', 'failed', 'exchange_uncertain'].includes(state)) break;
  await new Promise(resolve => setTimeout(resolve, 1000));
}
```

| Route | Parameters | Answer variable | Answer |
| --- | --- | --- | --- |
| `open` | none | `plaidOpen` | The new operation, normally `fetching_token`. `not_configured`, `busy` or `unavailable` before it starts. |
| `status` | optional `id` | `plaidStatus` | The operation's state. An unknown id answers `not_found`. |

States: `idle`, `fetching_token`, `waiting_activity`, `presenting`, `exchanging`, `linked`, `cancelled`, `failed`, `exchange_uncertain`.

- Show "linked" only after your server's exchange returned a connection ID (`connection_id`).
- `exchange_uncertain` means your server may already have exchanged the token. Check with your server before offering another attempt.
- The `changed` event calls `onPlaidChanged` with `state` and `session_id`. It is a notification; `status` is the truth.

## Bank sign-in through OAuth

- iOS: register the exact HTTPS Universal Link redirect in the Plaid Dashboard, add the matching Associated Domain, serve the AASA file, and send that redirect in your Link token request.
- Android: register your package name in the Plaid Dashboard and send `android_package_name` in the token request. Do not send an iOS `redirect_uri` for Android.

See [Plaid's OAuth guide](https://plaid.com/docs/link/oauth/). The return from the bank app is not tested in an installed app yet.

## Platform limits

- iOS: LinkKit 7.4.0, iOS 15 or later. A Link session cannot resume after the app process ends; start again through your server.
- Android: Plaid `sdk-core` 6.4.0, minSdk 25. After a process restart, an exchange in progress becomes `exchange_uncertain` and others become `failed` with `session_lost`.
- Standard Item-based bank linking only. Not included: Identity Verification, Headless, Layer, Embedded Link, update mode.
- Waiting for a token, a host screen or the exchange each times out after 30 seconds. The bank screen has no time limit.

## Reference

Version 1.0.0. Call a route as `extension://plaid/<route>`. The answer is written to the route's variable on `window`, then its callback is called with it.

Server secrets (never set in your web project; keep them on your server):

- `plaidClientId` (Plaid client ID): keep it in your server's environment as `PLAID_CLIENT_ID`.
- `plaidSecret` (Plaid secret): keep it in your server's environment as `PLAID_SECRET`.

### Routes

| Route | Parameters | Answer variable | Callback |
| --- | --- | --- | --- |
| `open` | none | `plaidOpen` | `onPlaidOpenResult` |
| `status` | `id`: string, max 36 | `plaidStatus` | `onPlaidStatusResult` |

### Events

| Event | Callback | Scope |
| --- | --- | --- |
| `changed` | `onPlaidChanged` | document |

| Android | minSdk 25 |
