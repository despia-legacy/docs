```bash
npx despia-extensions add supabase --set url=https://abcdefghijklmnop.supabase.co --set publishableKey=sb_publishable_xxxxxxxx
```

```js
import despia from 'despia-native';
import { createSupabaseClient } from './supabase.mjs';

const supabase = createSupabaseClient(despia);
const status = await supabase.status();
if (status.configured) {
  const page = await supabase.select('catalog', { columns: 'id,title', order: 'id.asc' });
  const subscription = await supabase.subscribe('catalog');
  const updates = await supabase.events(0);
  console.log(page.rows, updates.events);
  await supabase.unsubscribe(subscription.subscription_id);
}
```

The extension reads public-schema data with the anonymous role and notifies you when rows change. It does not sign users in and does not write.

## Values

| Setting | What it is |
| --- | --- |
| `url` (required) | Your project URL, `https://<ref>.supabase.co` |
| `publishableKey` (required) | The `sb_publishable_...` key. It ships in your app. |
| `serviceRoleKey` | **Secret.** Refused. Keep it on your server as `SUPABASE_SERVICE_ROLE_KEY`. |

Before you ship, set row-level security and grants for exactly the data anonymous users may read. For change notifications, add the table to the `supabase_realtime` publication. See Supabase's [API keys](https://supabase.com/docs/guides/getting-started/api-keys) and [Postgres Changes](https://supabase.com/docs/guides/realtime/postgres-changes) guides.

## Routes

| Helper | Route | Answer |
| --- | --- | --- |
| `status()` | `status` | Configured or not, platform, key mode, subscription count. No network check. |
| `select(table, options)` | `select` | `rows`, `limit`, `offset`. 20 rows by default, up to 50 per page, up to 16 columns, one sort column. |
| `subscribe(table)` | `subscribe` | `subscription_id` and `connected` once the server acknowledges. Up to 8 subscriptions. |
| `events(after)` | `events` | Change type and table name with a cursor. The last 128 are kept. `gap` means your cursor is out of range. |
| `unsubscribe(id)` | `unsubscribe` | `removed` |

Answer variables are `despiaSupabase<Route>`. Change events are notifications only: after one, query again. After a `gap`, a reconnect or an app restart, query again.

## Platform limits and what was tested

- A successful answer body is at most 64 KiB.
- Not included: sign-in sessions, writes, local caching, offline sync. For data that lives on the device, use the SQLite native feature.
- iOS: Supabase Swift 2.55.7. Android: Supabase Kotlin 3.4.1, Android 7.0 or later.
- Tested on the Android API 37 emulator against a live test project: 84 checks passed, including reads under row-level security and INSERT and UPDATE notifications.
- Tested on the iOS simulator: reads under row-level security and INSERT notifications. In one run an UPDATE notification did not arrive within 12 seconds. Plan to query again rather than rely on every notification.
- Hosted builds are not tested.

## Reference

Version 1.0.0. Call a route as `extension://supabase/<route>`. The answer is written to the route's variable on `window`, then its callback is called with it.

### Settings

| Setting | Type | Required | Platforms | Environment variable |
| --- | --- | --- | --- | --- |
| `url` | https_url (public) | yes | ios, android | `DESPIA_EXT_SUPABASE_URL` |
| `publishableKey` | string (public) | yes | ios, android | `DESPIA_EXT_SUPABASE_PUBLISHABLE_KEY` |

Server secrets (never set in your web project; keep them on your server):

- `serviceRoleKey` (Supabase secret or service-role key): keep it in your server's environment as `SUPABASE_SERVICE_ROLE_KEY`.

### Routes

| Route | Parameters | Answer variable | Callback |
| --- | --- | --- | --- |
| `status` | none | `despiaSupabaseStatus` | `onDespiaSupabaseStatus` |
| `select` | `table`: string, max 63, **required**<br/>`columns`: string, max 1024<br/>`order`: string, max 68<br/>`limit`: int, min 1, max 50<br/>`offset`: int, min 0, max 1000000 | `despiaSupabaseSelect` | `onDespiaSupabaseSelect` |
| `subscribe` | `table`: string, max 63, **required** | `despiaSupabaseSubscribe` | `onDespiaSupabaseSubscribe` |
| `unsubscribe` | `subscription_id`: string, max 36, **required** | `despiaSupabaseUnsubscribe` | `onDespiaSupabaseUnsubscribe` |
| `events` | `after`: int, min 0, max 2147483647 | `despiaSupabaseEvents` | `onDespiaSupabaseEvents` |
