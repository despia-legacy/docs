```bash
npx despia-extensions <command> [options]
```

The binary is also installed as `dext`. It needs Node 18.17 or later. `doctor` and `validate` use Python 3.9 or later to run the build's own validator.

## Install and manage

| Command | Does |
| --- | --- |
| `init [--public-dir <dir>] [--web-dir <dir>]` | Writes `despia.extensions.json`, the lock and `<public>/despia/extensions.json` with no extensions. Finds `public/`, or `static/` for SvelteKit. `add` runs it for you. `--web-dir` is where helper files for your app's source go (default `src/despia-extensions/` when `src/` exists, else `despia-extensions/`). |
| `add <name>[@version] \| github:owner/repo[#ref] \| <path>` | Fetches the extension, checks its tree hash, copies it into `<public>/despia/<id>/`, adds the id to the index, writes your values, updates the lock, and checks the result before anything is written. Refuses a 9th extension (the build's own limit). Without the required values it still installs and reports `needs_config` with the exact keys missing. `--with <name>` and `--bind <capability>=<id>` resolve [dependencies](/extensions/build/dependencies). |
| `remove <name>... [--keep-config] [--force \| --with-dependents] [--prune]` | Removes the folder, index entry, values and lock entry. Refuses (exit 5, `DX-G006`) when another installed extension requires it. |
| `list [--available]` | Installed: id, version, latest, config state (`ok`, `needs_config`), modified files. `--available` lists what you can install. |
| `info <name>` | Settings (never values), server secrets, routes, permissions, SDK pins and docs. |
| `update [name[@version]]... [--major] [--force] [--overwrite \| --keep-mine]` | Moves to the latest version this CLI release knows, and reports what changes for the app first. A breaking version needs `--major`. With no name, each extension moves to the newest version every installed dependent accepts. |
| `config get [name[.key]] [--reveal]` | Reads values. They are shown by their last 4 characters unless you pass `--reveal`. |
| `config set <name>.<key>=<value>...` | Writes values and re-writes where they land. |
| `config unset <name>.<key>...` | Clears values. |
| `sync [--overwrite]` | Re-writes the served folder from the config file and the lock. Safe to repeat. |
| `doctor [--hosted <url>] [--strict]` | Project, index, values, dependency graph, file integrity, secrets, the build's own validator for iOS and Android, and with `--hosted` the files your deployed site serves. Without Python 3.9 the validator step is skipped; `--strict` makes that a failure. `--ios-bundle-id` and `--android-package` check with your real identity. |

### Values

| Option | Meaning |
| --- | --- |
| `--set key=value` | A value; repeatable. With several extensions in one command, `--set <id>.<key>=value`. |
| `--values <file.json>` | Values from a JSON file |
| `--from-env` | Values from `DESPIA_EXT_<ID>_<KEY>`, for example `DESPIA_EXT_METAADS_APP_ID` |
| `--public-value <id.key> --confirm-public "this value ships in my app"` | Accept a public value that looks like a secret. A setting declared `secret` can never be set. |

### Global options

| Option | Meaning |
| --- | --- |
| `--json` | One JSON object on stdout: `{"ok", "command", "changed", "extensions", "missing", "errors", "next", ...}` |
| `--dry-run` | The same report; nothing is written |
| `--yes`, `--no-input` | Accepted for scripts. No command ever prompts. |
| `--cwd <dir>` | Run as if in that folder |
| `--registry <path\|url>` | Use another registry file |
| `--offline` | Cache only (`DESPIA_EXT_CACHE`, default `~/.cache/despia-extensions`) |
| `--validator local\|off\|hosted:<url>` | Where `doctor` runs the build's validator |
| `--strict` | A skipped validator step fails `doctor` |

## Build your own

| Command | Does |
| --- | --- |
| `create <id> [--spec f.json] [--route r] [--event e] [--config c]` | Writes a new extension repository. Also `--platform ios,android`, `--android-lang kotlin\|java`, `--dir`, `--title`, `--description`, `--license <SPDX>`. See [Create an extension](/extensions/build/create). |
| `gen [--check]` | Rewrites the generated route tables, typed config, web helpers and types. `--check` fails when one is stale. |
| `route add "<name>[:p=type,...]" [--timeout <ms>]` | Declares a route in `manifest.json`, adds its contract file, and regenerates |
| `event add <name>[:app]` | Declares an event and regenerates |
| `config add <key>:<type>[:public\|secret][!]` | Declares a setting and regenerates |
| `validate [--platform ios\|android]` | Installs the extension into a scratch web app with example values and runs `doctor` and the build's validator on it |
| `check` | Static checks without a toolchain: generated files, contract files, mock, and the Core/Platform split |
| `mock` | Prints the snippet that runs this extension in the browser through the mock bridge |
| `setup [android\|swift]` | Reports what this machine has for each tier and how to get the rest. Never installs anything. |
| `compile android\|ios [--via local\|github]` | Compiles the native code. Each file is reported with the check it actually got. |
| `test [--tier contract,android,swift,ios-sim]` | Runs the tiers this machine can run. A tier it cannot run is reported, never counted as passed. |
| `next` | The one next step for this repository, from what has passed at its current files |
| `explain <code>` | What a `DX-` or `NX-` code means and what to do |

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | ok |
| 1 | internal error (`DX-X001`) |
| 2 | usage, including an update that needs `--major` |
| 3 | validation failed, including `doctor` findings, `needs_config`, a compile error and a failed test |
| 4 | secret refused |
| 5 | local changes block the action: use `--overwrite` or `--keep-mine`; also a refused `remove` or `update` of a required extension |
| 6 | network or registry, including a tree-hash mismatch and a private source without `GH_TOKEN` |
| 7 | a toolchain this step needs is missing here (`setup` names it) |
| 8 | a hosted run was asked for; this CLI does not start one |

## Error codes

CLI codes start with `DX-`. Codes from the build's validator start with `NX-` and pass through unchanged. `npx despia-extensions explain <code>` prints the same text as this table for any `DX-` or `NX-` code.

### Usage

| Code | Means | Fix |
| --- | --- | --- |
| `DX-U001` | Usage error | See --help for the command. |
| `DX-U002` | Unknown or not installed extension | Run list --available, or list. |
| `DX-U003` | The extension has no such setting | Run info <name> for its settings. |
| `DX-U004` | A major update needs --major | Read the breaking changes listed, then pass --major. |
| `DX-U005` | Unknown code | Run explain with no code for the count; codes are DX- (this CLI) or NX- (the runtime validator). |

### Project

| Code | Means | Fix |
| --- | --- | --- |
| `DX-P001` | No despia.extensions.json here or above | Run init, or add (which runs it). |
| `DX-P002` | despia.extensions.json is malformed | Restore publicDir and extensions. |
| `DX-P003` | The new files could not be moved into place; nothing changed | Check disk space and permissions, then retry. |

### Values

| Code | Means | Fix |
| --- | --- | --- |
| `DX-V001` | The value is not an integer | Give a whole number. |
| `DX-V002` | The value does not match the expected form | Use the form of the example. |
| `DX-V003` | The value matches a secret pattern | Public values only; keep secrets on the server. |
| `DX-V004` | A required setting has no value | config set <name>.<key>=<value>. |
| `DX-V005` | A REPLACE_ placeholder is still in a file | Set the value with config set. |

### Secrets

| Code | Means | Fix |
| --- | --- | --- |
| `DX-S001` | A server secret was given where it would ship in the app | Keep it on your server; the extension reads it there. |
| `DX-S002` | A file matches a secret pattern and would ship in the app | Remove the secret from the file. |
| `DX-S003` | A file setting names a credentials or dot file (.env, .npmrc, a key or certificate) | Point the setting at the file the extension needs; credentials never go into public/. |

### Registry and sources

| Code | Means | Fix |
| --- | --- | --- |
| `DX-R001` | A descriptor, sink kind or registry is unreadable | Fix the file the message names. |
| `DX-R002` | The fetched or local source differs from what was recorded | Run update, or check the source was not changed under the same version. |
| `DX-R003` | The source has no manifest.json or no clear extension id | Add despia.extension.json with id and root. |
| `DX-R004` | The archive or tree holds links or oversized entries | Remove symbolic links from the extension. |
| `DX-R005` | A settings file failed the schema: a descriptor, the project config, the lock, an installed copy or an authoring repository | Fix the field the error names; every path in these files is a plain relative path inside its folder (no .., no leading /, no backslash, no dotfile where a served file is meant). |
| `DX-R006` | A path leaves its folder (.., an absolute path or a link that points outside) | Name a file inside the project or the extension folder; the CLI never reads or writes outside it. |

### Network

| Code | Means | Fix |
| --- | --- | --- |
| `DX-N001` | A network or registry fetch was refused or failed | Check the URL and the network. |
| `DX-N002` | A github: source was not found | Check owner/repo, or set GH_TOKEN for a private repository. |
| `DX-N003` | The source is not cached and --offline is set | Run once without --offline. |

### Local changes

| Code | Means | Fix |
| --- | --- | --- |
| `DX-L001` | Local changes in installed files block the write | Keep them with --keep-mine, or replace with --overwrite. |

### Doctor

| Code | Means | Fix |
| --- | --- | --- |
| `DX-D001` | The extension is not installed in this web app | Run add first. |
| `DX-D002` | A served file the lock records is missing | Run sync, or update the extension. |
| `DX-D003` | A file sits in the served folder that no listed extension owns | Move it out of public/despia/, or add its extension with this CLI. |
| `DX-D004` | The runtime validator step was skipped | Install Python 3.9 or later; --strict makes this a failure. |
| `DX-D005` | The hosted check needs https on port 443 | Use the https URL of your deployed site. |
| `DX-D006` | The deployed site answers HTML where JSON is expected | Your host serves a single-page-app fallback for public/despia/; serve the folder as static files. |
| `DX-D007` | files.json is missing or differs from the served folder | Run sync; it writes public/despia/files.json, which the build's signer reads for every directory a manifest names. |
| `DX-D010` | The runtime validator failed without a known code | Read the message; run with DESPIA_EXT_DEBUG=1 for details. |
| `DX-D011` | The hosted validator could not be reached | Retry, or use --validator local. |

### Dependencies

| Code | Means | Fix |
| --- | --- | --- |
| `DX-G001` | An installed version is outside a range another extension requires | Update one of them, or pin with name@version. |
| `DX-G002` | A required capability has no provider installed | Add a provider (--with <name>). |
| `DX-G003` | Several providers offer a capability and none is chosen | Choose one with --bind capability=extension. |
| `DX-G004` | The served index order or the lock graph differs from the resolved graph | Run sync. |
| `DX-G005` | The requirements form a cycle | Remove one of the requirements in the cycle. |
| `DX-G006` | remove was refused: other extensions require this one | Use --with-dependents, or --force to leave them broken. |
| `DX-G007` | update was refused: the new version breaks a requirement | Update the dependents too, or --force. |
| `DX-G008` | A uses/capability version does not match | Install a provider whose capability version is in range. |
| `DX-G009` | requires or provides is malformed | Fix the declaration the message names. |
| `DX-G010` | The registry's copy of requires/provides differs from the fetched source | The registry row is stale; report it, or install from github: directly. |
| `DX-G011` | A required extension is missing or not in the registry | Add it, or install it from github:. |
| `DX-G012` | A --bind value is malformed or names a non-provider | Write --bind capability=extension with an installed provider. |

### Configuration and toolchains

| Code | Means | Fix |
| --- | --- | --- |
| `DX-K001` | A configuration sink points at something the extension's files do not have | The extension's descriptor and files disagree; report it to its author. |
| `DX-K002` | A sink pointer does not start with / | Fix the descriptor's sink. |
| `DX-K003` | A boolean sink got a value that is not true or false | Set true or false. |
| `DX-K101` | The Android toolchain is missing | Run setup android, use the devcontainer, or push for the linux job. |
| `DX-K102` | Swift is missing | Install Swift, use the devcontainer, or set DESPIA_EXT_SWIFT_IMAGE with Docker. |
| `DX-K103` | The iOS SDK compile needs macOS with Xcode | Run it on a Mac, or read the macos job of the workflow. |
| `DX-K104` | Hosted runs are not started by this CLI yet | Push; the repository's workflow runs the jobs. |
| `DX-K200` | A compile or test run failed without a parsed diagnostic | Open the log file the result names. |
| `DX-K201` | Kotlin or Java compile error | Fix the file and line named; a missing route branch means a route lacks its handler. |
| `DX-K202` | Swift compile error | Fix the file and line named; a non-exhaustive switch means a route lacks its handler. |

### Authoring

| Code | Means | Fix |
| --- | --- | --- |
| `DX-A001` | No despia.extension.json here or above | Run create <id>, or cd into the extension repository. |
| `DX-A002` | despia.extension.json or the extension's manifest.json is missing, not JSON, or names a route, parameter, event or callback outside the bridge grammar | Fix the file; gen and every authoring command read both, and a name that reaches generated code must match the grammar the error names. |
| `DX-A003` | create was pointed at a folder that already holds other files | Choose --dir or an empty folder; create never overwrites your files. |
| `DX-A010` | A --route, --event or --config flag is malformed | See create --help for the flag grammar. |
| `DX-A011` | The --spec file is not a valid authoring spec | Fix the field the message names. |
| `DX-A012` | The route, event or setting is already declared | Pick another name, or edit the existing declaration. |
| `DX-A013` | The extension does not target that platform | Add the platform to manifest.json, or compile the platform it targets. |
| `DX-A014` | DESPIA_EXT_CLI_REF is not a full commit | Set it to the 40-character commit of despia-legacy/despia-extensions the new repository should run, or unset it. |

### Contract checks

| Code | Means | Fix |
| --- | --- | --- |
| `DX-C101` | A generated file is stale or missing | Run gen. Never edit a file that says GENERATED. |
| `DX-C110` | A route has no contract vector | Add tests/contract/<route>.json with at least one case. |
| `DX-C111` | A contract vector names a route manifest.json does not declare | Rename the vector or declare the route (route add). |
| `DX-C112` | A contract vector is malformed | Write {"route", "cases": [{"name", "params", "expect": {"ok": true, "data"?} \| {"code"}}]}. |
| `DX-C120` | despia.extension.json describes a route or event manifest.json does not declare | Remove the entry or declare the route or event. |
| `DX-C140` | The mock handlers file does not load, or answers an undeclared route | Fix mock/<id>.mock.js; it exports an object of route functions. |
| `DX-C150` | A Core or Entry file imports an Apple UI framework or android.* | Move that code into the Platform file so the rest builds and tests on Linux. |

### Tests

| Code | Means | Fix |
| --- | --- | --- |
| `DX-T001` | A test failed | Read the test name and message; the result file holds the run. |
| `DX-T002` | A test tier ran no test | Add tests (tests/contract, tests/android, tests/ios). |

### Internal

| Code | Means | Fix |
| --- | --- | --- |
| `DX-X001` | Internal error | Run with DESPIA_EXT_DEBUG=1 and report the stack. |
