Add the Despia Docs connector to Bolt. It lets Bolt read this documentation, so it writes correct Despia code for your app.

<EnvNew />

<Info>
  Checked 2026-10-09 against Bolt's [Connect to MCP servers](https://support.bolt.new/building/using-bolt/connect-mcp) guide. Bolt connects **remote** MCP servers by URL, so it uses the Despia Docs MCP.
</Info>

## Add the Despia Docs connector

<Steps>
  <Step title="Open connectors">
    On the bolt.new home page, click **+** in the chat box, then **Connectors**, then **Manage connectors**.
  </Step>
  <Step title="Add a custom MCP server">
    Choose **Custom MCP server** and fill in:

    - **Name:** `Despia Docs`
    - **URL:** `https://setup.despia.com/mcp`
    - **Transport type:** **HTTP**
    - **Authentication:** **None** (the Docs MCP is public and read-only)

    Turn on **Auto-enable for all projects** if you want it in every project.
  </Step>
  <Step title="Connect">
    Click **Connect**, then ask: "Using the Despia docs, add native push notifications to this app with the Despia V4 Modern API (`window.dsx`)."
  </Step>
</Steps>
