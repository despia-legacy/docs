Bolt connects **remote** MCP servers by URL, so it uses the Despia Docs MCP. The hosted Despia MCP for your account is [coming soon](/mcp/overview#hosted-despia-mcp-with-oauth-coming-soon).
</Info>

## Add the Despia Docs MCP

<Steps>
  <Step title="Open connectors">
    On the bolt.new home page, click **+** in the chat box, then **Connectors**, then **Manage connectors**.
  </Step>
  <Step title="Add a custom MCP server">
    Choose **Custom MCP server** and fill in:

    - **Name:** `Despia Docs`
    - **URL:** `https://setup.despia.com/mcp`
    - **Transport type:** **HTTP**
    - **Authentication:** **None** (the Docs MCP is public and read-only)

    Turn on **Auto-enable for all projects** if you want it in every project.
  </Step>
  <Step title="Connect">
    Click **Connect**, then ask: "Using the Despia docs, add native push notifications to this app with `despia-native`."
  </Step>
</Steps>
