## Add the Despia Docs MCP

<Steps>
  <Step title="Open plugins">
    Go to [chatgpt.com/plugins](https://chatgpt.com/plugins) and click **+**, then **Add custom MCP server**.
  </Step>
  <Step title="Describe the server">
    - **Name:** `Despia Docs`
    - **Description:** `Search and read the Despia documentation.`
  </Step>
  <Step title="Connect">
    Under **Connection**, enter `https://setup.despia.com/mcp`. Choose **no authentication**: the Docs MCP is public and read-only.
  </Step>
  <Step title="Create it">
    Confirm the warning about custom servers, then create it. Enable **Despia Docs** in a chat from the tools menu and ask: "Using Despia Docs, how do I add in-app purchases to my web app?"
  </Step>
</Steps>
