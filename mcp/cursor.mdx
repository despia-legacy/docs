## Add both servers

Create `.cursor/mcp.json` in your Despia project (for this project) or `~/.cursor/mcp.json` (for every project):

```json .cursor/mcp.json
{
  "mcpServers": {
    "despia-docs": {
      "url": "https://setup.despia.com/mcp"
    },
    "despia": {
      "type": "stdio",
      "command": "npx",
      "args": ["despia", "mcp"]
    }
  }
}
```

- `despia-docs` is the remote [Docs MCP](/mcp/overview#despia-docs-mcp-live): no sign-in.
- `despia` is the local [toolchain MCP](/mcp/overview#despia-toolchain-mcp-despia-mcp). `npx despia mcp` uses the CLI installed in your project. In the global file, use `["-y", "-p", "@despia-native/cli", "despia", "mcp", "--dir", "${workspaceFolder}"]` instead.
- Sign in to Despia once in Cursor's terminal: `npx despia login`.

Open Cursor's settings to see both servers and their tools. If one fails, the **Output** panel has **MCP Logs**.

<Note>
  `@despia-native/cli` is published as 0.1.0. Until it is on npm, the global `npx -y -p @despia-native/cli` form installs a placeholder.
</Note>
