<Info>
  Checked 2026-10-09 against each tool's official documentation, linked below. Browser-based tools take the remote **Despia Docs MCP** (`https://setup.despia.com/mcp`, no sign-in). Tools that run on your computer can also run the **Despia toolchain MCP** (`npx despia mcp`); see the [overview](/mcp/overview).
</Info>

## v0

[v0 MCP documentation](https://v0.app/docs/MCP). In the prompt box, open **+**, choose **MCPs**, and add a custom server:

- **URL:** `https://setup.despia.com/mcp`
- **Authentication:** **No Auth**

v0 only connects remote servers, so the toolchain MCP is not available there.

## Zed

[Zed MCP documentation](https://zed.dev/docs/ai/mcp). Add both servers under `context_servers` in Zed's settings (or **Settings**, **AI**, **MCP Servers**, **Add Server**):

```json settings.json
{
  "context_servers": {
    "despia-docs": {
      "url": "https://setup.despia.com/mcp"
    },
    "despia": {
      "command": "npx",
      "args": ["-y", "-p", "@despia-native/cli", "despia", "mcp", "--dir", "/path/to/your/project"]
    }
  }
}
```

## Gemini CLI

[Gemini CLI MCP documentation](https://geminicli.com/docs/tools/mcp-server/). In `.gemini/settings.json` in your project (or `~/.gemini/settings.json`):

```json .gemini/settings.json
{
  "mcpServers": {
    "despia-docs": {
      "httpUrl": "https://setup.despia.com/mcp"
    },
    "despia": {
      "command": "npx",
      "args": ["despia", "mcp"]
    }
  }
}
```

Gemini CLI uses `httpUrl` for streamable HTTP servers; `url` means the older SSE transport.

## Cline

[Cline remote server documentation](https://docs.cline.bot/mcp/connecting-to-a-remote-server). Open the **MCP Servers** icon, **Configure**, **Remote Servers**, and add `Despia Docs` with URL `https://setup.despia.com/mcp` and transport **Streamable HTTP**. Add the toolchain MCP as a local server with command `npx` and args `despia mcp` in your project.

## GitHub Copilot coding agent

[Extend the coding agent with MCP](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/coding-agent/extend-coding-agent-with-mcp). In your repository, **Settings**, **Copilot**, **MCP servers**, add:

```json MCP configuration
{
  "mcpServers": {
    "despia-docs": {
      "type": "http",
      "url": "https://setup.despia.com/mcp",
      "tools": ["*"]
    }
  }
}
```

The coding agent does not support remote servers that need OAuth; the Docs MCP needs no sign-in, so it works there.
