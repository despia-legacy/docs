## Add both servers

Create `.vscode/mcp.json` in your Despia project. Note that VS Code uses a top-level `servers` key:

```json .vscode/mcp.json
{
  "servers": {
    "despia-docs": {
      "type": "http",
      "url": "https://setup.despia.com/mcp"
    },
    "despia": {
      "type": "stdio",
      "command": "npx",
      "args": ["despia", "mcp"]
    }
  }
}
```

Or run **MCP: Add Server** from the Command Palette and enter the same values.

- `despia-docs` is the remote [Docs MCP](/mcp/overview#despia-docs-mcp): no sign-in.
- `despia` is the local [toolchain MCP](/mcp/overview#despia-toolchain-mcp-despia-mcp), the CLI installed in your project. Sign in to Despia once in the terminal: `npx despia login`.
- VS Code asks you to trust a workspace's servers before it starts them; in restricted mode it does not start them.

Check with **MCP: List Servers**.
