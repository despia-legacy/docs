FFmpeg is an optional native extension for processing audio and video on the device. Installing it is your own choice and at your own risk. The usage documentation for this extension is being written and will be added to this page.

## Open-source licenses

<Accordion title="Open-source licenses and corresponding source">

### 1. What is in an app that installs the extension

An app that installs this extension contains FFmpegKitNext 9.0.2 and FFmpeg n9.0.2, licensed under the GNU Lesser General Public License, version 3 or later (LGPL-3.0-or-later). The builds are made with `--enable-version3` and without `--enable-gpl` and without `--enable-nonfree`. The `libavcodec` license string of the built libraries is `LGPL version 3 or later`. An app without the extension contains none of this code.

This software uses code of FFmpeg (https://ffmpeg.org) licensed under the LGPLv3 and its source can be downloaded from the links below. Copyright (c) the FFmpeg developers. FFmpegKitNext copyright (c) 2018-2026 Taner Sener and the FFmpegKitNext contributors.

The libraries are linked as dynamic libraries: dynamic frameworks (`.framework` inside an XCFramework, embedded in the app) on iOS and shared objects (`.so` files inside the app) on Android. You can replace them with your own build of the same source, see section 6.

H.264, HEVC and AAC encoding use the encoders of the device's operating system (VideoToolbox and AudioToolbox on iOS, MediaCodec on Android). No x264, x265, or FFmpeg native AAC encoder is built.

### 3. Build configuration

Upstream passes `--enable-version3 --enable-shared --disable-static --enable-small --disable-programs --disable-autodetect` to FFmpeg's configure. Our build appends one allow-list (patch 0001 below) that starts from `--disable-everything` and enables only the listed components, so nothing else is compiled. The lines below are generated from our allow-list file by the build script `flags.py` (section 5).

Upstream script options. Android: `./android.sh --api-level=24 --enable-lib-android-media-codec --enable-lib-android-zlib --no-ffmpeg-kit-protocols <libs> --disable-arch-arm-v7a --disable-arch-x86 -f`. iOS: `./ios.sh --xcframework --enable-lib-ios-videotoolbox --enable-lib-ios-audiotoolbox --enable-lib-ios-zlib --no-ffmpeg-kit-protocols <libs> --disable-arch-arm64-mac-catalyst --disable-arch-arm64e --disable-arch-x86-64 --disable-arch-x86-64-mac-catalyst -f`. `<libs>` is empty for `min` and `--enable-lib-freetype --enable-lib-fribidi --enable-lib-harfbuzz --enable-lib-libass` for `captions`. The refused flags are `--enable-gpl`, `--enable-nonfree`, `--enable-libx264`, `--enable-libx265`, `--enable-libfdk-aac`, `--enable-network` and the other GPL, non-free and network options in the allow-list file; the build stops if the line contains one.

### 5. Build scripts, in full

The build runs on a Linux x86_64 host with Android NDK r27d for Android and on macOS with Xcode for iOS. Run `build.sh <android|ios> <variant> <work-dir> <out-dir>`. `UPSTREAM` pins the commits:

**build.sh**

```bash
#!/bin/bash
# Builds the FFmpegKitNext artefact for one platform and variant from the upstream tag in UPSTREAM, with the Despia
# component allow-list (allowlist.json) and writes the proof files beside it. Runs on a build host, never the Pro:
#   android: an x86_64 Linux build host, Android NDK r27d, JDK 17, the Android SDK
#   ios:     a macOS build host, Xcode, autoconf/automake/libtool/pkg-config/nasm (brew) on the build host
# usage: build.sh <android|ios> <variant> <work-dir> <out-dir>
# Writes <out-dir>: <platform>-<variant>.zip, components.json, strings.txt, SHA256SUMS, build.log, source/ (the
# source offer bundle: the upstream trees and every fetched dependency source as built).
set -euo pipefail
PLATFORM=${1:?platform} VARIANT=${2:?variant} WORK=${3:?work dir} OUT=${4:?out dir}
HERE=$(cd "$(dirname "$0")" && pwd)
. "$HERE/UPSTREAM"
mkdir -p "$WORK" "$OUT"
KIT="$WORK/kit"
if [ ! -d "$KIT/.git" ]; then git clone -q "$repo" "$KIT"; fi
git -C "$KIT" rev-parse -q --verify "refs/tags/$tag" >/dev/null || git -C "$KIT" fetch -q --tags
git -C "$KIT" checkout -q -f "$tag"
[ "$(git -C "$KIT" rev-parse HEAD)" = "$commit" ] || { echo "build: tag $tag is not commit $commit"; exit 2; }
if [ "$PLATFORM" != ios ]; then git -C "$KIT" clean -fdxq -e src -e prebuilt; fi   # ios: keeps the pre-generated autotools files (below)
for p in "$HERE"/patches/*-"$PLATFORM".patch; do git -C "$KIT" apply --check "$p" && git -C "$KIT" apply "$p"; done
export DESPIA_COMPONENT_FLAGS; DESPIA_COMPONENT_FLAGS=$(python3 "$HERE/flags.py" "$PLATFORM" "$VARIANT")
case "$DESPIA_COMPONENT_FLAGS" in *enable-gpl*|*enable-nonfree*|*libx264*|*libx265*) echo "build: refused flag in the allow-list"; exit 2;; esac
export DESPIA_LIBS; DESPIA_LIBS=$(python3 "$HERE/flags.py" "$PLATFORM" "$VARIANT" libs)   # external libraries of the variant, empty for min
cd "$KIT"
case "$PLATFORM" in
  android)
    : "${ANDROID_SDK_ROOT:?}" "${ANDROID_NDK_ROOT:?}"
    export HOST_CC=${HOST_CC:-gcc}   # the upstream script needs a build-machine C compiler
    ./android.sh --api-level=24 --enable-lib-android-media-codec --enable-lib-android-zlib --no-ffmpeg-kit-protocols $DESPIA_LIBS \
      --disable-arch-arm-v7a --disable-arch-x86 --jobs="$(nproc)" -f ;;
  ios)
    # The macOS build hosts ship no autoconf, automake, libtool, pkg-config, GNU sed, meson or ninja. The captions variant builds
    # external libraries from git sources (autoreconf/autogen and meson), so those tools must be on PATH (the build host
    # installs them from release tarballs and pip, see the HANDOFF). For the min variant, which has no external library, the
    # older shim path remains: the autotools outputs of apple/ are generated on Linux (pregen-autotools.sh), autoreconf is a
    # no-op and pkg-config only answers the zlib flag queries.
    if ! command -v autoreconf >/dev/null 2>&1 || ! command -v pkg-config >/dev/null 2>&1; then
      [ -n "$DESPIA_LIBS" ] && { echo "build: variant $VARIANT needs real autoconf and pkg-config on PATH"; exit 2; }
      [ -f "$KIT/apple/configure" ] || { echo "build: apple/configure missing; run pregen-autotools.sh on Linux first"; exit 2; }
      SHIM="$WORK/shim"; mkdir -p "$SHIM"
      printf '#!/bin/sh\nexit 0\n' > "$SHIM/autoreconf"
      printf '#!/bin/sh\ncase "$*" in *--exists*|*--modversion*|*--atleast*) exit 1;; esac\nexit 0\n' > "$SHIM/pkg-config"
      chmod +x "$SHIM/autoreconf" "$SHIM/pkg-config"; export PATH="$SHIM:$PATH"
    fi
    # GNU sed 4.9 (gnu.org, sha256 6e226b73...5181) built from source on the build host: the stock BSD sed is refused by the upstream script.
    export SED=${SED:-$WORK/../tools/gnu/bin/sed}
    ./ios.sh --xcframework --enable-lib-ios-videotoolbox --enable-lib-ios-audiotoolbox --enable-lib-ios-zlib \
      --no-ffmpeg-kit-protocols $DESPIA_LIBS --disable-arch-arm64-mac-catalyst --disable-arch-arm64e --disable-arch-x86-64 \
      --disable-arch-x86-64-mac-catalyst --jobs="$(sysctl -n hw.ncpu)" -f ;;
  *) echo "build: unknown platform"; exit 2;;
esac
cp build.log "$OUT/build.log"
echo "build: upstream script finished; collect the proof files with collect.sh"
```

**flags.py**

```python
#!/usr/bin/env python3
"""Prints the DESPIA_COMPONENT_FLAGS configure line for one platform and variant, from allowlist.json.
usage: flags.py <android|ios> <variant> [libs]
  without "libs": the DESPIA_COMPONENT_FLAGS line; with "libs": the upstream external-library options of the variant
  (--enable-lib-<name>), each checked against permitted_libs of allowlist.json."""
import json, os, sys
HERE = os.path.dirname(os.path.abspath(__file__))
def flags(platform, variant):
    a = json.load(open(os.path.join(HERE, "allowlist.json")))
    v = a["variants"][variant][platform]
    out = ["--disable-network", "--disable-everything"]
    for kind, opt in (("protocols", "protocol"), ("demuxers", "demuxer"), ("muxers", "muxer"), ("decoders", "decoder"),
                      ("encoders", "encoder"), ("parsers", "parser"), ("bsfs", "bsf"), ("filters", "filter")):
        out.append("--enable-%s=%s" % (opt, ",".join(v[kind])))
    return " ".join(out)
def libs(platform, variant):
    a = json.load(open(os.path.join(HERE, "allowlist.json")))
    out = []
    for lib in a["variants"][variant][platform].get("libs", []):
        if lib not in a.get("permitted_libs", {}):
            raise SystemExit("flags: library %s is not in permitted_libs" % lib)
        out.append("--enable-lib-" + lib)
    return " ".join(out)
if __name__ == "__main__":
    print(libs(sys.argv[1], sys.argv[2]) if len(sys.argv) > 3 and sys.argv[3] == "libs" else flags(sys.argv[1], sys.argv[2]))
```

**collect.sh**

```bash
#!/bin/bash
# Collects the proof files of one built artefact. Runs on the build host, after build.sh.
# usage: collect.sh <android|ios> <variant> <kit-dir> <out-dir>
# Writes <out-dir>: <platform>-<variant>.<aar|xcframeworks.zip>, strings.txt (configuration string, license strings),
# sizes.txt (per architecture, raw and compressed), checks.txt (T-LINK/T-16K/T-POLICY facts), SHA256SUMS.
set -euo pipefail
PLATFORM=${1:?} VARIANT=${2:?} KIT=${3:?} OUT=${4:?}
mkdir -p "$OUT"; X="$OUT/x"; mkdir -p "$X"
conf() { strings -a "$1" | grep -E -- '--enable-version3' | head -1; }
case "$PLATFORM" in
  android)
    AAR=$(ls "$KIT"/prebuilt/bundle-android-aar-*/com/arthenica/ffmpeg-kit-next/*/ffmpeg-kit-next-*.aar)
    cp "$AAR" "$OUT/android-$VARIANT.aar"; (cd "$X" && unzip -oq "$OUT/android-$VARIANT.aar")
    : > "$OUT/strings.txt"; : > "$OUT/sizes.txt"; : > "$OUT/checks.txt"
    for abi in arm64-v8a armeabi-v7a x86_64; do
      u=$(ls "$X"/jni/$abi/libavutil*.so); c=$(ls "$X"/jni/$abi/libavcodec*.so)
      { echo "[$abi] $(strings -a "$c" | grep -m1 'libavcodec license')"; echo "[$abi] config: $(conf "$u")"; } >> "$OUT/strings.txt"
      python3 - "$X/jni/$abi" "$abi" >> "$OUT/sizes.txt" <<'P'
import sys,os,zipfile,io
d,abi=sys.argv[1:3]; raw=0; b=io.BytesIO()
with zipfile.ZipFile(b,'w',zipfile.ZIP_DEFLATED,compresslevel=9) as z:
    for f in sorted(os.listdir(d)):
        raw+=os.path.getsize(os.path.join(d,f)); z.write(os.path.join(d,f),f)
print(f"{abi} raw={raw} deflate={len(b.getvalue())}")
P
      for so in "$X"/jni/$abi/*.so; do
        echo "$abi $(basename "$so") loadalign=$(readelf -lW "$so" | awk '/LOAD/{print $NF}' | sort -u | tr '\n' ',') needed=$(readelf -d "$so" | awk '/NEEDED/{gsub(/[\[\]]/,"",$NF);printf "%s,",$NF}')" >> "$OUT/checks.txt"
      done
    done ;;
  ios)
    : > "$OUT/strings.txt"; : > "$OUT/sizes.txt"; : > "$OUT/checks.txt"
    for xc in "$KIT"/prebuilt/bundle-apple-xcframework-ios*/*.xcframework; do
      n=$(basename "$xc" .xcframework)
      for slice in "$xc"/*/; do
        s=$(basename "$slice"); bin=$(ls "$slice"/*.framework/"$n" 2>/dev/null | head -1); [ -n "$bin" ] || continue
        echo "[$n/$s] $(lipo -archs "$bin") size=$(stat -f %z "$bin")" >> "$OUT/sizes.txt"
        strings -a "$bin" | grep -E "license: |--enable-version3" | cut -c1-4000 | sed "s|^|[$n/$s] |" >> "$OUT/strings.txt" || true
        echo "[$n/$s] $(otool -L "$bin" | tail -n +2 | awk '{printf "%s,",$1}')" >> "$OUT/checks.txt"
      done
    done
    (cd "$(ls -d "$KIT"/prebuilt/bundle-apple-xcframework-ios*)" && ditto -c -k --keepParent . "$OUT/ios-$VARIANT.xcframeworks.zip") ;;
esac
if grep -Eq -- 'enable-gpl|enable-nonfree|libx264|libx265|GPL version 2|(^|[^L])GPL version 3' "$OUT/strings.txt"; then echo "collect: GPL or nonfree marker in the build"; exit 3; fi
( cd "$OUT" && f=$(ls *.aar *.zip 2>/dev/null) && { shasum -a 256 $f 2>/dev/null || sha256sum $f; } > SHA256SUMS )
echo "collect: ok"; cat "$OUT/sizes.txt"
```

#!/bin/bash
# Generates the autotools outputs of apple/ (configure, ltmain.sh, Makefile.in, aclocal.m4, ...) for the iOS build on a Linux host
# that has autoconf, automake and libtool, from the pinned upstream tag, then prints the sha256 of every generated file.

### 6. Replacing the library

The FFmpeg libraries are not part of your app's main program: on iOS they are separate dynamic frameworks embedded in the app, and on Android they are separate `.so` files inside the app. To use a modified version, rebuild the libraries from the source above with the scripts above (change the source or the patches as you like), then replace the corresponding frameworks or `.so` files in your app project and build and sign the app again with your own certificate. Our component allow-list and configuration are the ones shown in section 3.
