```javascript
import despia from 'despia-native';

const doc = {
  widgetJson: 1,
  kind: 'widget',
  id: 'steps',
  state: { steps: 0, goal: 10000 },
  layouts: [{
    root: { type: 'stack', dir: 'v', gap: 6, children: [
      { type: 'text', text: { var: 'state.steps' }, style: { font: 'largeTitle', 'font-weight': 700 } },
      { type: 'progress', shape: 'linear', value: { var: 'state.steps' }, to: { var: 'state.goal' } }
    ] }
  }]
};

window.onWidgetJsonResult = (r) => console.log(r.call, r.ok ? r.data : r.code);
despia('widgetjson://widget/set?id=steps&doc=' + encodeURIComponent(JSON.stringify(doc)));
despia('widgetjson://widget/state?id=steps&patch=' + encodeURIComponent(JSON.stringify({ steps: 4200 })));
```

Widget JSON draws real native widgets from a JSON document: SwiftUI in WidgetKit on iOS, Glance on Android. The document holds the layout and its state; formulas in the layout read the state, so an update sends only new state, never a new picture. One document format serves home screen widgets, lock screen widgets, and Live Activities on iOS and Live Updates on Android.

It is built into the app. An app built before it was added needs a new build. On iOS the widget uses the same widget target as [Home Widgets](/native-features/home-widgets), so follow its [iOS setup](/native-features/home-widgets#ios-setup-apple-developer-and-despia) once. On Android the app's widget appears in the launcher's widget list only after your page first sets a widget document.

## Calls and answers

Every call is `widgetjson://<route>?<parameters>`. Encode every value with `encodeURIComponent`; documents, state and patches are JSON text.

Every call answers on `window.onWidgetJsonResult(result)`, and the last answer stays in `window.widgetJsonResult`:

```javascript
{ rid, call, ok, data }              // success
{ rid, call, ok: false, code, error, path }  // failure; path points into the document
```

Pass your own `rid` to match an answer to its call. Some answers carry `notes`, such as `android_inexact_alarms`.

| Route | Parameters | Does |
| --- | --- | --- |
| `capabilities` | | What this device supports: `platform`, `os`, `families`, `features`, `widgets`, `activities`, `interactive`, `pushToStart`, `push`, and on Android `pin` and `liveUpdates` |
| `validate` | a document (below), optional `state`, `attrs` | `{ ok, errors }` for this platform, without storing anything |
| `widget/set` | `id`, a document, optional `state`, `default` | Stores a widget document and redraws |
| `widget/state` | `id`, `state` (replace) or `patch` (merge) | Changes the state and redraws |
| `widget/timeline` | `id`, `entries` | Schedules state patches (below) |
| `widget/refresh` | `id`, `url`, `every` (minutes, at least 15) | Fetches state from your server in the background; without `url` it stops |
| `widget/get` | `id` | The stored document and state |
| `widget/clear` | `id` | Deletes the document and its state |
| `widget/reload` | | Redraws every widget |
| `widget/installed` | | The widgets on the home screen and the stored document ids |
| `widget/pin` | | Android: asks the launcher to add the widget |
| `activity/start` | `id`, a document, `attrs`, `state`, optional `name`, `staleAfter`, `relevance` | Starts a Live Activity or Live Update |
| `activity/update` | `id`, `state` or `patch`, optional `alert`, `staleAt` | Updates it |
| `activity/end` | `id`, optional `state`, `dismissal` | Ends it |
| `activity/list` | | The running activities |
| `tokens` | | The push tokens (below) |
| `token-sink` | `url`, optional `bearer`; or `clear=1` | Sends every push token to your server |
| `events` | optional `ack` | Taps and changes queued while no page was open |
| `permission` | | `notifications` (`granted`, `denied`, `prompt`) and `activities` |
| `settings` | | Opens the app's notification settings |

A document is passed one of three ways: `doc` (the JSON document, or `{"name": "..."}` for a stored one, or `{"z": "..."}` for raw DEFLATE in base64), `name`, or `src` (an `https://` URL the app fetches). An `id` is 1 to 64 letters, digits, `_`, `.` or `-`.

The home screen shows one widget for your app. It draws the document set with `default=1`, else the first one stored.

### Order of updates

Every local call is stamped with the device clock in milliseconds, unless you pass `seq`. An update older than the last one for the same widget or activity answers `stale` (or `duplicate`) and is dropped, so a late push never overwrites newer state.

## The document

```json
{
  "widgetJson": 1,
  "kind": "widget",
  "id": "habit",
  "state": { "streak": 4, "doneToday": false },
  "actions": { "markToday": { "set": { "doneToday": { "!": { "var": "state.doneToday" } } } } },
  "layouts": [
    { "for": ["small"], "widgetUrl": "/habits", "root": { "type": "text", "text": { "var": "state.streak" } } },
    { "root": { "type": "toggle", "value": { "var": "state.doneToday" }, "action": "markToday", "label": "Today" } }
  ],
  "styles": { "secondary": { "font": "subheadline", "color": "secondary" } }
}
```

| Field | Meaning |
| --- | --- |
| `widgetJson` | `1` |
| `kind` | `widget` or `activity` |
| `id` | The document's own name |
| `state` | The starting state; formulas read it as `state.*` |
| `layouts` | A list of `{ for, when, root, widgetUrl, background, margins }`. The first layout whose `for` lists the current family and whose `when` is true is drawn; a layout without `for` serves every family |
| `styles` | Named styles, used by an element's `class` |
| `actions` | Named actions for buttons, toggles and taps |
| `summary` | Activities: `icon`, `largeIcon`, `title`, `text`, `subText`, `progress`, `countdownTo`, `countUpFrom`, `chip`, `actions`, `open`. Android draws its Live Update from this |
| `staleAfter`, `relevance`, `dismissal`, `tint`, `android` | Activities: when it goes stale, its rank, how it leaves, its colours and Android options |
| `requires`, `meta` | The renderer version the document needs, and your own data |

### Families

| Kind | Families |
| --- | --- |
| `widget` | `small`, `medium`, `large`, `extraLarge`; iOS also `accessoryCircular`, `accessoryRectangular`, `accessoryInline` (lock screen) |
| `activity` | `lockScreen`, `island.compactLeading`, `island.compactTrailing`, `island.minimal`; iOS also `island.expanded.leading`, `island.expanded.trailing`, `island.expanded.center`, `island.expanded.bottom`, `supplemental.small` |

`small`, the accessory families and the compact and minimal island families have one tap target: use the layout's `widgetUrl`, not a `link`.

| `type` | Fields |
| --- | --- |
| `text` | `text`, `format` |
| `image` | `symbol` (`{ "ios": "<SF Symbol>", "android": "<Material Symbol>" }`), `src`, `svg`, `asset`, `fit` (`cover`, `contain`, `fill`), `rendering` (`original`, `template`, `accented`, `desaturated`, `accentedDesaturated`, `fullColor`), `label` |
| `stack` | `dir` (`h`, `v`, `z`), `children`, `align`, `gap` |
| `spacer` | `size` |
| `divider` | |
| `progress` | `shape` (`linear`, `circular`), `value`, `from`, `to`, `label` |
| `gauge` | `value`, `min`, `max`, `label`, `current`, `shape` (`circular`, `linear`), `capacity` |
| `timer` | `to`, `from`, `display` (`timer`, `relative`, `offset`), `showsHours` |
| `date` | `value`, `display` (`time`, `date`) |
| `link` | `to`, `children` |

`align` is one of `start`, `center`, `end`, `top`, `bottom`, `topStart`, `topEnd`, `bottomStart`, `bottomEnd`.

### Images

An `image` shows a symbol, an `https://` picture (`src`), inline SVG text (`svg`) or a bundled `asset`. A widget and an activity cannot load the network when they draw, so the app does it for them:

- When a document, a state, a timeline or a push arrives, the app downloads every `https://` image the document can show, in every family, for the current state and each timeline state. It keeps the picture, so the widget draws at once.
- Inline `svg` is turned into a picture by the app the same way, at its own aspect ratio.
- A picture is scaled down to at most 1200 pixels on its longest side. A download larger than 16 MB is not used, and neither is a response other than 200 OK. A picture that could not be fetched is simply not drawn; the widget keeps working.
- A `src` that is not `https://` is refused with `bad_url`. This is checked by `validate`.
- A summary `icon` or `largeIcon` of an activity takes the same forms as `image`: `{ "src": "https://..." }`, `{ "svg": "<svg ...>" }`, `{ "asset": "..." }` or `{ "symbol": { "ios": "bag.fill", "android": "shopping_bag" } }`. Each value inside it may be a formula, the object itself is not one. A `background.image.src` is fetched the same way.

Use a `src` that changes in state (`{ "src": { "var": "state.img" } }`) to change a picture with a push. The new picture is fetched when the push arrives.

## Formulas

Any value in a document can be a formula, computed from the state each time the widget is drawn. A layout's `when` reads only `env` and `now`; a `list`'s `max` reads only `env`. These rules are the same on iOS and Android.

### Where formulas are allowed

A formula may stand anywhere a document takes a value:

- every element field except the structural ones (`type`, `id`, `class`, `only`, `children`, `template`, `empty`, `as`);
- an element's `if`;
- a layout's `when`, `widgetUrl`, `background` and `margins`;
- a `list`'s `items` and `max`;
- every style value;
- every `summary` field of an activity.

### Values

A value is one of six types: null, boolean, number (an IEEE 754 double), text (a string), array, or object.

- No value is ever converted to another type. `{"==": [1, "1"]}` is false, and `{"+": ["1", 2]}` is an error. Use `cat` to join text.
- Only `false` and `null` count as false (for `if`, `and`, `or`, `!`, `filter`, `some`, `all`, `count`, a layout's `when` and an element's `if`). `0`, `""`, `[]` and `{}` count as true.
- Equality (`==`, `!=`, `in` on an array) is deep. Two values are equal only when they have the same type and the same content. Object key order does not matter. `0` equals `-0`.
- Text is compared and measured in Unicode code points, never in UTF-16 units. `len`, `substr`, `pad`, `trim`, `split` with `""`, `<` on text and `sort` on text all work on code points.
- A number becomes text in one canonical way, used by `cat`, `join`, `pad`, `plural` and the `#` of `plural`:
  - an integer below 10^15 in size is written as plain digits;
  - any other number is written with 15 significant digits, rounded half away from zero on its exact value, in plain notation (never `1e21`), with trailing zeros removed.
- No operator returns NaN or an infinity. A result that would be one is the error `non_finite`. A result of `-0` is returned as `0`.

### The formula form

A formula is one of three things:

- A **literal**: null, a boolean, a number, or text. It stands for itself.
- An **array**: each item is evaluated as a formula, and the result is the array of results.
- An **object**:
  - With exactly one key, the key is the operator and its value is the argument list: `{"op": [a, b]}`. A single argument may be written without the list: `{"abs": -3}` is `{"abs": [-3]}`.
  - With any other number of keys (none, or two and more), it is a literal object and is not evaluated.
  - A literal object with one key must be written with `lit`: `{"lit": {"decimals": 2}}`. Without `lit`, `{"decimals": 2}` would be read as an unknown operator `decimals`.

Arguments are evaluated only when the operator needs them. `if`, `and`, `or`, `default` and `var` stop as soon as they have their answer.

### Scopes and paths

`var` and `has` take a path: text made of names separated by dots, such as `state.items.0.name`. The first name is the scope:

| Scope | What it holds |
|---|---|
| `state` | The document's state: its default `state`, then every `set` and `update` call and every push (merged by RFC 7396). |
| `attrs` | Activities only: the attributes given when the activity started. They do not change. |
| `env` | Facts about this render (below). |
| `now` | The time of this render in epoch seconds: the timeline entry's date in a widget, the render time in an activity. It does not tick; a live clock is the `timer` element's job. |
| `item` | Inside `map`, `filter`, `some`, `all`, `count` and `sum`: the current array item. Inside a `list` template: the current row, under the name given by the list's `as` (`item` when `as` is not set). |
| `index` | The position of `item`, from 0. |

The `env` keys are:

| Key | Type | What it holds |
|---|---|---|
| `platform` | text | `"ios"` or `"android"`. |
| `os` | number | The major OS version. |
| `family` | text | The family being drawn, such as `small`, `accessoryCircular`, `island.compactLeading` or `lockScreen`. |
| `width` | number | Width of this instance, in points (iOS) or dp (Android). |
| `height` | number | Height of this instance, in points or dp. |
| `colorScheme` | text | `"light"` or `"dark"`. |
| `renderingMode` | text | `"fullColor"`, `"accented"` or `"vibrant"`. |
| `locale` | text | The locale used by the formatting operators, such as `"en-US"`. When it is not set, `en-US` is used. |
| `timeZone` | text | The time zone used by `datetime`, such as `"Europe/Berlin"`. |
| `isStale` | boolean | Activities: the activity is past its `staleAfter`. |
| `isLuminanceReduced` | boolean | iOS Always-On display. |
| `showsBackground` | boolean | False where the system removes the widget background (iOS StandBy and tinted modes). |
| `renderer` | text | The renderer version, `"1.0"`. |

Path rules:

- A path that leads nowhere gives `null`. This covers a missing key, an index past the end, and a step into a non-container.
- An array step is a decimal index with no leading zero (`0`, `1`, `12`).
- A key that holds a dot cannot be reached by a path. Use `at` for it: `{"at": [{"var": "state"}, "a.b"]}`.
- A first name that is not a scope is the error `unknown_scope`.

### Formula errors

An error inside a formula never stops a render. The formula that failed gives `null`, and one diagnostic records the error code and the JSON path of the formula. A field whose formula gives `null` takes its default, and a `text` whose text is `null` shows nothing. The error codes are:

| Code | When |
|---|---|
| `type_error` | An argument has the wrong type, such as `+` on text or `upper` on a number. |
| `non_finite` | A result would be NaN or an infinity. |
| `division_by_zero` | `/` or `%` with a divisor of 0. |
| `out_of_range` | An argument is outside its allowed values, such as `round` decimals above 10, a `clamp` low above high, a currency code that is not three capital letters, or a `duration` style that is not `positional` or `abbrev`. |
| `array_too_long` | `map` or `split` would make an array longer than the array cap (256). |
| `bad_formula` | Wrong number of arguments, a `var` path that is not text, or a `plural` with no matching form. |
| `unknown_operator` | A one-key object whose key is not an operator. |
| `unknown_scope` | A path whose first name is not a scope. |
| `too_deep` | Formulas nested deeper than 32. |
| `budget_exceeded` | The render used up its step budget (below). |

### The budget

A widget extension that uses too much memory or time is killed by the system and shows nothing. The budget makes every render finish, and it fails in the same place on every device and in the validator.

- Each operator evaluation costs one step, and so does each `lit`.
- `map`, `filter`, `some`, `all`, `count` with a predicate, and `sum` cost one more step per item they visit. `sort` costs one step per item.
- One render (one layout with one state) has 20 000 steps.
- Past the budget, every later formula in that render gives `null` with the diagnostic `budget_exceeded`.
- Formulas nest at most 32 deep. No array made by a formula may have more than 256 items.

The language has no loop, recursion, assignment, user function, or `reduce` with a free accumulator. Each array operator walks its array once.

### Operators

Notes on the table:

- Min and max are the counts of arguments; `n` means no upper bound.
- The arguments column gives each argument's type in order. Square brackets mark an optional argument. "Formula" means an argument evaluated once per item, with `item` and `index` set.
- Each example is evaluated with the example state and env below, and gives the result shown.

Example state:


Example env:

```json
{"platform": "ios", "family": "small", "locale": "en-US", "timeZone": "UTC", "now": 1700000000}
```

| `substr` | 2 | 3 | text, start (integer), [length (integer)] | Text: the code points from start. A negative start counts from the end. Without a length, the rest. A negative length leaves that many code points off the end. | `{"substr": ["Despia", -3]}` | `"pia"` |

| `pad` | 2 | 4 | text or number, width (integer up to 256), [fill (text of one code point; default space)], [side (`"start"` or `"end"`; default `"start"`)] | Text filled to the width in code points. Text already that long is returned unchanged. | `{"pad": [7, 3, "0"]}` | `"007"` |

#### Arrays

| Operator | Min | Max | Arguments | Result | Example | Gives |
|---|---|---|---|---|---|---|
| `map` | 2 | 2 | array, formula | Array of the formula's result for each item. | `{"map": [{"var": "state.items"}, {"var": "item.name"}]}` | `["Tea", "Cake"]` |

| `all` | 2 | 2 | array, formula | Boolean: the formula counts as true for every item (also for an empty array). Stops at the first false one. | `{"all": [{"var": "state.items"}, {">": [{"var": "item.qty"}, 0]}]}` | `true` |
| `count` | 1 | 2 | array, [formula] | Number: the items, or the items for which the formula counts as true. | `{"count": [{"var": "state.items"}, {"==": [{"var": "item.qty"}, 1]}]}` | `1` |
| `sum` | 1 | 2 | array, [formula] | Number: the sum of the items, or of the formula's result for each item. Every summed value must be a number. | `{"sum": [{"var": "state.items"}, {"*": [{"var": "item.qty"}, {"var": "item.price"}]}]}` | `11.25` |

| `first` | 1 | 1 | array | The first item, or null when the array is empty. | `{"first": {"var": "state.tags"}}` | `"new"` |

#### Formatting

These operators use the platform's own formatters (`NumberFormatter` and `Date.FormatStyle` on iOS, `android.icu` on Android) with `env.locale`. Spacing and symbols can differ by platform for some locales, because the platforms ship different locale data. The vectors pin the `en-US` results. `compact`, `duration` and `plural` do not depend on the locale.

| Operator | Min | Max | Arguments | Result | Example | Gives |
|---|---|---|---|---|---|---|
| `number` | 1 | 2 | number, [options (object): `decimals` (integer 0 to 10; without it, up to 6 fraction digits), `grouping` (boolean; default true)] | Text: the number in the locale's form. | `{"number": [1234.5, {"lit": {"decimals": 2}}]}` | `"1,234.50"` |
| `percent` | 1 | 2 | fraction (number; 0.42 means 42%), [options: `decimals` (integer 0 to 10; default 0)] | Text: the percentage in the locale's form. | `{"percent": 0.425}` | `"43%"` |
| `currency` | 2 | 3 | amount (number), code (ISO 4217 text: three capital letters), [options: `decimals` (integer 0 to 10; default 2)] | Text: the amount with the currency in the locale's form. | `{"currency": [{"var": "state.price"}, "USD"]}` | `"$12.40"` |
| `compact` | 1 | 1 | number | Text: the number shortened with `K`, `M`, `B` or `T`. One decimal is kept below 100 of a unit; a result that rounds up to 1000 moves to the next unit. | `{"compact": 12400}` | `"12.4K"` |
| `datetime` | 1 | 2 | epoch seconds (number), [options: `date` and `time`, each `"none"`, `"short"`, `"medium"` or `"long"`; `date` defaults to `"medium"`, `time` to `"none"`, and null means the default] | Text in `env.locale` and `env.timeZone`. Both `"none"` gives `""`. | `{"datetime": [{"var": "state.eta"}, {"lit": {"date": "long"}}]}` | `"November 14, 2023"` |
| `duration` | 1 | 2 | seconds (number), [style: `"positional"` (default) or `"abbrev"`] | Text. The seconds are rounded to a whole number first. `positional` gives `m:ss`, or `h:mm:ss` from one hour. `abbrev` gives `1h 2m 5s` and leaves out zero parts. A negative duration starts with `-`. | `{"duration": [3725, "abbrev"]}` | `"1h 2m 5s"` |
| `plural` | 2 | 2 | count (number), forms (object of text: `"=N"` for an exact count, `zero`, `one`, `other`) | Text: the first form that applies, in this order: `"=N"` for the exact count, `zero` for 0, `one` for 1, then `other`. `plural` picks a form by the count only. It does not apply a language's plural rules: write the forms for the language the text is in. A language with more forms (such as Arabic or Polish) can use `"=N"` keys and `if`.

## Actions and taps

An action is `{ open, set, value }`. `set` changes state without opening the app: each key is a state path, each value a formula over the state before the action. `open` opens the app at a path on your site.

```json
"actions": {
  "markToday": { "set": { "doneToday": { "!": { "var": "state.doneToday" } } } },
  "details": { "open": "/habits/today" }
}
```

Every tap reaches your page on `window.onWidgetJsonAction(event)` as `{ target, id, action, kind, at, state }`. A tap while no page is loaded is queued: read it with `events`, then pass the last `seq` you handled as `ack`.

On iOS, buttons and toggles that only `set` run without opening the app on iOS 17 and later; below that they show as plain content.

## Timeline and refresh

`widget/timeline` takes up to 64 entries `[{ at, patch }]` (`at` in seconds), at least 300 seconds apart, so the widget changes on time with the app closed. On Android the times are inexact.

`widget/refresh` fetches `url` every `every` minutes (15 at least) in the background. The answer is a JSON state object, the same as `state` in `widget/state`, and replaces the widget's state.

## Live Activities and Live Updates

A document with `kind: "activity"` runs as a Live Activity on iOS 16.2 and later (lock screen, Dynamic Island) and as an ongoing notification on Android, promoted to a Live Update on Android 16 and later when the build declares Live Updates (`capabilities.liveUpdates` is `true`).

```javascript
despia('widgetjson://activity/start?id=match-42'
  + '&src=' + encodeURIComponent('https://example.com/widgets/score-activity.json')
  + '&attrs=' + encodeURIComponent(JSON.stringify({ homeName: 'Lions', awayName: 'Hawks' }))
  + '&state=' + encodeURIComponent(JSON.stringify({ home: 0, away: 0, period: '1st' })));
```

`window.onWidgetJsonActivity({ id, state, origin })` reports each change of an activity's state. Android draws the activity from `summary`, so an activity document needs `summary.title` unless `android.style` is `custom`. `relevance` is iOS only. An activity's attributes and state together are at most 4 KB.

## Push updates

Widgets and activities also update from a push, with the app closed. Put an envelope under the push's `widgetjson` key (or `data.widgetjson`), as an object or as JSON text:

```json
{ "v": 1, "target": "widget", "id": "steps", "event": "patch", "patch": { "steps": 5100 }, "seq": 1732450000000 }
```

| Field | Values |
| --- | --- |
| `target` | `widget`, `activity` |
| `event` | For a `widget`: `state`, `patch`, `doc`, `timeline`, `reload`, `clear`. For an `activity`: `start`, `update`, `end` |
| `state`, `patch`, `doc`, `attrs`, `entries`, `alert` | as in the calls |
| `staleAt`, `dismissAt`, `relevance` | activity timing |
| `seq`, `ts` | ordering; older updates are dropped |

Always send `seq` or `ts`. An envelope is applied when the push is delivered. On iOS an alert push is also read when it shows while the app is open and when someone opens it later; from those two paths only an envelope with `seq` or `ts` is applied, so opening an old notification is dropped as `stale` and never rolls a widget back or restarts an activity. An alert push without `seq` or `ts` and without `content-available` is therefore not applied on iOS. Android applies envelopes on delivery only, never from a notification tap.

The envelope works through APNs and OneSignal on iOS, and through Firebase Cloud Messaging and OneSignal on Android. On iOS, Live Activities have their own push tokens: `tokens` lists them as `{ kind, id, token, environment }`, where `kind` is `activity_start` (push to start, iOS 17.2 and later), `activity_update` (one per running activity) or `widget`. `window.onWidgetJsonToken(token)` reports each new token, and `token-sink` posts each one to your server (an `https://` URL on your page's own site, with an optional bearer token).

## Limits

| Limit | Value |
| --- | --- |
| Document | 64 KB |
| State | 64 KB |
| Activity attributes and state | 4 KB |
| Elements | 512, nested at most 24 deep |
| Formula | 20000 steps, nested at most 32 deep |
| List length | 256 |
| Timeline | 64 entries, 300 seconds apart |
| Queued events | 32 |

## Platform notes

| | iOS | Android |
| --- | --- | --- |
| Renderer | SwiftUI in WidgetKit | Glance |
| Lock screen widgets | `accessory*` families | Not available |
| Activities | Live Activities, iOS 16.2 and later | Ongoing notification; Live Update on Android 16 and later when the build declares Live Updates |
| Push to start | iOS 17.2 and later | Not available |
| Adding the widget | The user adds it from the widget gallery (`widget/pin` answers `platform_limit`) | `widget/pin` asks the launcher, Android 8.0 and later |
| Icons | SF Symbols | Material Symbols when the build bundles them; `svg` always works |
| Image `rendering` | Every value | `original` and `template` |
| iOS-only styles | | Ignored |

Run `validate` on each platform: its errors say exactly what a document does there.

The JavaScript validator (the command line and the preview) checks more than the app does. Besides the codes above it reports `unknown_property` (a field, style property or `symbol` platform the format does not have), `unknown_family` (a name in a layout's `for`) and `link_needs_widget_url` (a `link` in a family with one tap target), and it adds notes such as `android_ignored`. The app's own `validate` call does not report those three.
