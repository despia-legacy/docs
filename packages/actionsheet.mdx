Presents a list of choices in the platform's native action sheet or bottom sheet and gives you back the value of the row the user chose, or nothing if they dismissed it. You supply the rows, the title and the message, and mark destructive choices so the system styles them.

**When to use it.** Use it when the user must choose one action from a short list, such as share, edit or delete for an item. For choosing a value in a form or a long list, use a picker or list screen instead.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `actionsheet` package is on the global `window.dsx`. `dsx.has('actionsheet')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('actionsheet')) {
  // Shows the action sheet and waits. You get the value of the chosen row, or nothing when the user dismissed it.
  const showResult = await dsx.module.actionsheet.show({ items: [{"label": "Edit", "value": "edit"}, {"label": "Delete", "role": "destructive", "value": "delete"}], title: "Choose an action" })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Action reference

<Accordion title="show">

Shows the action sheet and waits. You get the value of the chosen row, or nothing when the user dismissed it.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `items`? | object[] | The rows to show, top to bottom, each with a label, a value and an optional role; leave it out and nothing is shown, the call resolves null. |
| `message`? | string | A line of explanation under the title; leave it out for none. |
| `title`? | string | The title line shown at the top of the sheet; leave it out for none. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.actionsheet.show({ items: [{"label": "Edit", "value": "edit"}, {"label": "Delete", "role": "destructive", "value": "delete"}], title: "Choose an action" })
```

## Broadcasts

Listen with `window.dsx.module.actionsheet.on('<broadcast>', (data) => { ... })`. It returns a function that stops listening.

| Broadcast | When it fires |
| :-- | :-- |
| `select` | The user picked a row or dismissed the sheet. Dismissing sends no value. |
