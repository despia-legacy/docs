Uses Apple's Declared Age Range on iOS and Google's Play Age Signals on Android to learn which age band the user is in, without asking for a birthdate. Both give the same answer shape, with a yes, no or unknown result for each age you test. It asks the system to show its own prompt. You write what your app does for each age group.

**When to use it.** Use it when you must treat under-age users differently, for example to show or hide adult content. Check for yes with a strict true test, because unknown is not the same as no. If the system cannot answer, ask for a birthdate yourself.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `ageassurance` package is on the global `window.dsx`. `dsx.has('ageassurance')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('ageassurance')) {
  // Asks the system for the user's age band and tells whether the user is at least each age you list; the system may show a prompt.
  const check = await dsx.module.ageassurance.check({ gates: [13, 15, 17] })

  // On Android, starts Google's verification step for the user and then returns a fresh answer; on iOS it reports that it is not supported.
  const resolve = await dsx.module.ageassurance.resolve({ gates: [18] })

  // Returns the most recent age answer without asking again, or an unavailable answer if nothing has been asked yet.
  const last = await dsx.module.ageassurance.last()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Action reference

<AccordionGroup>
<Accordion title="check">

Asks the system for the user's age band and tells whether the user is at least each age you list; the system may show a prompt.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `gates`? | int[] | Up to three ages in whole years to test against; if left out, the ages set in the package settings are used. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.ageassurance.check({ gates: [13, 15, 17] })
```

```json Result
{
  "ageLower": 13,
  "ageUpper": 16,
  "gates": {
    "13": true,
    "15": null,
    "17": false
  },
  "status": "shared"
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `ageLower`? | number | The lower bound of the user's age band in whole years; null when there is no band. |
| `ageUpper`? | number | The upper bound of the user's age band in whole years; null when the band is open at the top or unknown. |
| `assurance`? | string | How the age was established, or unknown when the system does not say. |
| `bridge`? | number | The version of the answer format. |
| `error`? | object | The error code and message when the call failed; null when it did not. |
| `gates`? | object | Whether the user is at least each age you asked about, keyed by age: true, false, or null when the band cannot tell. |
| `ok`? | boolean | True when the system gave an answer; false when age assurance is unavailable or the call failed. |
| `platform`? | string | The platform that answered: ios, android or web. |
| `platformExtras`? | object | Extra fields only one platform reports, grouped by platform name; empty when there are none. |
| `provider`? | string | Which service answered, or none when no age service exists on the device. |
| `runtime`? | number | The runtime generation of the package that produced the answer. |
| `status`? | string | The outcome: shared, declined, unavailable or error. |

**Errors**

| Code | Message |
| :-- | :-- |
| `invalid_gates` | Gates must be whole numbers of years. |
| `too_many_gates` | At most three age gates per request. |
| `unsupported_device` | This device has no age-range service: the OS ships no age assurance API (iOS below 26.2), Google Play services are absent, or this is a browser. |

</Accordion>

**Result**

## Configuration

Set these in the package settings of your app (see [Add a package](/packages/add-a-package)).

| Setting | What it is |
| :-- | :-- |
| Default age gates (`default_gates`) | The ages this app asks about when a call passes none. At most three, whole years. |

For apps built on Despia V3, see [Migrate from Despia V3](/packages/migrate-from-v3).
