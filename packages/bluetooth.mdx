Scans for Bluetooth Low Energy devices, connects, discovers services and reads, writes and subscribes to their data. Use it for wearables, sensors and other accessories. Asks for Bluetooth permission the first time it is used, with text you set. Works on phones and desktop.

**When to use it.** Use it to talk to Bluetooth Low Energy accessories such as heart rate straps, sensors and smart devices. It does not handle classic Bluetooth audio or pairing screens.

<EnvNew />

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `bluetooth` package is on the global `window.dsx`. `dsx.has('bluetooth')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('bluetooth')) {
  // Connects to a device found by scanning, waiting for the radio to be on if needed.
  const connect = await dsx.module.bluetooth.connect({ auto_connect: false, id: "1A2B3C4D-0000-1111-2222-3344556677AA", server: "", timeout: 5000 })

  // Disconnects from a device and turns off automatic reconnecting for it.
  const disconnect = await dsx.module.bluetooth.disconnect({ id: "1A2B3C4D-0000-1111-2222-3344556677AA" })

  // Finds the services and characteristics a connected device offers, which you need before reading or writing.
  const discover = await dsx.module.bluetooth.discover({ id: "1A2B3C4D-0000-1111-2222-3344556677AA" })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Action reference

<AccordionGroup>
<Accordion title="connect">

Connects to a device found by scanning, waiting for the radio to be on if needed.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `auto_connect` | boolean | Pass true to reconnect automatically after an unexpected drop; an explicit disconnect turns it off. |
| `id` | string | The device id from a device event while scanning; it is not a hardware address and can change after a reinstall. |
| `server` | string | An https address that receives a copy of connection events for your backend. |
| `timeout` | number | How long to wait for the connection, in milliseconds, before giving up. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.bluetooth.connect({ auto_connect: false, id: "1A2B3C4D-0000-1111-2222-3344556677AA", server: "", timeout: 5000 })
```

```json Result
{
  "id": "1A2B3C4D-0000-1111-2222-3344556677AA",
  "state": "connected"
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | string | The id of the connected device. |
| `state` | string | The connection state, connected on success. |

**Errors**

| Code | Message |
| :-- | :-- |
| `permission_denied` | Bluetooth permission has not been granted. |
| `switched_off` | Bluetooth is turned off. |
| `unsupported_device` | This device has no Bluetooth radio this app can use. |

## Broadcasts

Listen with `window.dsx.module.bluetooth.on('<broadcast>', (data) => { ... })`. It returns a function that stops listening.

| Broadcast | When it fires |
| :-- | :-- |
| `bluetooth` | Reports radio state changes, device disconnects and notifications that arrive when no call is waiting; missed ones are replayed when the app returns. |
| `data` | A characteristic you subscribed to sent a new value. |
| `device` | A device was found during a scan, with its name, signal strength and advertised services. |

## Configuration

Set these in the package settings of your app (see [Add a package](/packages/add-a-package)).

| Setting | What it is |
| :-- | :-- |
| Permission prompt (`usage_description`) | The message shown when iOS asks the user for Bluetooth access. |

## Known limits

- Android: automatic reconnect (`auto_connect`) does not reconnect yet.
- Android: writes are capped at 20 bytes (no MTU request).
- Android: no background connections or notifications.
- Not supported: the peripheral role (advertising, hosting a GATT server), pairing control, L2CAP channels, Bluetooth Classic and beacons.
