Opens a web address in Safari's in-app tab on iOS, a Chrome Custom Tab on Android and a new tab on the web, with the same checks everywhere. Phone, mail and other safe app links are handed to the system. Unsafe addresses such as javascript: are refused.

**When to use it.** Use it for links that leave your app, such as articles, terms or a payment page. For screens inside your own app, use navigation instead.

<EnvNew />

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `browser` package is on the global `window.dsx` and is built into every app:

```javascript
// built into every Despia V4 app
const dsx = window.dsx
if (dsx) {
  // Opens a link outside the app's own screens. Web addresses open in an in-app browser tab, and safe links such as phone or mail are passed to the system.
  const openResult = await dsx.module.browser.open({ url: "https://example.com" })

  // Reloads the page the app is showing.
  const reload = await dsx.module.browser.reload()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.browser.open()` | `target`?: "blank" \\| "self"<br/>`url`: string | `opened` | iOS, Android | Opens a link outside the app's own screens. Web addresses open in an in-app browser tab, and safe links such as phone or mail are passed to the system. |
| `dsx.module.browser.reload()` | none | `reloaded` | iOS, Android | Reloads the page the app is showing. |

## Action reference

<AccordionGroup>
<Accordion title="open">

Opens a link outside the app's own screens. Web addresses open in an in-app browser tab, and safe links such as phone or mail are passed to the system.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `target`? | "blank" \\| "self" | On the web only: blank opens a new tab (the default) and self replaces the current page. |
| `url` | string | The address to open. It can be a web address, a bare host such as example.com, or a safe app link like tel: or mailto:. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.browser.open({ url: "https://example.com" })
```

```json Result
{
  "opened": true
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `opened` | boolean | True when the link was opened. |

**Errors**

| Code | Message |
| :-- | :-- |
| `blocked` | The browser blocked the new tab. Open it from a tap handler. |
| `invalid_target` | Use blank or self for the browser target. |
| `invalid_url` | Use an HTTP(S) URL, a host, or a safe external app link. |
| `missing_url` | A non-empty "url" is required. |

</Accordion>
<Accordion title="reload">

Reloads the page the app is showing.

**Arguments:** none.

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.browser.reload()
```

```json Result
{
  "reloaded": true
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `reloaded` | boolean | True when the reload was started. |

</Accordion>
</AccordionGroup>
