<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.0.2), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

Takes a set number of photos as fast as the hardware allows and returns them as files, with no preview or shutter button. Use it when your app captures frames alongside a sensor reading or other event. Asks for camera permission the first time it runs. Phones only.

**When to use it.** Reach for it when your app needs the camera in code: a burst of photos matched to a sensor reading, a held-open session with controls and recording, or a live preview you draw yourself. For a picker where the person chooses a photo, use the platform file picker instead.

<EnvNew />

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `camera` package is on the global `window.dsx`. `dsx.has('camera')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('camera')) {
  // Deletes every photo file that earlier bursts wrote.
  const clear = await dsx.module.camera.clear()

  // Takes a number of photos in a row as fast as the hardware allows, with no preview, and returns them as files.
  const burst = await dsx.module.camera.burst({ count: 3, interval: 0, quality: 0.8 })

  // Reports the limits of burst capture on this device.
  const capabilities = await dsx.module.camera.capabilities()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Action reference

<AccordionGroup>
<Accordion title="burst">

Takes a number of photos in a row as fast as the hardware allows, with no preview, and returns them as files.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `camera`? | "back" \\| "front" | Which camera to use: back or front. |
| `count`? | number | How many photos to take, from 1 up to the configured maximum burst length. |
| `interval`? | number | Minimum milliseconds between photos; 0 means as fast as the sensor delivers. |
| `prompt`? | boolean | Set false to never show the permission dialog; the call then fails with permission_denied instead. |
| `quality`? | number | JPEG quality from 0.01 to 1; the default is 0.9. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.camera.burst({ count: 3, interval: 0, quality: 0.8 })
```

```json Result
{
  "count": 3,
  "durationMs": 240,
  "photos": [
    {
      "bytes": 2411500,
      "height": 3024,
      "path": "cache:despia-burst/0.jpg",
      "timestamp": 1700000000000,
      "width": 4032
    },
    {
      "bytes": 2409800,
      "height": 3024,
      "path": "cache:despia-burst/1.jpg",
      "timestamp": 1700000000120,
      "width": 4032
    },
    {
      "bytes": 2412100,
      "height": 3024,
      "path": "cache:despia-burst/2.jpg",
      "timestamp": 1700000000240,
      "width": 4032
    }
  ]
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `count` | number | How many photos were really captured; compare it with what you asked for. |
| `durationMs` | number | How long the burst itself took in milliseconds, not counting camera warm-up. |
| `photos` | object[] | The photos in capture order, each with a Files path, size, byte count and timestamp. |

**Errors**

| Code | Message |
| :-- | :-- |
| `busy` | A burst is already running. |
| `capture_failed` | The capture session could not be started. |
| `permission_denied` | Camera access is not granted. The data carries the contract state: &#123; permission, status, canAsk &#125;. |
| `unavailable` | No camera on this device. |
| `unsupported_device` | This device has no camera to take a burst with. |

## Configuration

Set these in the package settings of your app (see [Add a package](/packages/add-a-package)).

| Setting | What it is |
| :-- | :-- |
| Maximum burst length (`max_burst`) | Upper bound on how many frames one burst may request. |
| Camera prompt (`usage_camera`) | The message shown when iOS asks for camera access. |
| Microphone prompt (`usage_microphone`) | The message shown when iOS asks for microphone access. |

For apps built on Despia V3, see [Migrate from Despia V3](/packages/migrate-from-v3).
