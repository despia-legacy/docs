<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.0.2), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

Gives you one call to read text, links, rich text, images and files from the clipboard, one to write them with options such as expiry and sensitive content, and one to check what is there without reading it. A change notification tells you when the clipboard changes. You write the buttons and screens that use it.

**When to use it.** Reach for it for copy buttons, paste buttons and share-to-clipboard features. For plain copy of a short string on a web page the browser clipboard may be enough, but this also handles images and expiry.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `clipboard` package is on the global `window.dsx`. `dsx.has('clipboard')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('clipboard')) {
  // Reads the current clipboard as text, a link, rich text, an image or files.
  const readResult = await dsx.module.clipboard.read({ type: "image" })

  // Checks what kinds of content are on the clipboard without reading it, so no paste alert appears.
  const inspect = await dsx.module.clipboard.inspect()

  // Puts text, a link, rich text, an image or files on the clipboard, with optional expiry and privacy settings.
  const writeResult = await dsx.module.clipboard.write({ text: "Copied value" })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.clipboard.inspect()` | `patterns`?: string[] | `changeCount`<br/>`hasFiles`<br/>`hasHTML`<br/>`hasImage`<br/>`hasText`<br/>`hasURL`<br/>`patterns`<br/>`pendingPatterns`<br/>`unsupportedPatterns` | iOS, Android | Checks what kinds of content are on the clipboard without reading it, so no paste alert appears. |
| `dsx.module.clipboard.read()` | `type`?: "text" \\| "url" \\| "html" \\| "image" \\| "files" | `files`<br/>`html`<br/>`image`<br/>`text`<br/>`url` | iOS, Android | Reads the current clipboard as text, a link, rich text, an image or files. |
| `dsx.module.clipboard.write()` | `expiresIn`?: number<br/>`files`?: string[]<br/>`html`?: string<br/>`image`?: string<br/>`localOnly`?: boolean<br/>`sensitive`?: boolean<br/>`text`?: string<br/>`url`?: string | `expiry`<br/>`ignored`<br/>`ok` | iOS, Android | Puts text, a link, rich text, an image or files on the clipboard, with optional expiry and privacy settings. |

## Action reference

<AccordionGroup>
<Accordion title="inspect">

Checks what kinds of content are on the clipboard without reading it, so no paste alert appears.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `patterns`? | string[] | Content types to look for without reading, such as webURL, phoneNumber or emailAddress. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.clipboard.inspect()
```

```json Result
{
  "hasFiles": false,
  "hasHTML": false,
  "hasImage": false,
  "hasText": true,
  "hasURL": false
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `changeCount`? | number | A number that goes up each time the clipboard changes, on iOS only. |
| `hasFiles` | boolean | True when the clipboard holds files. |
| `hasHTML` | boolean | True when the clipboard holds rich text. |
| `hasImage` | boolean | True when the clipboard holds an image. |
| `hasText` | boolean | True when the clipboard holds text. |
| `hasURL` | boolean | True when the clipboard holds a link. |
| `patterns`? | object | For each pattern you asked about, whether the clipboard matches it. |
| `pendingPatterns`? | string[] | Patterns Android has not finished classifying yet; ask again shortly. |
| `unsupportedPatterns`? | string[] | Patterns this device cannot detect. |

**Errors**

| Code | Message |
| :-- | :-- |
| `invalid_param` | patterns takes canonical detection words. |
| `permission_denied` | The browser will not report clipboard contents without a clipboard-read grant. |
| `unsupported_platform` | This context has no clipboard API. |

</Accordion>
<Accordion title="read">

Reads the current clipboard as text, a link, rich text, an image or files.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `type`? | "text" \\| "url" \\| "html" \\| "image" \\| "files" | What to read: text (the default), url, html, image or files. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.clipboard.read({ type: "image" })
```

```json Result
{
  "image": "temp:clipboard/1/image.png"
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `files`? | string[] | Temporary file paths of the files on the clipboard. |
| `html`? | string | The rich text as HTML, when type is html. |
| `image`? | string | A temporary file path to the image, or null when there is none. |
| `text`? | string | The clipboard text, when type is text. |
| `url`? | string | The link on the clipboard, or null when the clip is not a whole web address. |

**Errors**

| Code | Message |
| :-- | :-- |
| `denied` | The browser did not allow this page to read the clipboard. |
| `invalid_param` | type takes text, url, html, image or files. |
| `unavailable` | Core/Files did not take the clipboard content. |
| `unsupported_platform` | This platform's clipboard cannot carry that type. |

</Accordion>
<Accordion title="write">

Puts text, a link, rich text, an image or files on the clipboard, with optional expiry and privacy settings.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `expiresIn`? | number | Seconds after which the clipboard is cleared, if it still holds this copy. |
| `files`? | string[] | File paths to copy. Works on iOS only today. |
| `html`? | string | Rich text to copy, as HTML. |
| `image`? | string | A file path to a PNG image to copy. |
| `localOnly`? | boolean | On iOS, keeps the copy off Universal Clipboard so it does not reach the person's other devices. |
| `sensitive`? | boolean | On Android 13 and later, hides the copy in the clipboard preview. |
| `text`? | string | The plain text to put on the clipboard. |
| `url`? | string | A web address to copy. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.clipboard.write({ text: "Copied value" })
```

```json Result
{
  "ok": true
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `expiry`? | "system" \\| "app" \\| "unsupported" | Who clears the copy: system, app, or unsupported when expiry could not be set. |
| `ignored`? | string[] | Options this device could not apply, listed by name. |
| `ok` | boolean | True when the clipboard was written. |

**Errors**

| Code | Message |
| :-- | :-- |
| `denied` | The browser did not allow this page to write to the clipboard. |
| `invalid_param` | write takes text, url, html, image or files, and expiresIn/localOnly/sensitive options. |
| `missing_param` | A text value is required. |
| `unsupported_platform` | This platform's clipboard cannot carry that item. |

</Accordion>
</AccordionGroup>

## Broadcasts

Listen with `window.dsx.module.clipboard.on('<broadcast>', (data) => { ... })`. It returns a function that stops listening.

| Broadcast | When it fires |
| :-- | :-- |
| `change` | The system clipboard changed. It starts after the first inspect call. |

For apps built on Despia V3, see [Migrate from Despia V3](/packages/migrate-from-v3).
