<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.1.0), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

Gives you one call to read text, links, rich text, images and files from the clipboard, one to write them with options such as expiry and sensitive content, and one to check what is there without reading it. A change notification tells you when the clipboard changes. You write the buttons and screens that use it.

**When to use it.** Reach for it for copy buttons, paste buttons and share-to-clipboard features. For plain copy of a short string on a web page the browser clipboard may be enough, but this also handles images and expiry.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `clipboard` package is on the global `window.dsx`. `dsx.has('clipboard')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('clipboard')) {
  // Reads the current clipboard as text, a link, rich text, an image or files.
  const readResult = await dsx.module.clipboard.read({ type: "image" })

  // Checks what kinds of content are on the clipboard without reading it, so no paste alert appears.
  const inspect = await dsx.module.clipboard.inspect()

  // Puts text, a link, rich text, an image or files on the clipboard, with optional expiry and privacy settings.
  const writeResult = await dsx.module.clipboard.write({ text: "Copied value" })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.clipboard.inspect()` | `patterns`?: string[] | `changeCount`<br/>`hasFiles`<br/>`hasHTML`<br/>`hasImage`<br/>`hasText`<br/>`hasURL`<br/>`patterns`<br/>`pendingPatterns`<br/>`unsupportedPatterns` | iOS, Android | Checks what kinds of content are on the clipboard without reading it, so no paste alert appears. |
| `dsx.module.clipboard.read()` | `type`?: "text" \\| "url" \\| "html" \\| "image" \\| "files" | `files`<br/>`html`<br/>`image`<br/>`text`<br/>`url` | iOS, Android | Reads the current clipboard as text, a link, rich text, an image or files. |
| `dsx.module.clipboard.write()` | `expiresIn`?: number<br/>`files`?: string[]<br/>`html`?: string<br/>`image`?: string<br/>`localOnly`?: boolean<br/>`sensitive`?: boolean<br/>`text`?: string<br/>`url`?: string | `expiry`<br/>`ignored`<br/>`ok` | iOS, Android | Puts text, a link, rich text, an image or files on the clipboard, with optional expiry and privacy settings. |

## Broadcasts

Listen with `window.dsx.module.clipboard.on('<broadcast>', (data) => { ... })`. It returns a function that stops listening.

| Broadcast | When it fires |
| :-- | :-- |
| `change` | The system clipboard changed. It starts after the first inspect call. |
