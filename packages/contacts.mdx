<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.0.2), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

The default is the system contact picker, which needs no permission and only returns the contact the user chooses. For features that need more, it can list, search, add, update and remove contacts and groups after asking permission, with text you set.

**When to use it.** Use pick when the user needs to choose one or a few people for a feature such as an invite. Only use the list, add and remove actions when the feature really needs the address book, because App Review rejects apps that ask for more than they use.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `contacts` package is on the global `window.dsx`. `dsx.has('contacts')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('contacts')) {
  // Returns the whole address book at once as names mapped to phone numbers, asking for access first.
  const readResult = await dsx.module.contacts.read()

  // Asks for the address book with the system dialog, for a settings row or an onboarding step; the dialog only appears while the system still allows it.
  const permissionRequest = await dsx.module.contacts.permission.request({ level: "read" })

  // Saves a new contact in the address book; it needs the user's write permission.
  const add = await dsx.module.contacts.add({ contact: {"emails": [{"label": "work", "value": "ada@example.com"}], "familyName": "Lovelace", "givenName": "Ada"} })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Action reference

<AccordionGroup>
<Accordion title="add">

Saves a new contact in the address book; it needs the user's write permission.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `contact` | object | The details of the new contact. |
| `prompt`? | boolean | Leave it out or pass true to let the system permission dialog appear on this call when needed; pass false to never show a dialog and fail with the permission state instead. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.contacts.add({ contact: {"emails": [{"label": "work", "value": "ada@example.com"}], "familyName": "Lovelace", "givenName": "Ada"} })
```

```json Result
{
  "id": "c9"
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | string | The id of the contact that was created. |

**Errors**

| Code | Message |
| :-- | :-- |
| `invalid_contact` | A contact needs at least one of displayName, givenName, familyName, phones or emails. |
| `permission_denied` | Contacts access is not granted. The data carries the contract state: &#123; permission, status, canAsk &#125;. |
| `write_failed` | The contact could not be saved. |

</Accordion>

<Accordion title="list">

Returns one page of contacts from the address book, optionally filtered by name and limited to the fields you ask for.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `after`? | string | The end cursor from the previous page, to get the next page. |
| `fields`? | string[] | A list of contact fields to load; asking for fewer fields makes the call faster. |
| `limit`? | int | How many contacts to return in this page; defaults to 100 and never exceeds 500. |
| `prompt`? | boolean | Leave it out or pass true to let the system permission dialog appear on this call when needed; pass false to never show a dialog and fail with the permission state instead. |
| `query`? | string | Text to look for inside the contact display names, ignoring case. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.contacts.list({ limit: 2 })
```

```json Result
{
  "access": "granted",
  "contacts": [
    {
      "displayName": "Jane Doe",
      "id": "c1"
    },
    {
      "displayName": "Sam Ray",
      "id": "c2"
    }
  ],
  "endCursor": "2",
  "hasNextPage": true
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `access` | string | Whether the app can see the whole address book or only a limited selection the user shared. |
| `contacts` | object[] | The contacts found in this page, with the fields you asked for. |
| `endCursor`? | string | Pass this as after to load the next page. |
| `hasNextPage` | boolean | True when another page is available. |

**Errors**

| Code | Message |
| :-- | :-- |
| `permission_denied` | Contacts access is not granted. The data carries the contract state: &#123; permission, status, canAsk &#125;. |
| `read_failed` | The address book could not be read. |

</Accordion>
<Accordion title="permission.manage">

Lets the user change which items this app can see when the address book is limited, without leaving the app; elsewhere it only reports the current state.

**Arguments:** none.

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.contacts.permission.manage()
```

```json Result
{
  "canAsk": false,
  "changed": false,
  "status": "granted"
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `canAsk` | boolean | True while the system can still show its permission dialog for the address book; false means only Settings can change it. |
| `changed` | boolean | True when the user changed the selection in the system picker. |
| `level`? | string | The permission level that this answer is about. |
| `status` | string | The current state of the address book: undetermined, granted, limited, denied, restricted or unavailable. |

</Accordion>

## Configuration

Set these in the package settings of your app (see [Add a package](/packages/add-a-package)).

| Setting | What it is |
| :-- | :-- |
| Contacts page size (`page_size`) | How many contacts one dsx.module.contacts.list() page returns when the caller does not pass a limit. |
| Contacts permission prompt (`usage_description`) | The message iOS shows when the app asks to read the user's contacts. Say what the app does with them, in one concrete sentence. |
| Contacts write permission prompt (`write_usage_description`) | The message iOS shows when the app asks to add or change contacts without reading the rest of the address book. |

For apps built on Despia V3, see [Migrate from Despia V3](/packages/migrate-from-v3).
