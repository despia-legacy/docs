Switches the phone's torch on or off from your app. It reports clearly when the device has no torch or another app is using the camera, and you can switch the feature off in settings. You draw your own torch button.

**When to use it.** Use it for a torch button, a scanner light or a signal. Check availability first so you can hide the button on devices with no torch.

<EnvNew />

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `flashlight` package is on the global `window.dsx`. `dsx.has('flashlight')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('flashlight')) {
  // Turns the torch on or off.
  const setResult = await dsx.module.flashlight.set({ on: true })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.flashlight.set()` | `on`: boolean | `ok`<br/>`on`<br/>`reason` | iOS, Android | Turns the torch on or off. |

## Action reference

<AccordionGroup>
<Accordion title="set">

Turns the torch on or off.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `on` | boolean | True turns the torch on and false turns it off. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.flashlight.set({ on: true })
```

```json Result
{
  "ok": true,
  "on": true,
  "reason": ""
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `ok` | boolean | True when the torch was set as asked. |
| `on` | boolean | Whether the torch is on now. |
| `reason` | string | Why nothing happened when ok is false; disabled means the app was built with the flashlight turned off. |

**Errors**

| Code | Message |
| :-- | :-- |
| `invalid_value` | Pass on: true or false. |
| `permission_denied` | Camera access was refused, and a browser can only reach the torch through the camera track. |
| `unavailable` | The torch could not be driven: another app is holding the camera. |
| `unsupported_device` | This device has no torch. |

</Accordion>
</AccordionGroup>

## Configuration

Set these in the package settings of your app (see [Add a package](/packages/add-a-package)).

| Setting | What it is |
| :-- | :-- |
| Flashlight enabled (`enabled`) | Allow the web app to toggle the device torch via dsx.module.flashlight.set(&#123; on &#125;). |

For apps built on Despia V3, see [Migrate from Despia V3](/packages/migrate-from-v3).
