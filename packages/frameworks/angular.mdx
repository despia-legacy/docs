## Where dsx code runs

Only in the browser: the client web view of your app, never during server rendering.

- With Angular SSR, lifecycle hooks also run on the server, so the component checks `isPlatformBrowser` before it touches `window`.
- Answers and broadcasts come from native code outside Angular's zone; the component updates its state in `NgZone.run`.

## Call a package and listen to a broadcast

```typescript done-button.component.ts
import { AfterViewInit, Component, NgZone, OnDestroy, PLATFORM_ID, inject, signal } from '@angular/core'
import { isPlatformBrowser } from '@angular/common'

@Component({
  selector: 'app-done-button',
  standalone: true,
  template: `@if (env() === 'v4') { <button [disabled]="busy()" (click)="done()">Done @if (error()) { ({{ error() }}) }</button> }`,
})
export class DoneButtonComponent implements AfterViewInit, OnDestroy {
  private zone = inject(NgZone)
  private isBrowser = isPlatformBrowser(inject(PLATFORM_ID))
  private off?: () => void
  env = signal<'v4' | 'web'>('web')
  busy = signal(false)
  error = signal<string | null>(null)

  ngAfterViewInit() {
    if (!this.isBrowser) return // Angular SSR: the server never touches window
    this.env.set(window.dsx ? 'v4' : 'web')
    this.off = window.dsx?.module.revenuecat.on('customerInfo', (data: unknown) => this.zone.run(() => console.log(data)))
  }

  ngOnDestroy() {
    this.off?.()
  }

  async done() {
    this.busy.set(true)
    this.error.set(null)
    try {
      await window.dsx!.module.haptic.success()
    } catch (e: any) {
      this.zone.run(() => this.error.set(e.code))
    } finally {
      this.zone.run(() => this.busy.set(false))
    }
  }
}
```

- **Environment check:** the component sets `env` in the browser only, so the server and the first browser render match.
- **Call:** `dsx.module.haptic.success()` with a busy state; a failed call rejects with an error that has a `code`.
- **Broadcast:** `dsx.module.revenuecat.on('customerInfo', ...)` returns a function that stops listening; it runs when the component goes away.

More in [How calls, results and broadcasts work](/packages/concepts).
