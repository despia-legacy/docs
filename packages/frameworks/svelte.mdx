The Modern API is the global `window.dsx`, so there is nothing to install. Copy these two helpers into your project.

## The helpers

```javascript despia.js
import { onMount } from 'svelte'

export const getDsx = () => window.dsx

// dsxCall('revenuecat', 'purchase', args): the result, or throws { code, message }
export async function dsxCall(pkg, action, args) {
  const dsx = getDsx()
  if (!dsx) throw { code: 'no_dsx' } // our own code: not in Despia V4
  const fn = action.split('.').reduce((m, key) => m[key], dsx.module[pkg])
  return fn(args)
}

// onDsxBroadcast('focus', 'change', (data) => ...), removed when the component is destroyed
export function onDsxBroadcast(pkg, name, handler) {
  onMount(() => {
    const dsx = getDsx()
    return dsx ? dsx.module[pkg].on(name, handler) : undefined
  })
}
```

## Call a package and listen to a broadcast

```svelte BuyButton.svelte
<script>
  import { onMount } from 'svelte'
  import { dsxCall, onDsxBroadcast } from './despia'

  export let userId
  let ready = false, loading = false, error = null

  onMount(() => { ready = !!window.dsx?.has('revenuecat') })
  onDsxBroadcast('focus', 'change', ({ focused }) => { if (!focused) console.log('app went to the background') })

  async function buy() {
    loading = true
    error = null
    try { await dsxCall('revenuecat', 'purchase', { external_id: userId, product: ['coins_100'] }) }
    catch (e) { error = e }
    finally { loading = false }
  }
</script>

{#if ready}
  <button disabled={loading} on:click={buy}>
    {loading ? 'Buying…' : 'Buy 100 coins'}
    {#if error}<small> ({error.code})</small>{/if}
  </button>
{/if}
```

This uses the Svelte 4 syntax, which Svelte 5 still accepts. With runes, keep the helpers as they are and hold `ready`, `loading` and `error` in `$state`.

## SvelteKit

`onMount` runs only in the browser, so the helpers are safe in SvelteKit pages and layouts. Never read `window.dsx` at the top level of a component script or in `load` functions: they also run on the server.
