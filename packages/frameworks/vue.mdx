The Modern API is the global `window.dsx`, so there is nothing to install. Copy these two composables into your project.

## The composables

```javascript useDespia.js
import { onMounted, onUnmounted, ref } from 'vue'

const getDsx = () => window.dsx

// useDsxCall('revenuecat', 'purchase') -> { call, data, error, loading }
export function useDsxCall(pkg, action) {
  const data = ref(null)
  const error = ref(null)
  const loading = ref(false)
  async function call(args) {
    const dsx = getDsx()
    if (!dsx) throw (error.value = { code: 'no_dsx' }) // our own code: not in Despia V4
    loading.value = true
    error.value = null
    try {
      const fn = action.split('.').reduce((m, key) => m[key], dsx.module[pkg])
      return (data.value = await fn(args))
    } catch (e) {
      error.value = e
      throw e
    } finally {
      loading.value = false
    }
  }
  return { call, data, error, loading }
}

// useDsxBroadcast('focus', 'change', (data) => ...), removed on unmount
export function useDsxBroadcast(pkg, name, handler) {
  let off = null
  onMounted(() => { const dsx = getDsx(); if (dsx) off = dsx.module[pkg].on(name, handler) })
  onUnmounted(() => off && off())
}
```

A failed call rejects with an object that has a `code`; `no_dsx` is the composable's own code for "not in Despia V4".

## Call a package and listen to a broadcast

```vue BuyButton.vue
<script setup>
import { onMounted, ref } from 'vue'
import { useDsxBroadcast, useDsxCall } from './useDespia'

const props = defineProps({ userId: String })
const ready = ref(false)
const { call, loading, error } = useDsxCall('revenuecat', 'purchase')
onMounted(() => { ready.value = !!window.dsx?.has('revenuecat') })
useDsxBroadcast('revenuecat', 'customerInfo', ({ customerInfo }) => console.log(customerInfo))

const buy = () => call({ external_id: props.userId, product: ['coins_100'] }).catch(() => {})
</script>

<template>
  <button v-if="ready" :disabled="loading" @click="buy">
    {{ loading ? 'Buying…' : 'Buy 100 coins' }}
    <small v-if="error"> ({{ error.code }})</small>
  </button>
</template>
```

## Nuxt

`onMounted` runs only in the browser, so these composables are safe in Nuxt pages and components. Never read `window.dsx` directly in `setup()` or in a server plugin. Wrap parts that only make sense in the app in `<ClientOnly>`.
