Plays short vibrations: light, medium and heavy taps for touches, and success, warning and error patterns for outcomes. Also supports custom patterns. Use it to make buttons and confirmations feel responsive. Needs no setup or permission.

**When to use it.** Use it for a small physical confirmation of a touch or an outcome, such as a toggle, a saved item or a failed payment. Do not buzz on every scroll frame or for things the person cannot connect to an action.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `haptic` package is on the global `window.dsx`. `dsx.has('haptic')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('haptic')) {
  // Plays a light single tap.
  const light = await dsx.module.haptic.light()

  // Plays a medium-firm single tap.
  const medium = await dsx.module.haptic.medium()

  // Plays a firm single tap.
  const heavy = await dsx.module.haptic.heavy()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.haptic.error()` | none | `ok` | iOS, Android | Plays a sharp triple tap that signals that an action failed. |
| `dsx.module.haptic.heavy()` | none | `ok` | iOS, Android | Plays a firm single tap. |
| `dsx.module.haptic.light()` | none | `ok` | iOS, Android | Plays a light single tap. |
| `dsx.module.haptic.medium()` | none | `ok` | iOS, Android | Plays a medium-firm single tap. |
| `dsx.module.haptic.pattern()` | `events`: object[] | `fallback`<br/>`ok` | iOS, Android | Plays a custom sequence of vibrations that you describe event by event. |
| `dsx.module.haptic.success()` | none | `ok` | iOS, Android | Plays an upbeat double tap that signals something finished cleanly. |
| `dsx.module.haptic.warning()` | none | `ok` | iOS, Android | Plays two heavy taps that signal a problem the person can recover from. |

<Accordion title="pattern">

Plays a custom sequence of vibrations that you describe event by event.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `events` | object[] | The vibrations to play in order, each with an optional delay, duration, intensity from 0 to 1 and sharpness from 0 to 1. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.haptic.pattern({ events: [{"duration": 0.2, "intensity": 1, "sharpness": 0.5}] })
```

```json Result
{
  "ok": true
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `fallback`? | "impact" \\| "pattern" \\| "none" | Set when the device could not play the full pattern: impact means a series of simple taps was used, none means the device cannot vibrate. |
| `ok` | boolean | True once the pattern was requested. |

</Accordion>
