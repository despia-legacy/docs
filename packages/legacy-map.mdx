Despia version 4 keeps V3 apps working: the Legacy polyfill answers the old `despia('scheme://...')` calls (from the `despia-native` npm package or a raw URL scheme) and runs the modern package call for you. This table is generated from the polyfill's own map, so it lists exactly what is answered.

<Warning>Removed in 0.1.0: `inapppurchase://` and `inappsubscription://` are no longer answered. Use [RevenueCat](/packages/revenuecat) (`dsx.module.revenuecat.purchase`). Still answered: `getpurchasehistory://`, `restoreinapppurchases://`, `revenuecat://` and `cancelinapppurchase://`.</Warning>

Rows marked *Legacy polyfill* have no one-to-one modern call: the polyfill keeps the V3 behaviour through its own compatibility module.
