<Info>Requires Despia version 4 or greater and the CLI `@despia-native/cli`.</Info>

`despia mcp` serves the Despia CLI to a coding agent as an MCP server. The agent gets the same commands you run in the terminal, as tools named `despia_<command>`, and works on the project in the current folder. It talks over stdin and stdout, so the client starts it for you.

## Connect it

Add the server to your client's MCP configuration. For Claude Code, put this in `.mcp.json` at the root of your project:

```json .mcp.json
{
  "mcpServers": {
    "despia": { "command": "npx", "args": ["despia", "mcp"] }
  }
}
```

Other clients (Cursor, Windsurf, VS Code and so on) use the same command, `npx despia mcp`, in their own MCP settings. To point it at a project in another folder, add `--dir <folder>` to the arguments.

To see every tool the server offers:

```bash
npx despia mcp --list
```

## The tools you will use most

| Tool | What it does |
| :-- | :-- |
| `despia_search` | Finds a package in the built-in index. |
| `despia_add` | Adds a package to the project (`plan: true` previews it and writes nothing). |
| `despia_remove` | Removes a package. |
| `despia_packages` | Lists the packages in the project. |
| `despia_docs` | Shows a package's documentation. |
| `despia_doctor` | Checks the project for mistakes that would make a build fail later. |
| `despia_lint` | Validates the project. |
| `despia_build` | Builds the project. |
| `despia_describe` | Describes the project's structure, so the agent edits it at exact addresses. |
| `despia_builds` | Shows your builds. |

There are about 90 tools in total, one per CLI command. `npx despia --help` describes each command.

## Example prompts

> Which Despia packages do I need for subscriptions with a paywall? Search, then show me the plan before adding anything.

> Add haptics and the share sheet to this app.

> List the packages in this app and tell me which ones need settings, such as an API key.

> Run the doctor on this project and fix what it finds.

> My web app calls `despia('lighthaptic://')`. Show me the Modern API call for each `despia(...)` call in `src/`.

## Safety

- **Plan first.** Commands that change something can preview the change (`plan`) before they write. Ask the agent to show the plan, then let it apply.
- **Nothing leaves your project without you.** Over MCP, anything that acts outside your project is refused: applying a change to an external service, account commands, and accepting an unreviewed community package (`add` with `yes`). The refusal hands back the exact command, so you can run it yourself in the terminal.
- **The agent works on the folder it was started in**, or the one you pass with `--dir`.
