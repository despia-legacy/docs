A complete video player for your app: the picture, touch controls that hide themselves, a seek bar with chapters, speed, quality, audio and subtitle choices, Picture in Picture and offline copies. You can put the player inside a screen like any other element, or open it full screen with one call. You write the video addresses, titles and the screens around the player.

**When to use it.** Use it whenever the app plays a video or a streamed playlist, inline in a card or full screen. For plain audio, use the audio package instead.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `player` package is on the global `window.dsx`. `dsx.has('player')` is true when the package is in your app's build:

```javascript
if (window.dsx && window.dsx.has('player')) {
  // Opens the player full screen over the app and plays a video file or HLS playlist.
  const play = await window.dsx.module.player.play({ url: "https://cdn.example.com/clip.m3u8" })

  // Stops a download that is running and forgets it.
  const cancelDownload = await window.dsx.module.player.cancelDownload({ id: "a" })

  // Closes the full screen player if it is open; it is safe to call when nothing is playing.
  const closeResult = await window.dsx.module.player.close()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.player.cancelDownload()` | `id`: string | `cancelled` | iOS, Android | Stops a download that is running and forgets it. |
| `dsx.module.player.close()` | none | `closed` | iOS, Android | Closes the full screen player if it is open; it is safe to call when nothing is playing. |
| `dsx.module.player.download()` | `id`?: string<br/>`meta`?: object<br/>`poster`?: string<br/>`title`?: string<br/>`url`: string | `id`<br/>`state` | iOS, Android | Starts keeping a copy of a video on the device for offline viewing and answers at once with its state. |
| `dsx.module.player.play()` | `artist`?: string<br/>`autoplay`?: boolean<br/>`chapters`?: object[]<br/>`gravity`?: string<br/>`id`?: string<br/>`loop`?: boolean<br/>`muted`?: boolean<br/>`pip`?: boolean<br/>`poster`?: string<br/>`skipStep`?: number<br/>`speed`?: number<br/>`speeds`?: number[]<br/>`start`?: number<br/>`title`?: string<br/>`url`: string | `pictureInPicture`<br/>`playing`<br/>`url` | iOS, Android | Opens the player full screen over the app and plays a video file or HLS playlist. |
| `dsx.module.player.removeDownload()` | `id`: string | `removed` | iOS, Android | Deletes a saved video and its files from the device, whether it is still downloading or finished. |

## Coming from the Legacy API

Older apps call these through `despia-native` or a URL scheme. They keep working on Despia V4 through the Legacy polyfill. New code should use the modern call.

| Legacy (`despia('...')`) | Modern |
| :-- | :-- |
| `startnativevideo://` | `dsx.module.player.play()` |
