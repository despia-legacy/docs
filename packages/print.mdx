<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.0.2), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

Presents the system print sheet for a file in your app or for a web address it downloads first, and tells you whether printing went ahead. The person picks the printer and options in the system sheet. You supply the document and a job name.

**When to use it.** Use it for receipts, tickets, reports and other documents the person may want on paper. For sharing a file rather than printing it, use the share sheet.

<EnvNew />

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `print` package is on the global `window.dsx`. `dsx.has('print')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('print')) {
  // Shows the system print sheet for a document, which is a file in your app or one downloaded from a web address.
  const document = await dsx.module.print.document()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.print.document()` | `jobName`?: string<br/>`path`?: string<br/>`url`?: string | `completed`<br/>`fallback` | iOS, Android | Shows the system print sheet for a document, which is a file in your app or one downloaded from a web address. |

## Action reference

<AccordionGroup>
<Accordion title="document">

Shows the system print sheet for a document, which is a file in your app or one downloaded from a web address.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `jobName`? | string | The name shown for the job in the print queue. |
| `path`? | string | A Files path of the document to print, such as cache:invoice.pdf or documents:report.pdf. Give either path or url. |
| `url`? | string | A web address to download the document from before printing. |

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `completed` | boolean | True when printing went ahead; false when the person cancelled the print sheet. |
| `fallback`? | "unknown" | On the web only, unknown means the browser cannot tell a cancel from a print, so completed only says the dialog closed. |

**Errors**

| Code | Message |
| :-- | :-- |
| `cannot_print` | This document can't be printed, the system found no printable representation for it. |
| `download_failed` | Couldn't download the document to print. |
| `missing_param` | Pass the document as `path` (a Core/Files path) or `url`. |
| `no_presenter` | Couldn't find an active screen to present the print sheet from. |
| `not_found` | There is no file at that path. |
| `print_failed` | The print job couldn't be completed. |
| `write_failed` | Couldn't save the document for printing. |

</Accordion>
</AccordionGroup>
