<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.1.0), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

Presents the system print sheet for a file in your app or for a web address it downloads first, and tells you whether printing went ahead. The person picks the printer and options in the system sheet. You supply the document and a job name.

**When to use it.** Use it for receipts, tickets, reports and other documents the person may want on paper. For sharing a file rather than printing it, use the share sheet.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `print` package is on the global `window.dsx`. `dsx.has('print')` is true when the package is in your app's build:

```javascript
const dsx = typeof window !== 'undefined' ? window.dsx : undefined
if (dsx && dsx.has('print')) {
  // Shows the system print sheet for a document, which is a file in your app or one downloaded from a web address.
  const document = await dsx.module.print.document()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.print.document()` | `jobName`?: string<br/>`path`?: string<br/>`url`?: string | `completed`<br/>`fallback` | iOS, Android | Shows the system print sheet for a document, which is a file in your app or one downloaded from a web address. |

## Coming from the Legacy API

Older apps call these through `despia-native` or a URL scheme. They keep working on Despia V4 through the Legacy polyfill. New code should use the modern call.

| Legacy (`despia('...')`) | Modern |
| :-- | :-- |
| `printitem://` | `dsx.module.print.document()` |
