<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.1.0), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

Adds the familiar pull-down-to-refresh control to the web page your app shows, with a spinner whose colours you can set for light and dark. It reloads the page, and you can also start a refresh from code. Screens built with DSX use the native refreshable element instead.

**When to use it.** Reach for it when your app shows a web page and people expect to pull down to refresh it. For native DSX screens use the refreshable element instead.

<EnvNew />

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `pulltorefresh` package is on the global `window.dsx` and is built into every app:

```javascript
// built into every Despia V4 app
const dsx = window.dsx
if (dsx) {
  // Turns the pull-to-refresh control on or off and sets its spinner and background colours. Anything you leave out stays as it was.
  const setResult = await dsx.module.pulltorefresh.set({ enabled: true })

  // Starts a refresh from code, as if the person had pulled down. It shows the spinner, reloads the page and finishes when the reloaded page is ready or after 10 seconds.
  const refresh = await dsx.module.pulltorefresh.refresh()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.pulltorefresh.refresh()` | none | `refreshed` | iOS, Android | Starts a refresh from code, as if the person had pulled down. It shows the spinner, reloads the page and finishes when the reloaded page is ready or after 10 seconds. |
| `dsx.module.pulltorefresh.set()` | `background`?: string<br/>`enabled`?: boolean<br/>`tint`?: string | `enabled` | iOS, Android | Turns the pull-to-refresh control on or off and sets its spinner and background colours. Anything you leave out stays as it was. |
