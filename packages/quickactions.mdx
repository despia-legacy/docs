<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.1.0), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

Lets you set the shortcuts that appear when someone presses and holds your app icon, each with a title, an icon and a value. When one is chosen the app opens and your code is told which value was picked, whether the app was closed or already running. You choose the items and decide what each one does.

**When to use it.** Use it to give quick routes into your app, such as New message or Scan, from the Home screen icon. The shortcuts are shown by the system, so keep them few and short.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `quickactions` package is on the global `window.dsx`. `dsx.has('quickactions')` is true when the package is in your app's build:

```javascript
if (window.dsx && window.dsx.has('quickactions')) {
  // Removes all the shortcuts from the app icon's menu.
  const clear = await window.dsx.module.quickactions.clear()

  // Reads the shortcuts that are currently set, including the ones kept from an earlier launch.
  const getResult = await window.dsx.module.quickactions.get()

  // Sets the shortcuts shown when the app icon is long pressed, replacing the ones set before.
  const setResult = await window.dsx.module.quickactions.set({ items: [{"symbol": "magnifyingglass", "title": "Search", "value": "search"}] })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.quickactions.clear()` | none | `ok` | iOS, Android | Removes all the shortcuts from the app icon's menu. |
| `dsx.module.quickactions.get()` | none | `count`<br/>`items` | iOS, Android | Reads the shortcuts that are currently set, including the ones kept from an earlier launch. |
| `dsx.module.quickactions.set()` | `items`?: object[] | `count` | iOS, Android | Sets the shortcuts shown when the app icon is long pressed, replacing the ones set before. |

## Events

Subscribe with `window.dsx.module.quickactions.on('<event>', (data) => { ... })`. It returns a function that unsubscribes.

| Event | When it fires |
| :-- | :-- |
| `tap` | Fires when the person chooses one of your shortcuts, including when it launched the app. |
