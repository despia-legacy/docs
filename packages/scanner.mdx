Opens the phone's own scanner to read a QR code or barcode, or to scan a paper document into pages with the text read off them. It also gives you a scanner preview you can place inside your own layout. QR and barcode scanning stay free.

**When to use it.** Reach for it when people need to scan a QR code, a barcode or a paper document. If you want your own camera screen with scanning on top, use the scanner preview in your layout instead.

<EnvNew />

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `scanner` package is on the global `window.dsx`. `dsx.has('scanner')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('scanner')) {
  // Opens the system scanner for a code or a document and resolves with what was read. Backing out resolves as cancelled.
  const scan = await dsx.module.scanner.scan({ for: "code", formats: ["qr"] })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Action reference

<AccordionGroup>
<Accordion title="scan">

Opens the system scanner for a code or a document and resolves with what was read. Backing out resolves as cancelled.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `facing`? | string | On the web code sheet only, which camera to use: back, the default, or front. |
| `for` | string | What to scan, either code or document. |
| `formats`? | string[] | For codes only, the code types to read. Left out, QR, EAN-8 and EAN-13 are read on the phone, and everything the reader knows on the web. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.scanner.scan({ for: "code", formats: ["qr"] })
```

```json Result
{
  "format": "qr",
  "value": "https://despia.com"
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `cancelled`? | boolean | True when the person backed out without scanning. |
| `format`? | string | For a code, the type of code that was read, such as qr. |
| `pages`? | object[] | For a document, the scanned pages, each with a file path and the text read from it. |
| `result`? | string | The older name for value, kept so existing pages still work. |
| `type`? | string | The older name for format, kept so existing pages still work. |
| `value`? | string | For a code, the text the code contains. |

**Errors**

| Code | Message |
| :-- | :-- |
| `busy` | The camera is held by another owner. |
| `camera_unavailable` | No usable camera is available on this device. |
| `invalid_param` | `for` is `code` or `document`. |
| `no_presenter` | Couldn't find a screen to present the scanner from. |
| `permission_denied` | Camera access was denied. Enable it in Settings to scan. |
| `scan_in_progress` | A scan is already in progress. |
| `scanner_failed` | The scanner could not finish. |
| `scanner_unsupported` | This device has no document scanner. |
| `unsupported_platform` | This browser has no barcode detector and the bundled decoder did not load. |

## Configuration

Set these in the package settings of your app (see [Add a package](/packages/add-a-package)).

| Setting | What it is |
| :-- | :-- |
| Permission prompt (`usage_description`) | The message shown when iOS asks the user for camera access to scan a code or a document. |
