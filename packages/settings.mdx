<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.1.0), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

Sends the user to this app's page in the Settings app, or to a deeper page such as notifications, so they can switch back on a permission they denied earlier. The phone will not show the system prompt a second time, so this is the way back. It does not wait for the user to return. You write the button and the explanation around it.

**When to use it.** Use it from a button the user taps after a permission was denied, such as notifications or location. Do not call it automatically, and note that it cannot change a setting for the user.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `settings` package is on the global `window.dsx`. `dsx.has('settings')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('settings')) {
  // Opens this app's notification settings page, which needs iOS 15.4 or later on iPhone.
  const notifications = await dsx.module.settings.notifications()

  // Opens this app's own page in the system Settings, where the user can change its permissions.
  const app = await dsx.module.settings.app()

  // On Android, asks the system to let the app ignore battery optimization; on iOS it fails with unsupported_platform.
  const battery = await dsx.module.settings.battery()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.settings.app()` | none | `ok` | iOS, Android | Opens this app's own page in the system Settings, where the user can change its permissions. |
| `dsx.module.settings.battery()` | none | `ok` | iOS, Android | On Android, asks the system to let the app ignore battery optimization; on iOS it fails with unsupported_platform. |
| `dsx.module.settings.bluetooth()` | none | `ok` | iOS, Android | Opens the Bluetooth settings on Android; on iOS it fails with unsupported_platform because Apple allows no such link. |
| `dsx.module.settings.defaults()` | none | `ok` | iOS, Android | Opens the system default apps page, which needs iOS 18.2 or later on iPhone. |
| `dsx.module.settings.locale()` | none | `ok` | iOS, Android | Opens the Android per-app language settings on Android 13 and later; on iOS it fails with unsupported_platform. |
| `dsx.module.settings.location()` | none | `ok` | iOS, Android | Opens the location settings on Android; on iOS it fails with unsupported_platform because Apple allows no such link. |
| `dsx.module.settings.notifications()` | none | `ok` | iOS, Android | Opens this app's notification settings page, which needs iOS 15.4 or later on iPhone. |
| `dsx.module.settings.overlay()` | none | `ok` | iOS, Android | Opens the Android page where the user allows drawing over other apps; on iOS it fails with unsupported_platform. |
| `dsx.module.settings.wifi()` | none | `ok` | iOS, Android | Opens the Wi-Fi settings on Android; on iOS it fails with unsupported_platform because Apple allows no such link. |
