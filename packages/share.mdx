<Info>Modern API. Requires Despia V4 or greater. Despia V4 is currently a pre-release (0.1.0), stable for web view apps. Check for it first, see [Detect Despia V4](/packages/overview#detect-despia-v4).</Info>

Opens the native share sheet so users can send to Messages, Mail, WhatsApp, AirDrop, Files or copy to the clipboard. You can share a message, a link and attachments from your app's files together. No account or keys needed.

**When to use it.** Reach for it when the user wants to send something out of your app, such as a link, a message or a file, through whichever app they choose. It does not post to a specific network for you.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `share` package is on the global `window.dsx`. `dsx.has('share')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('share')) {
  // Opens the system share sheet with a message, a link and files, and resolves when the user shares or closes it.
  const url = await dsx.module.share.url({ message: "Check out this listing", url: "https://example.com/listings/cozy-loft" })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).
