Adds the browser SpeechRecognition API to your web pages inside the app, because the iOS and Android web views do not have it, and also offers a simple start, stop and abort call. It listens through the microphone, streams interim and final transcripts, and asks for speech and microphone permission the first time. You write the page that shows the text.

**When to use it.** Use it for dictation, voice search or voice commands in a web page. Code written for the standard speech recognition API keeps working without changes.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `speechrecognition` package is on the global `window.dsx`. `dsx.has('speechrecognition')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('speechrecognition')) {
  // Starts listening and streams what the user says as results, asking for speech and microphone permission first if needed.
  const startResultSub = dsx.module.speechrecognition.start({ continuous: false, interim: true, language: "en-US", max: 1 }, (event) => {
    console.log(event.event, event.data)
  })
  // later: startResultSub.stop()

  // Stops listening and lets the recognizer finish the words it already heard; it is safe to call when nothing is running.
  const stopResult = await dsx.module.speechrecognition.stop()

  // Stops listening and throws away what was heard; it is safe to call when nothing is running.
  const abort = await dsx.module.speechrecognition.abort()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.speechrecognition.abort()` | none | `ok` | iOS, Android | Stops listening and throws away what was heard; it is safe to call when nothing is running. |
| `dsx.module.speechrecognition.permission.manage()` | none | `canAsk`<br/>`changed`<br/>`level`<br/>`status` | iOS, Android | Lets the user change which items this app can see when speech recognition and the microphone is limited, without leaving the app; elsewhere it only reports the current state. |
| `dsx.module.speechrecognition.permission.openSettings()` | none | `opened` | iOS, Android | Opens this app's page in the system Settings so the user can change a denied permission. |
| `dsx.module.speechrecognition.permission.request()` | none | `canAsk`<br/>`level`<br/>`status` | iOS, Android | Asks for speech recognition and the microphone with the system dialog, for a settings row or an onboarding step; the dialog only appears while the system still allows it. |
| `dsx.module.speechrecognition.permission.status()` | none | `canAsk`<br/>`level`<br/>`status` | iOS, Android | Reads the current state of speech recognition and the microphone without ever showing a dialog, so a settings screen can call it every time it appears. |
| `dsx.module.speechrecognition.polyfill()` | `action`: string<br/>`config`?: object<br/>`recognizerId`: string |  | iOS, Android | The internal route the SpeechRecognition polyfill uses to talk to the phone; you do not call it by hand. |
| `dsx.module.speechrecognition.start()` | `continuous`?: boolean<br/>`interim`?: boolean<br/>`language`?: string<br/>`max`?: number | stream (sends `start`, `result`) | iOS, Android | Starts listening and streams what the user says as results, asking for speech and microphone permission first if needed. |
| `dsx.module.speechrecognition.stop()` | none | `ok` | iOS, Android | Stops listening and lets the recognizer finish the words it already heard; it is safe to call when nothing is running. |

## Action reference

<AccordionGroup>
<Accordion title="abort">

Stops listening and throws away what was heard; it is safe to call when nothing is running.

**Arguments:** none.

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.speechrecognition.abort()
```

```json Result
{
  "ok": true
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `ok` | boolean | True when the recognizer is stopped. |

</Accordion>
<Accordion title="permission.manage">

Lets the user change which items this app can see when speech recognition and the microphone is limited, without leaving the app; elsewhere it only reports the current state.

**Arguments:** none.

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.speechrecognition.permission.manage()
```

```json Result
{
  "canAsk": false,
  "changed": false,
  "status": "granted"
}
```

**Result**

| Field | Type | Description |
| :-- | :-- | :-- |
| `canAsk` | boolean | True while the system can still show its permission dialog for speech recognition and the microphone; false means only Settings can change it. |
| `changed` | boolean | True when the user changed the selection in the system picker. |
| `level`? | string | Not used here; this permission has no separate levels, so it is normally empty. |
| `status` | string | The current state of speech recognition and the microphone: undetermined, granted, limited, denied, restricted or unavailable. |

</Accordion>

**Arguments**

## Broadcasts

Listen with `window.dsx.module.speechrecognition.on('<broadcast>', (data) => { ... })`. It returns a function that stops listening.

| Broadcast | When it fires |
| :-- | :-- |
| `polyfill` | Carries the standard web speech events to the polyfill on the page; you should not read it by hand. |
| `result` | The recognizer heard something and has a best transcript with its alternatives. |
| `start` | The recognizer has started listening. |
