Lists the voices installed on the device, speaks text with a chosen voice, speed, pitch and volume, and reports progress word by word. It can also render speech into audio files that your app keeps. You write the text and decide when to speak or stop.

**When to use it.** Use it to read content aloud, give spoken feedback or make audio from text. For recorded or streamed audio, use the audio packages instead.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `speechsynthesis` package is on the global `window.dsx`. `dsx.has('speechsynthesis')` is true when the package is in your app's build:

```javascript
if (window.dsx && window.dsx.has('speechsynthesis')) {
  // Speaks one piece of text, or saves the speech to a file. Progress arrives as events while it speaks.
  const startResultSub = window.dsx.module.speechsynthesis.start({ speed: 1, text: "Hello there" }, (event) => {
    console.log(event.event, event.data)
  })
  // later: startResultSub.stop()

  // Stops a speech session, or the one currently playing if you give no id. Stopping one that already ended is fine.
  const stopResult = await window.dsx.module.speechsynthesis.stop({ id: "utterance-1" })

  // Turns text into audio files that your app owns and does not play aloud. Each finished piece arrives as a chunk event, and the result gives the final file.
  const renderSub = window.dsx.module.speechsynthesis.render({ text: "Hello there", to: "documents:take.wav" }, (event) => {
    console.log(event.event, event.data)
  })
  // later: renderSub.stop()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.speechsynthesis.render()` | `id`?: string<br/>`language`?: string<br/>`pitch`?: number<br/>`rate`?: number<br/>`text`: string<br/>`to`?: string<br/>`voice`?: string | stream (events: `queued`, `chunk`, `end`, `cancel`) | iOS, Android | Turns text into audio files that your app owns and does not play aloud. Each finished piece arrives as a chunk event, and the result gives the final file. |
| `dsx.module.speechsynthesis.start()` | `id`?: string<br/>`lang`?: string<br/>`output`?: "stream" \\| "file"<br/>`pitch`?: number<br/>`speed`?: number<br/>`text`: string<br/>`voice`?: string<br/>`volume`?: number | stream (events: `queued`, `start`, `boundary`, `pause`, `resume`, `end`, `cancel`, `file`) | iOS, Android | Speaks one piece of text, or saves the speech to a file. Progress arrives as events while it speaks. |
| `dsx.module.speechsynthesis.stop()` | `id`?: string | `id`<br/>`ok` | iOS, Android | Stops a speech session, or the one currently playing if you give no id. Stopping one that already ended is fine. |
| `dsx.module.speechsynthesis.voices()` | `gender`?: string | `voices` | iOS, Android | Lists the voices installed on the device, with their language and quality. You can filter them by gender, which is guessed from the voice name on Android and the web. |

## Events

Subscribe with `window.dsx.module.speechsynthesis.on('<event>', (data) => { ... })`. It returns a function that unsubscribes.

| Event | When it fires |
| :-- | :-- |
| `boundary` | A word is about to be spoken, so you can highlight it. |
| `cancel` | The session was stopped before it finished. |
| `chunk` | One piece of a render was written to a file. |
| `end` | The session finished: the speech reached the end or the file job completed. |
| `file` | A speech job that saves to a file has written its audio. |
| `pause` | The stream paused, on iOS and the web. |
| `queued` | A speech or render session was accepted, before any audio starts. |
| `resume` | The stream continued after a pause, on iOS and the web. |
| `start` | The stream has begun speaking the text aloud. |

## Coming from the Legacy API

Older apps call these through `despia-native` or a URL scheme. They keep working on Despia V4 through the Legacy polyfill. New code should use the modern call.

| Legacy (`despia('...')`) | Modern |
| :-- | :-- |
| `speechsynthesis://start` | `dsx.module.speechsynthesis.start()` |
| `speechsynthesis://stop` | `dsx.module.speechsynthesis.stop()` |
