Sets the colour, icon style and visibility of the status bar and the navigation bar, and switches fullscreen modes for video or immersive content. Unstated fields keep their value, so each screen changes only what it needs. You write the colours and when each screen applies them.

**When to use it.** Use it when a screen needs its own bar colours, hidden bars or a fullscreen video mode. Leave it alone if the default bar look already suits the app.

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `systembars` package is on the global `window.dsx`. `dsx.has('systembars')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('systembars')) {
  // Changes the status bar, the navigation bar or the fullscreen mode. Anything you leave out keeps its current value.
  const setResult = await dsx.module.systembars.set({ status: {"background": "#1A1A2E"} })

  // Reports the page's top colour and background change so the bar can follow the page. The package calls it for you, not your code.
  const body = await dsx.module.systembars.body({ color: "#FFFFFF", duration: 300, easing: "ease-in-out", style: "solid" })

  // Reports whether the page can read the safe-area values on its own. The package calls it for you, not your code.
  const env = await dsx.module.systembars.env({ native: true })
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Configuration

Set these in the package settings of your app (see [Add a package](/packages/add-a-package)).

| Setting | What it is |
| :-- | :-- |
| Bottombar (`bottombar`) | Show the home-bar safe-area filler (home-indicator devices, no home button). |
| Bottom bar background (`bottombar_background_color`) | Bottom bar background color in light mode (#RRGGBB or #RRGGBBAA). |
| Bottom bar background (dark) (`dark_mode_bottombar_background_color`) | Bottom bar background color in dark mode (#RRGGBB or #RRGGBBAA). |
| Status bar background (dark) (`dark_mode_status_bar_background_color`) | Status bar background color in dark mode (#RRGGBB or #RRGGBBAA). |
| Status bar background (`status_bar_background_color`) | Status bar background color in light mode (#RRGGBB or #RRGGBBAA). |
