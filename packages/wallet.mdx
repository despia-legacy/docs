Downloads a pass file from a web address and shows the system sheet to add it to Apple Wallet on iOS. On Android and the web it hands the pass to the system or browser handler. You host the pass file yourself. Only iOS tells you when the sheet closes.

**When to use it.** Use it to offer an Add to Wallet button for a ticket, coupon, loyalty card or boarding pass you already generate as a pass file. It does not create passes.

<EnvNew />

## Call it from JavaScript

No npm package is needed. Inside a Despia V4 app, the `wallet` package is on the global `window.dsx`. `dsx.has('wallet')` is true when the package is in your app's build:

```javascript
const dsx = window.dsx
if (dsx && dsx.has('wallet')) {
  // Gets a .pkpass file from a web address and hands it to the system so the person can add it to Wallet. On iOS the Apple add-pass sheet is shown.
  const pkpassSub = dsx.module.wallet.pkpass({ url: "https://example.com/boarding.pkpass" }, (event) => {
    console.log(event.event, event.data)
  })
  // later: pkpassSub.stop()
}
```

Calls that return something give you a promise; calls that stream take a handler as the second argument and return an object with `stop()`. Errors reject with an object that carries a `code`. See [Calling convention](/packages/overview#calling-convention).

## Actions

| Call | Arguments | Returns | Platforms | What it does |
| :-- | :-- | :-- | :-- | :-- |
| `dsx.module.wallet.pkpass()` | `url`: string | stream (sends `presented`) | iOS, Android | Gets a .pkpass file from a web address and hands it to the system so the person can add it to Wallet. On iOS the Apple add-pass sheet is shown. |

## Action reference

<AccordionGroup>
<Accordion title="pkpass">

Gets a .pkpass file from a web address and hands it to the system so the person can add it to Wallet. On iOS the Apple add-pass sheet is shown.

**Arguments**

| Field | Type | Description |
| :-- | :-- | :-- |
| `url` | string | The http or https address of the .pkpass file to add. |

**Example** (from the package's own test)

```javascript
const result = await window.dsx.module.wallet.pkpass({ url: "https://example.com/boarding.pkpass" })
```

```json Result
{
  "action": "pkpass",
  "status": "dismissed"
}
```

**Result:** a stream. Pass a handler as the second argument; it receives each update.

**Errors**

| Code | Message |
| :-- | :-- |
| `cannot_add_passes` | This device cannot add passes to Apple Wallet. |
| `download_failed` | The pass couldn't be downloaded. |
| `invalid_pass` | The downloaded file is not a readable .pkpass. |
| `invalid_url` | The pass URL isn't valid. |
| `missing_or_invalid_url` | pkpass needs an http(s) url pointing at a .pkpass file. |
| `no_presenter` | Couldn't find a screen to present the pass from. |

## Broadcasts

Listen with `window.dsx.module.wallet.on('<broadcast>', (data) => { ... })`. It returns a function that stops listening.

| Broadcast | When it fires |
| :-- | :-- |
| `presented` | Fires when the system pass handler is on screen, with the same details as the call result. |

## What you need on your side

- Your server produces signed `.pkpass` files (Apple Wallet passes are signed with your own Pass Type ID certificate); `wallet.pkpass({ url })` downloads one from your address.

Despia never hosts your app, your backend or your users' content: the accounts and servers above are your own.

For apps built on Despia V3, see [Migrate from Despia V3](/packages/migrate-from-v3).
