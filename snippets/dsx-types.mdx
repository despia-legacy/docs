Despia V4 has no package to install, so declare the global once and your editor autocompletes it. This block describes the members of `window.dsx` in 0.0.2; later releases add members.

```typescript despia-dsx.d.ts
// The window.dsx surface of Despia V4 (pre-release 0.0.2)
export interface DsxEnvelope {
  event?: string          // the broadcast's name, or 'error' when a stream update failed
  data?: unknown          // its payload
  scheme?: string         // the package that sent it
  final?: boolean
  code?: string           // set on errors
  message?: string
  recoverable?: boolean
}

export interface DsxSurface {
  // dsx.module.<package>.<action>(args) returns a promise; with a handler as the
  // second argument it streams and returns { id, stop() }.
  // dsx.module.<package>.on('<broadcast>', (data) => {}) returns a function that stops listening.
  module: any
  has(nameOrScheme: string): boolean
  version(nameOrScheme: string): string | null
  wasExcluded(nameOrScheme: string): boolean
  packages: Array<{ name: string; version?: string; scheme?: string }>
  on(scheme: string, handler: (envelope: DsxEnvelope) => void): () => void
}

declare global {
  interface Window {
    dsx?: DsxSurface
  }
}
```

`module` is typed `any` on purpose: every package adds its own actions. To type a call, write its result from the package page. For example, from [Device](/packages/device) `info`:

```typescript
interface DeviceInfo {
  deviceType: string
  osName: string
  osVersion: string
  brand?: string
  manufacturer?: string
  model?: string
}

async function deviceInfo(): Promise<DeviceInfo> {
  return window.dsx!.module.device.info()
}
```
