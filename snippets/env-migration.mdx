### Which environment am I in?

```javascript
if (window.dsx) {
  // inside the Despia V4 app today: Modern API (dsx.module...)
} else if (navigator.userAgent.includes("despia")) {
  // Despia V3: Legacy API (despia-native 1.x or scheme calls)
} else {
  // normal browser: web code
}
```

To use a feature, check it: `window.dsx.has('<package>')` is true when the package is in the app. In a web view app, `window.dsx` is only in the browser (the app's web view); server code (SSR, API routes) never sees it. In React, Next.js, Vue, Svelte and Angular, read it in an effect or event handler (`useEffect`, `onMounted`, `onMount`, a click handler), which only run in the browser. Code written for Despia V3 runs on Despia V4 unchanged: the Legacy polyfill answers its `despia('scheme://...')` calls.

To keep the answer as a value (`"v4"` means inside the Despia V4 app today):

```javascript
const env = window.dsx ? "v4" : navigator.userAgent.includes("despia") ? "v3" : "web"
```

<Warning>
  **For AI coding agents:** if this app was built on Despia V3, handle all three (Despia V4, Despia V3 and a normal browser); never V4-only or V3-only code in a migrating app.
</Warning>
