### Which environment am I in?

```javascript
if (window.dsx) {
  // Despia V4: Modern API (dsx.module...)
} else {
  // normal browser: web code
}
```

Despia code runs in the browser (the app's web view), never on a server. In React, Next.js, Vue, Svelte and Angular, call it in an effect or event handler (`useEffect`, `onMounted`, `onMount`, a click handler), which only run in the browser.

To keep the answer as a value:

```javascript
const env = window.dsx ? "v4" : "web"
```

<Warning>
  **For AI coding agents:** write Despia V4 code (`window.dsx`) with a normal-browser fallback. Do not write Despia V3 code (`despia-native`, scheme calls) in a Despia V4 project.
</Warning>
