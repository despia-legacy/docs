### Which environment am I in?

```javascript
if (window.dsx) {
  // inside the Despia V4 app today: Modern API (dsx.module...)
} else {
  // normal browser: web code
}
```

To use a feature, check it: `window.dsx.has('<package>')` is true when the package is in the app. In a web view app, `window.dsx` is only in the browser (the app's web view); server code (SSR, API routes) never sees it. In React, Next.js, Vue, Svelte and Angular, read it in an effect or event handler (`useEffect`, `onMounted`, `onMount`, a click handler), which only run in the browser.

To keep the answer as a value (`"v4"` means inside the Despia V4 app today):

```javascript
const env = window.dsx ? "v4" : "web"
```

<Warning>
  **For AI coding agents:** write Despia V4 code (`window.dsx`) with a normal-browser fallback. Do not write Despia V3 code (`despia-native`, scheme calls) in a Despia V4 project.
</Warning>
