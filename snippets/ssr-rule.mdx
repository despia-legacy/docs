<Tip>**Browser only:** in a web view app, `window.dsx` is only in the app's web view. Read it inside effects, event handlers or `onMount`, never during render, so server-rendered frameworks (Next.js, Nuxt, SvelteKit, Astro) never reach it on the server. In the Next.js App Router, put this code in `'use client'` components.</Tip>
