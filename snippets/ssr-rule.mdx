<Tip>**Browser only:** Despia code runs in the app's web view, never on a server. Read `window.dsx` inside effects, event handlers or `onMount`, never during render, so server-rendered frameworks (Next.js, Nuxt, SvelteKit, Astro) never reach it on the server. In the Next.js App Router, put Despia code in `'use client'` components.</Tip>
